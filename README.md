# VizTell

当前仓库用于持续沉淀可复用的视觉表达、软件、AI 与经营方法资产。

## 当前文档

- [通用链路宇宙](docs/通用链路宇宙/00_总览与核心结论.md)：覆盖生活、工作、OPC、公司、软件 IT 与 AI 原生场景的通用生命周期、基础链路库和领域装配体系。
- [术语与编号索引](docs/通用链路宇宙/12_术语、边界与编号索引.md)：快速区分相邻概念，并按稳定编号定位三十条核心基础链。
- [场景验证与覆盖矩阵](docs/通用链路宇宙/13_场景验证与覆盖矩阵.md)：用七个高相关场景验证正常、失败、异常和退出路径。
- [L4 工作流装配方法](docs/通用链路宇宙/14_工作流装配方法.md)：提供轻量、标准和严格三档装配规则与可复制模板。
- [优化路线与遗漏清单](docs/通用链路宇宙/11_优化路线与遗漏清单.md)：记录下一阶段的真正缺口、优先级、验证方式和收敛条件。
- [持续优化母提示词](docs/通用链路宇宙/90_持续优化母提示词.md)：连接本仓库后可直接用于下一轮多轮审计、修改、验证和提交。

后续内容以独立目录维护，重要结论和导航统一放在每个目录的 `00_` 文件顶部。

运行结构校验：`python3 scripts/validate_chain_universe.py`。
