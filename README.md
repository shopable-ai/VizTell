# VizTell

当前仓库用于持续沉淀可复用的视觉表达、软件、AI 与经营方法资产。

## 全局研究入口（R2）

从全局地图选择有价值的问题，再进入一个节点的有界研究；候选登记、证据成立与行动权限分开。

| 入口 | 唯一职责 |
| --- | --- |
| [全局地图与既有资产](docs/00_知识宇宙目录与跨域关联.md) | 看清已有宇宙、专业边界、组织方案与跨仓引用 |
| [宇宙候选与研究优先级](docs/01_全局宇宙候选与研究优先级.md) | 系统枚举、独立性判定、100分排程、风险门与开放缺口 |
| [因素与关系索引](docs/02_跨宇宙因素与关系索引.md) | 按专业维度召回因素，区分机制、结果和指标 |
| [多维推理与续研协议](docs/思维与方法宇宙/03_跨宇宙多维推理与节点续研协议.md) | Global Map → Focused Run → 验证 → 差量回写 |
| [三个样例与R2验收](docs/03_全局路由样例与R2验收.md) | 核验范围、未完成项、独立审查及下一阶段唯一任务 |

R2是候选地图与文档协议，已核验范围以验收记录为准；不宣称覆盖全部世界知识或已证明候选因果。本轮没有批量新增宇宙目录。
