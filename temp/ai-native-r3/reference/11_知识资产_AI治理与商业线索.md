## 一、资产生命周期

原文：想法、候选、验证、采用、实施、测量、优化、退役。资产宇宙关注文档、代码、模板、测试、知识长期复用。

相关链路：创建 → 使用 → 维护 → 升级 → 替换或退役；实践 → 经验 → 通用方法 → Skill → 复用。

研究建议：哪些研发资产需要长期保留，如何区分灵感、候选方案、已验证经验和实际采用的资产？如何处理过时知识？目前原文没有定义正式状态机或存储协议。

## 二、执行成本与AI治理

原文：上下文成本、模型选择、重复执行、人工干预；成本、权限、上下文、执行状态；上下文恢复、事实与证据、关系追溯、输入输出契约、知识复用、防止目标漂移。

研究建议：比较真实任务的重复执行量、上下文恢复成本和工具/模型选择，对相同任务验证是否降低成本且不损害正确性。权限、执行状态及回退策略仍需要单独实证，不先假设一个完备的治理引擎。

## 三、知识复利

原文：错题库、回归测试、经验提取、Skill化；决策记录、错题归纳、上下文交接、Skill优化。

研究建议：从实际失败、修复、回归验证中提取可复用知识，记录来源与适用边界；在另一任务中检验知识是否减少重复错误和重复研究。不要把未经验证的AI结论当成稳定经验。

## 四、公司与商业体系

原文：产品研发、商业化、增长、运营、组织、财务、法务、资本；市场与商业领域包含用户需求、竞争、付费意愿、成本、盈利能力。

商业宇宙关心产品价值、定价、增长、市场和竞争；运营价值链为用户使用 → 行为反馈 → 效果分析 → 产品改进。

研究建议：它是可以独立推进的业务方向，不能因原文出现公司与商业体系就把当前软件研发研究扩大为一个完整的企业OS。先研究实际用户价值、商业可行性和运营反馈。
