# AI-Native Dev · R3 临时独立研究资料包

本目录是用户授权的独立研究暂存区，不是正式知识库或工程框架。R2 为高价值研究线索，R3 提示词为候选研究任务，不代表实际研究或验证已完成。

## 使用方式

每个研究专题保持独立上下文。若使用真实多Agent/云任务环境，主控可按批次启动多个独立专题；无并行能力时逐个执行并保存。先读取本 README，然后读取 prompts/ 中相应编号的完整 Markdown（内嵌 R2 参考材料）。只在需要时读取 reference/ 中相关文件；不得默认扫描 VizTell 其他目录、合并历史上下文或覆盖既有研究成果。可针对专题未知项研究公开资料和获授权的真实项目案例，但不修改外部仓库。专题之间只引用必要成果，不重复执行。

## 一句话启动提示词（将 R3-A 替换为所需任务编号）

请访问 https://github.com/shopable-ai/VizTell 的 main 分支，读取 temp/ai-native-dev/README.md 和 prompts/ 中 R3-A 对应完整提示词，按其原始目标、关键任务和验收条件直接执行深度专题研究。R2仅为高质量线索，可批判、补充和推翻。只读取本目录内与任务有关的资料；不得默认读取、整合或修改 VizTell 其他目录。可以定向检索公开专业资料及真实项目案例，区分证据和推断。不要只生成计划或新提示词，必须交付实质研究成果。用户授权本次将研究结果增量保存至 temp/ai-native-dev/results/R3-A/，只允许修改该任务结果目录，原始资料和提示词保持不变；优先复用该任务已有成果并核实提交及差量范围。若当前工具无写入权限，提供可下载成果并如实说明。按提示词的评价要求报告完成、未完成、证据、阻断、各项评分与后续任务，不能虚称独立专家验证或95分。目录隔离及写入授权以本启动指令为准。
