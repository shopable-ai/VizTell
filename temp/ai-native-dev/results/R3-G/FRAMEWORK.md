# 推理模式宇宙 · 总体框架 F1

**独立问题：** AI 如何思考、发现未知、形成判断及修正？当前研究模式和组合，不继续具体浏览器实验。

## 1. 多维分类（不是13个平行逻辑类别）
| 一级视图 | 二级模式/操作 | 含义 |
|---|---|---|
| 逻辑推断 | 演绎、归纳、溯因 | 必然结论、经验概括、解释假设，证据义务不同 |
| 推导方向 | 条件→结果（预测）；目标→必要条件；失败→候选原因 | 分别回答会发生什么、必须满足什么、为什么可能发生 |
| 对象与关系分析 | 分解、抽象、类比、组合、系统关系/反馈 | 找组成与边界、共性、迁移、交互、循环依赖；分解和抽象是认知操作，不宣称是新形式逻辑 |
| 探索与反例 | 场景、边界、对抗、反事实、时间演化 | 展开正常/异常、极限、破坏条件、替代假设、长期变化 |
| 因果与证据 | 因果分析、证据审查、竞争假设比较 | 区分预测、解释和证实，明确证据适用范围 |
| 约束与价值决策 | 约束推理、价值权衡、候选比较/裁决 | 可行性、必要性、冲突、成本收益和风险；不是纯逻辑推断 |
保留原13模式：正向归条件预测；逆向拆目标逆推与失败溯因；因果/证据归证据分析；对抗/反事实/场景/边界/时间演化归探索；类比/组合归对象关系；约束/价值归决策。另将抽象、分解、综合列为候选认知操作，以免缺少从复杂问题到模型的能力，但不与演绎归纳强行同级。

## 2. 理解推理的接口
每个方法应能说明所解决的未知、所需前提、输入对象、推断性质、可产生的结果、反例、停止/回退、证据要求。信息检索用于获得证据，代码工具用于执行，专家角色提供视角；三者不是推理模式。模型输出的解释也不是实际事实。

## 3. 组合与选择（方法层候选）
| 任务性质 | 最小推理组合 | 不应发生 |
|---|---|---|
| 理解目标/需求 | 分解与场景→目标逆推→约束→必要性/证据 | 一种可行方案当必要条件 |
| 发现遗漏/风险 | 场景与组合→边界/对抗→价值筛选 | 无限枚举、把所有猜想当需求 |
| 理解系统 | 抽象/分解→关系与时间→条件预测 | 用结构图替代运行逻辑 |
| 诊断失败 | 溯因→竞争解释→可证伪预测→因果证据 | 相关或自信当根因 |
| 选择方案 | 硬约束→候选比较→反事实/权衡→决策 | 评分抵消硬性约束 |
| 审查结论 | 证据审查→反例→更新/保留未知 | 自评高分当真实验证 |
组合可迭代或按需并行，不能证明完备。停止由“新判断能否改变目标、方案、风险、证据或后续任务”决定。需要人工决策、外部事实或真实实验时保留待证。

## 4. 核心边界
- 目标逆推的必要性需要 G⇒条件 的依据或已限定的设计空间；某种实现充分不代表必要。
- 溯因是假设，归纳有样本边界，演绎依赖前提正确及推理有效。
- 反事实预测依赖模型和假设；受控实验也只能支持特定环境。
- 分解和综合互补，过度拆分会丢失系统交互。
- 推理方法用于各阶段和 C/H/I，不是固定工作流；D 表达知识对象，G 操作和判断对象。

## 5. F2：按认知任务选择推理及组合

| 认知任务 | 优先方法 | 输出性质 |
|---|---|---|
| 从规则和已知条件得出结果 | 演绎 | 在前提有效及逻辑有效时的结论 |
| 从样本寻找共性 | 归纳 | 有范围的概括或统计判断 |
| 观察到异常，寻找原因 | 溯因 | 候选解释及可区别它们的条件 |
| 由目标发现必要前提 | 逆向/目标反推 | 条件与候选方案，不自动成为必需 |
| 理解复杂系统 | 分解、综合、抽象、系统推演 | 子对象、关系与交互 |
| 探索替代和边界 | 反事实、情景、类比、组合 | 假设空间、边界、预测 |
| 冲突与方案选择 | 约束筛选、价值权衡、比较 | 可行方案及取舍 |
| 质疑和收敛 | 对抗、反例、证据核查 | 否决、限定或保留结论 |

SEP Abduction（https://plato.stanford.edu/entries/abduction/，2025-06-18修订，本轮查阅）区分解释性推断与逻辑必然；生成解释和以解释优势支持假设也有区别。其支持溯因不自动真值保持；上表的工程路由为候选归纳。

**组合原则：** 目标/疑问→选一类足以产生所需结果的方法→显式区分候选、前提与推断→用不同方向寻找反例或竞争解释→不满足时修正或标记未知。溯因生成候选→演绎推出可区分预期→依据可信观察进行更新；本轮只研究组合，不进行观察实验。抽象反例：P⇒Q 且 Q 成立，不能推出 P，另有 R⇒Q；这类肯定后件谬误可同时破坏根因推理和需求逆推。停止于新增推理不能改变判断、关键分歧已明确或需要外部信息时，不以循环次数称深度。

本节为F2通用结构推导和概念反例，未进行具体应用；重要分类和完整专业知识仍须独立核验。


## R1 深化：原13种模式的推理操作、前提与结论强度

13种阅读模式保留，不能冒称13种彼此排斥的逻辑推断。正/逆向属于方向；演绎/归纳/溯因是结论依据；场景、组合等是探索组织；约束/价值是决策问题。一次工作可组合多种类型。

| 原模式 | 必要输入与思路 | 产出与结论边界/停止 |
|---|---|---|
| 正向 | 前置、规则、事件→推演后果 | 条件化结果；规则未知则不宣称必然 |
| 逆向 | 目标或异常→寻找可能前置/解释 | 候选必要条件或原因；按C排除替代、按因果证据判定 |
| 因果 | 原因候选、时间/机制、混杂因素、证据 | 可区别的解释与支持强度；相关性非因果 |
| 对抗 | 当前主张、允许边界、失败目标→搜索反例 | 一个有效反例足以否定相应全称主张；没有找到不证明完备 |
| 反事实 | 明确观察事实、替换条件与因果假设 | 在假设下对未发生结果的比较；无可识别依据则保留未知 |
| 类比 | 源与目标对象、关系映射及差异 | 候选迁移方法；仅相似表面不支持结论 |
| 组合 | 因素域、约束、交互强度 | 有界有效组合和关注交互；按A/H说明未覆盖区域 |
| 约束 | 硬条件、资源、相容关系 | 可行集合或矛盾；不以偏好抵消禁止条件 |
| 场景 | 主体、目标、状态、触发 | 正常/替代/异常/恢复候选；非所有路径已证明 |
| 边界 | 域、临界条件、不变量 | 内外/等于/缺失/极限时的判别义务；未知阈值不捏造 |
| 价值 | 目标、受益方、代价、备选及不确定性 | 权衡、非劣候选或裁决；区分事实与主观权重 |
| 证据 | 待支持主张、来源/版本/范围、反证 | 支持、反驳、不可判定；不以文本数量或自信为证据 |
| 时间演化 | 初始状态、变化规则、时序、外部条件 | 路径、反馈、累积与失效假设；无未来证据不宣称已发生 |

### 方法选择与组合

未知的是事实→先K检索与来源检查；目标是否需要某条件→C逆向+反例；现象为什么发生→溯因提出竞争解释、演绎预测各解释不同后果、再求能区分的证据；何种方案可行→约束筛选后评价价值；复杂状态→分解+正向+组合+边界；审查全称主张→对抗寻找反例、证据确认。每步记录可解释结论及关键依据即可，不要求暴露完整思维过程。

演绎在前提为真且形式有效时保证结论；归纳及溯因超出前提，可能因新证据撤回。用先验、似然与后验刻画不确定性时，证据来源和相关性需显式处理；重复同一来源不等于独立似然，无法估计时不造精确概率。观察条件下 P(Y|X) 一般不等于干预 X 的结果；反事实依赖结构假设。可能性、可行性、必要性、充分性、已证实事实、授权选择是六种不同结果，不能沿链升级。

抽象反例：P→Q，观察Q；P与另一原因R均可产生Q，逆向得到的是候选而非P的证明。若增加独立事实¬P，应撤销P解释而非忽略证据。另一反例：从有限样本全为Q不能演绎所有对象Q；适用范围与抽样条件必须保存。
