# 学习适配、掌握与迁移

> 研究“这项知识对这个主体到底还差多少、需要掌握到什么程度、形成能力要付出多少成本，以及能否迁移”。知识复杂度与个人学习成本不是一回事。

本文件正式承接原 `04` 中“已知/误解/遗忘/已掌握”等主体知识状态。

---

## 一、L2 二级维度

- **已有知识重合**：概念、定义、事实、原理、机制、模型、方法、技能、术语、案例的已有覆盖程度。
- **主体知识状态**：未知、知道存在、部分理解、理解、误解、遗忘、能判断、能执行、能迁移、熟练。
- **前置知识覆盖**：必要前置、推荐前置、缺失前置、错误前置。
- **知识邻近度**：同主题、同领域、相邻领域、远距离跨域。
- **术语熟悉度**：熟悉、部分熟悉、陌生、同名误解。
- **理解难度**：从当前状态建立正确概念与关系模型的难度。
- **记忆要求**：是否需要长期记忆、主动回忆或仅知道在哪里查。
- **练习难度**：无需练习、少量练习、重复练习、真实环境长期训练。
- **反馈速度**：即时、短周期、长周期、结果难观察。
- **反馈质量**：明确、噪声较大、延迟、存在错误反馈。
- **迁移距离**：原场景、相似场景、跨场景、跨领域。
- **负迁移风险**：旧模型是否会干扰新判断。
- **掌握目标**：识别、理解、回忆、辨别、判断、执行、适应、迁移、教学/设计。
- **预计掌握成本**：理解、记忆、练习、反馈、迁移、维护和纠错成本。

## 二、Knowledge Gap 是核心对象

学习不应该从“整本资料”计算，而应从：

> **目标掌握状态 − 当前主体状态 = Knowledge / Capability Gap**

例如：

```yaml
learning_gap:
  target_knowledge_id: K-...
  current_level: H2
  target_level: H5
  known_components: []
  missing_components: []
  misconceptions: []
  missing_prerequisites: []
  practice_requirements: []
  estimated_cost: {}
```

已有 80% 前置并不代表“资料只读 20%”这么简单；必须知道缺的是不是关键机制、边界或程序性能力。

## 三、人类掌握层级

| Level | 名称 | 能力表现 |
|---|---|---|
| H0 | Unknown | 不知道 |
| H1 | Recognize | 能识别名称/术语 |
| H2 | Understand | 能解释核心含义 |
| H3 | Judge | 能判断适用性、边界、常见错误 |
| H4 | Execute | 能按方法完成标准任务 |
| H5 | Adapt | 能针对情境调整 |
| H6 | Transfer | 能迁移到新场景 |
| H7 | Teach / Design | 能教学、设计、改进或指导他人 |

掌握层级不是“看完”状态，而需要对应验证。

---

## 四、L3：已有知识重合

优先展开：

- 概念重合率；
- 定义重合；
- 原理/机制重合；
- 模型/框架重合；
- 方法重合；
- 程序步骤重合；
- 技能重合；
- 术语重合；
- 案例熟悉度；
- 前置覆盖；
- 相邻技能可迁移程度。

但重合率不能单独决定学习成本，因为：

- 重合内容可能是错误旧知；
- 少量缺口可能恰好是关键瓶颈；
- 程序性技能仍需要练习。

---

## 五、L3：错误旧知与负迁移

至少记录：

- misconception count；
- misconception severity；
- confidence_in_wrong_model；
- interference_scope；
- correction evidence；
- replacement practice required。

“已经听过”甚至可能让学习更难。

---

## 六、L3：从理解到能力的转换成本

需要分别判断：

- H1 → H2：概念建立；
- H2 → H3：边界、反例、辨别；
- H3 → H4：Procedure、真实执行；
- H4 → H5：异常与变化处理；
- H5 → H6：跨场景迁移；
- H6 → H7：抽象、教学、设计与改进。

很多资料只支持 H1-H2，不能因为理解文字就宣布形成技能。

---

## 七、L3：练习与反馈

高价值指标：

- deliberate practice need；
- feedback latency；
- feedback signal quality；
- number of distinct cases；
- edge-case exposure；
- error correction speed；
- real-task transfer；
- delayed retention；
- calibration between confidence and performance。

---

## 八、记忆需求必须与消费路由联动

某知识即使重要，也不必默认长期记忆。

如果：

- 低频；
- 查询延迟可接受；
- 可可靠 Search/RAG；
- 信息变化快；

则目标可能只需 H1-H3。

如果：

- 高频；
- 低延迟；
- 高错误代价；
- 需要现场判断；

则可能需要 H4-H6。

最终路由见 `18_知识价值、学习投入与消费路由.md`。

---

## 九、掌握验证

不同层级需要不同证据：

- H1：识别；
- H2：解释；
- H3：辨别正确/错误案例和边界；
- H4：标准任务执行；
- H5：异常场景调整；
- H6：陌生场景迁移；
- H7：教学、设计、改进。

只做选择题通常不足以证明 H4-H7。

---

## 十、关键关系

> **知识复杂度 ≠ 个体学习难度 ≠ 最终掌握成本。**

并且：

> **资料已解析 ≠ 人已理解 ≠ 人已掌握 ≠ 能迁移。**
