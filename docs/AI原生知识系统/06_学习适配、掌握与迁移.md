# 学习适配、掌握与迁移

> 研究“这项知识对这个主体到底有多容易学、需要学到什么程度、能否迁移”。知识难度与个人学习成本不是一回事。

## 一、L2 二级维度

- **已有知识重合**：概念、原理、模型、方法、技能、术语、案例的已有覆盖程度。
- **前置知识覆盖**：必要前置、推荐前置、缺失前置、错误前置。
- **知识邻近度**：同主题、同领域、相邻领域、远距离跨域。
- **术语熟悉度**：熟悉、部分熟悉、陌生。
- **理解难度**：低、中、高、极高。
- **练习难度**：无需练习、少量练习、重复练习、真实环境长期训练。
- **反馈速度**：即时、短周期、长周期、结果难观察。
- **迁移距离**：原场景、相似场景、跨场景、跨领域。
- **预计掌握成本**：理解成本、记忆成本、练习成本、反馈成本、迁移成本、维护成本。
- **掌握目标**：知道、理解、回忆、辨别、判断、应用、迁移、熟练。

## 二、关键关系

已有相邻技能越多，新的学习成本可能越低；因此：

> **知识难度 ≠ 个体学习难度 ≠ 最终掌握成本。**

同一项技能对零基础者可能需要完整学习，对已有 80% 前置知识的人可能只需要学习知识差额。

## 三、后续 L3 展开方向

- 概念重合率、模型重合率、方法重合率、技能重合率；
- 前置缺口数量及关键程度；
- 错误旧知识的负迁移；
- 从“理解”到“能判断”、从“能判断”到“能行动”的转换成本；
- 人工主动回忆、案例辨别、真实应用、跨场景迁移与延迟复查指标。
