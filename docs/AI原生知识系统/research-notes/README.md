# research-notes

本目录保存尚未进入正式框架的研究记录、外部方案对比、技术实验、失败案例、开放问题与证据审计。

## 使用约束

- 研究笔记不自动等于正式结论；
- 进入正式文档前需完成语义归类、来源核查、反例审计和冲突处理；
- 临时模型、阈值、产品选型和 Benchmark 结果优先留在此处，避免污染稳定框架；
- 已被正式文档吸收的研究笔记必须标记晋升状态与对应事实源，避免形成并行事实源；
- 当研究笔记与已经晋升的正式文档不一致时，**以正式文档为准**，研究笔记只用于追溯研究过程。
