# 参考书籍、课程、论文、网站与持续研究清单

> 本文件维护 01E 的外部专业来源、经典教材、方法手册与待研究队列。
>
> `anchor` 表示已确认适合作为当前体系的方法锚点；`candidate` 表示值得继续研究，不代表已被正式采纳。

---

## 一、引用原则

1. 优先原始方法、专业机构和大学课程；
2. 通俗书可作为教学入口，不作为唯一专业事实源；
3. 一个框架“很有名”不代表适合直接 AI 化；
4. 需要记录适用范围、误用风险和专业训练门槛；
5. 最新网页、标准、指南和软件方法需要记录核验时间；
6. 不以“引用数量”替代来源独立性和方法质量。

## 二、批判性思维、非形式逻辑与论证理论

### anchor — Stanford Encyclopedia of Philosophy: Informal Logic

https://plato.stanford.edu/entries/logic-informal/

重点研究：

- argument standardization；
- premises / conclusion / inference；
- natural-language argument evaluation；
- argumentation schemes；
- Critical Questions；

重点研究：

- premise acceptability；
- relevance；
- sufficiency；
- 日常自然语言论证分析。

### anchor — Stephen Toulmin, *The Uses of Argument*

重点：Claim / Data / Warrant / Backing / Qualifier / Rebuttal。

### anchor — Douglas Walton, Christopher Reed, Fabrizio Macagno, *Argumentation Schemes*

重点：高频 argument schemes 与 Critical Questions；后续需研究哪些子集值得纳入普通用户/AI Checker，而不是照搬全部模式。

### candidate — Argument Mapping

研究：论证图是否提高 AI/人工发现隐含前提、反驳和依赖关系的能力。

## 四、数据、统计与图表素养

### anchor — University of Washington / Carl Bergstrom & Jevin West: Calling Bullshit

https://callingbullshit.org/

Tools：
https://callingbullshit.org/tools.html

重点：

作为历史/通俗统计素养入口；具体统计规则需继续由现代统计方法校准。

https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf

### candidate — Edward Tufte

重点研究 graphical integrity、data-ink 等概念的现代适用边界。

### candidate — Alberto Cairo

重点研究数据可视化误导、图形阅读和公众数据素养。

## 十五、后续重点文献研究问题

### 15.1 Argumentation Schemes

- 96+ 模式中哪些是普通文章高频？
- 哪些 Critical Questions 可稳定 AI 化？
- 哪些模式高度依赖领域知识？

### 15.2 Construct Validity

- 怎样用最少专业术语帮助普通用户发现“指标不等于目标概念”？
- 如何区分可接受 proxy 与错误 proxy？

### 15.3 Causal DAG

- 哪些 DAG 错误模式可以自然语言化？
- collider / confounder / mediator 如何降低误报？

### 15.4 Risk of Bias

- 哪些 signalling questions 可跨医学、社会科学、商业研究复用？
- 哪些必须保留领域 profile？

### 15.5 Evidence Synthesis

- 如何区分单项研究质量、整体确定性、共识和争议？
- AI 如何避免“论文多=证据强”？

### 15.6 Fact-checking

- 来源核验成本如何按风险动态分级？
- 哪些 Claim 值得追 primary source？

### 15.7 Rhetoric / Persuasion

- 如何识别 persuasive amplification 而不把它判成事实错误？
- 如何构建真实 TN / FP？

### 15.8 AI-generated Content

- 摘要、翻译、合并、RAG 综合最常丢失什么？
- 如何建立 F24 的真实 Benchmark？
