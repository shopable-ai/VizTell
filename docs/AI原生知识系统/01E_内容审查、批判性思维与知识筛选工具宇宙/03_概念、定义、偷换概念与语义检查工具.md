# 概念、定义、偷换概念与语义检查工具

> 核心目标：追踪一段内容中“词、定义、量词、模态、范围和规范强度”的变化，识别概念漂移、偷换概念和命题升级风险。

---

## 一、为什么语义检查必须独立

很多误导不是事实完全错误，而是：

```text
同一个词
在句子 A 表示 X
在句子 B 变成 Y
```

或：

```text
弱命题
→ 强命题
→ 更强行动建议
```

因此只做事实核验会漏掉：

- 定义变化；
- 日常概念 ↔ 专业概念偷换；
- 描述事实 → 价值判断；
- 相关 → 因果；
- 有效 → 最佳；
- 部分 → 全部；
- 可能 → 必然。

---

## 二、语义检查对象

至少结构化：

```yaml
semantic_object:
  term:
  local_definition:
  professional_definition:
  scope:
  quantifier:
  modality:
  value_type:
  time_scope:
  actor:
  object:
  condition:
```

同一核心术语每次出现时都允许保存“本地含义”，不要假设整篇文章永久同义。

## 三、F04 命题变形追踪器

### 3.1 概率/模态升级

```text
可能
→ 有时
→ 往往
→ 大概率
→ 几乎一定
→ 必然
```

检查：中间是否新增了足够证据？

### 3.2 范围升级

```text
这个案例
→ 某类人
→ 多数人
→ 所有人
```

检查：样本和外推是否支持量词变化？

### 3.3 因果强度升级

```text
同时出现
→ 相关
→ 可能影响
→ 导致
→ 主要原因
→ 唯一原因
```

路由到 `04`。

### 3.4 方法价值升级

```text
有效
→ 更有效
→ 最有效
→ 最佳实践
→ 所有人都应该使用
```

检查：比较对象、目标函数、成本和场景条件是否存在。

### 3.5 描述 → 规范升级

```text
存在
→ 有形成原因
→ 有功能
→ 合理
→ 正当
→ 应该保留
```

这是“存在即合理”类表达的关键拆解。

必须区分：

- `exists`：现实存在；
- `has_cause`：有形成原因；
- `has_function`：在某系统承担功能；
- `instrumentally_effective`：对某目标有效；
- `normatively_justified`：规范上正当；
- `recommended`：当前值得采用。

这些不是同一个命题。

## 四、概念偷换主要类型

### 4.1 广义 ↔ 狭义

例如先用宽泛“成功”，后文实际只测量收入。

### 4.2 日常语言 ↔ 专业术语

例如“能量”“焦虑”“抑郁”“人格”等词在日常与专业语境含义不同。

### 4.3 描述概念 ↔ 规范概念

“常见”被写成“正常/应该”。

### 4.4 标签 ↔ 本质

给某人贴“内向”“高价值”“低认知”等标签后，把标签当成稳定本质解释一切。

### 4.5 分类 ↔ 机制

“把人分成四类”不等于解释了为何出现某行为。

### 4.6 名称 ↔ 解释

给现象起名不等于解释机制。

## 五、定义检查器

面对关键术语至少问：

1. 作者是否给出定义？
2. 定义是操作性的还是循环的？
3. 同一词在全文是否稳定？
4. 是否与主流专业定义不同？
5. 若不同，作者是否明确说明？
6. 这个定义能区分正例与反例吗？
7. 定义是否过宽以至于什么都能装进去？
8. 定义是否过窄以便排除不利案例？
9. 被质疑后是否退回弱定义，传播时又恢复强定义？

## 六、命题规范化工具

AI 可把自然语言压成：

```yaml
claim:
  subject: "..."
  predicate: "..."
  object: "..."
  quantifier: some|many|most|all
  modality: possible|probable|necessary
  polarity: positive|negative
  scope: "..."
  conditions: []
  time_scope: "..."
```

然后比较相邻命题：

- subject 是否变化；
- predicate 是否变化；
- object 是否扩大；
- quantifier 是否升级；
- modality 是否升级；
- condition 是否删除；
- time_scope 是否扩展。

## 七、正常信号与风险信号

### 正常信号

- 定义明确；
- 术语变化有显式说明；
- 量词和不确定性保留；
- 推理中条件没有丢失；
- 专业术语与日常用法区分；
- 结论强度与证据强度大体匹配。

### 风险信号

- 同词不同义却未说明；
- 新定义只为逃避反例；
- “有时”被总结成“就是”；
- “可能有效”在标题变成“必学/必做”；
- 条件、时间、对象在二次传播中消失；
- 描述性事实被直接写成规范正当性。

---

## 八、AI 自动化边界

### Detect 较强

- 显式定义差异；
- 量词变化；
- 可能/必然等模态变化；
- 条件删除；
- 同词附近的语义表示明显变化；
- 标题与正文命题强度差异。

### Judge 较弱

- 变化是否属于合理语境适配；
- 某专业词是否被“偷换”而非正常多义；
- 作者是否故意操纵；
- 隐含规范价值是否成立。

正确输出优先是：

```text
“检测到概念/命题变化候选”
而不是
“确认作者偷换概念”
```

---

## 九、误报 Benchmark 必测

1. 作者先给通俗定义，后给专业定义，且明确说明；
2. 同一词本来就有合理多义；
3. 文章从“部分”总结到“多数”，中间确有新增总体数据；
4. 从“有效”到“推荐”时确实给了目标函数和比较证据；
5. “存在即合理”被用于历史解释意义，而不是规范正当性；
6. 文学比喻中的词义变化不应被当成事实论证错误。
