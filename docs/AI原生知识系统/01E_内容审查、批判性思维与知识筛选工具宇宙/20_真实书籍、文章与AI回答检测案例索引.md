### 3.1 Forer 1949 / Barnum 描述

**01D 视角**：NV-04 模糊、双面与自我适配陈述；现有矩阵候选 10。

**01E Checker 路由**：

```text
F02 Claim 分离
→ F04 命题/范围
→ F06 论证风险
→ F07 反例与区分性测试
→ F20 判断错觉
```

**关键检查**：

- 同一描述能否同时适配大量不同人？
- 是否产生可区分的预测？
- “觉得准确”是否被当成理论验证？

**误报边界**：真实高基准率人格描述可以确实适用于很多人；问题是把普适性描述包装成高区分度个体诊断。

**Benchmark readiness**：高。

### 3.2 仓库《冷读术》“外显 + 相反内在”技巧

**01D 视角**：NV-04；矩阵候选 11，同时关联 NV-15。

**01E 路由**：

```text
F04 语义与双面覆盖
→ F07 区分性/反例
→ F19 说服增强
→ F20 自我适配风险
```

**关键检查**：

- A/非 A 是否被同时覆盖？
- 什么回答会真正反驳描述？
- 是否依赖对方主动补全含义？

**误报边界**：心理描述本身允许复杂双面性；不能因为一句话同时提到两个倾向，就自动判冷读术。

**Benchmark readiness**：高，但需要保持原章节上下文。

### 3.3 “存在即合理”与黑格尔传播简化

**01D 视角**：NV-05 / NV-23；矩阵候选 13。

**01E 路由**：

```text
F04 概念/命题变形
→ F14 引用忠实度
→ F17 原始上下文
→ F21 历史语境/迁移
```

**关键检查**：

- “现实/理性/合理”分别如何定义？

**Benchmark readiness**：中高；哲学术语需要专家/权威译本边界。

## 五、案例进入 Benchmark 的 Gate

只有至少完成下面条件才进入 `21`：

- 真实材料可回溯；
- 输入片段固定；
- 原始上下文可查；
- 目标 Checker 明确；
- 正确判断不是只有一个模糊“感觉”；
- 有至少一个相邻误判或 False Positive；
- 高争议案例允许多标签/多状态；
- 最新事实需要时已重新外部核验。

本文件只是案例索引，不把“候选”误写成 Benchmark Gold。
