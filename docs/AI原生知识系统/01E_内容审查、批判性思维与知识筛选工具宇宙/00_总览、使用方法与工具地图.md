# 01E 总览、使用方法与工具地图

> 本目录是 `01E_内容审查、批判性思维与知识筛选工具宇宙.md` 的长期扩展层。
>
> 主文件保存稳定一级事实；本目录保存专业框架、具体检查问题、AI Checker 边界、真实案例索引和 Benchmark。

---

## 一、本目录解决什么问题

面对文章、书籍、报告、视频转录或 AI 回答，不能只问：

> “这是不是谬误？”

而应把任务拆成：

```text
它在说什么
→ 哪些是需要核验的 Claim
→ 用了什么推理
→ 概念有没有变化
→ 因果/统计/研究设计是否支持结论
→ 来源和引用是否可靠
→ 修辞是否放大说服力
→ 条件和边界是否丢失
→ 真正新增了什么
→ 是否需要外部核验或人工复核
→ 最后才决定怎样阅读、保存和使用
```

---

## 二、五层内容严格分开

### 第一层：专业领域

例如：非形式逻辑、因果推断、统计素养、测量学、研究方法、媒体素养。

### 第二层：成熟框架 / 方法

例如：Toulmin Model、Argumentation Schemes、Critical Questions、Causal DAG、RoB 2、GRADE、SIFT。

### 第三层：具体检查问题

例如：

- “这个词前后含义是否变化？”
- “是否存在第三变量？”
- “百分比有没有分母？”
- “引用原文是否真的支持当前 Claim？”

### 第四层：AI Checker 能力

例如：概念漂移候选检测、因果风险提示、引用支持度检查、图表轴检查。

### 第五层：真实案例与 Benchmark

验证 Checker 是否出现：TP / FP / TN / FN / Boundary / Insufficient Evidence / Appropriate Abstention。

- 每个 Checker 应看到什么；

禁止复制两份完全相同的案例正文。

## 六、三种实际使用模式

### 6.1 快速阅读筛选

```text
内容类型
→ 核心 Claim
→ 主要证据
→ 最大风险
→ 真正新增
→ 是否值得继续读
```

适合：普通文章、社交媒体、一本书的快速预审。

### 6.2 专业主张审查

```text
Claim 原子化
→ 论证结构
→ 专业 Checker 路由
→ 来源/原始证据
→ 不确定性
→ 专业裁决模块
```

适合：研究报告、商业报告、科普、政策、技术主张。

### 6.3 高风险知识入库 Gate

```text
Raw Content
→ 01E 风险发现
→ 03/04/08 正式裁决
→ 10 风险与责任 Gate
→ Human Review
→ verified / contested / unverified / quarantine 等状态
```

适合：企业知识库、RAG、医疗/法律/重大商业等高风险材料。

## 七、普通用户十问

1. 它到底在说什么？
2. 哪几句话是真的需要我相信或照做？
3. 作者拿什么支持它？
4. 证据真的支持到这么强吗？
5. 有没有其他解释或反例？
6. 原始来源在哪里？
7. 其他独立来源怎么说？
8. 这里主要靠证据说服我，还是靠故事、身份、情绪和语言？
9. 对我当前任务真正新增了什么？
10. 我应该继续读、局部读、核验、保存，还是停止？

这十问是轻量入口，不替代专业 Checker。

## 八、统一 Checker 输出

优先输出：

```yaml
checker_result:
  claim_ref:
  checker_id:
  status: risk_signal
  trigger_signals: []
  supporting_evidence: []
  missing_information: []
  alternative_explanations: []
  external_verification_required: false
  human_review_required: false
  next_action: "..."
```

禁止把 `risk_signal` 自动升级成 `confirmed_issue`。
