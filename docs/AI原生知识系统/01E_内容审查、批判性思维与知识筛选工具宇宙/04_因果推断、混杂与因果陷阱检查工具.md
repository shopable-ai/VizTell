# 因果推断、混杂与因果陷阱检查工具

> 核心目标：把“A 导致 B”类表达从直觉判断转成可执行检查问题；普通用户不必先学习完整因果推断数学，但 Checker 必须受成熟因果理论约束。

---

## 一、核心原则

```text
相关 ≠ 自动有因果
相关 ≠ 自动无因果
时间先后 ≠ 足够证明因果
随机实验 ≠ 所有现实问题唯一可用证据
观察研究 ≠ 自动无价值
```

正确任务是：

> **当前证据最多支持多强的因果结论？还缺什么？哪些偏差路径可能产生同样观察？**

## 三、普通用户因果十二问

文章说 A 导致 B 时，至少问：

1. A 与 B 只是同时出现吗？
2. A 是否明确发生在 B 之前？
3. B 是否可能反过来影响 A？
4. 是否存在 C 同时影响 A 和 B？
5. A 和 B 是否只是共同受到环境、群体、政策或选择机制影响？
6. 作者有没有合理比较“有 A”和“没有 A”的情况？
7. 两组在 A 之外是否本来就不同？
8. 样本是怎样被选进研究或报道的？
9. 如果没有 A，B 合理来说会怎样？
10. 是否存在中介变量，使“A→B”描述过于简单？
11. 是否存在调节变量，使效应只在某些人/条件下成立？
12. 现有证据是否只支持“相关/可能影响”，却被写成“主要原因/唯一原因”？

## 四、关键因果陷阱

### 4.1 混杂变量 Confounding

```text
C → A
C → B
```

A 与 B 相关，可能主要来自 C。

检查：

- 哪些变量同时影响暴露/行为 A 和结果 B？
- 作者有没有测量并合理处理？
- 是否有重要未测量混杂？

### 4.2 反向因果 Reverse Causality

```text
作者写：A → B
现实可能：B → A
```

例如“使用某工具的人绩效高”也可能是高绩效群体更容易采用该工具。

### 4.3 选择偏差 Selection Bias

观察到的人并不是目标总体的随机缩影。

检查：

- 谁没有被观察到？
- 进入样本是否同时受到 A/B 或其原因影响？
- 只研究成功者、存活者、回应者会怎样？

### 4.4 Collider Bias

```text
A → C ← B
```

错误地对共同结果 C 条件化，可能制造 A/B 的伪关联。

普通用户不必掌握图论，但 AI 应能提示：

> “你控制的这个变量会不会本来同时受两边影响？控制它反而会制造关系。”

### 4.5 回归均值

极端表现后自然回到平均水平，却被某干预认领为效果。

### 4.6 同时变化 / 时间趋势

两个变量都随时间上升不意味着彼此因果。

### 4.7 必要条件与充分条件

- A 必要：没有 A 就没有 B；
- A 充分：有 A 就足以产生 B。

现实文章经常把其中一个偷换成另一个。

### 4.8 单因果错觉

复杂系统的多重机制被压缩成“一个原因”“一个底层逻辑”。

## 五、因果 DAG 的普通用户价值

DAG 不只是数学工具，也可以作为“先画假设再下结论”的结构化方法。

最小动作：

1. 写出目标 A 与 B；
2. 列出可能共同原因 C；
3. 列出 A 可能经过的中介 M；
4. 列出样本进入/被观察的选择节点 S；
5. 标记哪些变量是在结果之后才产生；
6. 再判断应该控制什么、不应该控制什么。

即使不计算，也能暴露很多隐藏假设。

## 六、证据类型与因果强度

不能用一个固定“证据等级”覆盖所有问题，但通常需要区分：

- 个案 / anecdote；
- 横截面相关；
- 时间序列关联；
- 队列 / case-control；
- 准实验；
- 自然实验；
- 随机对照；
- 多研究复现 / evidence synthesis。

更重要的是：

> **研究设计是否真的能回答当前因果 Claim。**

例如随机实验内部效度高，但样本、干预和场景可能与当前任务非常不同。

## 七、AI Checker 输出

```yaml
causal_check:
  claim: "A 导致 B"
  evidence_type:
  temporal_order: yes|no|unclear
  reverse_causality: possible|unlikely|unclear
  confounders: []
  selection_risks: []
  collider_risks: []
  comparison_quality:
  counterfactual_support:
  mediators: []
  moderators: []
  supported_strength: association|possible_effect|causal_support|strong_causal_support|unknown
  missing_information: []
  external_verification_required: true
```

不要输出“因果分数 78”。

## 八、自动化边界

### AI 可较强执行

- 抽取因果措辞；
- 找反向因果候选；
- 生成潜在第三变量清单；
- 识别文本中明确的 treatment/control；
- 检查时间顺序是否被说明；
- 识别必要/充分条件语言；
- 从文字构造候选 DAG。

### AI 只能提示风险

- 未测混杂到底有多严重；
- 某变量到底是 confounder、mediator 还是 collider；
- 观察研究是否足以支持目标因果结论；
- 自然实验假设是否可信。

### 常需数据/专业分析

- 实际效应估计；
- 调整模型；
- 灵敏度分析；
- 因果识别条件；
- target trial emulation；
- 高风险干预结论。

---

## 九、因果误报 Benchmark

必须包含：

1. A 与 B 相关，但还有 RCT/自然实验等强因果证据——不能仅凭“相关”否定因果；
2. 作者明确写“相关，不能证明因果”——不能仍报警为“把相关当因果”；
3. 一个机制研究并未声称总体效果——不能要求不存在的总体对照；
4. 反向因果在时间顺序上明显不可能；
5. 合理控制 confounder 被误判为 collider；
6. 合理中介分析被误判成“控制了后果变量”；
7. 必要条件陈述本来没有声称充分条件。
