# 主体价值、场景价值与阅读投入检查触发器

> 核心目标：在内容经过真实性、推理和增量检查后，判断是否需要进一步问“这对当前主体、目标和任务值不值得投入”，并把正式裁决转交给现有 `05/18`。

本文件**不重新建立一套主体价值公式**。

---

## 一、为什么 01E 仍需要这一层

一篇内容可能：

- 基本正确；
- 证据不错；
- 没有明显误导；

但对当前任务仍然没有价值。

反过来，一条对当前任务很重要的 Claim 证据很弱，也不能因为“很有用”就跳过核验。

因此必须分开：

```text
knowledge_quality
subject_utility
reading_investment
consumption_route
```

正式含义和状态由 `05/18` 负责。

---

## 二、01E 在这里做什么

只负责收集触发信息：

```yaml
value_trigger:
  actor:
  role:
  current_goal:
  task:
  task_stage:
  urgency:
  use_probability:
  consequence_if_wrong:
  known_overlap:
  expected_increment:
  reading_cost:
  better_alternatives: []
  reusable_across_tasks:
```

然后转交：

```text
05 → 主体、目标、场景价值
18 → 学习投入与消费路由
```

## 三、主体价值快速十问

1. 我现在真正要解决什么问题？
2. 这段内容与当前目标是直接相关、间接相关还是无关？
3. 我是执行者、决策者、监督者、学习者还是仅研究者？
4. 当前处于发现、诊断、选择、执行还是复盘阶段？
5. 读完会改变什么判断或行动？
6. 我是否已经掌握大部分内容？
7. 真正的新机制/条件/证据有多少？
8. 有没有更短、更可靠、更直接的替代资料？
9. 错过这条内容的代价多大？
10. 继续投入会挤占什么更高价值任务？

---

## 四、内容价值类型不能混成一个“有用/没用”

触发时至少识别：

- 事实价值；
- 机制价值；
- 方法价值；
- 决策价值；
- 学习价值；
- 风险防御价值；
- 文学/叙事价值；
- 情绪价值；
- 文化/历史价值；
- 传播/商业价值。

正式类型仍以 `01C` 为准。

例如：

> 一本管理故事书知识增量低，但可能仍有叙事、沟通或历史观察价值。

不能因为 F22 判“低 Canonical Increment”就直接输出“无价值”。

---

## 五、知识增量与当前价值分开

```text
高增量 + 当前无关
→ 可能延后

低增量 + 当前关键任务复习
→ 仍可能有复习价值

高增量 + 高风险 + 证据弱
→ 先核验，不是直接学习为真

低增量 + 可随查
→ 可能无需完整阅读
```

因此 `15` 只提供增量信号，本文件负责触发 `05/18`。

## 六、阅读投入快速 Gate

### Gate 1：是否和当前目标相关？

若明显无关，优先 `DEFER / IGNORE / REFERENCE` 候选。

### Gate 2：是否有真正知识差额？

如果高度重复，降低完整阅读优先级。

### Gate 3：错误/遗漏后果有多大？

高后果内容可能值得核验，即使不值得“学习”。

### Gate 4：是否有更经济的替代？

例如：

- 官方文档；
- 一页总结；
- 搜索；
- RAG；
- 工具；
- 专业服务。

### Gate 5：人是否必须形成即时判断？

若高频、现场、不可慢查，内化价值上升。

最终 Route 由 `18` 决定。

## 七、推荐输出不是“值得读 82 分”

更合适：

```yaml
reading_trigger_result:
  task_relevance: high
  epistemic_gate: unresolved
  expected_increment: medium
  overlap_with_known: high
  reading_cost: high
  substitution_available: true
  next_step:
    - verify_claims_C03_C05
    - read_sections_2_5_only
    - skip_repeated_stories
  handoff:
    - 05
    - 18
```

## 八、快速阅读、局部阅读与完整阅读候选

### 快速扫读

适合：

- 低风险；
- 目标相关性未知；
- 先寻找 Claim 和增量。

### 局部阅读

适合：

- 只有少数章节直接相关；
- 大量叙事/重复；
- 核心机制集中。

### 完整深读

候选条件：

- 当前高价值；
- 结构强依赖上下文；
- 需要形成长期能力；
- 核心材料无法被短摘要替代；
- 阅读成本合理。

不是“好书就完整读”。

---

## 九、主体不同，检查结果不同

同一内容：

```text
工程师故障排查
→ 需要技术机制、版本、步骤

销售内容创作
→ 叙事、情绪和传播结构价值可能更高

历史研究
→ 旧制度的时代背景本身就是目标
```

因此 01E 的 checker risk 可以共享，但最后价值路由必须带主体/场景。

## 十、自动化边界

### AI 可较强辅助

- 提取用户目标/任务；
- 对齐内容 Claim；
- 估计主题相关性；
- 找与已有知识的重复；
- 识别可跳过章节；
- 提供替代资料候选；
- 估计阅读成本。

### AI 不应独立替代

- 用户真正长期目标；
- 高价值机会成本；
- 重大职业/商业选择；
- 用户愿意承担的学习成本；
- 高风险最终决策。

---

## 十一、误报 Benchmark 必测

1. 当前任务暂时无关，但属于明确未来前置知识；
2. 内容高度重复，但用户正在进行必要熟练训练；
3. 文学/历史内容知识密度低，但当前目标就是文学/历史研究；
4. AI 判断“可随查”，但任务现场实际不允许检索；
5. 短摘要遗漏了关键上下文，完整阅读仍有必要；
6. 内容对当前用户低价值，但对其他角色高价值，不应写成绝对“无价值”。
