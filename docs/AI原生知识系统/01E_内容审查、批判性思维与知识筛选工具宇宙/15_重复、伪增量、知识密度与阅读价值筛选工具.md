# 重复、伪增量、知识密度与阅读价值筛选工具

> 核心目标：面对大量书籍、文章和解释，识别“文本不同但知识没增加”“故事很多但机制没增加”“内容有一点价值但不值得继续投入”的情况。

本文件负责 01E 的**检查触发和风险发现**；正式知识关系与增量裁决进入现有 `04/17`，主体阅读投入与消费路由进入现有 `05/18`。

---

## 一、文本新 ≠ 知识新

需要分开：

```text
新文字
新名称
新故事
新案例
新图形
新框架包装
新命题
新机制
新条件
新边界
新反例
新独立证据
新决策价值
```

真正高价值增量通常集中在后几类。

---

## 二、F22 的八层检查

```text
文件/版本身份
→ 完全重复
→ 近似文本重复
→ 语义相似候选
→ 命题对齐
→ 机制/条件/边界对齐
→ 独立证据判断
→ 是否改变判断/行动
```

语义相似只能用于候选召回，不能直接授权删除或合并。

---

## 三、新瓶装旧酒检查

风险模式：

- 旧概念换新名字；
- 旧原则换专业术语；
- 只换行业；
- 只换人物；
- 只换故事；
- 只换图形；
- 把几个常识组合后重新命名；
- 把旧框架拆成更多步骤；
- 把多个旧框架合并后宣称“全新理论”。

检查问题：

1. 去掉名称后，核心命题是什么？
2. 与已有 Canonical Knowledge 是否等价？
3. 是否新增机制？
4. 是否新增条件/边界？
5. 是否新增独立证据？
6. 是否改变决策？

---

## 四、知识密度不等于术语密度

单位内容可观察：

- 新 Claim 数；
- 新机制数；
- 新条件/边界数；
- 新反例数；
- 新独立证据数；
- 可执行步骤数；
- 重复解释占比；
- 案例占比；
- 修辞/叙事占比。

但这些不能机械加权成永久质量分。

---

## 五、重复解释也可能有教学价值

重复不是自动低价值。

可能合理的重复：

- 不同例子帮助理解抽象概念；
- 间隔重复帮助记忆；
- 新受众需要不同解释；
- 不同场景帮助迁移；
- 高风险操作需要冗余提醒。

因此至少分开：

```text
canonical_increment
teaching_value
memory_value
transfer_value
```

---

## 六、新案例是否算增量

一个新案例可能是：

- 教学例子；
- 新应用场景；
- 边界案例；
- 反例；
- 独立经验性证据；
- 未核验故事。

不能自动写：

> 新案例 = 新知识。

具体案例角色进入 `13`，关系裁决进入 `04/17`。

---

## 七、正确废话检查

一种内容可能几乎不错误，却判断价值很低：

```text
“成功需要努力”
“管理需要因人而异”
“投资有风险”
```

检查：

- 是否能区分不同选项？
- 是否给条件？
- 是否能改变预测？
- 是否能指导不同动作？
- 是否比高基准率常识增加更多信息？

若不能，标记 `low_discriminative_value`，不是“false”。

---

## 八、阅读成本与边际增量

对长文/书籍按批次观察：

```text
新增 Canonical Knowledge / token
新增 Decision-changing Information / 时间
```

当连续章节只增加：

- 同义改写；
- 同机制案例；
- 情绪铺垫；
- 名人故事；

而没有新条件、边界、证据、反例时，可以触发“局部阅读/停止”候选。

最终是否停止由 `16` + 现有 `18` 判断。

---

## 九、饱和信号

```text
连续 N 个来源/章节
→ 新机制接近 0
→ 新条件/边界接近 0
→ 新独立证据接近 0
→ 未决冲突也没有下降
```

可能说明当前研究方向接近饱和。

但如果高风险未知仍存在，不能仅因平均增量低就停止。

## 十一、自动化边界

### Detect 较强

- 完全/近似重复；
- 同义改写候选；
- 术语别名候选；
- 文本中是否新增显式条件/步骤/案例；
- 重复解释段落；
- 新案例但同一原则。

### Judge 中等或较弱

- 真正知识等价；
- 两个机制是否相同；
- 一个案例是否构成新证据；
- 是否改变现实决策；
- 是否已经达到研究饱和。

这些必须保留 Relation Assertion、provenance 和人工回滚。

---

## 十二、误报 Benchmark 必测

1. 相同核心原理，但新增关键适用边界；
2. 文字高度相似，但新版修复了关键错误；
3. 新案例本身是反例，改变原模型；
4. 重复解释承担学习迁移价值；
5. 新数据来自独立来源，即使命题相同，也可能是重要 evidence increment；
6. 文章很短但知识密度低，不应把“短”自动等于高密度；
7. 文学/叙事文本的目标本来不是最大知识密度。
