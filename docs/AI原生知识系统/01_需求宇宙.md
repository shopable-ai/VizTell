# 需求宇宙：专业问题分类与 P-L1 / P-L2 事实源

> 本文件是 AI 原生知识系统的**专业问题宇宙（Problem Taxonomy）事实源**。
>
> 用户什么时候遇到什么问题、会怎样描述，由 `01A_用户旅程、需求与高频问题现象宇宙.md` 承载；大量用户原话如何形成稳定标准用户问题并映射到本文件，由 `01B_标准用户问题与专业问题映射.md` 承载。
>
> 本文件只保存**问题空间**。Search、RAG、Skill、Workflow、Agent、Software 等实现载体不属于 P-L1 / P-L2；系统去重错误、路由错误、模型成本等也不属于用户专业问题分类。

---

## 一、核心定位

AI 原生知识系统的上游正式采用：

```text
人的真实目标
→ 用户需求
→ 用户旅程与真实场景（01A）
→ 用户原话问题
→ 标准用户问题（01B）
→ 专业问题 P-L1 / P-L2（本文件）
→ 知识与评价空间
→ 系统能力
→ 验证
→ 解决方案与实现
→ 用户结果
```

本文件回答：

> **大量具体用户问题，从专业问题空间看，属于哪些稳定、可复用、跨场景的问题类别？**

### 1.1 本轮收敛原则

1. **用户问题与解决方案彻底分开。** 实现方式不占用 P-L1 / P-L2 编号。
2. **用户问题与系统错误彻底分开。** false merge、错误路由、模型成本、Agent 过度使用等进入 `13 / 19 / 22`。
3. **不为历史编号保留错误边界。** 当前仍处于框架收敛阶段，语义正确性优先于历史兼容性。
4. **活动名称不等于一级问题。** 阅读、笔记、记忆、AI 使用可以跨多个 P-L1。
5. **一个 SUP 可以映射多个 P-L1 / P-L2。** 不要求互斥，但必须区分主问题与关联问题。
6. **P-L1 保存稳定问题域，P-L2 保存稳定问题或稳定判断困难。** 类型枚举、状态值、需求属性、关系类型不能直接冒充 P-L2。
7. **规模、时间、主体、场景优先作为问题属性。** 只有当它们改变了问题机制，才形成独立 P-L2。
8. **覆盖不等于分类正确。** 一个 SUP 能“勉强找到位置”还不够，还必须通过相邻边界与反例测试。

## 二、P-L2 准入与净化规则

### 2.1 一个条目要成为正式 P-L2，至少满足

1. 能描述一个稳定、可复现的困难、失败、冲突、缺口或判断不确定性；
2. 不依赖某个具体实现技术才成立；
3. 能说明它阻碍了什么用户结果；
4. 与同一 P-L1 下其他条目有可解释边界；
5. 与相邻 P-L1 的主归属能够解释；
6. 至少能由一个 SUP、真实用户表达或合成反例支持；
7. 解决以后存在可观察的改善，而不是只“多了一个功能”。

### 2.2 以下内容不能直接作为 P-L2

- `知道 / 理解 / 记忆 / 判断 / 应用 / 迁移` 这类**掌握深度状态值**；
- `新概念 / 新机制 / 新案例 / 新证据` 这类**知识增量类型**；
- `因果 / 前置 / 替代 / 补充` 这类**关系类型**；
- `高 / 中 / 低`、单书 / 多书 / 海量等**属性值**；
- Search / RAG / Skill / Workflow / Agent / Software 等**解决方案载体**；
- false merge、citation mismatch、模型成本爆炸等**系统错误与 Benchmark 指标**。

这些对象可以作为 P-L2 的判定维度、原因、属性或测试条件，但不能仅凭对象名称占用问题编号。

### 2.3 正确写法

错误：

> `增加新证据`

正确：

> `新增案例、反例或证据时，无法判断它带来的证据增量与知识增量是否值得保留`

错误：

> `需要主动记忆和提取`

正确：

> `不知道哪些知识必须形成主动提取能力，哪些只需理解或随用随查`

## 三、编号规则与一级问题空间

- `P-L1-xx`：一级专业问题空间；
- `P-L2-xx-yy`：对应一级空间下的稳定二级问题。

当前正式范围为：

> **P-L1-01 ～ P-L1-17，共 17 个一级问题空间。**

历史 Research Note 中出现的旧编号仅用于追溯，不构成兼容要求。

| 编号 | 一级问题空间 | 人话核心问题 | 边界 |
| --- | --- | --- | --- |
| P-L1-01 | 用户需求与真实问题 | 用户真正要解决什么？ | 目标、问题定义、范围、成功标准 |
| P-L1-02 | 知识需求识别 | 为解决问题究竟需要知道什么？ | 已知/未知、前置、知识类型与深度 |
| P-L1-03 | 来源发现与资料获取 | 应该去哪里找、找什么资料？ | 来源发现与可获得性 |
| P-L1-04 | 资料筛选、阅读优先级与处理深度 | 哪些值得先处理、处理到多深？ | 单份/候选资料级投入判断 |
| P-L1-05 | 知识重复与等价 | 哪些其实是同一知识？ | 重复、改写、异名同义、同名异义 |
| P-L1-06 | 知识增量与补充 | 新材料真正增加了什么？ | 真正新增与边际知识价值 |
| P-L1-07 | 知识关系与结构 | 这些知识彼此什么关系、怎样形成整体？ | 语义结构、依赖、因果、层级与组合 |
| P-L1-08 | 冲突、条件与边界 | 为什么说法不同，什么时候成立？ | 条件、例外、反例、真实冲突 |
| P-L1-09 | 来源、证据与可信度 | 为什么相信它？ | 来源忠实度、证据、独立性与不确定性 |
| P-L1-10 | 时间、版本与知识失效 | 现在还有效吗？ | 时效、版本、修订、替代与失效 |
| P-L1-11 | 知识整理、多来源综合与压缩 | 怎样留下高密度、以后还能用的知识？ | 提取、记录、综合、压缩、回源与消费结构 |
| P-L1-12 | 主体价值与知识优先级 | 哪些知识对当前主体真正重要？ | 个人/目标/项目相关性与机会成本 |
| P-L1-13 | 理解、记忆、掌握与迁移 | 怎样从“看过”走到“真的会”？ | 人的理解、提取、练习、判断与迁移 |
| P-L1-14 | 知识到判断、决策与行动 | 怎样把知道转成现实结果？ | 方法选择、调用、执行、即时验证与调整 |
| P-L1-15 | 本人掌握、委托与监督边界 | 哪些必须本人掌握，哪些可以查询或委托？ | 人/AI/工具/服务的能力归属、监督与责任 |
| P-L1-16 | 规模、注意力与研究停止 | 资料越来越多以后，怎样避免失控并知道何时够了？ | 组合规模、人工注意力、边际增量、停止与重启 |
| P-L1-17 | 反馈、修正与长期再判断 | 结果、目标或环境变化后，哪些旧判断要改？ | 用户结果、实践反馈、变化传播与历史恢复 |

### 3.1 一级空间审计结论

当前**不新增新的 P-L1，也不合并现有 17 类**。

原因：

- 01 / 02 / 03 对应问题、知识缺口、信息获取的不同层；
- 05 / 06 分别回答“是不是同一个”与“真正新增什么”；
- 07 / 11 / 13 分别对应知识结构、外部整理产物、人的内部掌握；
- 09 / 10 / 17 分别对应证据判断、版本时效、变化后的再判断；
- 13 / 14 分别对应人的能力形成与现实任务执行；
- 04 / 16 分别对应局部资料投入与规模化注意力/停止；
- 15 是 AI 原生环境下稳定存在的能力归属与监督问题，不应退化成技术实现分类。

团队/组织共同知识协作、无障碍与特殊认知需求继续作为 Missing Candidate 研究，不因为“需要完整”而提前新增 P-L1。

## 四、P-L2 二级问题维度

### P-L1-01 用户需求与真实问题

- `P-L2-01-01` 原始需求模糊，无法形成可研究或可行动的问题
- `P-L2-01-02` 问题定义错误，后续努力可能高质量地解决错误问题
- `P-L2-01-03` 多个不同问题混杂在同一表达中
- `P-L2-01-04` 表面问题与真正根因不同
- `P-L2-01-05` 目标不明确，无法判断知识活动服务于什么结果
- `P-L2-01-06` 问题范围过大或过小
- `P-L2-01-07` 成功标准不清，无法判断何时算解决
- `P-L2-01-08` 需求随研究、执行或环境变化，但问题定义没有同步更新

### P-L1-02 知识需求识别

- `P-L2-02-01` 不知道为解决当前问题需要知道什么
- `P-L2-02-02` 已知、未知、误解与不确定性边界不清
- `P-L2-02-03` 前置知识缺失，却没有被识别出来
- `P-L2-02-04` 核心知识与辅助知识混杂
- `P-L2-02-05` 理论、方法、案例、数据等不同知识需求混杂
- `P-L2-02-06` 信息需求与能力需求混杂
- `P-L2-02-07` 当前必须知道与未来可能有用的知识混杂
- `P-L2-02-08` 为当前任务所需的知识深度不明确
- `P-L2-02-09` 不知道当前真正需要的是答案、解释、判断标准、方法、案例、练习还是反馈

### P-L1-03 来源发现与资料获取

- `P-L2-03-01` 不知道应该去哪里找
- `P-L2-03-02` 不知道当前问题适合哪一类来源
- `P-L2-03-03` 搜索结果过多，无法形成可处理候选集
- `P-L2-03-04` 搜索结果不足，关键问题仍缺少来源支持
- `P-L2-03-05` 用户词汇与专业概念不一致，导致发现失败
- `P-L2-03-06` 关键、高价值或权威资料难以发现
- `P-L2-03-07` 一手资料与二手资料混杂，难以确定应回到哪里核对
- `P-L2-03-08` 资料获取成本过高、受限或不可访问

### P-L1-04 资料筛选、阅读优先级与处理深度

- `P-L2-04-01` 标题相关但正文与当前问题低相关
- `P-L2-04-02` 一份资料只有部分内容有价值，却被整体处理
- `P-L2-04-03` 热门度被误当成资料质量
- `P-L2-04-04` 权威性被误当成当前适用性
- `P-L2-04-05` 资料质量高但与当前问题低相关
- `P-L2-04-06` 整体质量较低的资料仍可能包含独特增量，难以取舍
- `P-L2-04-07` 单份资料的阅读/处理成本与预期收益不匹配
- `P-L2-04-08` 不知道候选资料应该先读什么、后读什么
- `P-L2-04-09` 不知道一份资料应该跳过、浏览、局部阅读还是深读
- `P-L2-04-10` 候选资料持续积压，但局部优先级长期不清
- `P-L2-04-11` 不同资料类型或用途需要不同处理深度，却被统一处理
- `P-L2-04-12` 不知道何时应该跳过低价值章节、段落或重复内容

### P-L1-05 知识重复与等价

- `P-L2-05-01` 多个来源反复讲相同原则，却被当成多份新知识
- `P-L2-05-02` 同一知识只是换一种表达，却被误判为不同知识
- `P-L2-05-03` 同一模型使用不同名称，难以识别其等价关系
- `P-L2-05-04` 相同原理只是更换说明性案例，却被误判为知识新增
- `P-L2-05-05` 内容大量扩写但没有实质新增
- `P-L2-05-06` 摘要、改写、转载造成伪新增
- `P-L2-05-07` 名称相同但实际含义不同，容易发生错误合并
- `P-L2-05-08` 一份材料部分重复、部分新增，无法简单整体判定

### P-L1-06 知识增量与补充

> 本组原先大量条目只是“增量类型名称”。现已净化为“无法正确识别或评价该类增量”的问题表达。

- `P-L2-06-01` 新概念看似新增，但无法判断是否只是别名、重命名或重新包装
- `P-L2-06-02` 新机制看似新增，但无法判断是否真正提供新的解释结构
- `P-L2-06-03` 新原因或解释看似不同，但无法判断是否只是已有机制的换角度重述
- `P-L2-06-04` 新步骤出现时，无法判断它是否真正改变方法还是仅属实现细节
- `P-L2-06-05` 新方法出现时，无法判断它是否带来新的适用范围、效果或决策价值
- `P-L2-06-06` 新适用条件出现时，没有被识别为重要知识增量
- `P-L2-06-07` 新边界、限制或例外出现时，没有被识别为重要知识增量
- `P-L2-06-08` 新案例、反例或证据出现时，无法区分说明性重复、迁移增量与证据增量
- `P-L2-06-09` 内容更细时，无法判断是有价值细化还是低价值展开
- `P-L2-06-10` 已知知识形成新组合、模型或结构时，无法判断是否产生了新的可用知识

### P-L1-07 知识关系与结构

- `P-L2-07-01` 上位—下位关系不清
- `P-L2-07-02` 部分—整体关系不清
- `P-L2-07-03` 原因—结果关系不清
- `P-L2-07-04` 前提—结论关系不清
- `P-L2-07-05` 问题—方法关系不清
- `P-L2-07-06` 方法—步骤关系不清
- `P-L2-07-07` 原理—应用关系不清
- `P-L2-07-08` 理论—案例关系不清
- `P-L2-07-09` 依赖与前置关系不清
- `P-L2-07-10` 替代、补充与组合关系不清
- `P-L2-07-11` 作者显式目录结构与实际讨论的知识结构不一致
- `P-L2-07-12` 局部内容可理解，但跨章节/跨资料无法形成整体知识结构

### P-L1-08 冲突、条件与边界

- `P-L2-08-01` 多个来源结论直接冲突
- `P-L2-08-02` 表面冲突但成立条件不同
- `P-L2-08-03` 场景不同导致结论不同
- `P-L2-08-04` 人群/主体不同导致结论不同
- `P-L2-08-05` 时间不同导致结论不同
- `P-L2-08-06` 隐含前提没有显式表达
- `P-L2-08-07` 方法存在适用边界但边界不清
- `P-L2-08-08` 例外情况被忽略
- `P-L2-08-09` 反例削弱或推翻原结论，但没有被正确纳入判断
- `P-L2-08-10` 当前证据不足以判定谁正确，却被迫生成单一确定答案

### P-L1-09 来源、证据与可信度

- `P-L2-09-01` 找不到原始来源
- `P-L2-09-02` 大量来源实际来自同一个源头，却被误认为独立支持
- `P-L2-09-03` 多次转述造成信息失真
- `P-L2-09-04` 作者观点被误当成事实
- `P-L2-09-05` 个别案例被误当成普遍规律
- `P-L2-09-06` 相关性被误认为因果
- `P-L2-09-07` 单一证据被过度推广
- `P-L2-09-08` 不同来源的证据质量差异巨大，却被等权处理
- `P-L2-09-09` 专家或研究之间存在真实争议，却无法合理保留不确定性
- `P-L2-09-10` 新证据出现后，无法判断其是否足以支持、削弱、升级或推翻旧结论
- `P-L2-09-11` AI 或二次解释引入原始来源未支持的内容
- `P-L2-09-12` 引用/出处存在但与实际主张不匹配
- `P-L2-09-13` 流畅表达、权威身份或确定语气造成过度信任
- `P-L2-09-14` 原始事实、作者观点、用户理解与 AI 推断被混合表达

### P-L1-10 时间、版本与知识失效

- `P-L2-10-01` 无法识别内容是否已经过时或失效
- `P-L2-10-02` 无法判断新版本是否真正替代旧版本
- `P-L2-10-03` 无法判断新旧版本是修订、补充、并行有效还是替代
- `P-L2-10-04` 规则、政策、技术或环境发生变化后，不知道哪些知识对象受影响
- `P-L2-10-05` 无法识别结论只在特定时期或时间窗口有效
- `P-L2-10-06` 已失效知识仍被继续采用或传播
- `P-L2-10-07` 无法确定当前有效版本
- `P-L2-10-08` 无法识别版本变化具体改了什么、哪些内容仍有效

### P-L1-11 知识整理、多来源综合与压缩

- `P-L2-11-01` 大量资料知识密度低，重点难以显现
- `P-L2-11-02` 核心原则被大量案例和叙述淹没
- `P-L2-11-03` 多来源难以综合成既统一又不抹平差异的结构
- `P-L2-11-04` 不同作者使用不同术语体系，综合后难以形成稳定表达
- `P-L2-11-05` 不知道哪些内容应该保留
- `P-L2-11-06` 压缩时丢失重要条件、边界或证据
- `P-L2-11-07` 摘要看似正确但无法支持后续判断或行动
- `P-L2-11-08` 整理结果信息很多，但没有形成可理解、可导航的外部模型
- `P-L2-11-09` 综合后仍无法显式看见当前关键知识缺口
- `P-L2-11-10` 综合输出无法说明其覆盖范围、剩余不确定性与尚未解决的问题
- `P-L2-11-11` 笔记/记录/知识单元粒度过细或过粗，后续难以理解和再使用
- `P-L2-11-12` 原文、作者观点、个人理解和后续推断混在同一记录中
- `P-L2-11-13` 笔记或整理结果长期不可检索、不可理解或从未再次使用
- `P-L2-11-14` 单资料/单书笔记形成孤岛，跨资料无法关联
- `P-L2-11-15` 摘要或结构重组破坏作者原意、原始结构或来源可追溯性
- `P-L2-11-16` AI 压缩遗漏关键差异、条件或边界，但用户难以及时发现

### P-L1-12 主体价值与知识优先级

> 本组不再把“高价值/低价值”本身当问题，而描述价值判断为什么困难或失败。

- `P-L2-12-01` 知识质量高，但无法判断它对当前问题是否真正相关
- `P-L2-12-02` 知识有价值，但无法判断应现在投入还是延后
- `P-L2-12-03` 无法平衡当前重要性与长期价值
- `P-L2-12-04` 长期价值高但投入成本也高，无法判断是否值得当前投入
- `P-L2-12-05` 通用知识与场景知识的价值边界难以比较
- `P-L2-12-06` 同一知识对不同主体价值不同，却被统一排序
- `P-L2-12-07` 目标和阶段变化后，知识价值与优先级没有及时重排
- `P-L2-12-08` 不知道哪些知识值得优先投入

### P-L1-13 理解、记忆、掌握与迁移

> `知道存在 / 理解 / 主动提取 / 判断 / 应用 / 熟练` 是掌握深度值，不单独因为“是一个状态”成为问题。本组保留的是**无法正确决定目标深度**或**无法达到目标深度**的稳定问题。

- `P-L2-13-01` 不知道哪些知识只需知道其存在，不应继续深学
- `P-L2-13-02` 不知道哪些知识理解即可，无需长期记忆
- `P-L2-13-03` 不知道哪些知识必须形成主动提取能力
- `P-L2-13-04` 不知道哪些知识必须形成独立辨别与判断能力
- `P-L2-13-05` 不知道哪些知识必须达到实际应用水平
- `P-L2-13-06` 不知道哪些知识必须通过反复练习形成稳定技能
- `P-L2-13-07` 知道或理解了知识，但实际不会使用
- `P-L2-13-08` 会在原场景使用，但不能迁移到新场景
- `P-L2-13-09` 已经掌握却仍在重复学习
- `P-L2-13-10` 无法判断当前掌握水平与目标掌握深度之间的真实差距
- `P-L2-13-11` 局部理解但没有形成可解释整体的内部结构模型
- `P-L2-13-12` 认知负荷过高，导致阅读、理解或学习效率显著下降
- `P-L2-13-13` 阅读/学习/研究中断后难以恢复上下文、进度和未决问题
- `P-L2-13-14` 熟悉感或看懂答案被误认为真正掌握
- `P-L2-13-15` 已学知识在需要时无法主动提取
- `P-L2-13-16` 不知道应该复习什么、何时复习或何时降低复习频率
- `P-L2-13-17` 缺少练习、反馈或真实任务检验，理解停留在表面
- `P-L2-13-18` 能解释或复述知识，但不能独立辨别、判断和选择
- `P-L2-13-19` AI 长期替代解释、回忆或判断，导致关键人工理解与掌握能力退化

### P-L1-14 知识到判断、决策与行动

- `P-L2-14-01` 知识无法转成现实方案
- `P-L2-14-02` 方法无法转成可执行步骤
- `P-L2-14-03` 多种方法之间无法选择
- `P-L2-14-04` 缺少方法选择条件
- `P-L2-14-05` 缺少执行前提或资源条件
- `P-L2-14-06` 理论在现实场景中因条件不匹配而失效
- `P-L2-14-07` 执行结果缺少可验证的成功标准或反馈
- `P-L2-14-08` 执行失败后不知道如何调整当前方案
- `P-L2-14-09` 在新场景中已识别到相关知识，却仍无法转成适合该场景的方案或行动
- `P-L2-14-10` 知识投入没有真正产生预期结果或能力变化
- `P-L2-14-11` 无法识别什么时候应该调用某项知识、原则或方法
- `P-L2-14-12` 执行失败时无法区分方法错误、条件不匹配、资源不足与执行偏差
- `P-L2-14-13` 行动产生副作用、二阶结果或新的约束后，不知道应继续、修正、降级还是停止
- `P-L2-14-14` 短期行为改变发生，但难以长期维持或形成稳定习惯

### P-L1-15 本人掌握、委托与监督边界

- `P-L2-15-01` 不清楚本人必须掌握到什么程度
- `P-L2-15-02` 不清楚随用随查或委托是否已经足够
- `P-L2-15-03` AI/工具能给结果，但本人缺少可靠验收能力
- `P-L2-15-04` 能力上可委托，但风险、隐私、版权、机密、权限或责任不允许
- `P-L2-15-05` 不知道成熟工具或专业服务是否比本人学习/亲自处理更划算
- `P-L2-15-06` 委托以后，不知道本人仍必须保留哪些理解、判断与验收能力
- `P-L2-15-07` 不知道哪些环节必须人工介入、复核或承担最终责任
- `P-L2-15-08` 过度委托导致关键人工判断或应急能力退化
- `P-L2-15-09` 人与 AI/工具/服务的分工边界随技术、目标或环境变化，需要重新判断

### P-L1-16 规模、注意力与研究停止

- `P-L2-16-01` 资料数量持续增长，人工无法全量阅读或处理
- `P-L2-16-02` 全量深度阅读、研究或整理所需时间与注意力超过可投入资源
- `P-L2-16-03` 新材料边际知识增量持续下降，但研究仍机械继续
- `P-L2-16-04` 重复阅读、重复研究或重复整理持续浪费时间
- `P-L2-16-05` 规模扩大后，无法把资料分成不同投入等级，仍逐份同等处理
- `P-L2-16-06` 不知道什么时候应该停止继续搜索
- `P-L2-16-07` 不知道什么时候应该停止继续阅读/分析
- `P-L2-16-08` 不知道什么变化出现后应该重新启动已经停止的研究
- `P-L2-16-09` 收藏、待读、待整理资料持续积压并失去控制
- `P-L2-16-10` 规模扩大后，人工浏览、定位和重新找到已有知识不可持续
- `P-L2-16-11` 不知道什么时候应从逐资料处理转向按问题、主题或知识差额处理

### P-L1-17 反馈、修正与长期再判断

- `P-L2-17-01` 不知道结果是否真正解决了原始用户问题
- `P-L2-17-02` 用户目标、约束或任务变化后，旧判断和优先级仍被沿用
- `P-L2-17-03` 新知识、新证据、新版本或环境变化后，已有结论没有被重新检查
- `P-L2-17-04` 实践反馈与原知识、条件或结论不一致后，不知道如何解释和修正
- `P-L2-17-05` 过去判断的依据、变化过程和失败原因无法恢复
- `P-L2-17-06` 发现关键错误或前提变化后，不知道哪些相关判断也需要一起重看
- `P-L2-17-07` 原本已解决的问题在条件变化后重新出现，却没有触发重新判断

| 容易混淆 | 主归属判断 |
| --- | --- |
| 01 vs 02 | 01 问“真正要解决什么”；02 问“为解决它需要知道什么” |
| 03 vs 04 | 03 问“能否发现/获得候选”；04 问“候选里哪些值得投入” |

| 05 vs 06 | 05 问“是不是同一个”；06 问“不是完全同一个时，真正多了什么” |
| 06 vs 09 | 06 判断内容/机制/条件等知识增量；09 判断独立证据与可信度增量 |
| 07 vs 11 | 07 是知识本身的语义关系与结构；11 是人或系统整理出来的外部表达、综合与压缩是否可用 |
| 11 vs 13 | 11 是外部知识产物是否可理解/可用；13 是人是否真正理解、记住、提取、判断和迁移 |
| 08 vs 09 | 08 判断条件、边界和冲突结构；09 判断支持这些主张的来源与证据是否可靠 |
| 09 vs 17 | 09 判断新证据本身意味着什么；17 判断已经存在的旧结论、优先级与行动是否需要重看 |
| 10 vs 17 | 10 识别版本、时间与失效事实；17 处理这些变化对既有判断和历史状态的后续影响 |
| 12 vs 04 | 12 判断知识对某主体/目标的价值；04 判断某一候选资料是否值得现在投入阅读/处理成本 |
| 13 vs 14 | 13 判断人是否形成能力与迁移；14 判断在一个现实任务中能否选择、调用、执行和调整 |

### 5.1 同一个现象为什么可以映射多个 P-L2

例如：

> “AI 总结一本书后漏掉了适用条件，我自己也没有发现。”

可以同时映射：

- `09-11`：AI 引入/遗漏造成来源忠实度问题；
- `11-16`：压缩遗漏关键边界；
- `15-03`：若用户因此没有能力验收 AI 结果。

但这不意味着三个 P-L2 是同义词。它们分别描述不同失效机制。

## 六、哪些旧候选不晋升为新 P-L2

对 `research-notes/2026-08-26_P-L2问题候选池与二次覆盖审计_V1.md` 的候选重新按当前 17 类审计后：

1. **知识拆太细/太粗、人工看不懂**：优先由 `11-08 / 11-11 / 13-11 / 13-12` 解释，不新增“知识粒度”一级问题。
2. **人和 AI 使用同一知识形式不合适**：这是消费与系统能力设计问题；用户后果可落 `11 / 13 / 15`，能力进入 `18 / 20`。
3. **AI 一次应该拿哪些、拿多少知识**：这是能力与运行质量问题；用户可感知后果保留在 P，检索/上下文选择能力进入 `20`，错误率与成本进入 `13 / 22`。
4. **20 万本书是否全部深加工**：用户侧“投入是否值得、何时停止”进入 `04 / 12 / 16`；模型、存储和处理成本不是新 P-L2。
5. **同一问题被反复发现、问题状态怎么保存、Problem Graph 怎么建**：属于问题实例治理、能力与实现设计，不新建 P-L1-18。
6. **解决方案制造新系统错误**：进入 `22`；若产生用户可感知的行动副作用，可由 `14-13 / 17` 解释。

因此本轮结论仍是：

> **不新增 P-L1；不恢复旧 P-L1-18；优先净化现有 P-L2，再用能力层承接系统性问题。**

## 九、需求属性维度

P-L1 / P-L2 回答“会遇到什么问题”。一条具体 Requirement 还需要通过需求属性描述：

- **目标用途**：当前解题、辅助决策、任务推进、项目推进、系统学习、能力形成、研究、探索未知、长期发展、未来备用；
- **时间时机**：立即、近期、当前阶段、下一阶段、未来、条件触发、暂无需求；
- **需求范围**：单点问题、主题、领域、项目、多领域、全局知识体系；
- **需求主体**：个人、AI、人+AI、团队、组织；
- **掌握深度**：知道存在、理解、主动提取、辨别、判断、应用、迁移、熟练；
- **期望结果**：答案、判断、决策、方案、行动、能力、知识体系、可调用能力、持续更新；
- **先验优先程度**：必须、重要、一般、低优先、暂缓、忽略；
- **需求周期**：一次性、短期持续、阶段持续、长期持续、周期复查；
- **触发来源**：问题、任务、项目、计划、目标、外部变化、兴趣探索、系统主动发现。

一条真实需求通常由多个属性组合，而不是落入一个互斥类别。
