# 需求宇宙

> 本文件只描述需求空间，不预设 ES、RAG、Skill、Wiki、知识图谱等解决方案。

## 一、L2 二级维度

- **目标用途**：当前解题、辅助决策、任务推进、项目推进、系统学习、能力形成、研究、探索未知、长期发展、未来备用。
- **时间时机**：立即、近期、当前阶段、下一阶段、未来、条件触发、暂无需求。
- **需求范围**：单点问题、主题、领域、项目、多领域、全局知识体系。
- **需求主体**：个人、AI、人+AI、团队、组织。
- **掌握深度**：知道存在、理解、辨别、判断、应用、迁移、熟练。
- **期望结果**：答案、判断、决策、方案、行动、能力、知识体系、可调用能力、持续更新。
- **优先程度**：必须、重要、一般、低优先、暂缓、忽略。
- **需求周期**：一次性、短期持续、阶段持续、长期持续、周期复查。
- **触发来源**：问题、任务、项目、计划、目标、外部变化、兴趣探索、系统主动发现。

## 二、需求组合原则

一条真实需求通常由多个维度组合，而不是落入一个互斥分类。

例如“半年后可能进入某领域，现在不用学”应表示为：

- 目标用途：未来项目准备；
- 时间时机：未来／条件触发；
- 优先程度：暂缓；
- 掌握深度：未确定；
- 当前动作：不占用人工注意力。

因此“延迟学习”不是一级需求，而是多个需求属性的组合状态。

## 三、需求宇宙的完整性检查

一级框架至少覆盖以下问题：

- 为什么需要这项知识；
- 谁需要；
- 什么时候需要；
- 需要多大范围；
- 要掌握到什么深度；
- 希望产生什么结果；
- 值不值得现在投入；
- 由什么事件触发；
- 需求持续多久。

后续扩展应优先增加 L3 细化或新增组合案例；只有现有 L2 无法表达新的独立需求轴时，才新增 L2。
