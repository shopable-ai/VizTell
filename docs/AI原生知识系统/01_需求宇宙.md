# 需求宇宙：专业问题分类与 P-L1 / P-L2 事实源

> 本文件是 AI 原生知识系统的**专业问题宇宙（Problem Taxonomy）事实源**。
>
> 用户什么时候遇到什么问题、会怎样描述，由 `01A_用户旅程、需求与高频问题现象宇宙.md` 承载；大量用户原话如何形成稳定标准用户问题并映射到本文件，由 `01B_标准用户问题与专业问题映射.md` 承载。
>
> 本文件只保存**问题空间**。Search、RAG、Skill、Workflow、Agent、Software 等实现载体不属于 P-L1 / P-L2；系统去重错误、路由错误、模型成本等也不属于用户专业问题分类。

---

# 一、核心定位

AI 原生知识系统的上游正式采用：

```text
人的真实目标
→ 用户需求
→ 用户旅程与真实场景（01A）
→ 用户原话问题
→ 标准用户问题（01B）
→ 专业问题 P-L1 / P-L2（本文件）
→ 知识与评价空间
→ 系统能力
→ 验证
→ 解决方案与实现
→ 用户结果
```

本文件回答：

> **大量具体用户问题，从专业问题空间看，属于哪些稳定、可复用、跨场景的问题类别？**

## 1.1 本轮重构原则

1. **用户问题与解决方案彻底分开。** 实现方式不再占用 P-L1 编号。
2. **用户问题与系统错误彻底分开。** false merge、错误路由、模型成本、Agent 过度使用等进入 `13 / 19 / 22`。
3. **不为历史编号保留错误边界。** 当前仍处于框架推理与正式化阶段，没有稳定外部接口需要兼容，因此允许重编号。
4. **活动名称不等于一级问题。** 阅读、笔记、记忆、AI 使用可以跨多个 P-L1。
5. **一个 SUP 可以映射多个 P-L1 / P-L2。** 不要求互斥。
6. **P-L1 只保存相对稳定的用户/知识使用问题域。** 技术路线、组件状态、Benchmark Error Taxonomy 后置。

# 二、编号规则

- `P-L1-xx`：一级专业问题空间；
- `P-L2-xx-yy`：对应一级空间下的稳定二级问题。

当前正式范围为：

> **P-L1-01 ～ P-L1-17，共 17 个一级问题空间。**

本轮正式删除原 `P-L1-16 能力化与实现载体选择`；原规模类重新编号为 `P-L1-16`，原反馈类净化后重新编号为 `P-L1-17`。

历史 Research Note 中出现的旧编号仅用于追溯，不构成兼容要求。

# 三、P-L1 一级问题空间总表

| 编号 | 一级问题空间 | 人话核心问题 | 边界 |
| --- | --- | --- | --- |
| P-L1-01 | 用户需求与真实问题 | 用户真正要解决什么？ | 目标、问题定义、范围、成功标准 |
| P-L1-02 | 知识需求识别 | 为解决问题究竟需要知道什么？ | 已知/未知、前置、知识类型与深度 |
| P-L1-03 | 来源发现与资料获取 | 应该去哪里找、找什么资料？ | 来源发现与可获得性 |
| P-L1-04 | 资料筛选、阅读优先级与处理深度 | 哪些值得先处理、处理到多深？ | 资料级投入判断 |
| P-L1-05 | 知识重复与等价 | 哪些其实是同一知识？ | 重复、改写、异名同义、同名异义 |
| P-L1-06 | 知识增量与补充 | 新材料真正增加了什么？ | 真正新增与边际知识价值 |
| P-L1-07 | 知识关系与结构 | 这些知识彼此什么关系、怎样形成整体？ | 结构、依赖、因果、层级与组合 |
| P-L1-08 | 冲突、条件与边界 | 为什么说法不同，什么时候成立？ | 条件、例外、反例、真实冲突 |
| P-L1-09 | 来源、证据与可信度 | 为什么相信它？ | 来源忠实度、证据、独立性与不确定性 |
| P-L1-10 | 时间、版本与知识失效 | 现在还有效吗？ | 时效、版本、替代与失效 |
| P-L1-11 | 知识整理、多来源综合与压缩 | 怎样留下高密度、以后还能用的知识？ | 提取、笔记、综合、压缩、回源与再利用 |
| P-L1-12 | 主体价值与知识优先级 | 哪些知识对当前用户真正重要？ | 个人/目标/项目相关性与机会成本 |
| P-L1-13 | 理解、记忆、掌握与迁移 | 怎样从“看过”走到“真的会”？ | 理解、提取、练习、反馈、判断与迁移 |
| P-L1-14 | 知识到判断、决策与行动 | 怎样把知道转成现实结果？ | 方法选择、调用、执行、验证与失败诊断 |
| P-L1-15 | 本人掌握、委托与监督边界 | 哪些必须本人掌握，哪些可以查询或委托？ | 人/AI/工具/服务的能力归属、监督与责任 |
| P-L1-16 | 规模、注意力与研究停止 | 资料越来越多以后，怎样避免失控并知道何时够了？ | 人工注意力、边际增量、停止与重启 |
| P-L1-17 | 反馈、修正与长期再判断 | 结果、目标或环境变化后，哪些旧判断要改？ | 用户结果、实践反馈、变化传播与历史恢复 |

## 3.1 一级空间审计结论

当前不新增新的 P-L1。

原因是：现有 17 个空间已经能覆盖单书、多书、领域级、海量和长期使用中的主要稳定用户问题。后续若出现团队/组织共同学习、无障碍与特殊认知需求等独立且大规模的问题域，再单独审计，而不是为了完整感提前创建分类。

# 四、P-L2 二级问题维度

## P-L1-01 用户需求与真实问题

- `P-L2-01-01` 原始需求模糊
- `P-L2-01-02` 问题定义错误
- `P-L2-01-03` 多个问题混杂
- `P-L2-01-04` 表面问题与根因不同
- `P-L2-01-05` 目标不明确
- `P-L2-01-06` 范围过大或过小
- `P-L2-01-07` 成功标准不清
- `P-L2-01-08` 需求随研究、执行或环境变化

## P-L1-02 知识需求识别

- `P-L2-02-01` 不知道需要知道什么
- `P-L2-02-02` 已知与未知不清
- `P-L2-02-03` 前置知识缺失
- `P-L2-02-04` 核心知识与辅助知识混杂
- `P-L2-02-05` 理论、方法、案例、数据需求混杂
- `P-L2-02-06` 信息需求与能力需求混杂
- `P-L2-02-07` 当前需求与未来需求混杂
- `P-L2-02-08` 所需知识深度不明确
- `P-L2-02-09` 不知道当前真正需要的是答案、解释、判断标准、方法、案例、练习还是反馈

## P-L1-03 来源发现与资料获取

- `P-L2-03-01` 不知道去哪里找
- `P-L2-03-02` 来源类型选择错误
- `P-L2-03-03` 搜索结果过多
- `P-L2-03-04` 搜索结果不足
- `P-L2-03-05` 用户词汇与专业概念不一致
- `P-L2-03-06` 重要资料难以发现
- `P-L2-03-07` 一手资料与二手资料混杂
- `P-L2-03-08` 资料获取成本过高或不可访问

## P-L1-04 资料筛选、阅读优先级与处理深度

- `P-L2-04-01` 标题相关但正文无关
- `P-L2-04-02` 一份资料只有部分内容有价值
- `P-L2-04-03` 热门不等于高质量
- `P-L2-04-04` 权威不等于适合当前需求
- `P-L2-04-05` 高质量但低相关
- `P-L2-04-06` 低质量资料可能包含独特增量
- `P-L2-04-07` 阅读／处理成本与收益不匹配
- `P-L2-04-08` 不知道先读什么、后读什么
- `P-L2-04-09` 不知道资料应该浏览、局部阅读还是深读
- `P-L2-04-10` 收藏、待读与候选资料持续积压但优先级不清
- `P-L2-04-11` 不同资料类型需要不同处理深度却被统一处理
- `P-L2-04-12` 不知道何时应该跳过低价值章节、段落或重复内容

## P-L1-05 知识重复与等价

- `P-L2-05-01` 多个来源反复讲相同原则
- `P-L2-05-02` 同一知识只是换一种表达
- `P-L2-05-03` 同一模型使用不同名称
- `P-L2-05-04` 相同原理只是换了案例
- `P-L2-05-05` 内容大量扩写但没有实质新增
- `P-L2-05-06` 摘要、改写、转载造成伪新增
- `P-L2-05-07` 名称相同但实际含义不同
- `P-L2-05-08` 部分重复、部分新增，难以整体判断

## P-L1-06 知识增量与补充

- `P-L2-06-01` 增加新概念
- `P-L2-06-02` 增加新机制
- `P-L2-06-03` 增加新原因或解释
- `P-L2-06-04` 增加新步骤
- `P-L2-06-05` 增加新方法
- `P-L2-06-06` 增加适用条件
- `P-L2-06-07` 增加边界、限制或例外
- `P-L2-06-08` 增加案例、反例或证据
- `P-L2-06-09` 对已有知识进行有效细化
- `P-L2-06-10` 形成新的组合、模型或知识结构

## P-L1-07 知识关系与结构

- `P-L2-07-01` 上位—下位关系不清
- `P-L2-07-02` 部分—整体关系不清
- `P-L2-07-03` 原因—结果关系不清
- `P-L2-07-04` 前提—结论关系不清
- `P-L2-07-05` 问题—方法关系不清
- `P-L2-07-06` 方法—步骤关系不清
- `P-L2-07-07` 原理—应用关系不清
- `P-L2-07-08` 理论—案例关系不清
- `P-L2-07-09` 依赖与前置关系不清
- `P-L2-07-10` 替代、补充与组合关系不清
- `P-L2-07-11` 作者显式目录结构与实际讨论的知识结构不一致
- `P-L2-07-12` 局部内容可理解，但跨章节／跨资料无法形成整体结构

## P-L1-08 冲突、条件与边界

- `P-L2-08-01` 多个来源结论直接冲突
- `P-L2-08-02` 表面冲突但成立条件不同
- `P-L2-08-03` 场景不同导致结论不同
- `P-L2-08-04` 人群／主体不同导致结论不同
- `P-L2-08-05` 时间不同导致结论不同
- `P-L2-08-06` 隐含前提没有显式表达
- `P-L2-08-07` 方法存在适用边界
- `P-L2-08-08` 例外情况被忽略
- `P-L2-08-09` 反例削弱或推翻原结论
- `P-L2-08-10` 当前证据不足以判定谁正确

## P-L1-09 来源、证据与可信度

- `P-L2-09-01` 找不到原始来源
- `P-L2-09-02` 大量来源实际来自同一个源头
- `P-L2-09-03` 多次转述造成信息失真
- `P-L2-09-04` 作者观点被误当成事实
- `P-L2-09-05` 个别案例被误当成普遍规律
- `P-L2-09-06` 相关性被误认为因果
- `P-L2-09-07` 单一证据被过度推广
- `P-L2-09-08` 不同来源的证据质量差异巨大
- `P-L2-09-09` 专家或研究之间存在真实争议
- `P-L2-09-10` 新证据改变或推翻旧判断
- `P-L2-09-11` AI 或二次解释引入原始来源未支持的内容
- `P-L2-09-12` 引用／出处存在但与实际主张不匹配
- `P-L2-09-13` 流畅表达、权威身份或确定语气造成过度信任
- `P-L2-09-14` 原始事实、作者观点、用户理解与 AI 推断被混合表达

## P-L1-10 时间、版本与知识失效

- `P-L2-10-01` 内容已经过时
- `P-L2-10-02` 新版本替代旧版本
- `P-L2-10-03` 新旧版本只是修订而非替代
- `P-L2-10-04` 规则、政策、技术或环境发生变化
- `P-L2-10-05` 结论只在特定时期有效
- `P-L2-10-06` 失效知识仍在大量传播
- `P-L2-10-07` 无法确定当前有效版本
- `P-L2-10-08` 知识更新后影响范围不清

## P-L1-11 知识整理、多来源综合与压缩

- `P-L2-11-01` 大量资料知识密度低
- `P-L2-11-02` 核心原则被大量案例和叙述淹没
- `P-L2-11-03` 多来源难以形成统一结构
- `P-L2-11-04` 不同作者使用不同术语体系
- `P-L2-11-05` 不知道哪些内容应该保留
- `P-L2-11-06` 压缩时丢失重要条件、边界或证据
- `P-L2-11-07` 摘要看似正确但无法支持判断或行动
- `P-L2-11-08` 信息很多但没有形成可理解模型
- `P-L2-11-09` 不知道当前仍缺哪些关键知识
- `P-L2-11-10` 不知道什么时候已经研究充分
- `P-L2-11-11` 笔记／记录粒度过细或过粗，后续难以再使用
- `P-L2-11-12` 原文、作者观点、个人理解和后续推断混在同一记录中
- `P-L2-11-13` 笔记或整理结果长期不可检索、不可理解或从未再次使用
- `P-L2-11-14` 单资料／单书笔记形成孤岛，跨资料无法关联
- `P-L2-11-15` 摘要或结构重组破坏作者原意、原始结构或来源可追溯性
- `P-L2-11-16` AI 压缩遗漏关键差异、条件或边界，但用户难以及时发现

## P-L1-12 主体价值与知识优先级

- `P-L2-12-01` 知识正确但与当前问题无关
- `P-L2-12-02` 有价值但当前无需使用
- `P-L2-12-03` 当前重要但长期价值低
- `P-L2-12-04` 长期高价值但投入成本高
- `P-L2-12-05` 通用知识与场景知识价值不同
- `P-L2-12-06` 同一知识对不同主体价值不同
- `P-L2-12-07` 知识价值随目标和阶段变化
- `P-L2-12-08` 不知道哪些知识值得优先投入

## P-L1-13 理解、记忆、掌握与迁移

- `P-L2-13-01` 只需要知道其存在
- `P-L2-13-02` 需要理解但无需记忆
- `P-L2-13-03` 需要主动记忆和提取
- `P-L2-13-04` 需要形成辨别与判断能力
- `P-L2-13-05` 需要能够实际应用
- `P-L2-13-06` 需要反复练习形成技能
- `P-L2-13-07` 知道但不会使用
- `P-L2-13-08` 会使用但不能迁移到新场景
- `P-L2-13-09` 已经掌握却仍在重复学习
- `P-L2-13-10` 不知道应该学习到什么深度
- `P-L2-13-11` 局部理解但没有形成可解释整体的结构模型
- `P-L2-13-12` 认知负荷过高，导致阅读、理解或学习效率显著下降
- `P-L2-13-13` 阅读／学习／研究中断后难以恢复上下文、进度和未决问题
- `P-L2-13-14` 熟悉感或看懂答案被误认为真正掌握
- `P-L2-13-15` 已学知识在需要时无法主动提取
- `P-L2-13-16` 不知道应该复习什么、何时复习或何时降低复习频率
- `P-L2-13-17` 缺少练习、反馈或真实任务检验，理解停留在表面
- `P-L2-13-18` 能解释或复述知识，但不能独立辨别、判断和选择
- `P-L2-13-19` AI 长期替代解释、回忆或判断，导致关键人工理解与掌握能力退化

## P-L1-14 知识到判断、决策与行动

- `P-L2-14-01` 知识无法转成现实方案
- `P-L2-14-02` 方法无法转成可执行步骤
- `P-L2-14-03` 多种方法之间无法选择
- `P-L2-14-04` 缺少方法选择条件
- `P-L2-14-05` 缺少执行前提或资源条件
- `P-L2-14-06` 理论在现实场景中失效
- `P-L2-14-07` 执行结果无法验证
- `P-L2-14-08` 失败后不知道如何调整
- `P-L2-14-09` 无法迁移到新的问题和场景
- `P-L2-14-10` 知识没有真正产生结果或能力变化
- `P-L2-14-11` 无法识别什么时候应该调用某项知识、原则或方法
- `P-L2-14-12` 执行失败时无法区分方法错误、条件不匹配、资源不足与执行偏差
- `P-L2-14-13` 现实反馈与原知识不一致后，不知道应继续、修正、降级还是放弃原判断
- `P-L2-14-14` 短期行为改变发生，但难以长期维持或形成稳定习惯

## P-L1-15 本人掌握、委托与监督边界

- `P-L2-15-01` 不清楚本人必须掌握到什么程度
- `P-L2-15-02` 不清楚随用随查或委托是否已经足够
- `P-L2-15-03` AI／工具能给结果，但本人缺少可靠验收能力
- `P-L2-15-04` 能力上可委托，但风险、隐私、版权、机密、权限或责任不允许
- `P-L2-15-05` 不知道成熟工具或专业服务是否比本人学习／亲自处理更划算
- `P-L2-15-06` 委托以后，不知道本人仍必须保留哪些理解、判断与验收能力
- `P-L2-15-07` 不知道哪些环节必须人工介入、复核或承担最终责任
- `P-L2-15-08` 过度委托导致关键人工判断或应急能力退化
- `P-L2-15-09` 人与 AI／工具／服务的分工边界随技术、目标或环境变化，需要重新判断

## P-L1-16 规模、注意力与研究停止

- `P-L2-16-01` 资料数量持续增长，人工无法全量阅读或处理
- `P-L2-16-02` 全量深度阅读、研究或整理所需时间与注意力超过可投入资源
- `P-L2-16-03` 新材料大量重复，边际知识增量持续下降
- `P-L2-16-04` 重复阅读、重复研究或重复整理持续浪费时间
- `P-L2-16-05` 不知道何时只需粗筛／浏览，何时值得深读／深研
- `P-L2-16-06` 不知道什么时候应该停止继续搜索
- `P-L2-16-07` 不知道什么时候应该停止继续阅读／分析
- `P-L2-16-08` 不知道什么变化出现后应该重新启动已经停止的研究
- `P-L2-16-09` 收藏、待读、待整理资料持续积压并失去控制
- `P-L2-16-10` 规模扩大后，人工浏览、定位和重新找到已有知识不可持续
- `P-L2-16-11` 不知道什么时候应从逐资料处理转向按问题、主题或知识差额处理

## P-L1-17 反馈、修正与长期再判断

- `P-L2-17-01` 不知道结果是否真正解决了原始用户问题
- `P-L2-17-02` 用户目标、约束或任务变化后，旧判断和优先级仍被沿用
- `P-L2-17-03` 新知识、新证据、新版本或环境变化后，已有结论没有被重新检查
- `P-L2-17-04` 实践反馈与原知识、条件或结论不一致后，不知道如何解释和修正
- `P-L2-17-05` 过去判断的依据、变化过程和失败原因无法恢复
- `P-L2-17-06` 发现关键错误或前提变化后，不知道哪些相关判断也需要一起重看
- `P-L2-17-07` 原本已解决的问题在条件变化后重新出现，却没有触发重新判断

# 七、需求属性维度

P-L1 / P-L2 回答“会遇到什么问题”。一条具体 Requirement 还需要通过需求属性描述：

- **目标用途**：当前解题、辅助决策、任务推进、项目推进、系统学习、能力形成、研究、探索未知、长期发展、未来备用；
- **时间时机**：立即、近期、当前阶段、下一阶段、未来、条件触发、暂无需求；
- **需求范围**：单点问题、主题、领域、项目、多领域、全局知识体系；
- **需求主体**：个人、AI、人+AI、团队、组织；
- **掌握深度**：知道存在、理解、辨别、判断、应用、迁移、熟练；
- **期望结果**：答案、判断、决策、方案、行动、能力、知识体系、可调用能力、持续更新；
- **先验优先程度**：必须、重要、一般、低优先、暂缓、忽略；
- **需求周期**：一次性、短期持续、阶段持续、长期持续、周期复查；
- **触发来源**：问题、任务、项目、计划、目标、外部变化、兴趣探索、系统主动发现。

一条真实需求通常由多个属性组合，而不是落入一个互斥类别。
