# 知识关系、增量与去重

> 目标：面对海量资料，不只判断“相似不相似”，而是判断新内容相对于已有知识究竟增加了什么。

## 一、L2 二级维度

- **主体知识关系**：已知、部分已知、未知、误解、遗忘、已掌握。
- **库内知识关系**：完全重复、近似重复、改写、包含、被包含、补充、扩展、支持、冲突、反例、替代、无关。
- **依赖关系**：前置、后置、组成、因果、条件、互补、替代、派生。
- **增量类型**：新事实、新概念、新命题、新机制、新方法、新条件、新范围、新证据、新反例、新案例、新版本、新时效信息。
- **增量强度**：无增量、弱增量、中增量、强增量、改变模型／决策的关键增量。
- **知识饱和度**：某主题继续加入资料时的边际新增率是否持续下降。

## 二、七层去重判断

1. 文件完全重复；
2. 文本完全重复；
3. 文字近似重复；
4. 语义相似候选；
5. 命题关系判断；
6. 知识增量判断；
7. 对人／AI 的消费差额判断。

语义相似只负责召回候选，不直接授权删除、合并或替代。

## 三、真正重要的增量

海量知识处理优先保留：**新机制、新边界、新条件、新证据、新反例、新版本，以及足以改变判断、行动或项目决策的信息**。单纯换例子、换术语、增加叙事长度，不应自动等价于高知识增量。

## 四、后续 L3 展开方向

- 同义概念归一；
- 命题标准化；
- 冲突类型：事实冲突、条件冲突、定义冲突、价值冲突、时效冲突；
- 替代类型：完全替代、局部替代、版本替代、场景替代；
- 饱和指标：新增节点率、新增机制率、新增边界率、新增证据率、单位 Token 增量。
