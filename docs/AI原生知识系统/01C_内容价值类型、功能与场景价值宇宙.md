# 内容价值类型、功能与场景价值宇宙

> 状态：正式上游内容价值视图。
>
> 本文件回答：**一段内容究竟在提供什么价值；这种价值对谁、在什么目标、角色、场景和时期成立；它是不是被错误地当成了知识价值。**
>
> 本文件不负责判断具体 Claim 真伪，不替代 `03_来源证据与可信度.md`；不负责最终学习/忽略路由，不替代 `18_知识价值、学习投入与消费路由.md`。

---

## 一、核心原则

1. **内容价值 ≠ 知识价值。** 文学、审美、叙事、情绪、意义、文化、娱乐都可能有真实价值。
2. **非知识内容 ≠ 无价值内容。** 问题在于它是否与当前目标匹配，以及是否冒充事实、规律、证据或方法。
3. **价值不是内容的绝对属性。** 应至少按“内容 × 主体 × 目标 × 角色 × 场景 × 阶段 × 时间 × 风险 × 替代方案”判断。
4. **同一内容可以同时有多种价值。** 例如一篇文章可以同时具有文学价值、共鸣价值和少量知识价值。
5. **同一内容对不同主体价值可以相反。** 对作者有传播/商业价值，不代表对读者有知识价值；对个人局部有利，不代表对团队或社会整体有利。
6. **真实性与有用性分开。** 真实但无关，不值得当前投入；有用但证据弱，不能自动当成事实执行。
7. **描述价值与行动推荐价值分开。** 一种权术可能真实存在、值得识别，但不等于值得内化为推荐行为。
8. **历史价值与当前行动价值分开。** 旧制度、宗教、思想、管理方式可以有历史解释价值，但不能因此直接升级为当前最佳实践。

## 三、价值受益者必须分开

同一内容至少分别判断：

- **阅读者/学习者价值**：理解、判断、行动、情绪、娱乐等；
- **作者/生产者价值**：表达、影响力、声誉、商业收益；
- **传播者/平台价值**：流量、停留、互动、网络效应；
- **组织价值**：协调、规范、控制、激励、文化；
- **交易方价值**：销售、议价、转化、信息优势；
- **共同体价值**：身份、秩序、互助、共享意义；
- **社会整体价值**：信任、公共秩序、创新、知识进步或负外部性。

禁止把“对传播者很值钱”写成“对读者很有知识价值”。

## 四、场景价值判断轴

一段内容的实际价值至少同时看：

1. **主体是谁**：个人、工程师、销售、管理者、研究者、创作者、团队、组织；
2. **当前目标是什么**：解决故障、学习技术、销售转化、情绪支持、文学欣赏、文化理解等；
3. **角色是什么**：执行者、决策者、监督者、被影响者、传播者；
4. **任务阶段是什么**：发现问题、诊断、选择方案、执行、复盘、恢复；
5. **场景是什么**：技术、商业、组织、亲密关系、教育、创作、公共传播等；
6. **时间与时代是什么**：历史时期、当前版本、未来触发条件；
7. **风险是什么**：错误是否可逆、是否会伤害他人或系统；
8. **替代方案是什么**：是否已有更可靠、更短、更便宜的资料、AI、工具或专业服务；
9. **投入成本是什么**：阅读、理解、记忆、练习、维护成本；
10. **谁获得收益、谁承担成本**：防止局部收益掩盖整体损失。

## 五、同一内容跨场景价值示例

| 内容 | 场景 | 主要价值判断 |
| --- | --- | --- |
| 情绪共鸣文章 | 软件故障排查 | 低任务价值，不能替代日志、证据和机制分析 |
| 情绪共鸣文章 | 团队成员情绪失控 | 可能先有较高情绪支持价值，再进入事实解决 |
| 情绪共鸣文章 | 销售/品牌内容 | 可能有较高传播、关系和转化价值 |
| 文学性强的故事 | 学习算法 | 通常低直接知识价值，除非作为教学类比 |
| 文学性强的故事 | 文学欣赏/写作训练 | 可能是核心价值 |
| 权术案例 | 组织管理最佳实践 | 可能行动推荐价值低甚至有害 |
| 权术案例 | 风险识别/反操控训练 | 可能有较高防御价值 |
| 旧管理制度 | 当前软件团队实践 | 需重新验证适用边界 |
| 旧管理制度 | 组织史研究 | 可能有较高历史解释价值 |

## 六、内容价值类型错位

以下不是“内容必然无价值”，而是**价值类型与使用目的错位**：

- 文学表达冒充事实证据；
- 比喻冒充机制；
- 共鸣冒充正确性；
- 安慰冒充问题解决；
- 激励冒充方法；
- 娱乐冒充学习；
- 历史事实冒充当前最佳实践；
- 文化传统冒充自然规律；
- 道德规范冒充经验性事实；
- 商业传播效果冒充知识质量；
- 组织控制价值冒充成员个人价值；
- 对作者有变现价值冒充对读者有学习价值。

详细失效现象见 `01D_无效阅读、低价值、伪知识、认知误导与有害信息现象宇宙.md`。

## 七、多角度价值审查

面对争议内容，不直接问“有价值还是没价值”，依次区分：

### 7.1 知识角度

- 它提出了什么可明确表达的 Claim？
- 是事实、机制、方法、观点、规范、比喻还是故事？
- 如果声称描述现实，证据如何？

### 7.2 使用角度

- 对当前主体和目标有没有直接帮助？
- 应该知道、理解、判断、执行，还是仅作为参考？

### 7.3 历史与文化角度

- 在当时的技术、制度、知识条件下，它承担了什么功能？
- 今天是否仍成立，还是只剩历史解释价值？

### 7.4 组织与制度角度

- 是否帮助形成规则、协调、共同身份和秩序？
- 是否同时产生控制、排他、权力集中或其他副作用？

### 7.5 经济与传播角度

- 谁因传播获得注意力、声誉、收入、议价权或控制力？
- 高传播/高变现是否与高真实性、高读者价值一致？不能默认一致。

### 7.6 外部性角度

- 对个人有利时，对团队、交易对手、组织、社会是否产生负外部性？
- 如果所有人都采用这种策略，系统会变好还是变坏？

## 八、宗教、神学与类似内容的正式边界

宗教、神学、传统思想不能被简单标记为“科学知识”，也不能被简单标记为“无价值”。至少拆成：

1. **经验事实主张**：涉及现实世界可验证事实时，进入 `03` 的证据与可信度审查；
2. **形而上/教义主张**：与可经验验证的科学命题分开，不伪装成同一验证路径；
3. **伦理与规范内容**：评价其价值主张、行为约束、后果与适用边界；
4. **意义与精神支持**：可能具有意义、希望、情绪支持和共同体价值；
5. **仪式与共同体功能**：可能形成身份、互助、秩序、协调与社会关系；
6. **文化与历史价值**：作为理解历史、艺术、文学、制度和社会变迁的资料；
7. **制度、治理与权力功能**：研究其在具体时期如何参与治理、权威、组织和资源分配；
8. **经济与商业功能**：具体制度、组织或传播行为可能涉及捐赠、交易、资源筹集或利益关系，应按具体证据分析；
9. **滥用与伤害**：若出现欺骗、强迫、剥削、错误事实主张等，再进入风险与证据层裁决。

因此禁止两个极端：

> `非科学 → 一切无价值`

以及：

> `有道德/文化/历史价值 → 其经验性事实主张自动正确`

同一传统、制度或文本在不同历史时期、不同主体和不同使用方式下可以同时产生正向功能、负面作用和不同受益者，不应只用单一故事解释全部现象。

## 九、与现有文件的职责边界

- 用户什么时候遇到价值错位问题 → `01A`；
- 标准用户问题与 P-L1/P-L2 映射 → `01B / 01`；
- 内容究竟是什么对象 → `02`；
- 事实与证据是否可信 → `03`；
- 是否重复、是否真增量 → `04 / 17`；
- 当前主体是否值得投入 → `05`；
- 时间、版本、历史有效性 → `08`；
- 风险、伦理、负外部性与治理 → `10`；
- 最终学、查、委托、监测、延后或忽略 → `18`。

## 十、当前最小判断模板

```text
这是什么类型的内容？
→ 它主要提供什么价值？
→ 价值给谁？成本由谁承担？
→ 当前主体/目标/角色/场景需要这种价值吗？
→ 它有没有冒充成另一种价值？
→ 如果声称是事实/机制，证据是否通过？
→ 是否有更高质量、更低成本替代？
→ 应该学习、参考、防御性了解、延后还是忽略？
```
