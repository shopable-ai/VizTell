# 内容审查、批判性思维与知识筛选工具宇宙

> 状态：正式上游识别工具视图，第一阶段稳定结构。
>
> 本文件回答：**面对文章、书籍、报告、视频转录、AI 回答等内容，人和 AI 可以用什么成熟方法主动发现低价值、误导、伪知识、错误推理、证据缺陷、知识重复和使用错配风险。**
>
> 本文件不是新的 P-L1 / P-L2 问题本体，也不是第二套 `01D` 现象分类，更不直接取代 `03 / 04 / 05 / 08 / 10 / 13 / 18` 的专业裁决。

## 一、为什么必须从 01D 继续到 01E

`01D_无效阅读、低价值、伪知识、认知误导与有害信息现象宇宙.md` 主要回答：

> **有哪些问题和失败现象？**

但知道一个问题叫什么，不等于会识别它。

例如：

- 知道“相关不等于因果”，不等于能识别第三变量、反向因果、选择偏差和 Collider；
- 知道“诉诸权威”，不等于所有专家意见都是谬误；
- 知道“故事冒充证据”，不等于故事没有教学、情境模拟或反例价值；
- 知道“概念偷换”，不等于能追踪一个命题从弱版本逐步升级成强版本；
- 知道“统计误导”，不等于能检查分母、基准率、样本、效应量、置信区间、多重比较和选择性报告；
- 知道“伪科学”，不等于可以凭语言风格自动判定一个理论是伪科学。

因此需要增加一个中间层：

```text
01D：发现什么风险现象
↓
01E：用什么问题、工具和检查步骤识别
↓
专业裁决模块：怎样正式判断
↓
13：检查能力是否真的准确
↓
18：最后应该怎样消费内容
```

`01E` 的正式身份是：

> **认识论诊断工具层 / 内容筛选操作层 / Detection & Evaluation Toolkit。**

## 二、与现有文件的正式边界

```text
01C
内容到底在提供什么价值？
↓
01D
常见低价值、误导、伪知识和有害现象是什么？
↓
01E
用什么检查工具发现这些现象？
↓
02 / 03 / 04 / 05 / 08 / 10
知识对象、证据、增量、主体价值、时间和风险怎样正式裁决？
↓
13 / 22
检查器是否准确？误报、漏报和边界案例怎样回归？
↓
18
最终精读、局部读、核验、随查、委托、忽略还是延后？
```

关键约束：

1. `01E` 不复制 `01D` 的全部 NV 定义，只保存“怎样检查”。
2. `01E` 不重新定义来源可信状态，正式 Evidence / Source 裁决仍进入 `03`。
3. `01E` 不重新建立知识去重本体，重复、等价、新条件、新边界、新机制进入 `04 / 17`。
4. `01E` 不把“可靠”与“对当前主体有价值”混合，主体价值进入 `05`。
5. `01E` 不重新建立完整时间模型，版本与失效进入 `08`。
6. `01E` 不自行放行高风险行动，风险、权限和人工 Gate 进入 `10`。
7. `01E` 不用单次 Demo 证明能力，Precision / Recall / FP / FN 等进入 `13 / 22`。
8. `01E` 不决定所有内容都要学习，最终消费路由进入 `18`。

## 三、01E 所依赖的成熟专业领域

01E 不是“逻辑谬误大全”，而是多个成熟领域共同形成的检查工具层。

| 专业领域 | 对 01E 的核心贡献 |
| --- | --- |
| 批判性思维 | 隐含前提、反例、替代解释、证据强度、结论强度 |
| 非形式逻辑 | 前提是否可接受、相关、足以支持结论 |
| 论证理论 | Argument Mapping、Toulmin、Argumentation Schemes、Critical Questions、举证责任、反驳 |
| 形式逻辑 | 明确的演绎无效、矛盾、肯定后件、否定前件等 |
| 因果推断 | 混杂、反向因果、选择偏差、反事实、DAG、自然实验等 |
| 统计与概率 | 样本、基准率、效应量、置信区间、多重比较、选择性分析 |
| 测量学与构念效度 | 指标到底是否测量了作者声称的概念 |
| 研究方法学 | 研究设计、对照、样本选择、测量、内外部效度 |
| 系统综述与证据综合 | 偏倚风险、证据总体确定性、不一致性、发表偏倚 |
| 科学哲学与科学怀疑论 | 可证伪、可验证、竞争解释、复现、反证 |
| 媒体与信息素养 | 横向阅读、来源调查、事实核查、原始上下文恢复 |
| 数字内容溯源 | 图片、视频、音频的来源、编辑链和 Content Provenance |
| 修辞学与说服研究 | Ethos / Pathos / Logos、框架、情绪、身份、故事、语言强度 |
| 判断与决策科学 | 认知偏差、动机性推理、基准率忽略、校准 |
| 情报分析与红队方法 | 关键假设检查、竞争假设、反方分析、What-if、Red Team |

其中必须特别吸收一个现代非形式逻辑原则：

> **不要把“形式看起来像某个谬误”直接升级成“论证必然错误”。**

更稳健的方法是：

```text
识别论证模式
→ 调用该模式对应的批判性问题
→ 检查前提、条件、例外与反驳
→ 再判断这个具体实例是否成立
```

例如，使用专家意见不自动等于“诉诸权威谬误”；应继续检查专家是否具有相关专业能力、专家意见是否被准确引用、是否存在领域共识、是否存在更直接证据以及是否有强反证。

## 五、24 类检查器的五层结构

为了避免人工面对 24 个平铺名称，正式使用时按五层组织。

### A 层：内容与命题结构

- F01 内容类型与功能识别器；
- F02 主张与言语类型分离器；
- F03 论证结构提取器；
- F04 概念、定义与命题变形追踪器。

目标：

> **先知道文章到底在说什么，再判断对不对。**

### B 层：推理、研究与数据

- F05 论证模式与批判性问题检查器；
- F06 逻辑一致性与谬误风险检查器；
- F07 替代解释、反例与反方压力测试器；
- F08 因果推断检查器；
- F09 测量、指标与构念有效性检查器；
- F10 研究设计与偏倚风险检查器；
- F11 统计、概率与数值检查器；
- F12 图表与数据可视化误导检查器。

目标：

> **检查从“观察/数据/案例”到“结论”之间有没有超出证据。**

### C 层：来源、证据与真实性

- F13 来源、溯源与独立性检查器；
- F14 引用—主张忠实度检查器；
- F15 证据综合、共识与不确定性检查器；
- F16 科学性、可证伪、复现与研究诚信检查器；
- F17 网络信息与原始上下文核验器；
- F18 图片、视频、音频与数字内容溯源器。

目标：

> **检查“作者说有证据”与“真正存在足够证据”之间的差距。**

### D 层：说服与认知影响

- F19 修辞、框架、情绪与说服增强检查器；
- F20 认知偏差与动机性推理检查器。

目标：

> **把说服力和证明力分开。**

### E 层：适用、增量、时间与 AI 失真

- F21 条件、边界、外部效度与迁移检查器；
- F22 重复、伪增量与知识差额检查器；
- F23 时间、版本与当前有效性检查器；
- F24 AI 转换失真与二次污染检查器。

目标：

> **即使内容“基本正确”，还要判断它是否适用于当前场景、是否真的新增、是否仍然有效、是否被 AI 二次加工失真。**

## 六、几个必须单独保留的关键检查器

### 6.1 F04 命题变形追踪器

需要追踪的不只是“同一个词有没有换含义”，还包括命题强度变化：

```text
可能
→ 往往
→ 大概率
→ 必然
```

```text
部分样本
→ 某类人
→ 大多数人
→ 所有人
```

```text
相关
→ 可能有影响
→ 造成
→ 主要原因
→ 唯一原因
```

```text
有效
→ 更有效
→ 最有效
→ 最佳方案
```

```text
存在
→ 有原因
→ 有功能
→ 合理
→ 应该保留
```

因此“存在即合理”类表达不能只做关键词判断，而应拆成：

1. `存在` 是事实性陈述还是修辞；
2. `合理` 是“有形成原因”“在某环境有功能”还是“规范上正当”；
3. 推理是否从描述事实跳到了规范结论；
4. 是否删除了受益者、成本承担者、历史条件与替代方案。

### 6.2 F08 因果推断检查器

面对“A 导致 B”至少提出：

1. A 与 B 是否只是同时出现？
2. B 是否可能反过来导致 A？
3. 是否存在 C 同时影响 A 与 B？
4. A 是否发生在 B 之前？
5. 作者是否真正操纵、隔离或利用外生变化观察 A？
6. 是否存在合理 Treatment / Control 或其他比较基线？
7. 没有 A 时，B 合理反事实会怎样？
8. 样本是否因为某种选择机制才被观察到？
9. 是否发生幸存者偏差、回归均值或基准率忽略？
10. 是否把必要条件写成充分条件，或反过来？
11. 是否存在中介、调节或 Collider，使简单相关关系不可直接解释？
12. 现有数据是否只能支持相关，而不支持因果？

普通用户不需要先学习完整因果推断数学，但系统可以把成熟因果理论转换成这些可执行问题。

### 6.3 F09 测量、指标与构念有效性检查器

这是不能被 F11“统计检查”吞并的独立能力。

典型问题：

```text
在线时长 ≠ 生产力
点赞数 ≠ 用户满意度
考试分数 ≠ 完整能力
自报意愿 ≠ 实际购买行为
某个代理指标 ≠ 它声称代表的复杂构念
```

至少检查：

- 构念怎样定义；
- 指标怎样操作化；
- 指标是否只覆盖构念的一部分；
- 是否存在更直接测量；
- 是否存在测量误差；
- 指标是否容易被策略性优化；
- 从“指标变化”到“真实构念变化”的解释是否有独立依据。

### 6.4 F10 研究设计与偏倚风险检查器

研究可以统计计算完全正确，但设计本身有严重问题。

至少检查：

- 样本怎样进入研究；
- 是否有合理比较组；
- 分组是否系统性不同；
- 测量是否对不同组公平一致；
- 缺失数据是否与结果相关；
- 分析计划是否事先确定；
- 是否选择性报告有利结果；
- 是否存在多重比较、p-hacking、HARKing；
- 是否存在外部效度和迁移问题。

成熟 Risk of Bias 方法的重要启发不是“给论文一个总分”，而是：

> **通过一组 Signalling Questions 定位不同偏倚来源，并允许结果为低风险、高风险或信息不足。**

### 6.5 F15 证据综合、共识与不确定性检查器

必须避免：

> 一篇论文 = 已形成科学事实。

至少区分：

- 单项研究质量；
- 同类研究结果是否一致；
- 研究设计是否直接回答当前 Claim；
- 样本与当前场景是否一致；
- 效应是否精确；
- 是否存在发表偏倚；
- 是否有独立复现；
- 是否形成主流共识、仍在争议，还是证据不足。

证据确定性应该是状态和理由，而不是简单累加来源数量。

### 6.6 F19 修辞、框架、情绪与说服增强检查器

核心原则：

> **说服力 ≠ 证明力。**

检查：

- 专家身份；
- 群体身份；
- 社会证明；
- 恐惧、愤怒、羞耻、希望；
- loaded language；
- euphemism / dysphemism；
- framing；
- repetition；
- rhetorical question；
- vivid anecdote；
- enemy construction；
- narrative persuasion。

但这些只能作为“影响判断方式”的描述，不自动等于内容错误。

例如：

- 使用专家意见，不自动是诉诸权威谬误；
- 使用故事，不自动是故事冒充证据；
- 有情绪表达，不自动是情绪操纵；
- 使用比喻，不自动产生事实错误；
- 语言强烈，不自动意味着 Claim 为假。

  risk_signals: []

  false_negative_conditions: []

其中两个字段必须特别保留：

### `missing_information`

高质量检查器不能只输出“有问题”，还必须能说：

> **现在缺什么信息，所以暂时不能下更强结论。**

### `alternative_explanations`

对于因果、管理、社会行为和复杂系统问题，必须主动保存竞争解释，而不是只围绕作者原结论继续推理。

---

## 八、AI 自动化能力不能只有一个等级

对每个检查器分别评估五种能力：

```text
Detect
能否发现候选问题

Explain
能否解释为什么值得怀疑

Verify
能否自行核验必要证据

Judge
能否可靠裁决是否真的有问题

Act
能否据此自动阻断、删除、合并、入库或执行
```

因此同一个 Checker 可能是：

```text
Detect = high
Explain = high
Verify = medium
Judge = low
Act = none
```

这比简单写“可自动化 / 不可自动化”更稳健。

---

## 九、自动化能力分级

### A. 适合直接自动检查

典型包括：

- Claim 提取；
- Fact / Opinion / Normative / Prediction 初步分离；
- 数字、比例和百分比抽取；
- 明显分母缺失；
- 简单计算错误；
- 同一术语前后显式定义差异；
- 量词变化；
- “可能 → 必然”等文本层命题升级；
- 引用标识是否存在；
- 摘要与原文的语义差异候选；
- 文本完全重复、近似重复和语义重复候选；
- 发布日期、版本号、时间表达；
- 部分图表轴截断、比例异常等视觉结构问题。

这些自动检查结果仍然可能需要置信度和边界处理。

### B. AI 可以发现风险并解释，但通常不应直接裁决

典型包括：

- 概念偷换；
- 稻草人；
- 诉诸专家是否合理；
- 类比是否真正支持结论；
- 因果是否成立；
- 是否存在重要混杂；
- 是否发生选择偏差；
- 构念效度是否足够；
- 外部效度是否足够；
- 修辞是否构成操纵；
- 某理论是否应判伪科学；
- 单项研究是否足以改变实践。

正确输出优先是：

```text
风险候选
+ 触发依据
+ 缺失信息
+ 替代解释
+ 建议核验动作
```

而不是：

```text
发现谬误：诉诸权威
可信度 -20
```

### C. 必须外部检索、数据或原始来源支持

例如：

- 某项研究是否真实存在；
- 引用是否准确；
- 原始数据是否与二手文章一致；
- 原视频是否被剪辑；
- 图像最早发布位置；
- 作者专业领域；
- 是否撤稿；
- 是否有后续复制或反证；
- 当前主流共识；
- 软件、法规、标准、医学指南和数据是否已更新。

此类任务应触发 `03` 的 Source Lineage / Evidence 核验和 `08` 的时间版本判断。

### D. 高风险必须进入人工或专业 Gate

典型包括：

- 医疗；
- 法律；
- 重大财务；
- 重大商业决策；
- 公共安全；
- 严重伦理后果；
- 高代价、不可逆行动。

此类场景不允许仅因为 AI confidence 高就自动放行，必须进入 `10` 的 Evidence Gate、Accountability Gate、Human Gate 等治理机制。

## 十、文章进入系统后的完整筛选链

推荐逻辑主链：

```text
0. 当前目标、主体与风险识别
↓
1. F01 内容功能识别
↓
2. F02 Claim 提取与主张原子化
↓
3. Claim 类型路由
   ├─ 可验证事实
   ├─ 因果主张
   ├─ 数字/统计主张
   ├─ 预测
   ├─ 方法
   ├─ 价值判断
   └─ 规范建议
↓
4. F03 论证结构提取
↓
5. F04 语义、定义和命题变形追踪
↓
6. F05 / F06 论证模式、批判性问题和逻辑检查
↓
7. F07 替代解释 / 反例 / 反方压力测试
↓
8. 按 Claim 类型调用专业检查器
   ├─ 因果 → F08
   ├─ 测量 → F09
   ├─ 研究 → F10
   ├─ 数字 → F11
   └─ 图表 → F12
↓
9. F13 / F14 来源、证据、引用溯源
↓
10. 必要时外部搜索和原始上下文恢复
↓
11. F15 / F16 证据总体、科学状态和复现判断
↓
12. F17 / F18 网络上下文与数字媒体真实性
↓
13. F19 / F20 修辞、说服和认知偏差风险单独标记
↓
14. F21 条件、边界和迁移检查
↓
15. F22 知识增量、重复和新瓶装旧酒检查
↓
16. F23 时间、版本和失效检查
↓
17. F24 AI 转换失真检查
↓
18. 调用 05：当前主体实际价值
↓
19. 调用 10：风险与权限 Gate
↓
20. 调用 18：最终消费路由
↓
21. 输出“发现 + 证据 + 未决 + 建议动作”
```

关键原则：

> **不是每篇内容都顺序跑完 24 个检查器。**

应先进行 Claim 类型识别和风险路由，只调用真正相关的检查器。否则会增加成本、延迟和误报。

## 十一、普通用户版快速筛选链

完整专业链很强，但普通阅读时不能要求用户先学习全部理论。

建议保留一个轻量入口：

```text
1. 它到底在说什么？
2. 哪几句话是真正需要相信或照做的主张？
3. 作者拿什么支持这些主张？
4. 证据真的支持到这么强吗？
5. 有没有其他解释、反例或遗漏条件？
6. 来源最初来自哪里？
7. 其他独立来源怎么说？
8. 这段内容主要靠证据说服我，还是靠故事、身份、情绪和语言？
9. 对当前任务真正新增了什么？
10. 值不值得继续读、核验、保存或学习？
```

这可以作为未来阅读助手中的“快速审查模式”。

## 十二、成熟工具和资料谱系

第一阶段优先把以下成熟资源作为方法来源，而不是把任意一本书作为唯一权威。

### 12.1 批判性思维与非形式逻辑

- Johnson & Blair：《Logical Self-Defence》；
- Informal Logic 传统；
- Argument Mapping；
- 前提可接受性、相关性和充分性检查。

### 12.2 论证理论

- Toulmin Model：Claim / Data / Warrant / Backing / Qualifier / Rebuttal；
- Argumentation Schemes；
- Critical Questions；
- burden of proof；
- rebuttal / counterargument；
- dialogue / dialectic。

其中 `Argumentation Schemes + Critical Questions` 特别适合 AI，因为它天然可以转成：

```text
识别论证模式
→ 调用对应问题模板
→ 找缺失前提和例外
→ 输出风险而不是只贴标签
```

### 12.3 科学怀疑与通用识别

- Carl Sagan：《The Demon-Haunted World》中的 Baloney Detection Kit；
- 独立验证；
- 多重假设；
- 主动尝试证伪；
- 不把权威身份当作证明；
- 量化与反例。

### 12.4 数据、统计与现实世界误导

- University of Washington：Calling Bullshit: Data Reasoning in a Digital World；
- Carl Bergstrom / Jevin West：《Calling Bullshit》；
- Darrell Huff：《How to Lie with Statistics》；
- American Statistical Association 关于 p-value 的原则与后续讨论。

### 12.5 研究设计和证据质量

- Cochrane Risk of Bias 2；
- ROBINS-I；
- GRADE；
- AMSTAR 2；
- PRISMA；
- EQUATOR Network 报告规范。

特别吸收两个设计原则：

1. 使用结构化 Signalling Questions，而不是只靠总体印象；
2. 关键缺陷不能被大量普通加分项平均掉，因此不要只依赖一个总分。

### 12.6 媒体与信息素养

- SIFT：Stop / Investigate the source / Find better coverage / Trace claims to original context；
- Civic Online Reasoning：谁在背后、证据是什么、其他来源怎么说；
- 专业 Fact-checking 工作流；
- lateral reading / reverse source tracing。

### 12.7 因果推断

- Counterfactual；
- Treatment / Control；
- Confounder；
- Mediator；
- Moderator；
- Collider；
- Natural Experiment；
- Causal DAG。

普通用户层不要求数学化完整掌握，但检查器设计应受这些成熟概念约束。

### 12.8 情报分析和反方压力测试

- Key Assumptions Check；
- Quality of Information Check；
- Analysis of Competing Hypotheses；
- Devil's Advocacy；
- Team A / Team B；
- What If；
- Red Team Analysis。

其价值是把“认知偏差”从一个标签，转成主动生成竞争解释和反证的操作程序。

### 12.9 数字媒体 Provenance

- C2PA / Content Credentials 等 provenance 思路。

注意：

> **内容来源和编辑链可信，不自动等于其中事实主张真实。**

Provenance 只能解决真实性判断的一部分。

## 十三、禁止只有“文章质量总分”

系统不应主要输出：

```text
文章质量：72 / 100
```

因为：

- 一个重大因果错误可能被大量格式正确项平均掉；
- 内容真实性与当前主体价值是不同问题；
- 单一分数隐藏了哪些 Claim 真正需要核验；
- 人无法知道下一步应该做什么。

优先输出结构化诊断：

```text
内容结构
事实主张：8
因果主张：3
预测：1
价值判断：4
规范建议：2

高优先发现
P1：1 项
P2：3 项
P3：6 项

具体问题
C03：
“使用软件 A 的企业增长更快”
风险：相关性可能被升级为因果
缺失：
- 基线差异
- 企业规模
- 选择软件的原因
- 对照
状态：需要外部验证

C05：
“研究证明效率提高 40%”
风险：未提供分母和原始研究
状态：来源待追踪

知识增量
新机制：0
新条件：2
新边界：1
独立新证据：0
教学案例：4

建议
→ 局部阅读
→ 核查 C03 / C05
→ 其余故事作为解释材料，不直接进入 Canonical Knowledge
```

总分可以作为辅助排序字段，但不能替代问题明细、证据状态、不确定性和下一步动作。

## 十四、Benchmark 必须以误报和正确拒判为核心

每个 F 检查器至少建立：

```text
True Positive
真正有问题，系统识别出来

False Positive
本来合理，系统误判成问题

True Negative
正常案例，系统正确不报警

False Negative
真正有问题，系统漏掉

Boundary Case
形式相似，但是否构成问题取决于条件

Insufficient Evidence
信息不足，正确状态应该是“暂不能判断”

Abstain
系统知道自己不应继续自动裁决
```

尤其增加两个指标：

### Overclaim Rate

AI 把“风险信号”错误升级成“已经确定有错”的比例。

### Appropriate Abstention Rate

证据不足、外部来源缺失或需要领域专家时，AI 是否能够正确保持未知并升级核验。

典型 False Positive 必须覆盖：

- 使用专家意见，但专家确实相关且论证合理；
- 使用案例只是帮助解释，没有把案例当成普遍证据；
- 使用比喻，但没有把比喻当成机制；
- A 与 B 相关，同时确实存在其他因果证据；
- 情绪表达存在，但没有替代证据；
- 强烈修辞存在，但核心 Claim 本身有强证据；
- 传统、历史或文学内容本来就没有声称自己是科学事实。

Benchmark 的正式指标和回归仍进入 `13_评测、Benchmark与质量指标.md` 与 `22_遗漏、反例与回归测试.md`。

## 十五、01E 的标准输出不是“判错”，而是诊断状态

推荐状态：

```text
no_issue_detected
当前未发现问题，但不等于已经证明正确

risk_signal
出现值得继续检查的风险信号

insufficient_information
信息不足，不能做更强判断

external_verification_required
必须查原始来源、数据、版本或其他外部证据

likely_issue
多个信号共同支持存在问题，但仍保留不确定性

confirmed_issue
已有足够证据确认具体问题

human_review_required
自动裁决风险过高，应转人工或领域专家
```

关键原则：

> **发现风险 ≠ 证明错误。**

> **暂未发现风险 ≠ 证明正确。**

> **来源可信 ≠ 每个 Claim 正确。**

> **Claim 正确 ≠ 对当前主体值得投入。**

## 十六、与知识入库 Gate 的关系

01E 可以成为未来企业知识库、个人知识库和 RAG 入库前的重要 Gate，但不得简单执行：

```text
检测到风险
→ 删除
```

建议：

```text
Raw Content
↓
01E 检查
↓
风险和未决问题结构化保存
↓
03 / 04 / 08 等正式裁决
↓
高风险内容进入人工复核
↓
允许作为：
- verified knowledge
- contested knowledge
- unverified claim
- evidence lead
- historical material
- teaching example
- rejected / quarantined content
```

即使一条 Claim 证据很弱，也可能仍具有：

- 研究线索价值；
- 反例价值；
- 历史记录价值；
- 风险识别价值；
- 误导案例 Benchmark 价值。

因此知识 Gate 不等于“真假二元删除器”。

## 十八、当前阶段验收标准

本文件第一阶段通过的最低要求：

1. 能清楚解释为什么 `01D → 01E` 必须存在；
2. 能说明 01E 与现有专业裁决文件的边界；
3. 一级结构覆盖论证、语义、因果、测量、研究设计、统计、图表、来源、引用、证据综合、科学性、网络核验、数字媒体、修辞、认知偏差、迁移、增量、时间和 AI 失真；
4. 不把谬误标签当成自动定罪机制；
5. 不把专家意见、故事、比喻、情绪和相关关系自动判错；
6. 能区分 Detect / Explain / Verify / Judge / Act；
7. 能在信息不足时输出 `insufficient_information`；
8. 能触发外部来源核验，而不是只分析文本风格；
9. 能触发高风险人工 Gate；
10. 能进入 `13 / 22` 做误报、漏报、边界和正确拒判测试；
11. 最终输出以具体 Claim、风险、证据、未决问题和动作建议为主，而不是只有总分；
12. 最终能与 `18` 的阅读和知识消费路由连接。

## 十九、核心原则

1. **问题名称不是识别能力。**
2. **谬误标签不是论证裁决。**
3. **风险信号不是已证实错误。**
4. **说服力不是证明力。**
5. **有引用不是引用支持主张。**
6. **有论文不是高质量证据。**
7. **单项研究不是整体科学共识。**
8. **统计正确不代表测量的概念正确。**
9. **相关关系本身既不能证明因果，也不能自动否定因果。**
10. **多个网页不等于多个独立证据。**
11. **案例可以有教学价值，但 Case ≠ Mechanism ≠ Independent Evidence。**
12. **修辞和情绪可以提高表达价值，但不能替代证据。**
13. **内容正确不代表适用于当前主体和场景。**
14. **有价值不代表值得现在完整阅读。**
15. **AI 能发现模式，不等于 AI 能可靠裁决全部认识论问题。**
16. **AI 自动检查必须允许“不知道”和“需要核验”。**
17. **高风险判断必须允许人工接管。**
18. **知识筛选系统的目标不是最大化删除，而是提高正确识别、正确保留、正确核验和正确消费的能力。**

最终目标不是建立“逻辑谬误大全”，而是逐步形成：

```text
内容输入
→ 内容价值类型识别
→ Claim 提取
→ 论证结构提取
→ 语义与命题变形检查
→ 逻辑与批判性问题
→ 因果检查
→ 测量与研究设计检查
→ 统计与图表检查
→ 来源、引用与证据检查
→ 科学性与外部核验
→ 修辞与认知影响检查
→ 条件、边界与迁移检查
→ 知识增量检查
→ 时间与 AI 失真检查
→ 主体场景价值判断
→ 风险 Gate
→ 阅读投入与知识消费路由
→ 人类最终判断
```

即：

> **AI 原生内容价值与知识质量筛选系统。**
