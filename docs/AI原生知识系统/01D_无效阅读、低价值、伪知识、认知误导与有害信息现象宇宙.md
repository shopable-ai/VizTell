# 无效阅读、低价值、伪知识、认知误导与有害信息现象宇宙

> 状态：正式上游反面现象视图。
>
> 本文件回答：**什么内容看起来值得读、值得信、值得学、值得照做，但实际上可能低价值、低增量、误导、错配或有害。**
>
> 本文件不是新的 P-L1/P-L2 本体，而是把散落在 `01 / 02 / 03 / 04 / 05 / 08 / 10 / 17 / 18` 中的反面问题集中成人工可读入口。

| NV-23 | 描述性事实、规范判断与行动建议混淆 | “存在/常见/有效”被偷换成“合理/应该/最佳” |

## 二十六、几个必须保留的典型识别规则

### 26.1 “正反覆盖”测试

如果一句话同时覆盖 A 与非 A，例如：

> “你表面坚强，但内心也渴望理解。”

不要因为“像自己”就自动判为高洞察。继续问：

- 它能区分谁不符合吗？
- 它能产生不同预测吗？
- 失败时是否仍能重新解释？

### 26.2 “存在即合理”测试

至少拆开：

```text
存在
≠ 有存在原因
≠ 有功能
≠ 对所有主体有利
≠ 正当
≠ 当前仍适用
≠ 应该继续保留
```

### 26.3 “拟人化”测试

如果出现“基因想要、市场惩罚、历史选择、植物驯服、社会希望”等表达，先判断它是：

- 文学修辞；
- 教学比喻；
- 简写；
- 还是被当成字面的因果主体。

比喻可以保留，但不得自动进入事实机制。

### 26.4 “如果所有人都这样做”测试

针对权术、操控和局部最优策略，问：

> 如果团队、公司或市场里所有人都采用同样策略，系统结果会更好还是更坏？

用于识别负和知识与有害最佳实践。
