# 案例分析与多视角裁决方法

> 目标：让案例分析优先服务人工判断，同时保留未来转为结构化数据和 Benchmark 的可能。

---

## 1. 最小案例结构

正式案例至少回答六组问题。

### A. 来源

- 案例 ID；
- 案例名称；
- 来源类型；
- 作者 / 发布机构；
- 时间；
- 原始出处；
- 原始上下文；
- 当前流行版本是否发生二次改写。

### B. 命题

- 它实际说了什么；
- 是事实主张、因果主张、解释、预测、规范、建议、比喻、故事还是情绪表达；
- 命题强度是“可能”“通常”“必然”还是“应该”。

### C. NV 归属

- 一级现象族；
- 二级现象；
- 主归属；
- 关联归属；
- 为什么不是相邻类别。

### D. 正确与风险

- 哪些部分可能正确；
- 哪些部分有证据；
- 哪些部分只是修辞；
- 哪些部分缺证据；
- 哪里发生概念移动；
- 哪一步发生命题升级。

### E. 边界

- 成立条件；
- 失效条件；
- 适用主体；
- 不适用主体；
- 适用场景；
- 不适用场景；
- 时代条件；
- 替代方案。

### F. 价值与行动

- 知识价值；
- 行动价值；
- 文学 / 情绪 / 传播价值；
- 历史价值；
- 商业价值；
- 防御价值；
- 负外部性；
- 推荐学习还是只需理解；
- 推荐执行还是只需防御。

**它声称什么**

- 关联：NV-xx / NV-xx

**哪些地方成立**

**风险发生在哪里**

**不同主体的价值**
- 阅读者：
- 作者 / 销售者：

## 3. 第一原则：先恢复原命题，再批判

很多“伪知识”并不是作者原句本身，而是传播过程发生了：

```text
原始弱命题
→ 标题化
→ 口号化
→ 去条件化
→ 强结论化
→ 行动处方化
```

例如：

```text
某种练习与专业表现相关
→ 练习很重要
→ 练够某个小时数就能成为专家
→ 所有人、所有领域都适用
```

如果不恢复原命题，就无法知道：

> 是研究错了，还是传播错了。

---

## 4. 命题强度梯子

对任何案例，优先检查是否跨越了下面的层级：

```text
可能存在
< 有时存在
< 在某些条件下较常见
< 通常存在
< 大多数如此
< 几乎必然
< 必然
```

以及：

```text
观察到
→ 有相关
→ 可能有机制
→ 是原因
→ 是主要原因
→ 是唯一原因
```

以及：

```text
现实存在
→ 有形成原因
→ 可以解释
→ 有某种功能
→ 对某主体有利
→ 合理
→ 正当
→ 应该接受
→ 应该保留
→ 应该学习
→ 应该执行
```

任何跨层级都需要新增证据或规范前提。

## 5. A/B 区分测试：专门识别正反覆盖

对人格、识人、冷读、星座和“懂人性”类内容，问：

> 如果给 A 人和 B 人同一句话，这句话会不会都被接受？

### 最小测试

假设两个相反的人：

- A：外向、社交活跃；
- B：内向、社交谨慎。

如果描述是：

> “你有时喜欢社交，有时也需要独处。”

它可能是真的，但区分力很弱。

进一步问：

1. 对 A 和 B 是否都成立？
2. 能否预测 A/B 下一步行为差异？
3. 什么观察会让该描述失败？
4. 是否存在事后解释所有结果的空间？

如果无法回答，优先归 NV-04，而不是直接归 NV-08 伪科学。

## 6. 修辞—机制双读法

对拟人化和文学表达，强制做两遍阅读。

### 第一遍：修辞阅读

问：

- 这个表达让人看见了什么新视角？
- 是否压缩了复杂机制？
- 是否提高记忆和传播？
- 是否明确被当作比喻？

### 第二遍：机制阅读

把意图词改成机制词。

例如：

```text
“小麦驯服了人类”
```

可改写成：

```text
小麦的可栽培特征、农业定居、人口增长、劳动结构和制度反馈共同改变了人类生活方式。
```

如果机制版有证据，原句可以是高价值修辞；
如果读者把原句理解成“小麦具有目的和意图”，才发生 NV-06 风险。

## 7. 故事—证据分离法

一个真实故事可以有四种不同角色：

1. **存在性证据**：说明“这种事至少发生过”；
2. **机制线索**：提示可能的因果链；
3. **教学例子**：帮助理解抽象概念；
4. **一般规律证据**：声称“多数情况下都这样”。

前 3 种不自动推出第 4 种。

因此：

```text
一个企业成功案例
≠ 该方法通常能让企业成功

一个秘书能阻碍项目
≠ 操纵信息时机是普遍最优策略

一个历史人物使用某计谋获胜
≠ 该计谋是胜利的主要原因
```

## 8. 多主体价值矩阵

至少检查以下角色中与案例相关者：

| 主体 | 需要问什么 |
|---|---|
| 阅读者 | 能否提高判断、行动或理解？ |
| 作者 | 是否获得表达、声誉、收入、传播？ |
| 销售者 | 是否提高成交、留存或客单价？ |
| 平台 | 是否提高点击、时长、广告或数据收益？ |
| 被说服者 | 是否获得真实利益，还是只被推动选择？ |
| 管理者 | 是否提高局部控制或绩效？ |
| 员工 | 是否增加压力、风险或自主性损失？ |
| 企业 | 是否提高长期能力，还是积累治理风险？ |
| 客户 | 是否获得价值，还是承担隐藏成本？ |
| 社会 | 是否产生污染、欺骗、信息污染或信任侵蚀？ |
| 历史研究者 | 是否具有解释时代制度的价值？ |
| 当前问题解决者 | 是否直接帮助当下任务？ |

### 禁止句式

```text
“这个内容有价值。”
“这个内容没价值。”
```

优先改为：

```text
“对谁、在什么目标和场景下，有什么价值，成本由谁承担？”
```

## 9. 全员采用测试

对权术、操纵、商业技巧和竞争策略，问：

> 如果组织里的所有成员都采用这个策略，会发生什么？

如果结果是：

- 信息失真；
- 互相设局；
- 协作成本飙升；
- 信任下降；
- 大量资源投入防御；
- 团队目标被局部博弈吞噬；

则该策略可能：

> 对个体短期有效，但属于负和知识或局部最优。

这类知识通常仍有很高**防御价值**。

## 10. 宗教 / 传统思想的 17 平面裁决

至少区分：

1. 可经验检验的事实主张；
2. 因果解释；
3. 形而上主张；
4. 教义内部一致性；
5. 伦理规范；
6. 情绪支持；
7. 意义建构；
8. 死亡与不确定性处理；
9. 共同体与身份；
10. 仪式协调；
11. 文化与历史；
12. 组织治理；
13. 社会协调；
14. 权力合法化；
15. 财富 / 资源 / 商业结构；
16. 对异议者、个人自由和社会的成本；
17. 当时与现代的替代制度。

任何一面上的正价值，不自动证明其他面的主张。

## 11. 时间版本测试

对医疗、科技、安全、法规、软件、经济等高时效领域必须记录：

- `valid_time`：什么时期有效；
- `superseded_by`：被什么更新替代；
- `change_reason`：新证据、威胁模型、定义、制度还是技术变化；
- `historical_value`：旧版本是否仍有解释价值。

例：

> “定期强制改密码”曾经是常见安全实践，但现代 NIST 指南明确反对无证据情况下任意周期性强制更换。

不能因此推断：

> “过去所有这么做的人都愚蠢。”

应判断当时的威胁模型、可用技术和证据环境。

## 12. 文学 / 情绪内容的边界规则

文学案例首先问：

> 它有没有声称自己在提供普遍经验事实？

如果没有，就不应该拿“不能证伪”直接判错误。

例如：

- 一首诗的思乡表达；
- 寓言对道德冲突的压缩；
- 小说对权力、孤独或爱的呈现；
- 祷告对悲伤者的意义支持。

这些内容可能知识密度低，但并不等于总价值低。

真正需要阻止的是：

```text
文学感染力
→ 当成经验事实可靠性
→ 再当成行动处方
```

## 13. 反例规则

每一个成熟 NV 至少需要一种反例。

### 反例 1：表面像错误，其实只是修辞

例如拟人化明确作为比喻。

### 反例 2：知识价值低，但其他价值正是目标

例如文学、仪式或情绪支持。

### 反例 3：现实策略确实有效，但不值得推荐

例如利用制度漏洞。

### 反例 4：旧知识今天失效，但当时有合理依据

例如安全规范和医学指南随证据更新。

### 反例 5：一个分类标签是人为约定，但仍可具有科学工具价值

例如天文学分类。

## 14. 最终裁决不使用单一总分

推荐使用“向量式结论”：

```text
事实可靠性：高 / 中 / 低 / 不适用
知识增量：高 / 中 / 低
情绪价值：高 / 中 / 低 / 不适用
文学价值：高 / 中 / 低 / 不适用
历史价值：高 / 中 / 低 / 不适用
行动价值：高 / 中 / 低 / 负
防御价值：高 / 中 / 低
外部性：正 / 中性 / 负 / 混合
适用边界：清楚 / 部分 / 模糊
```

然后再给消费路由。

## 15. 从案例转 Benchmark 的最小结构

未来进入 AI 评测时，一个案例可以转为：

```text
输入：原始短片段 + 必要上下文
问题：判断主 NV、关联 NV、内容价值与行动路由
标准答案：允许多标签，但必须有主归属
关键理由：3～6 条
相邻错误答案：至少 1 个
反例：至少 1 个
证据：原始来源
```

### 核心评测点

AI 是否能：

- 不把修辞当事实；
- 不把非科学内容都叫伪科学；
- 不把现实有效策略自动推荐；
- 不用书名判整书；
- 能区分作者原意和二次传播；
- 能识别命题强度升级；
- 能说出对谁有价值；
- 能主动发现应用范围；
- 能主动寻找反例。

只有做到这些，案例库才真正变成可用于长期知识判断和 AI 评测的基础设施。
