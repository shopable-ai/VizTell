# 反例、误判与边界案例库

> 如果案例库只有“看，这又是一种错误”，它自己就会制造确认偏误。
>
> 本文件与正例库同等重要：专门保存**看起来像 01D 问题，但不应该直接判错**的案例。

---

## CE-01 “你表面坚强，内心也需要理解”不构成逻辑矛盾

**对应：NV-04 的边界**

一个人完全可能：

- 在工作中坚强；
- 在亲密关系里渴望理解；
- 在某些时刻自信；
- 在另一些时刻不安。

因此不能因为句子同时包含两面，就说它“逻辑自相矛盾”。

真正的问题是：

> 如果几乎所有人都能接受它，它是否仍然具有区分、预测或诊断价值？

所以 NV-04 的识别点应是**低区分度 + 自我适配空间**，不是“任何双面描述都错”。

---

## CE-02 《冷读术》的一部分技巧可以是沟通技巧，不等于人格测量

**对应：NV-04 / NV-15 边界**

《冷读术》中的“不要只按外表给人单一评价”“注意对方反应”“用心听”等内容，可以在沟通场景有实际价值。

问题发生在：

```text
建立亲近感成功
→ 被解释成我准确识别了你独特的人格
```

因此同一本书可以同时包含：

- 可参考的沟通技巧；
- 低区分人格判断；
- 更缺乏证据的 We/Me 身体特征分类。

这再次说明：**不能一句话给整本书判死刑。**

---

## CE-03 “小麦驯服了人类”可以是高价值修辞

**对应：NV-06 边界**

Harari 的表达明显带有视角反转和拟人化。

如果读者知道这是修辞，并把它还原为：

> 农业作物、人类劳动、人口和制度之间存在长期反馈，

它可以有效打破“人类始终是唯一主动主体”的直觉。

只有当读者把它升级成：

> 小麦具有人的意图、计划和目的，

才进入主体错配。

**结论：拟人化是风险信号，不是自动错误标签。**

---

## CE-04 “自私的基因”不是说基因具有道德人格

**对应：NV-06 / NV-05 边界**

Dawkins 的标题语言用于解释基因层面的复制和选择，不应字面化为：

- DNA 会思考；
- 基因有贪婪人格；
- 人类伦理上应该自私。

但隐喻本身可以提高科学传播和记忆。

因此系统必须区分：

```text
科学隐喻
vs
字面机制
vs
伦理规范
```

---

## CE-05 “故事不是统计证据”不等于“故事没有证据价值”

**对应：NV-11 边界**

一个真实案例至少可以承担：

1. **存在性证明**：这种事情至少发生过；
2. **异常发现**：提示旧模型可能不完整；
3. **机制线索**：帮助提出假设；
4. **教学例子**：帮助理解概念。

它通常不能单独承担：

> “这种机制在大多数人/组织中普遍成立、效应有多大”。

所以：

```text
单案例 ≠ 一般规律
```

但也不是：

```text
单案例 = 零知识价值
```

## CE-06 《狼来了》是寓言，但可以高效传递信誉机制

**对应：NV-11 / NV-01 边界**

寓言不是关于“说谎次数和信任下降百分比”的研究。

但它能够非常低成本地让学习者理解：

> 重复虚假警报可能消耗可信度，导致真实警报也被忽略。

因此：

- 作为定量证据：弱；
- 作为机制启发：强；
- 作为文化传播：强。

---

## CE-07 宗教内容不能因为“不是科学”就判无价值

**对应：NV-08 / NV-01 / NV-17 边界**

宗教文本可能同时承担：

- 形而上主张；
- 道德规范；
- 仪式；
- 意义；
- 社会支持；
- 共同体；
- 历史文化。

可经验检验的疗效或历史主张仍需要证据。

但：

> “不能用实验验证某一教义”

不能直接推出：

> “它对任何主体、任何时代、任何任务都没有价值”。

同理，有社会功能也不能反推教义的经验真实性。

---

## CE-08 保密不等于知识隐藏式权术

**对应：NV-16 边界**

组织里不分享某些信息可能完全合理：

- 密码；
- 医疗隐私；
- 客户个人数据；
- 商业秘密；
- 法律要求；
- 最小权限原则。

因此不能用：

```text
“他没有告诉我”
```

直接判为：

```text
“他在搞办公室政治”
```

需要判断：

- 你是否拥有访问权；
- 信息是否已经被请求；
- 隐瞒是否有正当理由；
- 隐瞒是保护系统还是制造私人依赖。

---

## CE-09 阻止对手不总是负和策略

**对应：NV-16 边界**

在严格零和比赛中：

- 防守；
- 阻止对手得分；
- 限制对手资源

可以完全符合任务。

因此“扯后腿”类内容不能脱离博弈结构判定。

真正的风险是：

> 把零和对抗策略迁移到本来可以合作创造价值的组织环境。

---

## CE-10 旧安全规则失效，不代表当时毫无根据

**对应：NV-19 边界**

周期性强制改密码曾是大量系统的安全规则，现代 NIST 已不建议在没有泄露证据的情况下任意周期强制更换。

正确处理是：

```text
旧威胁模型 / 旧实践
→ 新证据与新攻击模型
→ 指南更新
```

而不是：

```text
现在不推荐
→ 过去的所有实践者都愚蠢
```

时间版本判断需要历史条件。

---

## CE-11 Pluto 被重新分类，不代表科学“随便改真相”

**对应：NV-20 边界**

Pluto 的标签从 planet 变成 dwarf planet，说明：

> 科学分类是人类为了研究和沟通建立的工具。

它不意味着：

- 物理对象随投票改变；
- 所有分类都任意；
- 科学事实纯粹由语言创造。

分类可以是人为制定，同时仍受：

- 可观察属性；
- 理论目标；
- 一致性；
- 解释价值

约束。

## CE-12 “正确废话”在低错误容忍任务里可能正是必要信息

**对应：NV-13 边界**

例如：

> “操作前切断电源。”

对有经验工程师可能毫无知识增量，但在安全 SOP 中重复出现仍可能非常重要。

因为其价值不是：

> 新颖性。

而是：

- 降低遗漏；
- 提醒关键关口；
- 形成共同操作协议；
- 减少高代价错误。

所以 NV-13 不能只用：

> “我早就知道了。”

来识别。

还要问：

> 这句话是否改变了当前任务中的错误概率、检查行为或责任边界？

---

## CE-13 低知识密度不总是灌水：迁移练习需要重复

**对应：NV-02 边界**

一本方法书可能用：

- 工作；
- 家庭；
- 销售；
- 决策

四个案例练同一个原则。

从“新命题数量”看，后三个案例增量可能很低。

但从学习科学看，它们可能承担：

- 变式练习；
- 迁移；
- 检索；
- 场景识别。

因此判断“灌水”前要区分：

```text
重复表达同一句话
vs
用不同场景训练迁移
```

真正的问题是：重复是否产生新的可迁移能力。

---

## CE-14 情绪安慰内容没有提供解决方案，也不等于“无效”

**对应：NV-14 / NV-01 边界**

当用户的真实任务是：

- 稳定情绪；
- 被倾听；
- 恢复行动能力；

一段没有技术解决方案的共情内容，可能正是核心价值。

只有在用户要：

> 查找事故根因、医疗证据、法律规则

时，用情绪替代事实才构成错位。

---

## CE-15 “现实中有效但不推荐”仍然值得学习

**对应：NV-16 / NV-23 边界**

例如：

- 暗黑模式；
- 未授权销售；
- 制造组织依赖；
- 信息操纵。

学习这些知识可以为了：

- 识别；
- 审计；
- 防骗；
- 合规；
- 产品治理；
- 风险建模。

因此系统不能把：

```text
“不应执行”
```

误判为：

```text
“不应知道”。
```

正确路由是：**防御性了解。**

## 2. 反例库对 AI 的强制测试

未来 AI 如果看到以下内容，不应该自动判错：

| 输入 | 不允许的自动结论 | 正确追问 |
|---|---|---|
| 有拟人化词 | “伪科学” | 是修辞还是字面因果？ |
| 宗教文本 | “无证据、无价值” | 当前判断的是事实、意义还是历史功能？ |
| 一则故事 | “故事不能证明，所以没用” | 它是在证明存在、启发机制，还是外推普遍规律？ |
| 重复安全提醒 | “正确废话” | 它是否降低关键错误？ |
| 不分享信息 | “权术” | 是否有隐私、合规或权限理由？ |
| 旧指南 | “过时垃圾” | 当时证据和替代方案是什么？ |
| 商业技巧 | “能提高转化，所以推荐” | 谁承担成本？全员采用会怎样？ |
| 情绪文章 | “知识密度低，所以忽略” | 用户此刻是否需要情绪支持？ |
