# 生活链路宇宙

> **生活总链**：感知需要与状态 → 判断价值和边界 → 安排时间、精力、金钱和环境 → 行动体验 → 记录必要反馈 → 调整平衡 → 长期维护 → 在变化时重新选择。

生活不是等待管理的项目集合。链路只在出现目标、冲突、风险、长期失衡或重要选择时展开；休息、关系、娱乐和体验不要求全部量化。

## 一、主要分区

1. 健康与身体状态
2. 时间、精力和注意力
3. 家庭、亲密关系和社会关系
4. 居住、物品和生活环境
5. 消费、预算和个人财务
6. 学习、成长和职业准备
7. 出行、休闲、体验和意义
8. 生活风险、突发事件和恢复

## 二、主要组合链

### 日常事务闭环

> 捕捉事项 → 澄清结果期限 → 判断价值紧急 → 安排时间资源 → 执行 → 记录状态 → 检查结果 → 收尾归档

调用：触发识别、价值排序、计划制定、任务执行、完成收尾。

### 时间与精力安排

> 汇总承诺和固定约束 → 记录精力高低峰 → 估计任务强度 → 按价值期限排序 → 匹配时段 → 留缓冲恢复 → 执行观察 → 周期重排

调用：价值排序、时间注意力、资源配置、进度监测、纠偏调整。

### 健康计划

> 识别健康需要 → 必要时专业评估 → 设安全目标标准 → 测量现状风险 → 选择行为方案 → 准备环境和最低行动 → 执行〔记录行为＋监测身体反馈〕→ 周期评估 → 调整强度方案 → 稳定维护

出现伤痛、严重不适或其他危险信号时，暂停原计划并转专业支持或异常响应。

### 习惯形成

> 选择具体行为 → 绑定稳定情境 → 降低启动难度 → 改造环境 → 重复执行 → 即时记录反馈 → 处理遗漏 → 逐步稳定 → 检查真实效果

无法坚持时优先检查动作是否过大、触发是否稳定、环境阻力和状态负荷，而不是直接否定目标。

### 关系维护与修复

> 识别关系价值边界 → 保持必要联系 → 表达需要并倾听 → 交换支持反馈 → 发现失衡或伤害 → 澄清事实利益 → 修复信任／调整距离／设置边界 → 继续／暂停／结束

关系链必须保留自愿、尊重、安全和退出权；不能把控制对方包装成协作管理。

### 物品生命周期

> 识别需要 → 决定购买／借用／租用／替代／放弃 → 验收登记 → 分类放置 → 使用维护 → 定期盘点 → 修理／转让／归档／淘汰

### 消费决策

> 澄清真实需要 → 判断不买或延迟 → 设预算和必须条件 → 搜集候选证据 → 比较全周期成本、价值、风险和可逆性 → 决定 → 交易验收 → 使用评估 → 售后／转卖／淘汰

### 个人财务循环

> 明确生活目标和安全边界 → 盘点资产负债收入支出 → 识别现金流风险缺口 → 排储蓄保障偿债投资优先 → 制定预算规则 → 执行记录 → 对账评估 → 调整配置 → 年度复盘

具体投资、保险、税务和法律问题需要适用当地规则和专业意见。

### 出行准备

> 明确目的人员时间限制 → 搜集路线费用规则 → 比较方案 → 预订并准备证件物品 → 检查天气交通安全和备选 → 执行行程 → 处理变更异常 → 返程核对 → 总结归档

### 生活事件响应

> 感知事件 → 判断常规／问题／异常 → 明确影响责任 → 选择处理方案 → 协调人员资源 → 执行 → 验证恢复 → 记录经验

## 三、关键平衡

- 目标与体验：不是所有有价值活动都必须产出可量化成果。
- 自律与恢复：持续失败可能来自状态、环境或资源，而非意志不足。
- 个人与关系：个人目标不能自动凌驾于共同承诺和他人边界。
- 当下与长期：紧急事项不能长期吞噬健康、关系和能力建设。
- 记录与负担：只记录能帮助安全、决策、反馈和复盘的必要信息。

## 四、最低运行问题

1. 现在真正需要改变什么？
2. 为什么值得做，是否损害更重要的生活价值？
3. 时间、精力、金钱和环境是否支持？
4. 最小可行动作是什么？
5. 用什么信号判断继续、调整、休息或求助？
6. 形成长期维护，还是完成后结束？
