# 通用总链与 Level 1—3 总地图

> **本文件最重要的内容**：二十节点总链是主导航；十一系统用于按问题选链；L2基础链承担唯一转化职责；L3只负责组合应用，不复制基础链。

## 一、三版通用总链

### 1. 八节点记忆版

> **感知 → 定向 → 规划 → 行动 → 检查 → 调整 → 学习 → 更新**

### 2. 二十节点完整紧凑版

> **发现信号 → 记录现象 → 定义需要／问题／机会／变化／任务 → 判断价值 → 排定优先 → 界定边界 → 初识现状 → 设定目标与标准 → 查找信息 → 核实证据 → 分析差距、原因与规律 → 生成备选方案 → 验证关键假设 → 比较并决策 → 拆解成果与任务 → 配置时间、资源、责任与预案 → 执行交付〔记录＋监测＋沟通＋质量＋风险＋合规〕→ 处理偏差、问题、变更与异常 → 验证要求、确认用途、验收移交并评估价值 → 总结复盘、沉淀复制，进入维护／扩大／暂停／交接／更新／归档／淘汰／重启**

### 3. 完整生命周期版

> **感知需求／问题／机会／变化／任务 → 登记并初筛 → 识别对象、相关方与边界 → 初判价值、紧迫性和正当性 → 初步了解现状与关键约束 → 明确目标、范围、成功标准和证据要求 → 完整调查现状、差距、原因与未知 → 生成方案、保底方案和退出方案 → 验证关键假设并作出选择 → 拆解成果、任务、依赖和里程碑 → 配置时间、精力、人员、资金、信息、工具、能力和权限 → 识别风险并准备预案 → 授权分工并启动 →〔执行行动＋记录事实＋监测进度＋同步协作＋检查质量＋控制风险合规〕→ 识别偏差、问题、变更或异常 → 分级纠偏、重规划、恢复或止损 → 形成成果并提交 → 验证是否符合规定要求 → 确认是否满足真实用途 → 由有权者验收并完成移交 → 测量实际结果、副作用与净价值 → 总结事实并复盘原因 → 提炼经验并安排改进验证 → 转化为知识、能力、方法、流程、标准或工具 → 维护、扩大、迁移、暂停、交接、归档、淘汰或重新启用**

## 二、Level 1—3 总地图

- **L0：通用行动生命周期**
  - 感知触发 → 定向取舍 → 研究选择 → 计划准备 → 执行控制 → 验收评价 → 学习沉淀 → 运维退出
  - **L1-01：感知与定向系统**
    - **L2：触发识别链**：接收信号 → 记录来源 → 辨别类型 → 核验真实性 → 估计影响 → 指定去向
    - **L2：需求澄清链**：识别相关方 → 收集诉求 → 还原场景 → 区分表象实需 → 处理冲突 → 确认需求
    - **L2：机会识别链**：观察变化 → 发现未满足价值 → 识别受益者 → 判断窗口能力 → 形成机会假设 → 探索／等待／放弃
    - **L2：价值排序链**：列出事项 → 比较收益成本风险时效 → 判断可逆性和依赖 → 排优先 → 立项／延后／委派／放弃
    - **L2：目标设定链**：承接事项 → 描述期望状态 → 设定指标期限 → 检查价值可行性 → 明确责任 → 确认承诺
    - **L2：范围界定链**：明确对象 → 列包含排除 → 识别接口约束假设 → 处理争议 → 建立范围基线
    - **L2：标准设定链**：明确成果用途 → 选择维度 → 定义阈值容差证据 → 指定判定人 → 确认标准
    - **L3应用**：个人目标、用户需求、市场机会、项目立项、组织战略事项。
  - **L1-02：研究与认识系统**
    - **L2：现状初判链**：明确目的 → 收集关键事实 → 识别硬约束 → 判断能否继续 → 形成初始说明
    - **L2：现状差距链**：描述目标状态 → 统一口径 → 收集当前证据 → 对照差距 → 识别障碍 → 排定关键差距
    - **L2：问题定义链**：发现偏差 → 分离事实判断 → 描述现状期望 → 界定边界影响 → 形成问题陈述
    - **L2：问题拆解链**：选择维度 → 分解子问题 → 检查重叠遗漏 → 标注依赖 → 确定关键问题
    - **L2：信息检索链**：明确问题 → 规划检索 → 选择来源 → 搜索采集 → 扩展线索 → 记录出处 → 判断充分
    - **L2：信息筛选链**：汇总资料 → 初筛相关 → 判断质量时效 → 分层排序 → 排除低值重复
    - **L2：数据采集链**：定义问题指标 → 选择来源方法 → 采集样本 → 校验质量 → 清洗标注 → 保存交付
    - **L2：证据核查链**：提取主张 → 追溯原始来源 → 检查方法语境 → 交叉验证 → 处理冲突 → 标注可信度未知
    - **L2：原因分析链**：收集事实 → 重建关系 → 生成原因假设 → 寻找反证 → 锁定可干预原因
    - **L2：知识加工链**：阅读解析 → 拆解提取 → 统一术语 → 归类去重 → 对比综合
    - **L2：知识建模链**：识别概念 → 建立分类关系 → 解释机制 → 补例证反例 → 检验发布
    - **L3应用**：陌生领域研究、多书蒸馏、市场调查、故障诊断、经营分析。
  - **L1-03：选择与验证系统**
    - **L2：方案生成链**：明确目标约束 → 寻找机制先例 → 生成多方案 → 补保底退出方案 → 筛除不可行项
    - **L2：决策选择链**：明确决策权 → 建立标准 → 比较收益成本风险可逆性 → 检查偏差 → 选择／试验 → 记录复查条件
    - **L2：假设验证链**：提出假设 → 定义预测 → 设计验证 → 收集结果 → 排除替代解释 → 接受／修正／否定
    - **L2：概念设计链**：理解需求 → 提核心概念 → 描述场景 → 设计结构机制 → 明确取舍 → 形成方案
    - **L2：原型试验链**：选择假设 → 制作最小原型 → 设计测试 → 收集行为反馈 → 判断 → 修改／推进／停止
    - **L2：阶段决断链**：汇总证据 → 评估剩余价值风险 → 继续／扩大／调整／暂停／转交／终止
    - **L3应用**：消费决策、技术选型、产品探索、投资立项、复杂问题解决。
  - **L1-04：计划与配置系统**
    - **L2：目标拆解链**：划分成果 → 分解子目标 → 建立依赖 → 分配责任 → 设置里程碑 → 校验完整
    - **L2：计划制定链**：读取目标方案 → 拆成果任务 → 排依赖优先 → 估时间资源 → 分责任 → 设检查点变更规则 → 形成基线
    - **L2：资源配置链**：识别需要 → 盘点存量 → 找缺口 → 获取调配替代 → 解决冲突 → 分配使用
    - **L2：预算管理链**：估收入成本 → 分配额度 → 留缓冲 → 批准支出 → 记录实际 → 比较偏差 → 调整
    - **L2：时间注意力链**：盘点承诺精力 → 匹配任务强度 → 安排时段缓冲 → 减少切换 → 执行观察 → 重排
    - **L2：责任授权链**：明确成果 → 选择负责人 → 说明权责 → 配资源权限 → 约定报告升级 → 确认接手
    - **L2：执行准备链**：确认任务 → 查前置 → 补能力 → 准备环境工具数据 → 演练检查 → 启动／补齐／暂停
    - **L2：风险预案链**：识别风险 → 定触发 → 评概率影响 → 选策略 → 设预警 → 准备预案责任
    - **L3应用**：日周计划、学习计划、项目计划、产品路线、经营计划、应急准备。
  - **L1-05：执行与创造系统**
    - **L2：任务执行链**：接收任务 → 确认要求 → 核对前置 → 推进行动 → 处理阻碍 → 自检 → 提交
    - **L2：创意形成链**：收集问题素材 → 发散联想 → 重组变异 → 生成构想 → 初筛价值可行 → 保留候选
    - **L2：生产完善链**：确认规格 → 组织资源 → 制作初版 → 编辑校验 → 修复缺陷 → 质量复核 → 形成成品
    - **L2：发布迭代链**：确认条件回退 → 发布上线 → 确认可达可用 → 监测反馈 → 排改进 → 更新版本
    - **L2：验证确认链**：明确要求用途 → 设计证据 → 验证符合要求 → 确认满足情境 → 处理差异 → 形成结论
    - **L2：验收移交链**：整理成果证据 → 正式提交 → 授权评审 → 处理遗留 → 接受／拒收 → 移交资料权限责任
    - **L2：完成收尾链**：确认验收 → 关闭遗留 → 结清资源责任 → 通知相关方 → 归档 → 正式结束
    - **L2：习惯形成链**：选行为 → 绑定情境 → 降启动难度 → 改环境 → 重复记录反馈 → 处理遗漏 → 稳定重评
    - **L2：状态调节链**：觉察状态 → 识别诱因需要 → 降低过载危险 → 休息／小行动／求助 → 观察恢复
    - **L3应用**：任务闭环、内容创作、产品生产、软件交付、健康习惯。
  - **L1-06：沟通与协作系统**
    - **L2：表达确认、倾听理解、请求回应、分工协作、冲突协商、会议决议、授权监督、关系维护**
    - **L3应用**：家庭协商、跨角色交付、团队协作、客户沟通、商务谈判、跨部门项目。
  - **L1-07：记录与保障系统**
    - **L2：过程记录、记录管理、证据管理、追溯管理、进度监测、状态预警、质量控制、风险管理、合规伦理审查、变更控制、异常响应、故障恢复、事件调查**
    - **L3应用**：个人记录、项目控制、质量保证、软件监控、合规审计、危机响应。
  - **L1-08：评估与改进系统**
    - **L2：评估判断、效果价值、反馈处理、纠偏调整、总结提炼、复盘改进、持续改进**
    - **L3应用**：日周复盘、学习评估、项目评审、产品分析、绩效改进、经营复盘。
  - **L1-09：学习与能力系统**
    - **L2：理解建构、记忆巩固、练习反馈、迁移应用、能力评估**
    - **L3应用**：个人学习、陌生领域进入、职业训练、AI工具能力、团队能力建设。
  - **L1-10：沉淀与复制系统**
    - **L2：经验沉淀、流程标准化、工具化自动化、培训上岗、组织采用、扩大复制**
    - **L3应用**：个人方法库、项目经验标准化、OPC自动化、公司转化、最佳实践推广。
  - **L1-11：运维与退出系统**
    - **L2：状态维护、版本更新、扩大迁移、交接转移、暂停恢复、归档保留、过时淘汰、重新启用**
    - **L3应用**：设备知识维护、软件升级、产品扩大、岗位交接、业务暂停、项目关闭、制度淘汰。

## 三、主要关口

| 关口 | 判断问题 | 未通过的去向 |
| --- | --- | --- |
| 价值门 | 值得、正当、及时吗 | 观察、延后、委派、放弃 |
| 清晰门 | 事项、对象和边界清楚吗 | 需求澄清、问题定义 |
| 目标门 | 结果、标准、证据和责任明确吗 | 目标、范围、标准重设 |
| 证据门 | 信息足以支持当前决定吗 | 检索、采集、核查、保留未知 |
| 方案门 | 有可接受方案、保底和退出方案吗 | 方案生成、放宽约束、调整目标、停止 |
| 就绪门 | 资源、权限、能力、风险、合规允许开始吗 | 补资源、授权、准备、缩范围、暂停 |
| 执行门 | 继续、纠偏、变更、升级还是停止 | 返回相应致因层级 |
| 验证门 | 是否符合规定要求 | 返工、质量纠正、规格变更 |
| 确认门 | 是否满足真实用途 | 返回需求、方案或产品假设 |
| 验收门 | 有权接收者是否接受并接管 | 补遗留、拒收、条件接受 |
| 价值门（二次） | 实际效果相对成本风险是否值得 | 调整、暂停、转向、退出 |
| 延续门 | 下一周期进入什么状态 | 继续、扩大、维护、更新、交接、归档、淘汰 |

## 四、总地图使用纪律

1. L1是导航，不是固定阶段顺序。
2. L2按输入、输出和主转化唯一归属。
3. L3只组合基础链，不复制同义链。
4. 记录、证据、监测、沟通、质量、风险、合规和版本贯穿全程。
5. 低风险事项只走必要节点；高风险事项展开完整关口。
6. 每个循环都必须有停止、升级、转向和退出条件。
