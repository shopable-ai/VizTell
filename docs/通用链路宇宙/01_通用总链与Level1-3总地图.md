# 通用总链与 Level 1—3 总地图

> **本文件最重要的内容**：二十节点总链是主导航；十一系统用于按问题选链；L2基础链承担唯一转化职责；L3只负责组合应用，不复制基础链。

> 导航：[返回总览](00_总览与核心结论.md)｜[三十条基础链](02_通用基础链路库.md)｜[术语与编号索引](12_术语、边界与编号索引.md)｜[工作流装配](14_工作流装配方法.md)

## 一、一分钟找到入口

1. **先看八节点记忆版**，确认事情处于感知、定向、规划、行动、检查、调整、学习还是更新。
2. **再按当前卡点选择 L1 系统**，不要把十一系统误当成固定顺序。
3. **从 C01—C30 或扩展基础链中选最少必要链**，再按具体场景装配为 L3／L4。
4. **普通事项走轻量路径**；金额、健康、安全、隐私、法律、多人协作、不可逆性或外部承诺上升时，增加正式关口、责任和证据。

| 常见情境 | 最短可用路径 | 何时加链 |
| --- | --- | --- |
| 日常小事 | 需要／触发 → 期望结果 → 完成条件 → 下一动作 → 执行 → 检查 → 结束 | 不清楚是否值得做时加价值排序；需要长期保持时加 C30 |
| 复杂问题 | C20 问题定义 → C23 信息处理 → C21 原因分析 → C22 决策选择 → C09 执行 → C15 评估 | 目标、标准或资源不清时补 C04—C08 |
| 学习陌生领域 | C04 目标 → C05 标准 → C23 信息处理 → C24 个人学习 → C09 场景运用 → C15 评估 → C19 沉淀 | 资料冲突时加证据核查；迁移失败时回练习与条件分析 |
| 项目／产品 | C01—C05 定向 → C22 选方案 → C06—C08 准备 → C09 执行并行束 → C14—C16 交付评价 → C18／C19／C30 | 多人协作加 C25／C26；生产与高风险场景加严格控制 |
| 组织采用／变更 | C19 经验证经验 → C27 组织转化 → 组织变更落地链 → C15 采用效果 → C30 维护、扩大或撤回 | 权责、能力、激励或迁移复杂时增加授权、培训、沟通和变更控制 |
| 风险与异常 | C28 风险管理 → C08 预案；风险发生后切换 C29 异常恢复 → C21／C18 → C30 | 先保护人员、资产与证据，再恢复、调查和防复发 |

## 二、三版通用总链

### 1. 八节点记忆版

> **感知 → 定向 → 规划 → 行动 → 检查 → 调整 → 学习 → 更新**

### 2. 二十节点完整紧凑版

> **发现信号 → 记录现象 → 定义需要／问题／机会／变化／任务 → 判断价值 → 排定优先 → 界定边界 → 初识现状 → 设定目标与标准 → 查找信息 → 核实证据 → 分析差距、原因与规律 → 生成备选方案 → 验证关键假设 → 比较并决策 → 拆解成果与任务 → 配置时间、资源、责任与预案 → 执行交付〔记录＋监测＋沟通＋质量＋风险＋合规〕→ 处理偏差、问题、变更与异常 → 验证要求、确认用途、验收移交并评估价值 → 总结复盘、沉淀复制，进入维护／扩大／暂停／交接／更新／归档／淘汰／重启**

### 3. 完整生命周期版

> **感知需求／问题／机会／变化／任务 → 登记并初筛 → 识别对象、相关方与边界 → 初判价值、紧迫性和正当性 → 初步了解现状与关键约束 → 明确目标、范围、成功标准和证据要求 → 完整调查现状、差距、原因与未知 → 生成方案、保底方案和退出方案 → 验证关键假设并作出选择 → 拆解成果、任务、依赖和里程碑 → 配置时间、精力、人员、资金、信息、工具、能力和权限 → 识别风险并准备预案 → 授权分工并启动 →〔执行行动＋记录事实＋监测进度＋同步协作＋检查质量＋控制风险合规〕→ 识别偏差、问题、变更或异常 → 分级纠偏、重规划、恢复或止损 → 形成成果并提交 → 验证是否符合规定要求 → 确认是否满足真实用途 → 由有权者验收并完成移交 → 测量实际结果、副作用与净价值 → 总结事实并复盘原因 → 提炼经验并安排改进验证 → 转化为知识、能力、方法、流程、标准或工具 → 维护、扩大、迁移、暂停、交接、归档、淘汰或重新启用**

## 三、Level 0—4 与 Level 1—3 总地图

| 层级 | 主要职责 | 典型输出 | 不应承担 |
| --- | --- | --- | --- |
| L0 通用生命周期 | 描述任何对象从触发到退出的完整状态变化 | 八节点、二十节点与完整生命周期总链 | 具体角色、工具和行业规则 |
| L1 功能系统 | 按当前问题或卡点导航 | 十一类运行系统与入口 | 固定阶段顺序 |
| L2 基础链 | 完成一种可复用状态转化 | C01—C30 核心包与扩展基础链 | 复制领域同义链 |
| L3 组合链 | 为一类场景组合多条基础链 | 学习、项目、产品、组织、事故等场景链 | 重写基础链定义 |
| L4 工作流 | 落实到真实角色、工具、时限、阈值、权限和证据 | 可运行、可验收、可审计的具体流程 | 冒充跨领域通用定义 |

> **纵向关系**：L0 定生命周期，L1 帮助选链，L2 提供转化模块，L3 负责组合，L4 负责落地。  
> **横向并行束**：任务执行期间按风险挂接记录、证据、监测、沟通、质量、风险、合规、安全、变更与版本控制；它们不是只在某个阶段出现一次。


- **L0：通用行动生命周期**
  - 感知触发 → 定向取舍 → 研究选择 → 计划准备 → 执行控制 → 验收评价 → 学习沉淀 → 运维退出
  - **L1-01：感知与定向系统**
    - **L2：触发识别链**：接收信号 → 记录来源 → 辨别类型 → 核验真实性 → 估计影响 → 指定去向
    - **L2：需求澄清链**：识别相关方 → 收集诉求 → 还原场景 → 区分表象实需 → 处理冲突 → 确认需求
    - **L2：机会识别链**：观察变化 → 发现未满足价值 → 识别受益者 → 判断窗口能力 → 形成机会假设 → 探索／等待／放弃
    - **L2：价值排序链**：列出事项 → 比较收益成本风险时效 → 判断可逆性和依赖 → 排优先 → 立项／延后／委派／放弃
    - **L2：目标设定链**：承接事项 → 描述期望状态 → 设定指标期限 → 检查价值可行性 → 明确责任 → 确认承诺
    - **L2：范围界定链**：明确对象 → 列包含排除 → 识别接口约束假设 → 处理争议 → 建立范围基线
    - **L2：标准设定链**：明确成果用途 → 选择维度 → 定义阈值容差证据 → 指定判定人 → 确认标准
    - **L3应用**：个人目标、用户需求、市场机会、项目立项、组织战略事项。
  - **L1-02：研究与认识系统**
    - **L2：现状初判链**：明确目的 → 收集关键事实 → 识别硬约束 → 判断能否继续 → 形成初始说明
    - **L2：现状差距链**：描述目标状态 → 统一口径 → 收集当前证据 → 对照差距 → 识别障碍 → 排定关键差距
    - **L2：问题定义链**：发现偏差 → 分离事实判断 → 描述现状期望 → 界定边界影响 → 形成问题陈述
    - **L2：问题拆解链**：选择维度 → 分解子问题 → 检查重叠遗漏 → 标注依赖 → 确定关键问题
    - **L2：信息检索链**：明确问题 → 规划检索 → 选择来源 → 搜索采集 → 扩展线索 → 记录出处 → 判断充分
    - **L2：信息筛选链**：汇总资料 → 初筛相关 → 判断质量时效 → 分层排序 → 排除低值重复
    - **L2：数据采集链**：定义问题指标 → 选择来源方法 → 采集样本 → 校验质量 → 清洗标注 → 保存交付
    - **L2：证据核查链**：提取主张 → 追溯原始来源 → 检查方法语境 → 交叉验证 → 处理冲突 → 标注可信度未知
    - **L2：原因分析链**：收集事实 → 重建关系 → 生成原因假设 → 寻找反证 → 锁定可干预原因
    - **L2：知识加工链**：阅读解析 → 拆解提取 → 统一术语 → 归类去重 → 对比综合
    - **L2：知识建模链**：识别概念 → 建立分类关系 → 解释机制 → 补例证反例 → 检验发布
    - **L3应用**：陌生领域研究、多书蒸馏、市场调查、故障诊断、经营分析。
  - **L1-03：选择与验证系统**
    - **L2：方案生成链**：明确目标约束 → 寻找机制先例 → 生成多方案 → 补保底退出方案 → 筛除不可行项
    - **L2：决策选择链**：明确决策权 → 建立标准 → 比较收益成本风险可逆性 → 检查偏差 → 选择／试验 → 记录复查条件
    - **L2：假设验证链**：提出假设 → 定义预测 → 设计验证 → 收集结果 → 排除替代解释 → 接受／修正／否定
    - **L2：概念设计链**：理解需求 → 提核心概念 → 描述场景 → 设计结构机制 → 明确取舍 → 形成方案
    - **L2：原型试验链**：选择假设 → 制作最小原型 → 设计测试 → 收集行为反馈 → 判断 → 修改／推进／停止
    - **L2：阶段决断链**：汇总证据 → 评估剩余价值风险 → 继续／扩大／调整／暂停／转交／终止
    - **L3应用**：消费决策、技术选型、产品探索、投资立项、复杂问题解决。
  - **L1-04：计划与配置系统**
    - **L2：目标拆解链**：划分成果 → 分解子目标 → 建立依赖 → 分配责任 → 设置里程碑 → 校验完整
    - **L2：计划制定链**：读取目标方案 → 拆成果任务 → 排依赖优先 → 估时间资源 → 分责任 → 设检查点变更规则 → 形成基线
    - **L2：资源配置链**：识别需要 → 盘点存量 → 找缺口 → 获取调配替代 → 解决冲突 → 分配使用
    - **L2：预算管理链**：估收入成本 → 分配额度 → 留缓冲 → 批准支出 → 记录实际 → 比较偏差 → 调整
    - **L2：时间注意力链**：盘点承诺精力 → 匹配任务强度 → 安排时段缓冲 → 减少切换 → 执行观察 → 重排
    - **L2：责任授权链**：明确成果 → 选择负责人 → 说明权责 → 配资源权限 → 约定报告升级 → 确认接手
    - **L2：执行准备链**：确认任务 → 查前置 → 补能力 → 准备环境工具数据 → 演练检查 → 启动／补齐／暂停
    - **L2：风险预案链**：识别风险 → 定触发 → 评概率影响 → 选策略 → 设预警 → 准备预案责任
    - **L3应用**：日周计划、学习计划、项目计划、产品路线、经营计划、应急准备。
  - **L1-05：执行与创造系统**
    - **L2：任务执行链**：接收任务 → 确认要求 → 核对前置 → 推进行动 → 处理阻碍 → 自检 → 提交
    - **L2：创意形成链**：收集问题素材 → 发散联想 → 重组变异 → 生成构想 → 初筛价值可行 → 保留候选
    - **L2：生产完善链**：确认规格 → 组织资源 → 制作初版 → 编辑校验 → 修复缺陷 → 质量复核 → 形成成品
    - **L2：发布迭代链**：确认条件回退 → 发布上线 → 确认可达可用 → 监测反馈 → 排改进 → 更新版本
    - **L2：验证确认链**：明确要求用途 → 设计证据 → 验证符合要求 → 确认满足情境 → 处理差异 → 形成结论
    - **L2：验收移交链**：整理成果证据 → 正式提交 → 授权评审 → 处理遗留 → 接受／拒收 → 移交资料权限责任
    - **L2：完成收尾链**：确认验收 → 关闭遗留 → 结清资源责任 → 通知相关方 → 归档 → 正式结束
    - **L2：习惯形成链**：选行为 → 绑定情境 → 降启动难度 → 改环境 → 重复记录反馈 → 处理遗漏 → 稳定重评
    - **L2：状态调节链**：觉察状态 → 识别诱因需要 → 降低过载危险 → 休息／小行动／求助 → 观察恢复
    - **L3应用**：任务闭环、内容创作、产品生产、软件交付、健康习惯。
  - **L1-06：沟通与协作系统**
    - **L2：表达确认链**：明确目的对象 → 组织事实意图请求 → 选择方式时机 → 清楚表达 → 接收回应 → 复述确认 → 记录共识
    - **L2：倾听理解链**：创造可表达条件 → 完整倾听 → 区分事实情绪判断需要 → 追问澄清 → 复述理解 → 请对方确认
    - **L2：请求回应链**：说明情境需要 → 提出具体请求 → 明确责任期限边界 → 对方评估 → 接受／拒绝／反建议 → 确认下一动作
    - **L2：分工协作链**：明确共同成果 → 拆工作包 → 匹配责任能力 → 约定接口依赖 → 配权限资源 → 同步进展 → 处理阻塞 → 合并验收
    - **L2：冲突协商链**：暂停对抗 → 分离人与问题 → 澄清事实立场利益底线 → 生成选项 → 比较交换 → 达成协议／升级裁决
    - **L2：会议决议链**：明确会议目的 → 准备议题证据 → 邀请必要角色 → 限时讨论 → 作出决定 → 指定责任期限 → 记录并跟进
    - **L2：授权监督链**：定义成果边界 → 选择承接者 → 配置权力资源 → 约定检查升级 → 放手执行 → 监督例外 → 验收或调整
    - **L2：关系维护链**：识别关系目标期望 → 保持真实互动 → 履行承诺与互惠 → 尊重边界 → 修复破损 → 定期重评
    - **L3应用**：家庭协商、跨角色交付、团队协作、客户沟通、商务谈判、跨部门项目。
  - **L1-07：记录与保障系统**
    - **L2：过程记录链**：明确记录目的 → 定最小字段 → 采集事实 → 标注时间来源责任 → 关联对象版本 → 校验保存 → 支持检索
    - **L2：记录管理链**：盘点记录 → 分类命名 → 设置位置权限保留期 → 建立索引 → 备份保护 → 定期清理迁移
    - **L2：证据管理链**：明确待证主张 → 收集证据 → 记录来源方法语境 → 评可信度 → 建主张映射 → 保留反证未知 → 受控存取
    - **L2：追溯管理链**：定义追溯对象 → 建立来源—决定—版本—结果关系 → 分配稳定标识 → 校验断点 → 支持正反向查询
    - **L2：进度监测链**：读取目标计划阈值 → 采集状态 → 比较进度成本负荷 → 识别偏差趋势 → 预警升级 → 触发处置
    - **L2：状态预警链**：选择领先指标 → 定义阈值趋势组合 → 持续观察 → 过滤噪声 → 分级通知 → 确认响应 → 调整规则
    - **L2：质量控制链**：读取标准 → 设置控制点 → 检测对象 → 记录缺陷 → 判定等级 → 返工／让步／放行 → 复检
    - **L2：风险管理链**：识别不确定性 → 分析概率影响关联 → 评价承受度 → 选择应对 → 指定责任触发器 → 监测复审
    - **L2：合规伦理审查链**：识别适用规则与受影响者 → 检查合法性正当性公平性 → 评估隐私安全伤害 → 补控制 → 授权决定 → 留证复查
    - **L2：变更控制链**：提出变更 → 说明原因范围 → 评估价值影响风险 → 批准／拒绝 → 更新基线版本 → 通知迁移 → 验证回退
    - **L2：异常响应链**：发现异常 → 验证分级 → 保护人员资产证据 → 控制影响 → 通知指挥 → 切换恢复或升级
    - **L2：故障恢复链**：确认可恢复目标 → 隔离诊断 → 修复／回退／替代 → 验证数据功能 → 逐步恢复 → 加强监测
    - **L2：事件调查链**：保护证据 → 重建时间线 → 分析技术与系统因素 → 确认影响责任 → 提整改建议 → 跟踪验证
    - **L3应用**：个人记录、项目控制、质量保证、软件监控、合规审计、危机响应。
  - **L1-08：评估与改进系统**
    - **L2：评估判断链**：明确对象用途标准 → 收集证据 → 测量结果影响 → 对照差距 → 表达不确定性 → 形成结论建议
    - **L2：效果价值链**：定义预期变化 → 建立基线对照 → 测量实际结果副作用 → 分析贡献 → 比较成本风险分配 → 决定延续
    - **L2：反馈处理链**：接收反馈 → 核验来源语境 → 分类聚合 → 定位影响对象 → 排价值优先 → 回复 → 分派去向
    - **L2：纠偏调整链**：确认偏差层级 → 定位可控原因 → 选最小有效调整 → 评连带影响 → 实施检查 → 保留／回退／升级
    - **L2：总结提炼链**：汇集材料 → 回顾事实 → 筛重点 → 区分事实解释 → 提炼规律边界 → 压缩表达 → 保存传播
    - **L2：复盘改进链**：还原目标假设过程 → 对照结果 → 识别成功失败意外 → 分析原因 → 提炼边界 → 设计改进试验
    - **L2：持续改进链**：建立基线 → 选择瓶颈 → 提出小改动 → 试验测量 → 比较净效果 → 标准化／撤回 → 进入下一轮
    - **L3应用**：日周复盘、学习评估、项目评审、产品分析、绩效改进、经营复盘。
  - **L1-09：学习与能力系统**
    - **L2：理解建构链**：激活旧知 → 接触新信息 → 解释含义机制 → 建联系结构 → 生成例子反例 → 自我解释检查
    - **L2：记忆巩固链**：选择关键内容 → 深度编码 → 主动回想 → 间隔复习 → 交错辨别 → 根据遗忘调整
    - **L2：练习反馈链**：定义表现目标 → 拆技能 → 设计递进练习 → 独立作答／操作 → 获得反馈 → 针对错误再练
    - **L2：迁移应用链**：识别原理与适用条件 → 比较新旧情境 → 选择策略 → 独立运用 → 检查结果 → 修正边界
    - **L2：能力评估链**：定义真实任务标准 → 设计代表性测评 → 独立完成 → 收集表现证据 → 诊断缺口 → 决定训练或认证
    - **L3应用**：个人学习、陌生领域进入、职业训练、AI工具能力、团队能力建设。
  - **L1-10：沉淀与复制系统**
    - **L2：经验沉淀链**：收集经验 → 区分规律偶然 → 提炼条件原则步骤例外 → 选择载体 → 试用验证 → 发布复用 → 更新
    - **L2：流程标准化链**：选择稳定做法 → 定义输入输出角色控制 → 编写标准 → 跨人试运行 → 修订批准 → 版本发布
    - **L2：工具化自动化链**：识别重复规则 → 判断自动化边界 → 设计人机分工 → 实现测试 → 监测错误 → 回退维护
    - **L2：培训上岗链**：定义岗位表现 → 设计学习练习 → 示范辅导 → 独立实操 → 评估授权 → 跟踪补训
    - **L2：组织采用链**：识别采用对象 → 对齐价值权责激励 → 配置流程工具支持 → 试点 → 收集阻力 → 扩散或撤回
    - **L2：组织变更落地链**：明确变更理由与目标状态 → 识别受影响者 → 建立赞助和决策权 → 设计过渡迁移回退 → 沟通参与 → 培训支持 → 分批采用 → 监测稳定
    - **L2：扩大复制链**：验证可复制单元 → 检查容量和差异 → 标准化接口 → 分批扩大 → 监测质量边际收益 → 调整上限
    - **L3应用**：个人方法库、项目经验标准化、OPC自动化、公司转化、组织变更、最佳实践推广。
  - **L1-11：运维与退出系统**
    - **L2：状态维护链**：定义健康状态 → 设检查周期 → 执行保养修补 → 验证状态 → 记录成本问题 → 决定继续或更新
    - **L2：版本更新链**：收集变化 → 判断兼容影响 → 设计新版本迁移回退 → 验证 → 批准发布 → 监测采用 → 淘汰旧版
    - **L2：扩大迁移链**：明确目标环境规模 → 盘点依赖差异 → 设计转换映射 → 分批迁移 → 验证完整可用 → 切换回退
    - **L2：交接转移链**：盘点状态资料权限关系风险 → 选择接收者 → 讲解演练 → 补能力权限 → 接收确认 → 转移责任
    - **L2：暂停恢复链**：决定暂停 → 保存安全状态版本 → 处理影响依赖 → 指定责任复查触发 → 重新核验 → 恢复／继续暂停／退出
    - **L2：归档保留链**：确认不再活跃使用 → 整理版本元数据 → 设置权限保留期 → 安全存放 → 验证可检索 → 到期处置
    - **L2：过时淘汰链**：识别过时风险 → 调查依赖用户 → 选替代迁移 → 通知停用 → 安全处置 → 验证无遗留
    - **L2：重新启用链**：提出重启需要 → 复核价值时效完整权限依赖 → 补更新测试 → 重新批准 → 小范围启用 → 监测稳定
    - **L3应用**：设备知识维护、软件升级、产品扩大、岗位交接、业务暂停、项目关闭、制度淘汰。

### 十一系统之间的调用纪律

- 同一事项可以在多个 L1 系统间往返，但每次必须说明当前输入、期望输出和返回位置。
- 记录、监测、沟通、质量、风险、合规与变更通常作为执行并行束，不应被误解为主链末端才做的步骤。
- 风险尚未发生使用 C28／C08；风险已经发生立即切换 C29，不继续停留在概率评估。
- 验证、确认、验收、效果和价值是不同判断，不得用一次“检查通过”代替全部关口。
- 组织采用、组织变更和扩大复制必须经过真实人员与真实场景验证，不能以文档发布或培训完成代替结果。


## 四、主要关口

| 关口 | 判断问题 | 未通过的去向 |
| --- | --- | --- |
| 价值门 | 值得、正当、及时吗 | 观察、延后、委派、放弃 |
| 清晰门 | 事项、对象和边界清楚吗 | 需求澄清、问题定义 |
| 目标门 | 结果、标准、证据和责任明确吗 | 目标、范围、标准重设 |
| 证据门 | 信息足以支持当前决定吗 | 检索、采集、核查、保留未知 |
| 方案门 | 有可接受方案、保底和退出方案吗 | 方案生成、放宽约束、调整目标、停止 |
| 就绪门 | 资源、权限、能力、风险、合规允许开始吗 | 补资源、授权、准备、缩范围、暂停 |
| 执行门 | 继续、纠偏、变更、升级还是停止 | 返回相应致因层级 |
| 验证门 | 是否符合规定要求 | 返工、质量纠正、规格变更 |
| 确认门 | 是否满足真实用途 | 返回需求、方案或产品假设 |
| 验收门 | 有权接收者是否接受并接管 | 补遗留、拒收、条件接受 |
| 价值门（二次） | 实际效果相对成本风险是否值得 | 调整、暂停、转向、退出 |
| 延续门 | 下一周期进入什么状态 | 继续、扩大、维护、更新、交接、归档、淘汰 |

## 五、总地图使用纪律

1. L1是导航，不是固定阶段顺序。
2. L2按输入、输出和主转化唯一归属。
3. L3只组合基础链，不复制同义链。
4. 记录、证据、监测、沟通、质量、风险、合规和版本贯穿全程。
5. 低风险事项只走必要节点；高风险事项展开完整关口。
6. 每个循环都必须有停止、升级、转向和退出条件。
