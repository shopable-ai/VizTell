# 阅读学习与知识研究链路宇宙

> **核心主链**：**明确问题／能力目标 → 判断资料是否值得进入 → 建立已有知识基线 → 搜集与分层资料 → 预读结构 → 定向阅读与提取 → 对照旧知 → 区分重复、增量、冲突、过时和未知 → 建立知识模型 → 主动回想与练习 → 在真实问题中应用 → 评估掌握与迁移 → 补差 → 沉淀来源关系 → 持续更新／归档／淘汰**。

## 一、本文件的职责与边界

本文件承担阅读、学习、研究和大量资料知识增量的 **L3 场景组合**。C23 信息处理链和 C24 个人学习链仍是 L2 的正式定义；本文件只说明它们在文章、单书、多资料和真实任务中怎样组合。

“资料已经收藏、处理或进入知识库”与“人已经理解、掌握和能够迁移”必须分开。知识处理解决外部信息状态，学习解决个人能力状态。

具体 OCR、哈希、MinHash、SimHash、向量模型、聚类、数据库和相似度阈值属于 L4 工具配置，不是新的通用基础链。

## 二、四种主要场景

### 1. 一篇文章

> **触发问题 → 判断相关性和可信度 → 扫描结构 → 提取主张、机制、条件、证据和例子 → 对照已有知识 → 判断重复／新增／冲突／过时／未知 → 决定忽略／收藏／核查／深读／练习／应用／归档**

文章不值得深读时，尽早退出本身就是有效处理。

### 2. 单本书

> **是否值得读 → 预读结构 → 映射已有知识 → 划分必读／选读／跳过 → 章节阅读和知识单元提取 → 与旧知和同类资料比较 → 回想练习 → 真实应用 → 延迟复查 → 更新／归档／淘汰**

阅读强度由目标和知识差额决定，不由页数决定。

### 3. 围绕问题的多资料研究

> **定义研究问题 → 建已有知识基线 → 搜不同来源 → 分层证据 → 提取主张和条件 → 对比来源 → 处理冲突与未知 → 建解释模型 → 找反例和边界 → 形成阶段结论 → 用新证据更新**

研究的停止条件不是“资料全部看完”，而是已经足以支持当前决定、学习或行动，继续搜索的边际收益下降。

### 4. 本地大量资料／书库

> **明确知识地图 → 盘点文件和版本 → 解析内容并保留来源定位 → 切分知识单元 → 完全重复检测 → 近似候选召回 → 语义候选召回 → 命题关系判断 → 知识增量判断 → 与个人掌握状态比较 → 生成高价值阅读队列 → 定向学习 → 抽样复核 → 新资料增量更新**

重点不是“删掉最多内容”，而是识别**真正新增的机制、条件、证据、反例、时效信息和个人未掌握部分**。

## 三、文章进入链

### 1. 快速筛选

> **为什么看到它 → 与当前问题是否相关 → 作者／来源是否值得初步信任 → 是否有明确主张和证据 → 是否值得继续投入 → 忽略／稍后／深读**

### 2. 内容提取

将重要内容尽量整理为：

> **概念／对象 → 核心主张 → 作用机制 → 成立条件 → 适用范围 → 证据 → 例子／反例 → 结论／行动含义**

这样才能比较两篇文字不同但实际表达同一机制的内容，也能避免把同主题却具有新条件、新证据的内容误删。

### 3. 与旧知比较

> **找到对应旧知识 → 判断相同／包含／扩展／支持／冲突／无关 → 检查是否增加新机制、新边界、新证据、新反例或新时效信息 → 更新知识模型**

### 4. 去向决定

- 没有价值增量：忽略或仅保留来源关系；
- 有新证据：挂到原知识节点；
- 有新边界或反例：修改适用条件；
- 有冲突：进入核查；
- 有真正新知识：进入学习和应用队列；
- 暂时无法判断：进入待核查，而不是强行合并。

## 四、单本书 T0—T7 阶段链

### T0：选择是否阅读

> **当前目标／问题 → 书的主题、作者、版本和证据质量 → 与已有知识重叠预估 → 预期新增价值 → 读／部分读／暂缓／不读**

### T1：预读

> **目录 → 序言 → 结论 → 索引／摘要 → 核心问题 → 作者整体结构 → 形成阅读地图**

### T2：映射已有知识

> **章节主题 → 对照已有知识 → 已知／不确定／未知 → 必读／选读／跳过 → 设章节问题**

### T3：章节阅读与提取

> **带问题阅读 → 找主张、机制、条件、证据、例子和反例 → 形成知识单元 → 保留原始定位**

### T4：比较与增量判断

> **与旧知／同类书比较 → 重复／扩展／支持／冲突／新增 → 检查时效和适用边界 → 更新知识模型**

### T5：主动回想与练习

> **合上资料 → 回想核心结构 → 解释原因机制 → 辨别相似概念 → 解决练习／案例 → 暴露理解和记忆缺口 → 返回补学**

### T6：真实迁移

> **选择真实问题／项目 → 判断何时适用 → 独立使用方法 → 观察结果 → 获取反馈 → 修正理解和边界**

### T7：延迟复查与生命周期

> **间隔一段时间 → 再次回想／应用 → 检查遗忘、过时和新证据 → 保留／更新／重新学习／归档／淘汰**

## 五、三种阅读模式

### 筛选式阅读

目标是快速判断有没有值得吸收的增量。

> **预读 → 定位新内容 → 只读高价值部分 → 更新知识关系 → 结束**

### 问题式阅读

目标是解决一个明确问题。

> **问题 → 需要哪些证据／机制 → 定位相关章节 → 提取 → 对比 → 解决问题 → 停止**

### 能力式阅读

目标是形成可以独立执行的能力。

> **表现目标 → 理解 → 回想 → 练习 → 反馈 → 真实应用 → 迁移 → 延迟验证**

一本书可以同时采用三种模式，不需要从第一页到最后一页保持同一阅读强度。

## 六、多资料去重与知识增量链

### 1. 建立基线

> **研究问题／知识地图 → 已有知识节点 → 已掌握／不确定／未掌握／未测试 → 形成当前基线**

没有基线就无法判断“新增多少”，只能判断资料彼此是否相似。

### 2. 资料盘点与解析

> **盘点文件 → 识别版本／格式／语言／质量 → 解析或 OCR → 保留文件、页码、章节和原始位置 → 切成章节／段落／命题级单元 → 建稳定标识**

### 3. 七层判断

1. **文件完全重复**：二进制或内容完全相同的副本。
2. **文本完全重复**：规范化后的文本相同。
3. **文字近似重复**：大量字词片段重合，仅有格式或轻微改写。
4. **语义相似候选**：主题和含义接近，需要进一步判断关系。
5. **命题关系**：相同、包含、扩展、支持、冲突或无关。
6. **知识增量**：是否增加新机制、新条件、新范围、新证据、新反例或更新信息。
7. **掌握差额**：这些知识是否已经能够被本人独立回想、辨别、应用和迁移。

语义相似只适合召回候选，不能单独授权删除或合并。

### 4. 建代表项和来源关系

> **选最完整、最清楚或最权威的代表项 → 其他来源挂关系 → 保留各自的新证据、新边界和反例 → 支持回到原始来源**

默认优先“代表项＋关系＋来源”，而不是永久删除知识内容。

### 5. 生成知识差额队列

> **知识模型 − 已掌握部分 → 未掌握／不确定／待核查的新知识 → 按当前目标价值、基础依赖和应用频率排序 → 生成定向阅读与练习队列**

这一步把“海量书库”转成“当前真正值得学的少量差额”。

## 七、“新瓶装旧酒”判断

先将候选内容都转换为相同语义结构：

> **对象／概念＋核心主张＋机制＋成立条件＋适用范围＋证据＋例子／反例＋结论／行动**

然后判断：

- 完全重复；
- 同义改写；
- 压缩或展开；
- 包含关系；
- 新证据；
- 新成立条件或适用边界；
- 新反例；
- 信息更新；
- 相互冲突；
- 真正新增；
- 暂时无法判断。

不能因为“讲的是同一个主题”就把新的证据、条件、反例和更新数据当成重复。

## 八、资料状态与掌握状态分开

### 资料状态

> **未处理 → 已收藏 → 已解析 → 已提取 → 已进入知识模型 → 已核查／待核查 → 已更新／过时／归档**

### 个人掌握状态

> **未测试 → 未掌握 → 不确定 → 能回想 → 能辨别 → 能应用 → 能迁移 → 延迟保持／需要复习**

核心原则：

- 有笔记 ≠ 已理解；
- 看过 ≠ 能回想；
- 能复述 ≠ 能应用；
- 一次会做 ≠ 能迁移；
- AI 判断“用户应该会了” ≠ 掌握证据。

## 九、评估指标与边界

真正值得关注的指标包括：

- 资料盘点和解析覆盖是否足够；
- 重复候选中错误合并和漏检情况；
- 真正知识新增比例；
- 新证据、新边界、新反例和冲突发现情况；
- 单位阅读时间获得的高价值知识增量；
- 回想、辨别、独立应用和迁移表现；
- 人工复核成本是否值得；
- 新资料进入后能否低成本增量更新。

相似度阈值、抽样比例和具体模型必须用真实样本校准，不在通用层虚构统一数字。

## 十、停止与返回条件

### 什么时候停止继续搜／读

- 已经足以支持当前决定或行动；
- 继续资料搜索主要产生重复；
- 新增信息不再改变知识模型或选择；
- 当前瓶颈已经从“缺知识”变成“缺练习、反馈或真实应用”；
- 时间成本超过预期新增价值。

### 什么时候返回

- 来源不可靠 → 返回证据核查；
- 概念关系混乱 → 返回术语统一和知识建模；
- 冲突无法解释 → 补来源、方法和适用条件；
- 看懂但记不住 → 返回回想和复习；
- 记得但不会做 → 返回练习；
- 会做但不会迁移 → 返回适用条件和变式练习；
- 知识已过时 → 重新检索和更新。

## 十一、层级与去重决定

本文件不新增核心链：

- 文章、单书、多资料和书库都是 L3 场景；
- 信息搜索、筛选、核实、知识建模由 C23 及其扩展动作承担；
- 理解、回想、练习、应用和迁移由 C24 承担；
- 效果判断用 C15；
- 经验和方法资产化用 C19；
- 更新、归档和淘汰用 C30；
- OCR、哈希、近似匹配、向量检索、聚类和具体数据库属于 L4。

未来只有在真实场景中出现现有 C 链无法表达的新跨领域状态转化时，才重新启动 C31 准入审计。
