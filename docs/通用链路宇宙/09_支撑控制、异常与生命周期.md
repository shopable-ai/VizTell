# 支撑控制、异常与生命周期

> **核心结论**：记录、证据、监测、沟通、质量、风险、合规、权限和版本是贯穿式控制；异常发生后优先安全和止损；完成后必须进入维护、扩大、暂停、交接、归档、淘汰或重启状态。

## 一、九条横向支撑链

### 证据支撑

> 明确待证明主张 → 规定证据等级 → 收集来源 → 核查真实性相关性 → 处理冲突 → 建立主张—证据映射 → 支持判断

### 记录支撑

> 定义最小记录 → 过程采集 → 标注来源时间责任 → 分类关联版本 → 安全保存 → 检索使用 → 归档处置

### 追溯支撑

> 连接需求、目标、方案、任务、版本、测试、决定、成果和验收 → 检查断点 → 修复映射 → 支持变更审计

### 监控支撑

> 读取目标基线阈值 → 采集实际状态 → 比较偏差趋势 → 预警升级 → 触发控制 → 跟踪恢复

### 沟通支撑

> 识别相关方 → 对齐事实目标术语 → 明确请求承诺 → 同步变化 → 处理分歧 → 确认行动闭环

### 质量支撑

> 定义质量标准 → 设置控制点 → 过程检查 → 缺陷分级 → 隔离纠正 → 复检放行 → 质量改进

### 风险支撑

> 识别不确定性 → 评价概率影响 → 选择应对 → 设置责任预警 → 监测复审 → 事件切换 → 关闭

### 合规伦理支撑

> 识别法律规则伦理隐私安全 → 解释义务红线 → 检查方案证据 → 修正缺口／申请例外 → 授权放行 → 留存审计

### 责任版本支撑

> 明确责任权限 → 约定升级移交 → 提出变更 → 评估影响 → 批准版本 → 发布迁移 → 监测回退 → 留存历史

## 二、风险到事件的切换

### 风险尚未发生

> 建立情境目标 → 识别风险机会 → 分析概率影响关联 → 评价优先承受度 → 选择规避／减轻／转移／接受／利用 → 指定责任资源 → 设置触发器 → 持续复审

### 风险已经发生

> 发现并验证异常 → 判断影响紧急安全边界 → 启动响应 → 保护人员关键资产证据 → 控制扩散损失 → 通知指挥 → 决定恢复路径

不能在事件已经发生后继续把它当作风险清单讨论。

## 三、异常恢复总链

> **预先准备 → 发现异常 → 验证分级 → 保障安全 → 控制扩散 → 通知指挥 → 诊断 → 修复／回退／替代 → 验证完整和服务 → 逐步恢复 → 善后补偿 → 事件调查 → 防止复发 → 更新目标、方案、标准、预案或系统**

处理顺序：

1. 先保护人身和关键资产。
2. 再控制影响范围和继续损失。
3. 先恢复最低可接受功能，再做完整调查。
4. 恢复不等于关闭；还要处理数据、客户、责任和善后。
5. 调查结论必须反馈到上游控制层，并验证措施有效。

## 四、失败重启

> 承认失败状态 → 停止继续损失 → 保存证据和可恢复资产 → 判断修复、回退、替代、转向或退出 → 评估剩余资源 → 缩小下一步 → 重建计划和节奏 → 取得早期反馈 → 再次评估

失败恢复与技术故障不同：它可能涉及目标、资源、信心、关系和商业模式，需要重新选择而不只是修复原方案。

## 五、生命周期状态机

| 当前判断 | 进入状态 | 必做事项 |
| --- | --- | --- |
| 达成且仍有下一周期 | 继续 | 更新目标计划和版本 |
| 效果可复制且承载允许 | 扩大 | 明确边界容量和副作用监测 |
| 有效但需保持 | 维护 | 定义健康状态、周期和责任 |
| 环境变化需修改 | 更新 | 影响分析、版本、测试、迁移回退 |
| 新环境需要使用 | 迁移 | 比较差异、准备容量、分批验证 |
| 暂不投入但可能恢复 | 暂停 | 保存状态、资产、责任和复查条件 |
| 责任主体变化 | 交接 | 资料、权限、风险、未决项和接收验证 |
| 退出活跃使用但需保留 | 归档 | 元数据、权限、期限、检索和复审 |
| 无净价值或风险过高 | 淘汰 | 通知、迁移依赖、停用和留证 |
| 暂停或归档对象恢复 | 重启 | 核验完整、时效、权限、依赖和安全 |
| 未达目标但决定结束 | 终止 | 说明理由、止损、结算责任和保存经验 |

## 六、扩大迁移

> 确认效果边界 → 识别新对象环境差异 → 评估容量资源质量风险 → 准备人员工具支持 → 分批扩大或迁移 → 比较一致性和副作用 → 修正 → 稳定／退回／停止

一次成功不能直接大规模复制；扩大后的复杂度可能改变原机制。

## 七、交接转移

> 确认交接范围接收者 → 整理状态资料权限责任关系风险 → 说明未决项和判断规则 → 接收者演练验证 → 处理能力缺口 → 观察接管期 → 正式转移责任 → 关闭原责任

只发送文档不等于完成交接。

## 八、暂停恢复

> 说明暂停原因 → 保存对象状态版本和证据 → 处理安全责任客户影响 → 设定复查日期触发条件 → 暂停投入 → 到期重新评价价值资源风险 → 恢复／转向／继续暂停／退出

没有复查条件的暂停容易变成永久悬置。

## 九、归档淘汰与重启

**归档**：确认结束 → 清理内容元数据 → 确定权限期限 → 转入归档 → 保持必要检索 → 到期复审。

**淘汰**：检查有效性和保留成本 → 识别依赖用户 → 设计替代迁移 → 通知 → 停止使用 → 安全处置 → 留存必要证据。

**重启**：提出需求 → 查找归档 → 检查完整时效权限依赖 → 修复迁移 → 重新测试 → 批准启用 → 纳入维护。
