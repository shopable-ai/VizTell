# 公司链路宇宙

> **公司经营总循环**：环境和利益相关方信号 → 战略与业务组合 → 目标预算和资源 → 市场与客户 → 产品服务与创新 → 营销销售与交易 → 运营交付与客户成功 → 收入现金和资产 → 人才组织与能力 → 治理风险与合规 → 绩效评估和经营复盘 → 调整、扩大、转型或退出。

公司不是一条线性流程，而是多个经营循环通过战略、资源、数据、治理和现金流互相连接的系统。

## 一、十一个公司系统

### 1. 环境洞察与战略

> 监测市场技术政策竞争 → 识别机会威胁 → 明确使命和价值边界 → 形成战略假设与选项 → 比较取舍 → 确定阶段重点 → 设复查和退出条件

### 2. 业务组合与资源配置

> 汇总业务产品项目 → 评估价值增长风险和资源需求 → 比较组合平衡 → 决定投入、维持、试验、缩减或退出 → 分配资金人才能力 → 周期重评

### 3. 市场、客户与品牌

> 定义市场和客户分层 → 研究问题、行为和替代 → 选择目标客户 → 建立定位和品牌承诺 → 设计渠道触点 → 监测认知、需求和关系变化 → 调整

### 4. 产品、服务与创新

> 发现用户问题机会 → 建立价值假设 → 概念原型 → 试验选择 → 产品服务开发 → 发布运营 → 测量用户价值 → 迭代增长 → 维护下线

### 5. 营销、销售与交易

> 生成需求和线索 → 识别匹配客户 → 诊断需求 → 提供价值方案 → 定价报价 → 谈判合同 → 成交履约 → 回款 → 分析漏斗和利润 → 优化

### 6. 运营、供应与交付

> 预测需求 → 规划产能供应 → 配置人员物料系统 → 排程执行 → 过程监控 → 质量检查 → 交付验收 → 异常恢复 → 效率质量改进

### 7. 客户服务与成功

> 客户启动 → 使用支持 → 问题响应 → 监测价值实现 → 识别风险机会 → 推动续费升级 → 收集反馈案例 → 反哺产品销售运营

### 8. 财务、现金与资产

> 建立财务目标政策 → 预算配置 → 记录核算 → 应收应付和现金预测 → 成本利润分析 → 风险控制 → 投资融资分配 → 审计报告 → 调整经营

### 9. 人才、组织与文化

> 识别组织能力需要 → 设计角色结构权责 → 招聘配置 → 目标对齐 → 培训辅导 → 绩效反馈 → 激励保留 → 继任交接 → 调整组织

文化不能只靠口号，应由实际决策、奖励、惩罚、资源和领导行为共同形成。

### 10. 治理、风险与合规

> 明确所有权和决策权 → 建立政策、授权和监督 → 识别风险与规则 → 设置控制点 → 审查重大事项 → 管理事件危机 → 审计问责 → 修订治理

### 11. 知识、能力与持续改进

> 收集项目运营经验 → 核实因果和边界 → 沉淀方法 → 流程工具化 → 试点 → 培训采用 → 监测质量 → 版本更新 → 淘汰过时做法

## 二、组织目标落地

> 明确战略方向 → 选择阶段重点 → 分解价值成果 → 形成公司、部门、团队和个人目标 → 对齐指标依赖 → 配资源权限 → 建执行计划 → 持续监控辅导 → 评估结果和价值 → 调整资源、计划、方案或目标

递归分解必须保持因果联系，不能把一个公司指标机械均摊给所有部门和个人。

## 三、经营节奏

| 节奏 | 主要活动 |
| --- | --- |
| 实时／每日 | 关键运营、客户、现金、安全和异常监控 |
| 每周 | 重点任务、销售管道、交付风险、跨部门阻塞 |
| 每月 | 经营结果、预算现金、客户产品、人员负荷 |
| 每季度 | 战略假设、目标组合、资源再配置、组织能力 |
| 每年 | 长期方向、业务组合、资本和人才结构、治理审计 |

节奏应服务真实决策，不以会议和报表数量代表管理成熟度。

## 四、从经验到组织能力

> 筛选有证据的实践 → 收集过程、决定、结果和例外 → 分析因果与适用边界 → 提炼原则、步骤和控制点 → 设计流程、标准、模板和工具 → 在新场景试点 → 比较复现效果和采用成本 → 修订批准 → 培训上岗 → 监测采用质量 → 版本更新或撤回

文档发布不等于组织能力。只有不同合格人员脱离原作者后仍能稳定产出可接受结果，才能证明转化成功。

## 五、公司化迁移关口

OPC或小团队进入公司化前，应检查：

1. 需求和收入是否具有一定稳定性。
2. 产品或服务是否能够定义标准和质量。
3. 是否存在可委派、可培训、可监督的工作。
4. 现金是否支持招聘、管理和合规成本。
5. 创始人是否愿意从亲自执行转向目标、系统、人才和治理。
6. 权限、知识、客户关系和关键风险是否可以转移。
7. 扩大后的复杂度和副作用是否仍有净价值。

## 六、经营结果边界

- 交付完成不等于客户成功。
- 收入增长不等于现金安全和利润健康。
- 指标达成不等于战略正确。
- 流程合规不等于真实有效。
- 培训完成不等于人员胜任和实际采用。
- 局部部门最优不等于公司整体最优。
- 扩大规模不等于增加长期净价值。
