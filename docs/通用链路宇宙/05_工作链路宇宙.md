# 工作链路宇宙

> **工作总链**：理解角色责任 → 接收并澄清需求 → 对齐目标范围标准 → 排定优先 → 计划任务依赖 → 配置时间资源权限 → 协作执行〔记录＋监测＋沟通＋质量＋风险〕→ 自检提交 → 验收移交 → 评估绩效和价值 → 学习沉淀 → 交接、发展或退出。

## 一、主要分区

1. 角色、职责、权限和承诺
2. 目标、优先级和周期计划
3. 需求、任务和成果交付
4. 沟通、会议和跨人依赖
5. 项目、质量、风险和变更
6. 绩效、反馈和工作负荷
7. 专业能力和职业发展
8. 知识记录、方法沉淀和岗位交接

## 二、主要组合链

### 需求转任务

> 接收要求 → 还原使用场景 → 确认目标范围标准 → 判断优先级 → 拆分可交付成果 → 拆成任务依赖 → 指定责任期限 → 进入执行队列

### 工作任务闭环

> 接收任务 → 确认结果标准权限 → 安排时间优先 → 准备资源 → 执行〔记录＋同步〕→ 处理阻碍 → 自检提交 → 验收收尾 → 简短总结

### 周期工作管理

> 汇总任务承诺 → 确定周期重点和不做项 → 建立计划基线 → 每日推进记录 → 定期监测纠偏 → 周期评估 → 复盘重排

新紧急事项先过价值和优先级关口，不自动插队。

### 会议行动闭环

> 判断是否需要会议 → 明确议题、决策权和预期产出 → 会前提供材料 → 围绕事实选项讨论 → 作出决议 → 指定责任期限 → 发布纪要 → 跟踪关闭

没有形成决定、责任、期限或明确未知项的会议，不构成行动闭环。

### 跨角色协作

> 定义共同成果 → 识别相关方和决策权 → 对齐事实术语利益 → 划分责任接口 → 约定同步升级 → 并行执行 → 处理冲突变更 → 集成验证 → 共同验收

### 授权任务

> 明确期望结果 → 选择承接者 → 说明权限边界资源期限 → 确认理解承诺 → 设置检查点 → 支持排障但不替代执行 → 评估结果 → 反馈发展

授权必须使责任、权力和资源基本匹配。

### 项目交付

> 识别需求和相关方 → 论证价值可行 → 明确目标范围标准 → 设计方案 → 建计划资源风险基线 → 分阶段执行控制 → 管理问题变更 → 集成果 → 验证要求 → 确认用途 → 验收移交 → 评估收益 → 复盘沉淀

### 绩效改进

> 对齐组织和个人目标 → 设结果与行为标准 → 持续记录辅导 → 阶段评估 → 区分能力、资源、意愿、目标和系统原因 → 制定措施 → 跟踪验证

不能把所有结果问题默认归因于个人态度。

### 职业能力发展

> 明确目标角色能力 → 评估当前差距 → 选择关键技能 → 设计学习练习 → 在真实工作应用 → 收集结果专家反馈 → 建立作品证据 → 更新发展方向

### 岗位交接

> 明确交接范围 → 整理事项状态、资料、权限、关系、风险和未决决定 → 说明关键判断规则 → 接收者演练确认 → 观察接管期 → 转移责任 → 关闭原角色义务

## 三、常见卡点与返回

| 卡点 | 优先返回 |
| --- | --- |
| 目标含糊、理解不同 | 需求澄清、目标范围标准 |
| 任务过多、全部紧急 | 价值排序、不做项、资源配置 |
| 任务持续拖延 | 任务颗粒度、前置条件、状态负荷 |
| 多人互相等待 | 责任接口、依赖、授权升级 |
| 交付总被退回 | 标准、证据、质量检查、需求理解 |
| 项目反复失控 | 计划基线、变更控制、风险监测 |
| 指标达标但没有价值 | 确认用途、效果价值、目标重审 |
| 同样问题反复出现 | 记录取证、原因分析、复盘标准化 |
| 只有一个人会做 | 经验沉淀、工具化、培训和交接 |

## 四、最低工作记录

- 目标、范围、完成标准和版本
- 当前负责人、协作者和决策权
- 下一动作、期限和关键依赖
- 重要决定、理由、假设和复查条件
- 风险、问题、变更和遗留项
- 成果、验收结论和必要复盘
