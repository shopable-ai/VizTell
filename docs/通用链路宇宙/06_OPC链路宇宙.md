# OPC 链路宇宙

> **OPC经营总链**：发现机会 → 选择细分用户 → 定义价值主张 → 设计产品或服务 → 验证需求和付费 → 建立最小交付 → 获客 → 成交 → 履约交付 → 客户成功 → 管理收入成本现金 → 找出个人瓶颈 → 标准化、产品化、AI化、自动化、外包或合作 → 沉淀品牌、客户、内容、软件、数据和方法资产 → 扩大、维持、转向、公司化或退出。

OPC不是缩小版公司。其核心矛盾是一个人同时承担投资者、经营者、产品、营销、销售、交付、客服和管理角色，而时间、注意力、健康和现金均有限。

## 一、十个经营循环

### 1. 机会与定位

> 观察变化和未满足需要 → 选择目标用户 → 研究现有替代 → 判断痛点频率强度和付费能力 → 形成细分定位 → 低成本接触验证 → 继续／换位／放弃

主要输出：目标用户、问题场景、价值主张、差异定位和验证假设。

### 2. 产品或服务创造

> 澄清结果 → 设计交付机制 → 确定最小范围 → 制作原型或样品 → 邀请目标用户试用 → 验证效果和使用成本 → 定价包装 → 建立可交付版本

优先验证真实价值和付费，不先构建庞大完整系统。

### 3. 内容、渠道与获客

> 识别用户聚集位置 → 设计可信内容和入口 → 生产发布 → 观察触达互动 → 引导留下线索 → 评估获客成本质量 → 保留高效渠道 → 形成可重复获客系统

### 4. 销售、定价与成交

> 确认潜在客户需求预算时机 → 判断匹配度 → 说明价值证据 → 提供方案价格边界 → 处理疑虑 → 成交／培育／拒绝 → 记录承诺和交付条件

低质量、不适配客户可能消耗超过收入，应保留拒绝和退出权。

### 5. 履约交付

> 确认合同订单和范围 → 收集客户输入 → 排定交付计划 → 生产执行 → 过程同步 → 质量检查 → 提交验收 → 处理遗留 → 完成交接

### 6. 客户成功与关系

> 引导启动 → 确认可用 → 观察实际结果 → 主动处理阻塞 → 收集反馈案例 → 支持续费升级 → 请求推荐 → 识别流失原因 → 改进产品服务

成交不是结束；客户获得结果才形成复购、口碑和长期价值。

### 7. 收入、成本与现金

> 记录收入成本应收应付 → 区分固定变动成本 → 预测现金 → 设安全储备和投入上限 → 评估产品客户渠道利润 → 调整定价成本和组合 → 决定再投入或停止

### 8. 个人瓶颈处理

> 记录时间精力和任务流 → 识别高频重复、等待、返工和低价值工作 → 判断删除／标准化／自动化／外包／合作／招聘 → 小试替代 → 比较成本质量风险 → 固化新方式

### 9. 资产化

> 回收项目经验和素材 → 提炼通用部分 → 转成内容、模板、数据、软件、提示词、工作流、品牌和客户关系 → 建立版本权限 → 多次复用 → 评估复利和维护成本

OPC应逐步减少“每次从零出售个人时间”，增加可复用和可重复销售的资产。

### 10. 扩大、公司化与退出

> 验证稳定需求利润 → 判断个人承载极限 → 比较保持OPC、合作、外包、招聘、融资或公司化 → 设计角色流程和治理 → 分批迁移 → 监测失真 → 稳定扩大／退回／退出

## 二、OPC角色切换

| 角色 | 主要责任 | 不应外包的核心 |
| --- | --- | --- |
| 所有者 | 方向、风险、资产和退出 | 价值取舍、重大风险承担 |
| 经营者 | 目标、预算、现金和优先级 | 资源分配和经营决定 |
| 产品 | 用户问题、价值和路线 | 真实需求与产品取舍 |
| 营销 | 定位、内容、渠道和线索 | 品牌承诺与目标用户 |
| 销售 | 匹配、报价、谈判和成交 | 价格边界与客户选择 |
| 交付 | 生产、质量、验收 | 结果责任与质量底线 |
| 客服成功 | 使用支持、反馈和续费 | 客户关系和关键承诺 |
| 系统建设 | 标准化、自动化、AI和外包 | 人机边界、权限和验收 |

## 三、OPC优先级规则

1. 现金和客户承诺优先于低价值内部完善。
2. 先验证需求和付费，再扩大产品建设。
3. 先删除不必要工作，再自动化低价值工作。
4. 高频、规则稳定、可验证工作优先工具化和AI化。
5. 低频、高判断、高关系风险工作保留人工责任。
6. 单一客户、平台、模型或渠道依赖必须进入风险管理。
7. 经营增长不能长期以健康、信誉、法律和现金安全为代价。

## 四、OPC关键指标

- 有效线索、成交率、客单价、交付周期
- 客户结果、满意、续费、推荐和流失
- 收入、毛利、现金储备和应收周期
- 创始人时间分配、返工率、自动化率
- 产品化收入与纯时间收入的比例
- 单一客户、渠道、平台和供应商集中度
- 可复用资产数量、使用次数、维护成本和真实效果

指标用于发现问题，不替代用户价值、信誉、安全和长期净收益判断。

## 五、AI重度OPC运行链

> 明确人类目标和责任 → 构建上下文与标准 → 选择模型工具Agent → 分解任务 → AI执行 → 自动测试与自检 → 独立核查证据 → 人工确认关键决定 → 发布交付 → 保存提示、流程、评估和版本 → 复用改进

人必须保留：目标、价值、伦理、授权、客户承诺、敏感数据、重大财务和法律风险以及最终验收责任。
