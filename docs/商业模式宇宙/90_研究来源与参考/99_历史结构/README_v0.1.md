# 商业模式宇宙 / Business Model Universe

> 版本：V0.1  
> 当前范围：Level 1 知识系统  
> 项目定位：为个人、OPC、小团队和企业内部提供一个可系统浏览、检索、组合与审计的商业模式知识空间。

## 当前阶段只做什么

本版本只建设知识系统，不提前建设 Agent、脚本、数据库、工作流或其他重型工程能力。

核心目标：

1. 建立可读、可检索、可扩展的商业模式知识地图。
2. 保留传统商业模式知识，同时建立更底层的结构化“商业模式宇宙”。
3. 系统覆盖价值创造、价值交换、价值捕获、价值分配、生态协作、增长、壁垒、风险与迁移。
4. 为后续真实项目的商业模式穷举、组合、评分和验证提供知识基础。
5. 严格区分知识内容与未来可能出现的工程文件。

## 一级目录

- `00_导航与说明/`：范围、导航、分类规范、审计规则。
- `01_商业模式宇宙/`：核心知识本体与搜索空间。
- `02_价值链与利润池/`：产业链位置、利润池、控制点与价值迁移。
- `03_生态与价值交换/`：多方参与者、资源交换、合作、激励与治理。
- `04_商业模式案例与证据/`：案例结构与证据规则。
- `05_行业商业模式地图/`：行业情境化的商业模式地图。
- `06_失败模式库/`：商业模式常见失败机制与反例。
- `07_商业模式迁移路径/`：商业模式随阶段、资源与市场变化的迁移。
- `90_参考知识/`：传统商业模式分类、术语、经典框架、新旧映射。

## 当前设计原则

- 一级目录少而稳定，细颗粒度放在目录内部。
- 不用“省略号”代替应存在的分类内容。
- 区分：原子、机制、结构、母型（Archetype）、变体、具体企业模式。
- 传统分类作为兼容和参考知识，不作为主推理骨架。
- 内容条目优先保持可被人直接阅读，同时兼容 AI 检索。
- 未来工程文件不得与知识内容混放。
