# 商业模式迁移路径总览

商业模式不是一次性选择，也不存在适用于所有企业的单向“高级模式升级阶梯”。

更准确的定义是：

> **商业模式迁移 = 当需求、技术、规模、竞争、资本、风险或治理条件变化时，使用一个或多个商业模式变换算子，改变 U01-U27 中部分设计选择，并验证新的价值、经济性与风险是否优于当前结构。**

完整的机会来源与 T1-T12 变换算子见：

`../../01_核心机制与组合模式/20_机会来源_差异捕获与商业模式变换算子.md`

---

## 1. 迁移不是“越平台、越金融越高级”

以下链路都只是**候选路径**：

- 咨询 → 标准化服务 → Productized Service → SaaS；
- 产品销售 → 租赁/PaaS → 结果服务；
- 工具 → 工作流 → 平台；
- 自营供给 → 聚合 → Marketplace → Managed Marketplace；
- 交易 → 支付 → 数据/洞察；
- 硬件 → 软件 → 持续服务；
- 单点服务 → 聚合 → 生态；
- 一次销售 → 维修/回购 → 二手/翻新 → 循环服务。

但每一次迁移都必须证明：

> **客户价值更强，单位经济/现金流可成立，参与方激励不崩，风险可承受，并且新复杂度值得。**

尤其：

> **平台 → 支付 → 金融不是默认终局。** 金融化只有在客户价值、牌照、资本、流动性、风控、合规和治理能力同时成立时才进入候选集。

# 2. 十二类迁移方向

## M1 权利迁移：所有权 → 使用权 → 结果

典型路径：

> 产品销售 → 租赁 → 按次/按量 → Product-as-a-Service → 结果即服务

适用触发：

- 客户前置 CapEx 太高；
- 资产利用率低；
- 客户真正要功能/结果而不是资产；
- 供给方能更好管理维护与残值。

新增风险：资产负债表、维修、残值、容量、回收、客户信用和结果责任。

主要映射：U03、U10、U20、U22、U23、U26。

---

## M2 颗粒度迁移：整体 → 切片 → 按需

典型路径：

> 整套购买 → 套餐分层 → 时间/容量/席位/功能切片 → 按实际使用量/任务收费

适用触发：客户需求差异大、整包门槛高、资源可计量、边际成本可核算。

新增风险：计量争议、复杂定价、极端用户、峰值容量、收入波动。

主要映射：U03、U10、U22。

---

## M3 供给迁移：自营 → 伙伴 → 聚合 → 平台

典型路径：

> 自己拥有/生产 → 外包/OEM → 第三方供给 → Aggregator → Marketplace → Managed Marketplace

适用触发：供给碎片化、资产投入高、需求增长快、外部供给质量可治理。

新增风险：质量、履约、供应商依赖、多方激励、平台流动性、责任边界。

主要映射：U07、U08、U09、U12、U20、U27。

> **注意：** 从自营变 Marketplace 不是天然升级。如果供给高度专用、质量难标准化、责任不可外移，内部化或 Managed 模式可能更优。

---

## M4 库存与时序迁移：Push → Pull

典型路径：

> 先生产/采购 → 小批快反 → 先订单后采购 → 按需生产 → 预售/众筹验证

适用触发：库存风险高、需求不确定、SKU 多、产品可延后生产或采购。

新增风险：交付延迟、供应稳定性、客户等待、预售履约和退款义务。

主要映射：U07、U13、U22、U26。

---

## M5 中介角色迁移：Merchant → Broker → Marketplace

典型路径：

> 自己买断再卖 → 代理/代采 → 经纪撮合 → Marketplace → Managed Marketplace

核心变化：

- 是否取得商品所有权；
- 谁承担库存、质量、价格、履约和售后风险；
- 收入从商品毛利变成佣金、服务费或平台费。

适用触发：市场供需分散、企业不必持货、发现/信任/交易组织价值高。

主要映射：U05、U08、U09、U11、U20、U26。

---

## M6 收入迁移：一次性 → 持续 → 使用/结果

典型路径：

> 一次性收入 → 订阅/会员 → Usage-based → 两部制 → 结果/收益分成

适用触发：客户价值持续产生、使用可计量、客户希望成本与价值匹配。

新增风险：Churn、收入波动、推理/服务成本、结果归因争议、过度承诺。

主要映射：U06、U10、U11、U21、U23。

---

## M7 付款者与补贴迁移：单边收费 → 多方价值捕获

典型路径：

> 使用者直接付款 → 第三方付款 → 广告/赞助/雇主/政府付款 → 跨边补贴/交叉补贴

适用触发：使用者价值高但支付意愿低，另一参与方能从其参与中获得更高价值。

新增风险：激励冲突、隐私、广告质量、补贴依赖、平台鸡蛋问题和监管。

主要映射：U01、U08、U10、U11、U24。

---

## M8 前端经济迁移：收费入口 → 免费/低价入口 + 后端利润

典型路径：

> 正常售价 → 试用/首单 → 免费/低价 Traffic Offer → Attach / Cross-sell / Subscription / Backend Profit

只有在以下指标成立时才是有效迁移：

> **Front-end Contribution → Basket Contribution → True Cohort Contribution**

必须排除：

- 只把原本会购买的用户降价；
- 需求前置；
- 补贴套利用户；
- 后端 attach 低于预期；
- CAC 与退款吞噬后端利润。

主要映射：U04、U10、U11、U19、U21。

---

## M9 现金流迁移：后收款/先付款 → 负营运资金

典型路径：

> 交付后收款 → 预付/年度预付/预售 + 供应商账期 → 更短现金转换周期

适用触发：需求可信、客户愿意提前承诺、供应商愿意提供信用。

新增风险：预收并不等于利润；企业承担未来履约、退款、流动性和客户资金义务。

主要映射：U13、U21、U25、U26。

---

## M10 风险迁移：客户承担 → 供给方承担 → 风险池

典型路径：

> 无保证 → 退款/保修/SLA → 按结果付费 → 收益/风险共担 → 保险/风险池

适用触发：客户因不确定性不愿交易，而企业拥有更好的数据、控制力或分散能力。

新增风险：逆向选择、道德风险、尾部损失、资本要求、保险/金融监管。

主要映射：U09、U23、U26。

---

## M11 能力产品化迁移：人 → 流程 → 产品 → 软件/API

典型路径：

> 咨询/人工服务 → 标准化服务 → Productized Service → 自助工具 → SaaS/API/AI 能力

适用触发：重复需求高、交付可标准化、边际成本下降空间大。

新增风险：过度标准化损害结果、软件维护成本、服务复杂度被低估、AI 使用成本随规模增长。

主要映射：U03、U12、U14、U15、U27。

---

## M12 生命周期迁移：销售终点 → 持续关系 → 循环价值

典型路径：

> 一次销售 → 维护/耗材 → 订阅服务 → 回购/残值 → 二手/翻新/再制造 → 闭环供应链

适用触发：产品寿命长、残值高、维修/耗材价值大、回收可以降低总成本或强化客户关系。

新增风险：逆向物流、残值波动、质量分级、库存、责任与循环经济合规。

主要映射：U06、U11、U17、U18、U22。

# 3. 迁移决策必须记录五件事

任何从 A → B 的迁移都至少记录：

1. **Trigger / 触发器**：为什么现在要迁移？是需求、成本、竞争、技术、规模、资本还是监管变化？
2. **Operator / 变换算子**：具体改变哪些参与方、权利、供给、价格、现金流、风险或治理？
3. **Target Metric / 目标指标**：希望改善 CAC、转化、毛利、贡献、现金周期、利用率、留存、风险还是增长？
4. **New Risk / 新风险**：新模式把什么风险转移给了谁？是否产生牌照、流动性、质量或平台治理风险？
5. **Kill / Reversal Condition**：什么证据出现时停止迁移、回退或改用混合模式？

---

# 4. 迁移不是二选一：混合模式通常更现实

常见的混合状态：

- 自营核心供给 + Marketplace 长尾；
- 固定订阅 + Usage overage；
- 直营大客户 + 渠道覆盖中小客户；
- 产品销售 + 租赁；
- 标准化软件 + 高价值实施服务；
- Merchant 核心 SKU + 第三方 Marketplace；
- 免费入口 + 付费核心 + 企业服务；
- 自有资产保障基础容量 + 第三方弹性容量。

混合结构的价值是让企业在控制、资本、灵活性和风险之间取得更好的边界，而不是追求“纯模式”。
