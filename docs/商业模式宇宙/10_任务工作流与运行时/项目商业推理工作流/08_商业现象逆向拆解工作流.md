# 商业现象逆向拆解工作流

> 当用户说“我看到别人这样卖，为什么还能赚钱？”时，第一任务不是替用户设计项目，而是先把**观察到的现象**与**真正的盈利结构**分开。

## 一、标准链路

```text
观察到一个商业现象
↓
表面上发生了什么交易？
↓
表面价格能不能解释利润？
↓
如果不能，建立多个盈利假设
↓
分别找现实证据
↓
寻找反证
↓
排除不成立假设
↓
重建真实收入结构
↓
判断哪些利润是核心
↓
判断哪些只是辅助
↓
判断哪些依赖平台/规则/漏洞
↓
判断模式是否长期成立
↓
判断是否可以迁移到其他项目
```

必须遵守：

> **假设 → 证据 → 反证 → 条件 → 结论。**

“听起来合理”不能升级成“对方就是这样赚钱”。

---

## 二、第一步：只记录真正观察到的事实

例如用户说：

> “闲鱼有人把电子书卖到 0.01～3 元。”

第一层只允许记录：

- 看到了某类商品；
- 看到了展示价格或用户声称的成交价格；
- 看到了某个店铺/页面/交付方式（如果确实提供）；
- 看到了销量、评价、其他 SKU（如果可验证）。

以下都不能自动当事实：

- “这是低价引流”；
- “靠网盘拉新赚钱”；
- “靠会员后端赚钱”；
- “一本不赚钱但用户很值钱”；
- “一定是盗版”。

这些只能进入假设树。

---

## 三、第二步：判断表面交易能否解释长期经营

至少建立一个最小经济式：

```text
表面成交收入
- 内容/采购/授权成本
- 平台/支付成本
- 获客成本
- 交付成本
- 售后/退款
= 表面交易贡献
```

如果在合理区间内可能为正，H1 不能被过早排除。

如果明显难以解释长期经营，则扩大盈利假设树。

---

## 四、H1-H12 盈利假设树

### H1 单本本身赚钱

可能机制：极低采购/授权成本、极低边际交付成本、规模订单、自动化。

需要证据：真实成交价、销量、交付成本、内容成本、平台费、退款率。

### H2 低价入口 → 后端商品

可能机制：低价商品承担获客或资格筛选，利润来自后续更高价商品。

需要证据：店铺商品阶梯、购买后的下一 Offer、后端成交或用户路径。

### H3 购买者作为高意向 Lead

可能机制：购买行为识别了明确任务和支付意愿，后续被转成更高价值客户。

需要证据：是否存在合规持续触达、后续转化、Lead Value。

### H4 合集 / 会员 / 订阅

可能机制：单本只是入口，长期价值来自合集、持续更新、会员或订阅。

需要证据：真实商品、价格、续费/复购、持续交付内容。

### H5 Affiliate / 官方分销

可能机制：书籍对应的软件、工具、平台或服务产生官方联盟/分销收入。

需要证据：正式联盟规则、佣金条件、实际跳转/成交路径。

### H6 软件 / AI / 工具

可能机制：内容只是需求识别，利润来自自营软件、AI、知识库或工具。

需要证据：真实产品、付费价格、购买路径和用户匹配。

### H7 课程 / 咨询 / 服务

可能机制：低价内容识别需求，后续出售结果型服务。

需要证据：服务 Offer、价格、交付、案例、转化。

### H8 企业后端

可能机制：个人入口识别专业用户或企业需求，再出售培训、实施、知识库、授权等。

需要证据：企业线索路径、合同/报价、服务能力。

### H9 平台奖励 / 渠道收益

可能机制：存在官方邀请、渠道激励、CPS、返点、MDF、Credits 等额外收益。

需要证据：当前有效官方规则、门槛、上限、归因和实际可获得性。

### H10 极低边际交付成本和自动化

可能机制：数字交付、自动发货、自动客服等把单笔成本压得极低，使薄利规模可能成立。

需要证据：交付链路、自动化成本、订单规模、售后和异常成本。

### H11 供应链 / 内容采购特殊经济

可能机制：合法批量授权、旧库存、版权合作、低价采购、捆绑采购或其他特殊供给结构。

需要证据：合法权利来源、采购合同、规模价、授权范围。

### H12 不合规 / 盗版 / 漏洞 / 短期套利

可能机制：未经授权内容、账号/许可违规、平台漏洞或短期规则套利。

需要证据：权利状态、平台规则、行为路径、处罚/下架/失效信号。

H12 即使在现实中可能解释部分现象，也不能被包装成长期、合规、可迁移的正式商业方案。

## 五、证据矩阵

对每个假设建立：

| 假设 | 支持证据 | 反证 | 关键未知 | 成立条件 | 当前判断 |
|---|---|---|---|---|---|
| H1 |  |  |  |  | 保留/降权/排除 |
| H2 |  |  |  |  |  |
| … |  |  |  |  |  |
| H12 |  |  |  |  |  |

禁止只填写“支持证据”。

## 六、怎样重建真实收入结构

完成证据筛选后，用四层表达：

```text
表面收入：用户第一眼看到的交易

核心利润：最可能支撑长期经营的贡献来源

辅助收入：有价值但不是主要支撑

条件性/不可持续收入：依赖规模门槛、规则、补贴、漏洞、侵权或其他脆弱条件
```

如果证据不足，正确结论可以是：

> **目前无法确认真实核心利润来源；只能给出概率较高的候选结构和下一步需要观察的证据。**

这比虚构“真实内幕”更有价值。

---

## 七、可持续性检查

至少问：

- 没有补贴还能成立吗？
- 平台规则变化后还能成立吗？
- 内容/供给合法性成立吗？
- 用户会不会绕过？
- 竞争者复制后利润还在吗？
- 自动化扩大后售后/退款会不会反噬？
- 规模扩大是否需要越来越多低价流量？
- 隐藏收益是否有门槛、上限或 Clawback？

---

## 八、迁移前的最后一道门

不要：

```text
别人看起来成功
→ 直接复制表面形式
```

应该：

```text
真实机制
→ 成立条件
→ 当前项目具备什么
→ 缺什么
→ 哪些不可复制
→ 合规与可持续性
→ 迁移后的新候选
→ 重新做 P15-P19
```

最终输出：

```text
最可能的真实商业结构：
证据强度：
仍未确认：

值得学的机制：
不应该复制的部分：

如果迁移到自己的项目：
会变成什么方案：
最大假设：
最小验证：
```

## 九、低价电子书现象特别检查清单

```text
展示价是否等于成交价？
单本边际成本是多少？
是否有其他更高价 SKU？
是否有合集/会员/持续更新？
购买后是否出现下一 Offer？
是否有相关软件/AI/工具/服务？
是否有正式 Affiliate/分销？
是否有平台/渠道官方激励？
是否存在合法批量授权或特殊采购？
是否依赖未经授权内容或短期漏洞？
30/90/180 天真实用户贡献是多少？
```

没有这些证据时，不得把“低价引流”当作已经被验证的真实商业模式。
