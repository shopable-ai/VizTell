# 真实项目与现实输入入口

> 先判断用户带来的是什么，再决定从 P01-P20 哪里进入。目标是快速进入最有价值的商业问题，而不是强迫所有任务从头跑完。

## 一、入口地图

| 入口 | 典型表达 | 优先进入 | 第一件事 |
|---|---|---|---|
| 已有项目 | “我已经有 AI PDF 阅读器，但不知道怎么赚钱” | P02-P07 → P11-P18 | 看已有用户、资产、收入、成本和未商品化价值 |
| 已有功能/资产 | “已有上传、问答、总结、知识库” | P06-P07-P11-P14 | 功能 → 用户价值 → 商品 → 价格 → 升级路径 |
| 灵感/想法 | “我想做模仿作者思维的 AI” | P01-P05-P07-P13 | 展开为多个真正可收费、可验证的项目方向 |
| 具体经营问题 | “每天 500 用户但利润很低” | P04-P06-P15-P19 | 找最影响利润的约束，不重讲整个项目 |
| 已有真实数据 | “9.9 元卖 1000 单，CAC 12 元，退款 8%” | P15-P20 | 算经济性、阈值并改变排序 |
| 商业现象 | “0.01-3 元电子书怎么赚钱？” | 先逆向拆解 → P08-P18 | 建盈利假设树，不预设“就是引流” |
| 成功/失败案例 | “Costco 为什么会员成立？” | P08-P09-P16-P17 | 拆成立机制、必要条件和不可复制部分 |
| 商业模式迁移 | “这种玩法能不能用于我的项目？” | P09-P12-P13-P18 | 先拆机制，再判断条件是否匹配 |

## 二、已有项目

先盘点：用户、付款方、功能/商品、价格、收入、成本、毛利、渠道、转化、退款、复购、后端、品牌/流量/技术/数据/供应商等资产。

优先诊断五类问题：

1. 用户没有分层，所有人只卖一个商品；
2. 功能没有商品化，价值没有形成明确付费权利；
3. 前端没有后端，第一次成交后价值链断裂；
4. 免费、低价、Pro、企业之间没有价值层级；
5. CAC、退款、推理/履约、渠道分成或现金流吞掉利润。

目标不是重新设计一门新生意，而是：

> **把现有用户、功能、流量、品牌、技术、数据、供应商和渠道重新组合成更好的商业结构。**

---

## 三、已有功能或资产

标准链：

```text
功能/资产
→ 解决什么用户任务
→ 对谁价值最大
→ 使用频率与价值强度
→ 是否可独立收费
→ 入口/核心/利润/后端中的角色
→ 商品组合
→ 价格与升级路径
→ 真实付费验证
```

注意：四个功能不等于四个收费项。功能可以组合成个人版、专业版、团队版、企业版，也可以部分按量、部分订阅；最终取决于支付意愿和成本。

---

## 四、灵感/想法

不要先写功能清单。先回答：

```text
它解决什么问题
→ 谁最痛
→ 用户今天怎样解决
→ 替代方案哪里不好
→ 谁愿意付钱
→ 可以卖什么结果/权利/服务
→ 可以形成哪些不同商业结构
→ 哪个最便宜验证
```

同一个“作者思维 AI”可以是个人订阅、作者 IP 数字产品、出版社白标、课程附加工具、专题知识库、企业培训工具、API 或咨询辅助系统。先找有人愿意付钱的版本。

---

## 五、具体经营问题

用户已经明确说利润低、转化低、复购低、CAC 高、退款高、企业成交慢时，直接定位：

```text
获客 → 转化 → 客单 → 毛利 → 履约 → 退款
→ 复购 → 后端 → 企业销售 → 供应链 → 返点/账期 → 现金流
```

优先进入对应的 P04/P06/P15/P16/P18/P19。

---

## 六、已有真实数据

真实数据不是报告素材，而是决策输入。至少回答：

- 哪个方案已经成立？
- 哪个只是表面增长？
- 哪个用户群贡献最高？
- 哪个渠道应停止？
- CAC 上限是多少？
- 哪个价格/套餐需要调整？
- 哪个后端值得扩大？

如果新数据没有改变方案排序，必须解释为什么。

---

## 七、成功/失败案例

成功案例必须拆成：

```text
收入来源
成本结构
用户频率
采购/供给结构
复购与续费
现金流
渠道
控制点/壁垒
成立条件
```

失败案例必须问：

> **失败的是整个模式，还是用户、价格、渠道、成本、时机、规模或执行条件？**

禁止从“某公司靠会员成功”直接得出“我的项目也应做会员”。

---

## 八、商业模式迁移

正确顺序：

```text
拆真正机制
→ 列成立条件
→ 当前项目具备哪些条件
→ 缺哪些条件
→ 哪些优势不可复制
→ 设计迁移后的新结构
→ 重新算经济性
→ 最小验证
```

输出必须区分：可直接迁移、需改造、当前缺失、不可复制、迁移候选、最小验证。

---

## 九、第一次回答的默认第一屏

无论哪种入口，都优先让用户看到：

```text
我怎样理解你给的对象
它属于哪种商业问题
当前最值得解决什么
接下来重点验证哪些假设
哪些信息暂时不知道但不妨碍先推进
```

然后再进入研究、知识调用、方案与经济性。
