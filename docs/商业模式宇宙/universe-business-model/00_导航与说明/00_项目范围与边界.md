# 项目范围与边界

## 1. 商业模式宇宙的定义

商业模式宇宙，是一个项目在价值创造、价值交换、价值交付、价值捕获、价值分配、组织协作、经济结构和长期增长方面的结构化设计空间。

它不是“商业运营的一切”。

## 2. 核心范围

包含：
- 参与者与角色
- 需求与价值
- 资源与能力
- 价值创造
- 价值交换
- 价值流与多方关系
- 交易与权利
- 价值交付与供给
- 收入与价值捕获
- 定价、计量、付款者与补贴
- 成本、资本与现金流
- 风险、责任、激励与治理
- 渠道、获客、留存与客户关系
- 增长、飞轮与网络效应
- 数据、IP、品牌与信任
- 壁垒、控制点与战略位置
- 商业模式母型、变体与复合模式

## 3. 相邻但不直接等同于商业模式的内容

以下内容可能影响商业模式，但不能不加区分地全部纳入商业模式本体：
- 产品功能设计
- 组织架构
- 技术架构
- 普通营销战术
- 日常运营 SOP
- 公司治理细节
- 纯粹的竞争战略
- 一般性宏观环境分析

这些内容只有在直接改变价值创造、交换、捕获、分配或控制结构时，才进入商业模式分析。
