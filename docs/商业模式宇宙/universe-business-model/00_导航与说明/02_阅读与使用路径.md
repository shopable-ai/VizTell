# 阅读与使用路径

## 快速理解商业模式
1. 阅读 `01_商业模式宇宙/00_商业模式宇宙总地图.md`
2. 阅读 `01_商业模式宇宙/17_商业模式母型_Archetypes.md`
3. 查阅 `90_参考知识/01_传统商业模式分类.md`

## 为具体项目寻找商业模式机会
1. 识别参与者、需求、资源与价值。
2. 扫描价值创造、价值交换和价值捕获。
3. 检查价值链位置与利润池。
4. 检查生态合作和非货币价值交换。
5. 组合收入、定价、交付、渠道、增长和壁垒。
6. 对照失败模式。
7. 设计可迁移路径。

## 深入研究某一种模式
1. 找到母型。
2. 拆解其机制和原子。
3. 查看案例与证据。
4. 查看行业适配。
5. 查看失败模式与迁移路径。
