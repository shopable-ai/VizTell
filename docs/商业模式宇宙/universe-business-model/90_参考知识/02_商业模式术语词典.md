# 商业模式术语词典

建议每个术语维护：
- 中文名
- 英文名
- 同义词
- 概念层级
- 主归属
- 简明定义
- 常见误用
- 关联概念

示例：

## SaaS
- 英文：Software as a Service
- 层级：Archetype
- 不是“订阅”的同义词
- 常见组成：软件价值载体 + 云端交付 + 持续客户关系 + 订阅或使用量收入

## Freemium
- 层级：机制
- 核心：免费基础层 + 付费增值层
- 可能用于 SaaS、内容、平台等多种母型

## Marketplace
- 层级：Archetype / 交易结构
- 核心：组织两个或多个独立参与侧之间的交易
