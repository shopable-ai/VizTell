# 传统分类与商业模式宇宙映射

## SaaS
- 价值载体：软件
- 交付：云端
- 收入：订阅 / 使用量
- 计量：席位 / 用量 / 功能层级
- 客户关系：持续
- 增长：Land and Expand / PLG / 销售
- 壁垒：数据、工作流、集成、转换成本

## Marketplace
- 参与者：至少两个独立侧
- 价值创造：降低搜索、匹配、交易和信任成本
- 收入：佣金、交易费、广告、服务费
- 关键问题：冷启动、供需密度、脱媒、治理
- 增长：双边网络效应

## Freemium
- 本质：定价与获客机制，不是独立产业类型
- 免费层：降低进入门槛、扩大用户基础
- 付费层：高级能力、容量、服务或权利
- 风险：免费用户成本过高、付费转化不足
