## 1. 七类高频变体方向

### V1 参与方与付款关系变体

- 替换客户；
- 替换使用者；
- 替换付款者；
- 替换受益者；
- 第三方付款；
- 单边 → 双边/多边；
- 客户 → Prosumer / 供给者。

主要映射：U01、U08、U11。

### V2 权利、所有权与商品颗粒度变体

- 所有权 → 使用权/访问权；
- 买断 → 租赁；
- 永久 → 订阅；
- 独占 → 共享；
- 整体 → 时间/容量/席位/功能切片；
- 产品 → Product-as-a-Service；
- 工具/过程 → 结果。

主要映射：U03、U10、U20、U22、U26。

### V3 供给、资产边界与履约变体

- 自营供给 → 第三方供给；
- 自持资产 → 资产轻/租赁/伙伴资产；
- 自持库存 → 寄售/Dropshipping；
- Push → Pull / 按需；
- 单一供给 → 聚合分散供给；
- 自建基础设施 → 共享基础设施；
- 内部执行 → 外包/OEM/合作网络。

主要映射：U07、U12、U20、U22、U27。

### V4 交易、中介与治理变体

- 直接销售 → 代理/经销；
- Merchant → Broker；
- Broker → Marketplace；
- Marketplace → Managed Marketplace；
- 双边市场 → 多边平台；
- 市场交易 → 长期合同；
- 单企业控制 → 联盟/特许/生态治理。

主要映射：U05、U08、U09、U20、U26。

### V5 收入、定价与现金流变体

- 商品差价 → 服务费/佣金；
- 一次性 → 订阅；
- 固定费 → Usage / 两部制；
- 工时 → 任务/结果；
- 固定费用 → 收益/成果分成；
- 收费入口 → 免费/低价入口 + 后端收入；
- 单一收入 → 多收入流/交叉补贴；
- 交付后收款 → 预收；
- 先付供应商 → 供应商账期。

主要映射：U10、U11、U13、U19、U21、U25。

### V6 风险、责任与信任变体

- 客户自担 → 退款/保证；
- 过程付费 → 结果付费；
- 单方风险 → 风险共担；
- 个体风险 → 风险池/保险；
- 直接付款 → Escrow；
- 不可逆购买 → 试用/租赁/回购/退出权；
- 非标准质量 → 认证/检测/可追溯。

主要映射：U09、U18、U23、U26。

### V7 能力、规模、生态与生命周期变体

- 人工服务 → 标准化服务 → Productized Service；
- 服务 → 软件/API；
- 产品 → 平台/生态；
- 交易 → 数据/分析；
- 单点 → 聚合/一站式；
- 单区域 → 密度化/区域复制；
- 单一产品 → 品类/范围经济；
- 一次销售 → 维修/回购/二手/循环；
- 小规模采购 → 集采/规模返点/供应链飞轮。

主要映射：U12、U14、U15、U17、U19、U22。

## 2. 复合模式：不是“把词堆在一起”

复合模式至少要说明：

> **参与方 + 价值主张 + 权利包装 + 供给结构 + 交易治理 + 定价/收入 + 现金流 + 风险 + 增长/壁垒。**

常见复合示例：

- 产品销售 + 耗材复购；
- SaaS + Usage-based；
- SaaS + 实施服务；
- Marketplace + 佣金 + 支付；
- Marketplace + 广告/置顶；
- Marketplace + Managed Service；
- 免费产品 + 广告；
- 免费入口 + 专业服务；
- 开源 + 托管 + 企业版；
- 硬件 + 订阅 + 数据服务；
- 数据产品 + API；
- 会员 + 零售 + 权益联盟；
- 内容 + 社区 + 课程/咨询；
- 平台 + 开发者生态 + 抽成；
- 低价入口 + Basket/Cohort Profit；
- 集中采购 + 阶梯价 + 合法返点 + 渠道分销；
- 资产轻供给 + Marketplace + Escrow + 保险/保证。

这些只是**组合实例**，不构成新的顶层分类。

## 3. 非典型机会：先识别“为什么反直觉”

高价值非典型机会经常来自：

- 客户不是付款者；
- 企业不拥有核心资产；
- 用户同时也是供应者；
- 客户购买使用权而非所有权；
- 先获得订单/资金，再组织供给；
- 前端低利润甚至负贡献，利润来自 Basket/Cohort；
- 主业务低利润，但合法后台经济、数据、支付、服务或耗材高利润；
- 交易不是终点，后续关系/数据/网络才是主要价值；
- 企业不生产，但控制发现、信任、标准、渠道、交易或治理；
- 规模达到阈值后，采购、返点、密度、网络效应或固定成本分摊突然成立；
- 资产所有者的闲置成本高，而需求方只需要部分使用权；
- 客户不愿承担结果风险，而供给方能够更有效管理风险。

“反直觉”本身不是价值。必须继续映射到 U01-U27、真实经济性和风险边界。

## 4. 三个分类禁区

### 4.1 不把战术当模式

临时降价、免费试用、销售承诺、促销活动、一次性独家合作，通常是 Tactic / Offer / Pricing，不自动成为 Pattern。

### 4.2 不把差异当价值

价格差、信息差、地域差、时间差、渠道差只是**机会来源**。企业必须把差异转成客户可感知的便利、降价、信任、速度、融资、风险降低、履约或更好结果。

### 4.3 不把违规做法当“非典型创新”

账号越权共享、盗版、未授权转售、规避访问控制、虚假交易、秘密回扣等不进入正常模式库。

正确处理：

> **高风险案例 → 抽象底层机制 → 寻找合法权利/合同版本 → 再进入候选模式。**
