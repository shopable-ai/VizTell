# 变体、复合与非典型商业模式

## 常见变异方向
- 替换客户
- 替换付款者
- 替换受益者
- 替换供给者
- 从卖产品变卖使用权
- 从一次性变持续收入
- 从固定费变按量
- 从过程付费变结果付费
- 从现金收费变收益分成
- 引入第三方付款
- 增加交叉补贴
- 去中介
- 增加中介
- 平台化
- 服务化
- 产品化
- 金融化
- 数据化
- API 化
- 嵌入化
- 社区化
- 生态化

## 复合模式示例结构
- 产品销售 + 耗材复购
- SaaS + Usage-based
- SaaS + 实施服务
- Marketplace + 广告
- Marketplace + 支付
- Marketplace + 金融
- 免费产品 + 广告
- 免费入口 + 专业服务
- 开源 + 企业版
- 硬件 + 订阅
- 数据产品 + API
- 会员 + 零售
- 内容 + 社区 + 课程
- 平台 + 开发者生态 + 抽成

## 非典型机会
- 客户不是付款者
- 企业不持有核心资产
- 用户同时也是供应者
- 核心产品免费但生态收费
- 主业务低利润，金融或数据高利润
- 通过控制标准或入口捕获价值
