# 完整性与反方审计清单

## 完整性审计
- 是否遗漏参与者？
- 是否遗漏非付款受益者？
- 是否遗漏非货币资源？
- 是否遗漏第三方付款、补贴和多方支付？
- 是否遗漏资金流、账期、预付和资本结构？
- 是否遗漏风险、责任和治理权？
- 是否遗漏价值链位置变化？
- 是否遗漏行业特殊约束？
- 是否遗漏商业模式迁移？

## 正交性审计
- 是否把 SaaS、订阅、按席位、PLG 放在同一抽象层级？
- 是否存在大量同义词重复？
- 是否把渠道战术误当商业模式？
- 是否把案例名称当成模式类型？

## 反方审计
- 需求是否真实？
- 谁愿意付钱，为什么？
- 是否存在绕开平台或脱媒？
- 单位经济是否可能为负？
- 规模扩大后成本是否反而增加？
- 网络效应是否真实而非口号？
- 护城河是否可持续？
- 供应商为何愿意参与？
- 监管、合规、信用或履约风险由谁承担？
- 哪条证据可以直接推翻当前商业模式假设？
