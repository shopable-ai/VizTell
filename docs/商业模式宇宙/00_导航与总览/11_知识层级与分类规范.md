# 知识层级与分类规范

## 1. 六个层级

### L1 原子（Atomic Element）
不可再细分或不适合继续细分的基本商业设计元素。
例：企业客户、按席位计量、预付款、API 交付。

### L2 机制（Mechanism）
多个原子构成的作用机制。
例：订阅、交叉补贴、佣金、动态定价、网络效应。

### L3 结构（Structure）
参与者、权利、资源和机制形成的关系结构。
例：双边市场、多边平台、经销结构、特许经营网络。

### L4 母型（Archetype）
市场中已形成稳定认知的典型商业模式组合。
例：B2B SaaS、Marketplace、广告支持平台、DTC、Franchise。

### L5 变体（Variant）
母型在计价、供给、客户、风险、交付等方面的具体变形。
例：按使用量计费的 AI SaaS、Managed Marketplace。

### L6 具体企业模式（Company-specific Model）
某个真实企业在特定时间点采用的复合商业模式。

## 2. 分类规则

- 不把不同层级的概念平铺在同一个列表中。
- 一个概念允许多标签，但只设置一个“主归属”。
- 多文件引用优于重复复制定义。
- 同义词进入术语映射，不创建重复概念。
- 案例不能替代定义，定义也不能以单一案例为准。
