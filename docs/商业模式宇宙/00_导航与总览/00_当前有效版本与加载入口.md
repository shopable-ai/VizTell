# 商业模式宇宙 v4：当前有效版本与加载入口

## 1. 当前有效版本

- v2 基线：U01-U19、500 个原子机制、P001-P130 共 130 个组合模式。
- v3 增量：U20-U27 共 149 个原子机制；P131-P170 共 40 个组合模式。
- v4 增量：不新增一级域；在既有 U01-U27 中增加 27 个跨域原子、PR01-PR40 共 40 个商品角色、P171-P200 共 30 个组合模式，并新增 v4 Schema、Validation 与 Offer 决策 Skill 协议。
- 当前合并视图：**U01-U27、676 个原子机制、200 个组合模式、40 个商品角色**。

其中 U19 是“条件性收益、返点与隐性经济层”；U20-U27 补齐所有权治理、会计经济真相、容量利用、风险转移、公共激励、财资与跨币种、合同权利义务、劳动力与激励；v4 再把商品角色、价格架构、Offer 转化、场景经济、隐藏利润层、Cohort Economics、KPI 与实验规则横向连接起来。
