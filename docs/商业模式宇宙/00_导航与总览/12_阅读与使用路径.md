# 阅读与使用路径

> 本文件只使用当前合并后的唯一目录 `docs/商业模式宇宙/`。旧路径 `01_商业模式宇宙/`、`90_参考知识/` 已废弃。
>
> **默认原则：如果目标是解决一个真实项目或看懂现实中的赚钱现象，先走业务工作流；只有需要查机制、结构化加载或质量保障时，才进入本体/机器/Benchmark 层。**

---

## 1. 真实商业项目：默认推荐路径

先读：

1. `../10_任务工作流与运行时/03_项目优先商业推理执行协议.md`：P01-P20 业务主干；
2. `../10_任务工作流与运行时/05_真实商业项目与商业现象解析.md`：判断当前属于已有项目、已有功能、灵感、经营问题、真实数据，还是别人赚钱现象/案例/模式迁移；
3. 根据实际问题按需调用 `../09_专题商业模式/`、`../01_核心机制与组合模式/`、`../02_价值链与利润池/`、`../03_生态与价值交换/`、`../04_案例与行业地图/`、`../05_失败模式与迁移/`、`../06_真实经济性_返点与治理/`；
4. `../10_任务工作流与运行时/06_从商业判断到实际赚钱.md`：把第一推荐变成可卖 Offer、真实交易、指标、继续/修改/停止条件；
5. 新数据出来后回到 P20，更新排序和下一步，而不是重新从零分析。

人工主链可压缩为：

> **项目是什么 → 现在到哪一步 → 真正商业问题 → 用户与付款 → 真实市场 → 成功/失败机制 → 钱在哪里 → 上下游机会 → 3-5 套方案 → 商品与收费 → 经济性 → 风险/成立条件 → 排序 → 最小行动 → 持续经营。**

## 2. 不同现实输入从哪里进入

### 已有项目

优先：

> `10/05 已有项目入口 → P02-P07 → P11-P18 → 10/06`

重点不是重新设计一门新生意，而是：

- 当前用户/付款方；
- 已有产品和功能；
- 当前收入与成本；
- 哪些资产还没有商品化；
- 哪里漏利润；
- 后端和企业价值是否缺失。

### 已有功能/资产

优先：

> `10/05 功能入口 → P06-P07-P11-P14-P18 → 10/06`

重点是：

> **功能 → 用户任务 → 商品角色 → 套餐 → 价格 → 真实付费。**

### 灵感/想法

优先：

> `10/05 灵感入口 → P01-P05-P07-P13-P19`

重点是先找：

- 谁最需要；
- 为什么现在会付钱；
- 用户当前替代方案；
- 一个灵感可以变成哪些不同的生意；
- 哪个版本最便宜验证。

### 具体经营问题

例如利润低、转化低、复购低、CAC 高。

优先：

> `P04 → P06 → P15-P19`

不要重讲整个项目历史。

### 已有真实数据

优先：

> `P15 → P17 → P18 → P19 → P20`

真实数据必须能导致方案保留、重排、修改或淘汰，而不是只生成分析报告。

## 3. 看到别人的赚钱现象：先逆向拆解

例如：

> “闲鱼上有人把电子书卖到 0.01-3 元，这么便宜他怎么赚钱？”

优先读：

> `../10_任务工作流与运行时/05_真实商业项目与商业现象解析.md`

先执行：

```text
观察现象
→ 表面交易能否解释长期盈利
→ 建立盈利假设树
→ 查现实证据和反证
→ 排除不成立假设
→ 找最可能的完整收入结构
→ 判断可持续性与条件
→ 最后才判断能否迁移
```

不要默认：

> “低价 = 引流”。

至少同时检查：

- 表面商品薄利规模；
- 后端商品/套餐/会员；
- Lead Generation；
- Affiliate/分销；
- 软件/AI/服务；
- 企业后端；
- 官方平台/渠道激励；
- 自动化和极低边际成本；
- 版权、账号、平台漏洞等不可持续条件。

最后输出：

> **最可能的盈利结构 + 证据 + 反证 + 关键未知 + 是否值得迁移。**

## 6. 研究“免费、低价、返点、共享、套利”类想法

不要直接把关键词当商业模式名称。

推荐顺序：

> `10/05 先判断现实输入/现象 → 01/06 机会来源与变换算子 → U04/U10/U11/U12/U13/U19/U22/U23/U25/U26 → 06_真实经济性_返点与治理 → 05_失败模式与迁移 → P17-P19`

重点检查：

- 免费/低价是获客、Offer、定价还是长期交叉补贴？
- 返点是正式合同收益还是未披露利益冲突？
- 共享是官方许可的使用权切分，还是违反许可/账号规则？
- 套利是否给客户创造真实价值，还是只依赖短期信息差/漏洞？
- 规模扩大后利润是否真实改善？
- 如果差异消失，模式是否仍然成立？
