## 二、新的完整分析链

> **商业机会 → 参与方 → 价值 → 获客/供给 → 交易 → 标价 → 返点/后台经济 → 所有权/治理 → Principal/Agent与真实收入 → 容量利用 → 风险转移 → 公共激励 → 财资/跨币种 → 合同权利 → 劳动力组织 → 单位经济 → 现金流 → 增长 → 壁垒 → 竞争反应 → 风险 → 生命周期**

## U20 所有权、治理与剩余索取权

定义谁拥有资产/平台、谁拥有投票和控制权、谁承担资本风险、谁获得剩余利润，以及经济权与控制权是否分离。

| 原子机制 | 核心含义 |
|---|---|
| 创始人控制 | 创始人拥有关键投票权或治理控制，即使经济持股比例下降仍可能保持决策权。 |
| 普通股股东所有 | 资本提供者按股权拥有剩余索取权与治理权。 |
| 双层股权/Dual-class | 不同类别股份拥有不同投票权，使经济权与控制权分离。 |
| 员工持股/ESOP | 员工通过股份或期权分享企业剩余价值。 |
| 合作社/成员所有 | 用户、供应者或劳动者共同拥有并参与治理。 |
| 用户所有平台 | 平台用户同时成为股东或成员，平台收益部分回流用户。 |
| 供应商所有联盟 | 关键供应商共同拥有交易、采购或行业基础设施。 |
| 合资企业/JV | 两家及以上主体共同出资、共同治理新实体。 |
| SPV/项目公司 | 将特定资产、项目、风险和现金流隔离在独立实体。 |
| 经济权与治理权分离 | 收益分配权与决策权由不同主体持有。 |
| 剩余索取权 | 合同支付完成后剩余利润/损失最终归属某一方。 |
| 否决权/Veto Rights | 少数参与方对重大事项拥有否决权。 |
| 董事会控制 | 通过董事席位和治理规则控制关键决策。 |
| 数据所有/控制权 | 数据的拥有、访问、使用、派生和删除权影响后续价值捕获。 |
| IP所有权 | 专利、代码、模型、品牌、内容和配方的所有权决定许可与退出价值。 |
| 客户关系所有权 | 谁拥有合同、账户、联系方式和续约权，决定渠道依赖与LTV归属。 |
| 资产所有权与运营权分离 | 资产由资本方持有，运营方按租赁、管理或分成方式经营。 |

## U21 会计口径与经济真相层

区分流水、GMV、Billings、会计收入、净收入、毛利、贡献利润和现金流，防止把规模表象当成真实经济性。

| 原子机制 | 核心含义 |
|---|---|
| GMV/交易总额 | 平台促成的总交易金额，不等于平台收入。 |
| Gross Billings | 向客户开票或收取的总额，可能包含代收或未来履约。 |
| Recognized Revenue | 按照会计规则满足履约义务后确认的收入。 |
| Principal模式/Gross | 企业在转移前控制商品或服务时，通常以总额展示相关收入与成本。 |
| Agent模式/Net | 企业主要负责安排第三方提供商品或服务时，经济收入通常是佣金/净额。 |
| Take Rate | 平台净收入或费用占GMV的比例。 |
| Gross Profit | 净收入扣除直接销售/履约成本后的毛利。 |
| Contribution Margin | 收入扣除与订单/客户直接相关的可变成本后的贡献利润。 |
| Operating Contribution | 进一步扣除必要运营费用后的经营贡献。 |
| Deferred Revenue/合同负债 | 已收现金但尚未完成履约，暂不属于已确认收入。 |
| Pass-through Revenue | 代收代付或低毛利转付项目，可能抬高流水但不创造同等价值。 |
| Contra Revenue | 返点、退款、credits等可能作为收入抵减项而非独立费用。 |
| Capitalized vs Expensed | 研发、获客、实施或资产成本的资本化/费用化改变当期利润呈现。 |
| Unit Economics View | 按客户、订单、SKU、渠道或地区计算真实经济贡献。 |
| Cash Collected | 实际收到的现金，不等于当期会计收入。 |
| Free Cash Flow | 经营产生并扣除资本开支后的可自由使用现金。 |
| Revenue Quality | 区分一次性、重复性、可预测、依赖补贴和高退款风险收入。 |
| Cohort Economics | 按获客批次观察收入、毛利、留存和回收期。 |

## U22 容量、利用率与损耗经济学

定义固定/易腐容量如何出售、预约、超售、闲置、过期与重新分配，以及利用率如何改变单位经济性。

| 原子机制 | 核心含义 |
|---|---|
| Capacity/可售容量 | 单位时间内可提供的座位、房间、算力、席位、工时或服务次数。 |
| Utilization Rate/利用率 | 实际使用量占可用容量的比例。 |
| Occupancy/占用率 | 房间、座位、设备等时点资产的占用程度。 |
| Load Factor | 交通/算力等场景实际售出或使用能力占总能力比例。 |
| Yield Management | 根据时间、需求、库存与支付意愿动态管理容量收益。 |
| Revenue Management | 联合价格和库存控制，实现有限容量收入最大化。 |
| Overbooking/超售 | 基于取消和No-show概率出售超过物理容量的预约。 |
| No-show | 客户预约但未使用，形成容量浪费或机会收益。 |
| Cancellation Economics | 取消政策、退款比例和再售概率共同决定取消成本。 |
| Breakage | 预付权利、礼品卡、积分或包月额度中最终未被使用的部分。 |
| Expiration | 权益到期造成负债释放、客户损失或收入确认变化。 |
| Under-utilization | 购买容量明显高于实际使用，可能支撑Flat-rate模式利润。 |
| Oversubscription | 基于用户不会同时满负荷使用而出售超过专用容量的共享资源。 |
| Statistical Multiplexing | 聚合非同步需求，降低为每个客户单独预留峰值容量的成本。 |
| Capacity Pooling | 多个客户/地点/资源共享一个容量池。 |
| Reservation/预留 | 客户为未来容量支付预订费或承诺。 |
| Priority Allocation | 根据价格、等级、合同或业务重要性分配稀缺容量。 |
| Spoilage/易腐库存 | 时间过去后无法再销售的库存。 |
| Waitlist | 容量不足时建立候补队列用于补位与价格发现。 |
| Surge Pricing | 供需紧张时提高价格以调节需求和供给。 |

## U23 风险转移、风险池与保险经济学

定义风险由谁承担、如何定价、如何聚合和转移，以及承担风险本身如何产生收入。

| 原子机制 | 核心含义 |
|---|---|
| Risk Transfer | 一方付费把特定不确定损失转移给另一方。 |
| Risk Pooling | 聚合大量相对独立风险，以统计规律降低单个事件波动。 |
| Premium/风险保费 | 承担风险所收取的价格。 |
| Deductible/免赔额 | 由客户承担第一层损失，降低小额理赔频率。 |
| Copay/共同承担 | 风险事件发生时由双方按比例承担损失。 |
| Warranty/保修 | 产品方承担一定期限内故障修复或替换风险。 |
| Extended Warranty | 把延长风险保障作为独立收费产品。 |
| Guarantee/保证 | 一方承诺在特定失败条件下补偿另一方。 |
| Performance Guarantee | 服务商为结果不达标承担退款、补偿或追加服务。 |
| Insurance Distribution | 非保险平台分销保险并获得佣金或分成。 |
| Embedded Insurance | 在购买商品/服务流程中嵌入保险保障。 |
| Reinsurance | 保险机构把部分保险风险再转移给再保险人。 |
| Excess-of-loss | 损失超过某一阈值后由另一风险承担方赔付。 |
| Reserve/准备金 | 为未来可能赔付或履约义务留存资金。 |
| Hedging/对冲 | 使用合同或金融工具降低价格、汇率、利率等市场风险。 |
| Risk-based Pricing | 根据客户/交易风险差异动态定价。 |
| Adverse Selection Control | 通过筛选、定价、资格和数据控制逆向选择。 |
| Moral Hazard Control | 通过共担、审计、限额和行为约束减少道德风险。 |

## U24 政府、补贴、税收与公共激励层

定义政府如何作为付款方、采购方、补贴方、担保方或规则制定者改变项目真实经济性。

| 原子机制 | 核心含义 |
|---|---|
| Direct Grant/直接补助 | 政府按资格和条件向项目或企业提供资源。 |
| Operating Subsidy | 按运营、产量、用户或服务覆盖提供补贴。 |
| Capital Subsidy | 补贴设备、厂房、基础设施等资本开支。 |
| Tax Credit/税收抵免 | 符合条件的支出或活动可直接减少税负。 |
| Tax Deduction/税前扣除 | 通过增加可扣除成本降低应税所得。 |
| R&D Incentive | 研发活动享受税收、补助或费用支持。 |
| Government Procurement | 政府作为大客户直接购买产品或服务。 |
| PPP | 政府与社会资本共同建设和运营公共项目。 |
| Concession/特许经营 | 政府授予特定基础设施或公共服务经营权。 |
| Government Guarantee | 政府为融资、需求或风险提供担保。 |
| Preferential Loan | 政策性低息、贴息或担保融资降低资金成本。 |
| Land/Rent Incentive | 土地、厂房、租金或园区条件给予优惠。 |
| Employment Subsidy | 按招聘、就业、培训或特定人群就业提供补贴。 |
| Export Incentive | 围绕出口、海外市场或贸易提供支持。 |
| Carbon Credit/环境信用 | 减排或环境绩效形成可交易或可抵扣的经济权益。 |
| Regulated Tariff | 价格由监管机制或公共合同确定。 |
| Universal Service Payment | 为覆盖低密度、低收入或偏远用户获得公共补偿。 |
| Outcome/Public Impact Payment | 政府或社会资方按社会效果支付。 |

## U25 财资、资产负债表与跨币种经济层

定义主营之外由资金持有、结算、利率、币种、账期和资产负债表结构产生的经济收益与风险。

| 原子机制 | 核心含义 |
|---|---|
| Float Income | 暂时持有待结算资金并在合法合规前提下获得资金收益。 |
| Interest Income | 现金、贷款、存款或固定收益资产产生利息。 |
| Interest Spread | 资金获取成本与资金投放收益之间的利差。 |
| FX Spread | 货币兑换买卖价差形成收入。 |
| FX Risk | 跨币种收入和成本产生汇率波动风险。 |
| Treasury Hedging | 通过远期、期权、掉期等降低汇率/利率风险。 |
| Cash Pooling | 集团集中资金以减少闲置现金和外部借款。 |
| Netting | 多方应收应付相互抵销，降低资金占用和结算次数。 |
| Settlement Delay Economics | 结算周期改变平台与商户双方营运资金价值。 |
| Merchant Reserve | 平台保留部分商户资金应对退款、争议和信用风险。 |
| Collateral Economics | 保证金/抵押物降低风险或形成融资能力。 |
| Working-capital Arbitrage | 利用客户预收、供应商账期和库存周期产生负营运资金优势。 |
| Securitization | 将未来现金流或应收资产打包融资。 |
| Receivables Financing | 应收账款保理或融资提前获得现金。 |
| Balance-sheet Lending | 利用自身资产负债表直接向客户提供融资。 |
| Off-balance-sheet Financing | 由合作金融机构提供资金，平台获得分成但减少资产占用。 |
| Cross-border Settlement | 通过跨境收付、路由和本地化结算产生费用与效率价值。 |
| Tax/Withholding Economics | 不同税制、预提税和税收身份改变跨境净收入。 |

## U26 合同架构、权利、义务与期权层

定义价格之外的合同权利、义务、选择权、退出权和风险分配如何改变交易真实经济价值。

| 原子机制 | 核心含义 |
|---|---|
| Minimum Commitment | 客户承诺最低采购/使用量换取价格或资源条件。 |
| Minimum Guarantee | 一方保证另一方获得最低收入、费用或业务量。 |
| Take-or-pay | 无论实际使用多少，都需支付约定最低数量。 |
| Pay-or-play | 不履行约定合作行为时需支付替代费用。 |
| Auto-renewal | 合同到期自动续期，影响留存和消费者保护要求。 |
| Early Termination Fee | 提前终止合同需支付费用，形成退出成本。 |
| Cancellation Window | 在特定窗口内可以无责取消或修改。 |
| Price Escalator | 价格按时间、指数、成本或其他条件自动增长。 |
| Renewal Cap | 限制续约价格涨幅。 |
| MFN/最惠条款 | 承诺某客户获得不劣于其他客户的价格/条件。 |
| Exclusivity | 限制一方与竞争者合作，交换更强投入或优惠。 |
| Territory Rights | 授予特定地区或客户群的销售/运营权。 |
| Right of First Refusal | 在第三方交易前给予现有参与方优先承接权。 |
| Call Option | 未来按约定条件购买资产/股权/资源的权利。 |
| Put Option | 未来按约定条件出售资产/股权/资源的权利。 |
| Buyback/Repurchase | 约定未来回购商品、资产或库存。 |
| SLA Credit | 未达到服务水平时以credits/费用抵扣补偿客户。 |
| Change Order | 范围变化触发额外价格、工期和资源调整。 |
| Audit Right | 允许核验用量、分成、返点、成本或合规记录。 |
| Data Portability/Exit Right | 合同规定退出时数据导出、迁移和删除权。 |

## U27 劳动力、组织与激励经济层

定义谁执行工作、以何种法律/组织关系参与，以及薪酬和激励如何改变固定成本、边际成本、质量和扩张速度。

| 原子机制 | 核心含义 |
|---|---|
| Full-time Employee | 固定工资、福利和管理成本较高，但控制力通常更强。 |
| Part-time Employee | 以部分工时满足波峰或特定时段需求。 |
| Contractor/独立承包 | 按项目/任务采购能力，固定成本更低但分类风险更高。 |
| Gig Workforce | 大量分散个体按任务接单完成履约。 |
| Agency Outsourcing | 第三方机构组织人员并承担部分管理责任。 |
| BPO/Managed Service | 把完整业务流程交给专业服务商持续运营。 |
| Piece-rate/计件 | 按完成单位数量支付报酬。 |
| Commission/销售佣金 | 按成交金额、毛利或订单支付销售激励。 |
| Tiered Commission | 业绩跨过门槛后佣金率提高。 |
| Bonus/奖金 | 完成目标、质量、增长或利润指标获得额外报酬。 |
| Profit Share | 团队或个人按利润分享收益。 |
| Revenue Share | 参与者按收入/流水比例获得报酬。 |
| Creator Revenue Share | 平台与创作者按广告、订阅、打赏或交易收入分成。 |
| Partner-operated | 合作伙伴承担本地销售或履约，平台提供品牌/系统/供给。 |
| Franchisee-operated | 加盟商投入资产和人力，按照统一规则运营。 |
| Owner-operator | 资产所有者本人参与运营，降低代理成本但扩张依赖个体。 |
| ESOP/Equity Incentive | 通过长期股权价值绑定关键员工。 |
| Tournament Incentive | 参与者按相对排名竞争有限奖金或晋升机会。 |
| Quality-linked Pay | 报酬与评分、复购、退款、事故等质量指标挂钩。 |
| Guaranteed Minimum + Variable | 保底收入与绩效变量结合，平衡供给稳定和激励。 |

# 三、四个横向系统

## X01 市场设计与稀缺资源分配
