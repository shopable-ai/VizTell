# 商业模式宇宙：经典模式与组合模式库

## 一、为什么模式要放在 L3

模式不是最小单位，而是多个原子机制的稳定组合。

> **模式 = 一组原子机制 + 参与方关系 + 现金/价值流 + 成立条件 + 失败条件**

下面提供 130 个可复用组合模式，覆盖传统、平台、软件、金融、AI、供应链、循环经济等。

## 四、模式之间还需要记录关系

### 互补关系示例

- Freemium + Subscription
- SaaS + Usage-Based
- Marketplace + Escrow + Rating
- Free B2B Tool + Supply Chain
- Hardware + Consumables
- Content + Lead Generation
- Vertical SaaS + Embedded Finance
- Product-as-a-Service + Circular Take-back
- AI Agent + Usage Credits + Outcome Add-on

### 冲突/张力示例

- Orchestrator ↔ 强垂直整合
- 极致开放 ↔ 强专有Lock-in
- 无限Flat Rate ↔ 高且不可预测边际成本
- 完全去中介 ↔ 高佣金平台
- 高度定制 ↔ 极致标准化低成本
- 绝对匿名 ↔ 强KYC/金融合规

### 迁移规则

不要问：

> “这个行业能不能用某模式？”

而问：

> “这个项目是否具备该模式所需的经济结构？”

例如 Razor & Blade 应检查：

1. 是否存在长期Installed Base？
2. 是否有自然、高频、不可轻易替代的补充品？
3. 补充品毛利能否覆盖前端让利？
4. 客户会不会因被锁定而反感或被监管限制？
5. 标准能否被竞争对手兼容或绕开？



## 五、P101-P130：返点、门槛与后台经济组合模式

| ID | 组合模式 | 机制公式 |
|---|---|---|
| P101 | Back-End Rebate / 后台返点 | 前台按名义价格交易 → 周期累计合格基数 → 后台返还 → 形成低于发票价的真实净价 |
| P102 | Tiered Volume Rebate / 阶梯数量返点 | 交易量进入不同档位 → 返点率分层 → 用规模换取更低净价 |
| P103 | Retroactive Rebate / 追溯返点 | 跨过门槛 → 对整个累计合格基数按新比例重算 → 门槛附近边际激励极强 |
| P104 | Incremental Rebate / 增量返点 | 每档只对新增部分奖励 → 经济曲线更平滑 → 降低断崖式采购扭曲 |
| P105 | Growth Rebate / 增长返点 | 相对基期增长 → 触发奖励 → 供应商购买增量而非绝对规模 |
| P106 | AVB / Annual Volume Bonus | 年度聚合量 → 年终奖金/返点 → 大客户、代理集团或渠道集中规模获得后台经济利益 |
| P107 | Partner Accelerator / 渠道加速器 | 基础奖励 + 超目标更高费率 → 鼓励伙伴冲刺战略产品或增长目标 |
| P108 | Commit-to-Save / 承诺换折扣 | 承诺未来采购/使用量或期限 → 供应方获得可预测需求 → 买方获得更低价格 |
| P109 | Co-op Fund / 合作营销基金 | 渠道产生合格收益 → 一部分以合作营销基金返还 → 需证明活动执行 |
| P110 | MDF / 市场发展基金 | 厂商投入专项预算 → 渠道用于需求生成/市场开发 → 以增长换取非直接价格补贴 |
| P111 | SPIFF / 一线销售激励 | 厂商奖励渠道销售人员推动指定产品 → 短期加速销量 → 必须治理个人受益与利益冲突 |
| P112 | Deal Registration / 商机登记保护 | 渠道先登记合格商机 → 获得价格保护/折扣/优先权 → 降低渠道抢单风险 |
| P113 | Free Goods Rebate / 免费商品返点 | 现金返点改为额外商品 → 提高表面价格稳定性 → 降低真实单位成本 |
| P114 | Credits Economy / Credits返利 | 返点转化为云、广告、服务或平台credits → 促进二次使用并形成生态留存 |
| P115 | Media Inventory Rebate / 免费媒体库存 | 媒体采购量 → 免费库存/价值池 → 形成非现金返点和实际CPM下降 |
| P116 | Service-Agreement Rebate Risk / 服务协议型返点 | 供应商支付研究/咨询等费用且与采购量关联 → 需区分真实服务与变相返点 |
| P117 | Slotting Allowance / 进场费 | 供应商支付前置费用 → 获得渠道上架/货架位置 → 渠道把稀缺分发位变现 |
| P118 | Pay-to-Stay / 留架费 | 持续付款/让利 → 保留销售/陈列资格 → 形成持续渠道租值 |
| P119 | Performance Fund / 绩效基金 | 达到陈列、推广、销售、服务等可验证指标 → 获得专项资金 |
| P120 | Principal Trading / 自营转售 | 中介先作为principal买入资源 → 再向客户转售 → 利润来自采购/销售价差而非代理费 |
| P121 | Dual Rate Card / 双重价卡 | 代理身份采购价 ≠ principal身份采购价 → 不同交易身份形成不同真实毛利 |
| P122 | Value Pot / 聚合价值池 | 基于集团预期/累计采购量获得免费或折扣资源 → 再在客户/业务间分配 |
| P123 | Portfolio Aggregation / 集团量聚合 | 多个账户/子公司/客户合并基数 → 跨过更高门槛 → 获得规模返点 |
| P124 | Rebate Stacking / 激励叠加 | 基础折扣 + 数量返点 + MDF + credits + 账期等叠加 → 优化综合净价而非单一报价 |
| P125 | Net Price Waterfall / 净价瀑布 | 标价 → 发票折扣 → 后台返点 → 非现金权益 → 费用/融资价值 → 计算真实净价 |
| P126 | Threshold Optimization / 门槛优化 | 预测累计基数和边际贡献 → 决定是否值得冲刺下一返点档位 → 防止为返点而亏损 |
| P127 | Rebate Accrual & True-up / 返点计提与期末校正 | 交易过程中按预计达成率计提 → 期末按实际资格重算 → 防止利润虚高/虚低 |
| P128 | Rebate Audit / 返点审计回收 | 统一交易数据 → 匹配合同条件 → 找出漏领、错算、逾期和clawback → 回收经济利益 |
| P129 | Preferred/Exclusive Incentive / 优先或排他奖励 | 供应商用返点换取更高份额、优先展示或排他 → 可能提高合作投入，也需竞争法审查 |
| P130 | Undisclosed Rebate Conflict / 未披露返点冲突 | 代理/渠道因客户交易获得供应方后台利益且客户不知情 → 激励可能偏离委托方最佳利益，列为风险模式而非推荐模板 |
