# 商业模式宇宙 v3：研究来源补充

> 本文件补充 U20-U27 的研究校准来源。具体项目中的会计、金融、税务、劳动和监管结论仍需按司法辖区与合同事实确认。

## 会计与 Principal / Agent

- IFRS Foundation — IFRS 15 principal-versus-agent guidance：核心判断是企业在向客户转移特定商品/服务之前是否控制它；用于区分 Gross 与 Net 呈现。
- IFRS Interpretations Committee — *Principal versus Agent: Software Reseller (IFRS 15)*：软件经销商场景说明“平台/经销商”标签本身不足以决定 principal/agent，必须回到合同事实与控制。

## 风险与保险

- IFRS Foundation — IFRS 17：保险合同的核心是投保人向保险人转移显著保险风险；保费、履约现金流、风险调整和赔付需要单独建模。
- IFRS 17 Effects Analysis：再保险用于保险机构继续转移部分风险，包括比例与超额损失类结构。

## 政府与公共激励

- IFRS Foundation — IAS 20：政府补助是企业满足特定条件后由政府转移的资源；政府援助、担保和采购都可能显著改变项目经济性。

## Breakage / 未使用权益

- SEC 上市公司公开披露提供现实案例：礼品卡与忠诚度权益通常先形成合同负债，企业可基于历史兑换模式估计最终不会兑换的 breakage，并按适用会计规则确认。

## 使用纪律

1. Principal/Agent 属于会计与交易控制校准层，不可仅凭业务名称判断。
2. Breakage 是真实经济变量，但不得通过误导、隐藏规则或人为增加兑换摩擦来制造。
3. 风险转移、保证、保险、贷款、Float 等结构必须加载当地金融监管。
4. 补贴必须记录资格、期限、返还条件和政策退坡情景。
5. 政府/税收优惠改善当前项目经济性，不代表无补贴情况下模式仍成立。
