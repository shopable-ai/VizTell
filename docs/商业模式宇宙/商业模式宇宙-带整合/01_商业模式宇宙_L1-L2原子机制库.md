> 共 19 个一级设计域，500 个原子机制。原子用于组合，不互斥。

## U01 参与方与市场结构

定义谁创造价值、谁使用、谁付款，以及市场边界。

| ID | 原子机制 | 核心含义 |
|---|---|---|

| U01-A03 | 第三方付款 | 使用者与付款者分离，例如广告主、雇主、保险方或政府付款。 |

| U01-A05 | B2C | 直接向个人消费者销售。 |
| U01-A06 | B2B2C | 借B端渠道服务C端，同时与B端共享价值。 |
| U01-A07 | C2C/P2P | 个人与个人之间供需匹配。 |
| U01-A08 | B2G/G2B | 围绕政府采购、授权、公共服务或监管场景。 |
| U01-A09 | 大众市场 | 标准化方案服务大规模相似需求。 |
| U01-A10 | 垂直细分 | 围绕特定行业、职业或场景深做。 |
| U01-A11 | 长尾市场 | 聚合大量低频小众需求形成总体规模。 |
| U01-A12 | 高端/奢侈人群 | 以稀缺、身份、体验或服务溢价为核心。 |
| U01-A13 | 低收入/BOP市场 | 通过极致成本与可负担性扩大覆盖。 |
| U01-A14 | 未被满足/被忽视人群 | 选择传统企业不愿服务但可形成新经济性的群体。 |
| U01-A15 | 生命周期人群 | 围绕结婚、育儿、养老等阶段串联连续需求。 |
