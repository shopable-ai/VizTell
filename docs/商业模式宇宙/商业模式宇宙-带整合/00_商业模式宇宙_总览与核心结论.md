# 商业模式宇宙：总览与核心结论

## 0. 定义

**商业模式不是一个行业标签，也不是一个“盈利方式”列表。**

建议统一定义为：

> **某个组织如何选择参与方和价值主张，组织资源与交易，形成需求与交付，通过定价、收入、成本和现金流捕获价值，并依靠留存、网络效应、复制和控制点持续存在。**

核心总链：

> **识别参与方与需求 → 设计价值主张 → 选择产品/权利包装 → 获客与分发 → 组织供给 → 建立交易与信任 → 定价与支付 → 识别返点/门槛/后台经济层 → 捕获收入 → 管理成本与现金流 → 留存复购 → 复制增长 → 建立壁垒 → 风险治理 → 迭代/迁移/退出**

## 1. 为什么不能只做“100种商业模式”

商业模式是一个**组合空间**。一个真实企业往往同时是：

> SaaS + Freemium + Usage-based + PLG + API + Marketplace + Revenue Share

因此“模式名词表”只能作为参考索引，不能作为宇宙本体。

商业模式宇宙采用五层结构：

- **L0 核心逻辑**：创造价值 → 交付/交换价值 → 捕获价值 → 强化/更新价值。
- **L1 19 个正交设计域**：市场、价值、包装、获客、渠道、留存、供给、平台、信任、定价、收入、成本、现金流、数字资产、增长、壁垒、循环、风险。
- **L2 原子机制**：最小可复用商业设计单元。
- **L3 组合模式**：多个原子机制稳定组合形成的模式。
- **L4 实例/案例**：具体公司、项目或行业中的真实实现。
- **L5 场景与迁移**：把现有模式迁移到新项目后的方案与实验。

## 2. 当前宇宙规模

- L1 设计域：**19**
- L2 原子机制：**500**
- L3 核心组合模式：**130**
- 外部经典模式索引：Gassmann / Business Model Navigator 当前版 **60 个模式名**
- 学术校准基线：Weking 等人的系统综述从文献中筛得 **164 个 BMP**，组织为 **194 个四层级分类元素**。

本宇宙不是声称“未来所有模式已枚举完”，而是追求：

> **维度尽可能完备、原子可组合、层级可继承、新模式可挂载、重复可消解。**

## 4. 三种知识对象必须分开

### 4.1 原子机制 Atom

单一设计选择，例如：

- 按量计费
- 供应商账期
- 托管支付
- 店中店
- 用户推荐
- 数据网络效应

### 4.2 组合模式 Pattern

多个原子稳定组合，例如：

> **Razor & Blade = 低利润耐用品 + Installed Base + 专有耗材 + 持续复购**

### 4.3 模式实例 Instance

具体公司的实际组合。

实例绝不能被强迫归入唯一分类。

## 6. 核心原则

1. **行业 ≠ 商业模式。**
2. **盈利方式 ≠ 完整商业模式。**
3. **免费不是模式终点，必须知道谁补贴、多久回收。**
4. **平台不是“做一个App”，必须存在多方交互价值。**
5. **现金流好不等于利润好；利润好也不等于现金流安全。**
6. **模式迁移要比较经济结构，而不是表面产品。**
7. **案例事实与机制推断必须分层。**
8. **高收益承诺、资金池、长期返现、借贷、保险、证券等必须先进入监管审查。**
9. **AI产品不能默认照搬传统SaaS固定席位价，因为推理成本随使用增加。**
10. **每个候选模式最后都要回到单位经济性、现金流、参与方激励和可执行实验。**
11. **账面价格 ≠ 实际净经济价格。** 必须计算折扣、门槛返点、credits、MDF、免费资源、账期、价差和clawback后的 Net Effective Economics。
12. **公司级合同返点 ≠ 个人秘密回扣。** 前者属于定价/渠道机制，后者可能触发商业贿赂、欺诈与利益冲突。

## 7. 研究基础

本宇宙综合以下框架而非由当前70个案例反推：

- Osterwalder / Strategyzer：Business Model Canvas，9个基本构件。
- Teece：价值创造、交付、捕获视角。
- Gassmann / Frankenberger / Csik：Business Model Navigator，经典模式重组思路。
- Weking 等：Business Model Pattern 四层级层次分类；系统综述筛选164个模式，形成194个元素。
- Taran 等：Five-V 结构。
- Remané 等：以价值主张、交付、创造、捕获形成形态学结构。
- Hagiu & Wright：多边平台的组织经济学。
- Bocken 等：可持续商业模式原型。
- 近期数字/AI商业模式研究：usage-based、activity-based、outcome-based、AI agent monetization 等。
