# 周期与演化宇宙（V0.1）

> **独立研究域**：研究系统随时间出现的重复波动、阶段演进、反馈时滞、结构跃迁与不可逆变化。周期既是一切研究域可调用的**时间推理坐标**，也有足够独立的研究对象、方法和证据要求，因此允许本目录独立发展。

## 1. 四种不同时间机制，不能统称“周期”

| 类型 | 基本含义 | 实例 | 关键警惕 |
| --- | --- | --- | --- |
| 周期/波动 | 围绕某种状态出现重复性起伏 | 某些景气与需求波动 | 有历史波动不代表未来周期固定 |
| 生命周期 | 对象经历探索、成长、成熟、衰退/退出等阶段 | 产品/项目/组织 | 阶段不一定线性，也不必然全部经历 |
| 累积与路径依赖 | 过去选择改变后续可选路径 | 技术债、网络锁定 | 不等于不可改变 |
| 结构性冲击/转型 | 外部冲击或内生阈值导致状态跃迁 | 技术替代、监管巨变 | 非周期性突变不应硬套波峰波谷 |

必须分开记录**日历时间、相对阶段、观测窗口、时滞、持续期、触发条件**。

## 2. 首批八个研究分区

1. 经济景气与需求周期：需求、信贷、利率、就业等的联动与偏差。
2. 产业与技术演化：技术成熟、范式转变、替代、扩散与产业重构。
3. 产品与客户生命周期：探索—采用—留存—衰退—退出/再激活。
4. 组织成长与治理演化：规模跃迁、管理复杂化、重组与能力再造。
5. 资本和现金转换周期：融资窗口、支出、回款、现金跑道与资金期限错配。
6. 竞争与策略互动节奏：对手感知、反制时滞、竞争升级/协调。
7. 个人技能与职业阶段：学习曲线、能力折旧、转型和机会窗口。
8. 项目交付与运维阶段：需求验证、开发、验收、上线、维护、迁移、退出。

上述是研究场景分区，不构成“八种固定周期定律”。

## 3. 多周期耦合是主要研究对象之一

一个软件产品可能处于“技术采用上升期”，但“资本融资收紧期”；开发交付周期比市场窗口长；竞争者的响应周期更短。技术可行仍可能商业失败。**是否失败必须基于真实指标和因果证据判断**，不能因为多周期不一致就直接判死刑。

最小分析表：

| 轴 | 问题 |
| --- | --- |
| 系统边界 | 观察个人、团队、项目、公司还是整个行业？ |
| 时间尺度 | 日、周、月、年，还是跨代技术迁移？ |
| 阶段识别 | 依据哪些指标和阈值定义转折？ |
| 同步性 | 各阶段是同步、错峰还是相互抵消？ |
| 时滞 | 原因何时发生、何时可观测后果？ |
| 反馈 | 正反馈、负反馈、库存/现金流/网络变化？ |
| 冲击 | 有什么外生事件可能改变原有路径？ |
| 干预/退出 | 调整节奏、缩短反馈、试验、转向、暂停？ |

## 4. 可复核的周期命题卡

- ID、研究对象、时间尺度与观察区间；
- **类型**：周期性波动 / 生命周期 / 路径依赖 / 结构性转型；
- 阶段定义、可观测指标、测量方法；
- 可能机制、时滞、阈值、交互关系、竞争性解释；
- 支持与反对的时间序列/历史事件、来源和可比性；
- 预测**范围与不确定性**，不伪造精确转折时间；
- 适用范围、失效条件、后续复核触发器。

当缺少连续数据时，只能写“阶段性判断假设”，不能称已证实周期。

## 5. 应用与跨宇宙边界

- 社会规则借本宇宙研究竞争、合作、权力变化的时间条件，但机制本体由 [社会运行规则宇宙](../社会运行规则宇宙/README.md) 管理。
- IT 失败宇宙可引用“技术窗口错配”的时序结论，具体事故/失败证据由 [软件IT失败宇宙](../软件IT失败宇宙/README.md) 管理。
- 项目失败宇宙可引用“交付周期与现金跑道错配”的判断，项目立项与阶段管理由 [企业项目失败宇宙](../企业项目失败宇宙/README.md) 管理。
- 推理坐标和局部续研方法由 [跨宇宙多维推理协议](../思维与方法宇宙/03_跨宇宙多维推理与节点续研协议.md) 管理。

## 6. 最小验证与下一步

先选“软件交付周期与市场窗口错配”作为一条**待验证**命题，寻找两个不同结果的真实案例，并对照产品质量、资金、获客与竞争等混杂因素。输出阶段判断、竞争性解释、证据缺口和决策影响；不能仅凭两个案例泛化为规律。后续再追加可复用的数据/时序分析方法。
