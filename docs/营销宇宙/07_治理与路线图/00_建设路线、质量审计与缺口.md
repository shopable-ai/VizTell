# 建设路线、质量审计与缺口

## 一、当前状态

- 当前版本：架构基础版 v0.3（外部参考与专业分支审计增量）。
- 已落盘：总入口、范围边界、24 域候选地图、分类与节点规范、研究方法与证据标准、关系模型、行动与决策框架、知识资产与 AI 协作协议、治理路线。
- 尚未完成：独立完整性审计、领域深度研究、权威来源索引、专业方法 SOP、领域级行动手册、模板库、机器可读关系、真实场景 Benchmark。
- 当前 24 域不是最终冻结分类；后续审计可以调整。

## 二、建设阶段

### Phase 0：架构审计与收敛

- 从传统营销、服务营销、B2B、零售、贸易营销、数字营销、品牌、增长、营销科学和组织管理等视角审查遗漏。
- 检查分类轴、粒度、重叠、边界和跨域接口。
- 检查不同商业模式和发展阶段的覆盖。
- 输出：架构审计、修订地图、缺口清单和变更记录。

### Phase 1：基础标准稳定

- 验证领域 ID、节点模板、适用等级、证据引用和关系规范。
- 对照 AI 原生知识系统，消除通用对象重复定义。
- 输出：稳定的分类和内容规范。

### Phase 2：三个候选试点领域

建议优先试点：
- D02 市场研究与市场情报；
- D10 品牌战略与品牌资产；
- D21 营销数据、分析与科学决策。

试点目的：分别验证外部市场研究、专业理论与长期资产、测量和因果分析能否使用同一套节点和验收标准。试点顺序可根据真实使用需求调整。

每个试点至少建设：完整二/三级地图、关键四级问题、成熟理论与方法、输入输出、操作步骤、指标、边界、证据来源、反例、行动手册和测试案例。

### Phase 3：其余领域深度展开

- 按领域依赖和实际需求安排建设顺序。
- 不批量生成空目录或无来源术语。
- 每个领域先完成边界和覆盖审计，再增加专业知识内容。
- 对交叉内容使用关系引用，不复制定义。

### Phase 4：专业研究方法库

- 为主要研究问题建立方法选择规则。
- 为每种重要方法记录设计、样本、数据、操作、局限、偏差和交叉验证。
- 对因果、预测、定价、品牌和广告测量设置专业方法审查。

### Phase 5：行动手册与决策工具

- 为高频营销任务建立可执行 SOP。
- 为不同业务模式和组织阶段建立条件分支。
- 建立机会评估、市场进入、渠道选择、预算、定价和实验决策模板。
- 每个行动明确输入、输出、决策门、失败处理和验收。

### Phase 6：资产模板与机器可读能力

- 先稳定人类可读文件和引用。
- 再按真实检索、自动校验和跨文件分析需求建立 Registry、Schema 或图关系数据。
- 机器校验成功不等于营销结论正确。
- 不为“未来可能需要”提前建设复杂 Agent Runtime。

### Phase 7：真实任务验证与持续演进

- 选择不同业务模式、规模和阶段的真实或脱敏任务。
- 测试 AI 能否正确定位领域、发现依赖、选择方法、标注证据和形成可执行输出。
- 记录错误、反例和遗漏，按影响范围局部修订。
- 定期审查动态知识的过时风险。

## 四、质量审计维度

- 完整性：重要营销任务、专业领域和业务模式是否覆盖。
- 边界：相邻领域是否有明确归属和接口。
- 粒度：同层节点是否处于相近抽象层级。
- 专业性：是否有成熟理论、方法、来源和实际操作。
- 证据：结论是否可追溯，是否区分事实、Claim、推断和假设。
- 关系：依赖、并行、反馈和共享数据是否明确。
- 可执行性：是否能说明输入、动作、输出、决策和验收。
- 经济性：是否考虑毛利、成本、现金流、客户价值和增量。
- 适用性：是否说明条件、边界、反例和不适用场景。
- 维护性：是否有唯一事实源、版本、更新和失效机制。
- AI 可调用性：是否能在真实任务中检索到正确知识并避免错误组合。

## 五、真实任务验证矩阵

至少覆盖以下场景：

- 新产品探索：需求发现、市场规模、价值主张和最小验证。
- B2B 市场进入：采购委员会、竞争、销售周期、渠道和证据。
- 成熟零售业务：商品、促销、门店/电商渠道、复购和毛利。
- 服务业务：服务体验、人员交付、客户满意和留存。
- 订阅业务：激活、使用、续费、流失和客户终身价值。
- 非营利/公共利益：使命、利益相关方、行为改变、信任和合规。
- 国际扩张：国家选择、文化、本地化、渠道、支付和法规。
- 品牌危机：舆情、事实核验、利益相关方、响应和恢复。

每个测试都应记录输入、目标、必要知识节点、预期方法、预期输出、禁止错误、评价依据和失败严重度。

## 六、禁止的质量捷径

- 不以一级分类数量证明完整。
- 不以文件数量证明专业。
- 不以 AI 生成流畅度证明事实可靠。
- 不以单个案例证明普遍规律。
- 不以相关性证明因果。
- 不以归因 ROAS 证明增量利润。
- 不以主观评分代替审计证据。
- 不因分类有遗漏就立即新增一级领域；先检查是否是现有节点粒度或边界问题。

## 七、下一轮优先任务

1. 逐项审计 24 个候选领域，尤其检查传统营销和专业行业分支。
2. 形成分类重叠与边界矩阵。
3. 选定三个试点领域并完成完整研究。
4. 为试点领域建立来源登记和证据引用。
5. 用真实任务验证知识地图和行动手册。
6. 根据失败记录修订分类和模板。
7. 再逐步扩展其他领域。
