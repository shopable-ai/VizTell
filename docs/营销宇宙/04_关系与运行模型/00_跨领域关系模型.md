# 跨领域关系模型

## 一、为什么需要关系模型

24 个一级领域不是 24 个互不相关的文件夹。营销问题通常跨越多个领域，且同一领域会同时影响多个商业结果。

关系模型需要回答：

- 哪些知识是前置条件；
- 哪些知识共同支持一个决策；
- 哪些领域并行工作；
- 哪些领域共享数据或资产；
- 哪些结果会反馈并改变上游判断；
- 哪些内容存在边界重叠或潜在冲突。

不能把所有关系都画成单向流程箭头。

## 二、关系类型

建议使用以下关系语义。正式机器化前先以文档和链接验证其稳定性。

- depends_on：执行或判断 B 需要 A 提供前置条件。
- informs：A 为 B 提供信息，但不是硬性前置。
- contributes_to：A 是 B 的一个影响因素。
- validates：A 用于验证 B 的假设或结果。
- executes_through：某个策略或目标通过某渠道、流程或能力实施。
- measured_by：某个目标或结果由特定指标/方法测量。
- feeds_back_to：结果反馈并改变上游知识、假设或决策。
- shares_data_with：两个领域共享数据或客户/市场对象。
- constrains：法规、经济、能力或风险对另一领域形成约束。
- conflicts_with：两个目标、指标、策略或资源安排可能冲突。
- supersedes：新版本或新规则替代旧对象。
- specializes：专业分支继承并限定通用能力。

关系需要有方向、适用条件、理由和必要证据；语义相似不自动构成依赖关系。

## 三、核心系统关系

### 1. 市场与需求认知

- D01 商业环境与经济性为市场判断提供宏观、产业和经济约束。
- D02 市场研究识别市场结构、规模、趋势和竞争环境。
- D03 用户与组织行为解释购买者、使用者和决策者的行为。
- D04 需求与机会研究把市场信号和用户问题转化为可验证机会。
- D02、D03、D04 相互补充，不应合并为一个泛化的“市场调研”。

### 2. 战略、定位与价值

- D05 营销战略确定目标、方向和资源取舍。
- D06 STP 选择细分市场、目标客户和定位。
- D07 竞争战略检验替代方案、竞争优势和竞争反应。
- D08 产品价值决定能够提供什么真实收益。
- D09 定价与商业化设计价值交换条件。
- D10 品牌将长期承诺、识别、联想和信任沉淀为品牌资产。
- D05-D10 不是严格流水线；产品、市场和品牌反馈可能触发战略重审。

### 3. 传播、触达与分发

- D11 营销组合负责协调产品、价格、渠道和促销。
- D12 内容提供信息、知识、创意和故事资产。
- D13 搜索与发现连接主动信息需求和可见性。
- D14 广告购买付费媒体触达并管理媒体投资。
- D15 渠道与合作伙伴负责市场覆盖、交易路径和分销。
- D16 社交与社区形成参与、关系和口碑信号。
- D17 公关与事件管理赢得媒体、公共影响和声誉。
- D12-D17 可以并行协作，但必须共享定位、目标受众、信息主张和测量口径。

### 4. 交易与客户生命周期

- D18 将触达和意向转化为线索、销售机会和交易。
- D19 管理购买后的激活、体验、留存、复购、续费、推荐和流失。
- D08 的实际价值交付影响 D19；D19 的使用和流失证据反馈 D08、D05、D10。
- D18 与 D19 之间需要明确客户交接、数据、承诺和责任边界。

### 5. 测量、增长、技术与治理

- D21 为各领域提供指标、数据、归因、增量和因果测量。
- D22 根据 D21 的诊断提出和验证增长假设。
- D23 提供数据与自动化能力，但不能替代正确的研究设计和业务判断。
- D24 提供组织、预算、流程、合规和风险约束。
- D21-D24 横向影响全部领域。

## 四、主要反馈回路

### 市场学习回路

市场变化 → 用户/渠道/竞争信号 → 需求解释 → 机会评估 → 战略选择 → 新证据 → 更新市场认知。

### 价值验证回路

产品/服务承诺 → 用户体验 → 首次价值 → 使用与留存 → 客户反馈 → 产品和价值主张调整。

### 品牌学习回路

品牌表达 → 触点体验 → 认知与联想 → 考虑与信任 → 购买和口碑 → 品牌测量 → 品牌策略调整。

### 获客与商业结果回路

渠道投资 → 触达/线索 → 转化/交易 → 毛利与履约成本 → 客户价值 → 渠道增量与预算调整。

### 增长实验回路

问题诊断 → 假设 → 实验 → 结果与不确定性 → 决策 → 扩大/迭代/停止 → 新问题。

## 五、重要依赖不等于强制顺序

- 新产品探索可能先从用户问题和需求验证开始。
- 成熟业务可能先从利润、留存或渠道瓶颈开始。
- 品牌危机可能直接从 D17 启动，再回到 D10、D24。
- 国际化项目可能先做 D20，再按需调用 D02-D19。
- B2B 销售周期可能由 D18 的采购流程驱动，同时需要 D03、D06、D08、D21。

行动路径应由问题、风险、现有证据和依赖决定，而不是所有任务跑同一条漏斗。

## 六、跨知识宇宙接口

- 商业模式宇宙：商业模式机制、利润池、真实经济性和价值捕获。
- AI 原生知识系统：知识对象、来源、证据、关系、版本、治理和 AI 路由。
- 通用链路宇宙：任务与项目生命周期、研究执行和验收链路。
- 思维与方法宇宙：通用研究、推理、实验、因果、决策和优化方法。

跨宇宙关系优先使用引用和映射，不复制对方的 canonical 定义。

## 七、关系验收

每条重要关系至少回答：

- 关系两端分别是什么节点？
- 关系类型是什么？
- 方向是否明确？
- 是硬依赖、软影响还是反馈？
- 在什么条件下成立？
- 是否有证据或明确理由？
- 是否存在反例？
- 变更一端会影响哪些下游节点？
