# 通用营销宇宙

> 当前版本：架构增量版 v0.8（D01-D24 全领域 L2-L3 首版地图）。
> 当前成熟度：已建立 24 域 Canonical Registry、领域类型与正交视图；完成 D02、D03、D04、D06、D08、D09、D10、D12、D13、D14、D15、D21 二十四个 L2-L3 知识地图，并建立 15 个正向与 5 个负向任务路由测试样本。领域仍为候选导航入口，专家复核、方法 SOP、真实任务盲测和回归尚未完成。
> 本项目不是已经完成的营销百科，不得宣称已达到 95 分或 97 分。

## 一、项目定义

通用营销宇宙（Universal Marketing Universe）是一套独立于具体企业、品牌、产品和行业的专业营销知识体系，长期支持知识发现、研究、战略判断、市场进入、传播分发、销售转化、客户生命周期、测量、实验和组织治理。

它既是专业知识地图，也是把知识连接到研究方法、决策、行动、证据和反馈的长期知识资产。

## 二、核心架构

- **专业知识地图**：24 个一级知识域作为候选基线，待完整性、边界和粒度审计。
- **横向支撑系统**：研究方法、证据与来源、决策与风险、绩效与学习、知识资产、AI 协作。
- **跨领域运行模型**：描述市场、用户、需求、机会、战略、价值、渠道、交易、生命周期、经济性与反馈如何连接。
- **行动与决策框架**：把营销知识转化为有输入、步骤、决策门、输出、风险和验收的专业行动。
- **质量与验证体系**：通过来源审查、反方审计和真实任务 Benchmark 判断成熟度。

## 五、与 VizTell 其他知识系统的边界

- **AI 原生知识系统**：提供通用知识对象、来源、证据、关系、版本、生命周期、治理和 AI 能力路由标准。营销宇宙引用并应用这些标准，不复制冲突的底层 Schema。
- **商业模式宇宙**：拥有商业模式机制、价值捕获、收入与成本结构、利润池和通用单位经济性定义。营销宇宙拥有市场、用户、需求、定位、传播、渠道、销售协同和客户生命周期的营销专业定义；营销侧的 CAC、LTV、获客回收和渠道经济性应用必须声明口径并引用商业模式宇宙。
- **通用链路宇宙**：提供跨领域任务、项目、研究、执行、验证和生命周期链路。营销行动手册是这些通用链路在营销任务中的专业装配。
- **思维与方法宇宙**：提供通用推理、研究、实验、因果和决策方法。营销宇宙记录领域适配、约束、指标和案例。

## 六、核心原则

- 不把 SEO、广告、内容或社交媒体等同于营销整体。
- 不把营销等同于增长；增长需要同时考虑产品价值、客户行为、经济性、组织能力和长期结果。
- 不把流量、转化率、归因 ROAS 或 AI 搜索引用单独视为商业成功。
- 不把用户自述、相关性、案例或 AI 生成内容自动升级为事实。
- 不假设所有业务都需要全部营销职能。
- 不把固定漏斗当作唯一客户旅程或增长路径。
- 不为了追求目录规模而批量制造空节点。
- 先建立可读、可验证的专业内容，再决定是否增加机器 Schema、Skill 或 Agent Runtime。

## 八、维护原则

- 本 README 是营销宇宙唯一总入口。
- 当前有效版本与加载优先级以当前版本入口为准。
- 专业领域定义以营销宇宙内唯一 Owner 文件为准；通用对象和方法由相应知识宇宙拥有。
- 新内容优先增量更新已有节点；跨领域内容通过关系引用，不复制第二份权威定义。
- 结构变化必须同步更新 MANIFEST、总入口、领域地图和受影响的交叉引用。
