# Universal Marketing Universe｜通用营销宇宙

> **当前状态：架构基础版 v0.1。** 本目录建立通用营销知识宇宙的独立入口、初始分类、研究与证据规范、关系模型、行动与决策框架，以及后续建设路线。它不是已经完成的营销百科，也不代表 24 个领域已经通过最终完整性审计。

## 一、项目定义

Universal Marketing Universe 是一套独立于具体企业、品牌、产品和行业的通用营销知识体系，目标是长期支持：

- 营销领域知识发现、分类、理解和检索；
- 市场、用户、需求、竞争与商业机会研究；
- 营销战略、价值主张、品牌、传播、渠道、销售和客户生命周期决策；
- 营销测量、实验、预算和组织运营；
- 可复用的研究方法、行动手册、决策模型和成果模板；
- AI 对营销知识的可靠检索、组合、验证和增量更新。

## 二、核心结构

- **专业知识地图**：当前以 24 个一级知识域作为待审计的初始架构。
- **横向支撑系统**：研究方法、证据与来源、决策与风险、绩效与学习、知识资产、AI 协作。
- **行动与决策框架**：把知识转化为可执行任务、条件判断、成果和验收标准。
- **长期治理**：维护来源、版本、适用范围、失效状态、关系和质量记录。

## 四、与 VizTell 其他知识系统的边界

- **AI 原生知识系统**：提供跨知识宇宙复用的知识对象、来源、证据、关系、版本、生命周期、治理和 AI 能力路由标准。营销宇宙引用并应用这些通用标准，不复制一套冲突的底层 Schema。
- **商业模式宇宙**：研究商业模式机制、价值捕获、收入与成本结构、利润池、真实经济性和商业模式组合。营销宇宙研究市场理解、用户与需求、STP、品牌、营销组合、传播分发、销售转化和客户生命周期。定价、收入、CAC/LTV、渠道经济性等属于接口领域，应通过明确引用和关系连接，不重复维护同一机制。
- **通用链路宇宙**：提供跨领域的任务、项目、研究、执行、验证和生命周期链路。营销行动手册是这些通用链路在营销任务中的专业化装配。
- **思维与方法宇宙**：提供跨领域通用思维、研究、推理、决策和验证方法。营销宇宙记录这些方法在营销问题中的适用方式与专业约束。

## 五、适用原则

- 不假设所有业务都需要所有营销职能。
- 不把 SEO、广告、内容或社交媒体等同于营销整体。
- 不把流量、转化率或归因 ROAS 单独视为商业成功。
- 不把用户自述、相关性、案例或 AI 生成内容自动升级为事实。
- 不把 CORE 标签误解为每个具体工具都必须采用。
- 不为了追求目录规模而批量制造空节点。
- 先建立可读、可验证的专业内容，再决定是否增加机器 Schema、Skill 或 Agent Runtime。

## 六、当前成熟度

- 已建立：初始顶层架构、24 个候选知识域、横向系统、节点分级方向、研究证据原则、关系模型、行动与决策框架、建设路线。
- 尚未完成：24 个领域的独立完整性审计、领域级四/五级知识展开、系统文献与权威来源研究、方法操作手册、领域间机器可读关系、模板库和真实任务 Benchmark。
- 当前版本不得宣传为“完整营销知识库”或“已达到 95 分”。后续成熟度必须以明确验收证据为依据。

## 七、维护原则

- 本 README 是营销宇宙唯一总入口。
- 当前有效版本与加载优先级以 00_导航与总览/00_当前有效版本与加载入口.md 为准。
- 专业领域定义以营销宇宙内的领域文件为准；通用知识对象和证据治理规则以 AI 原生知识系统为准。
- 结构变化必须同步更新 MANIFEST、总入口、领域地图和受影响的交叉引用。
- 新内容优先增量更新已有节点；只有出现稳定、可解释且无法合理归入现有分类的新知识域时，才考虑增加一级分类。
