# 知识资产与 AI 协作协议

## 一、营销宇宙需要沉淀的资产

- 战略资产：市场选择、营销战略、定位、增长方向和资源取舍。
- 研究资产：市场研究、用户访谈、需求地图、竞争情报、品牌研究和渠道研究。
- 价值资产：价值主张、产品/服务价值、定价、套餐和商业化验证。
- 品牌资产：品牌平台、识别规范、品牌信息、品牌测量和声誉记录。
- 传播资产：内容地图、创意简报、媒体计划、活动和传播效果。
- 增长资产：获客模型、渠道实验、转化优化、留存和推荐机制。
- 数据资产：指标字典、数据口径、分析报告、实验结果和归因/增量研究。
- 管理资产：预算、项目计划、SOP、供应商、合规和风险记录。
- 决策资产：备选方案、决策依据、风险、结果和复盘。
- 知识资产：专业节点、方法、模型、案例、反模式、模板和检查清单。

## 二、文件与资产组织原则

- 领域专业定义放在对应领域目录。
- 跨领域规范放在横向系统目录。
- 研究来源与原始证据应可追溯，不把摘录直接当成结论。
- 项目/组织专属的营销策略和客户数据不进入通用知识地图事实源；如需保存，应放入明确的项目或受控空间，并引用通用知识节点。
- 模板、案例、研究报告、实验记录和知识定义是不同资产类型。
- 一个主题只维护一个 canonical 文件，其他位置使用引用。
- 不为尚未建设的领域批量创建空文件。

## 三、建议元数据

每个正式资产可按需要记录：

- asset_id
- title
- asset_type
- domain_refs
- node_refs
- purpose
- scope
- owner
- status
- version
- created_at
- updated_at
- reviewed_at
- valid_from
- valid_until
- source_refs
- evidence_refs
- related_assets
- supersedes
- sensitivity
- license_or_usage_rights

具体通用字段、Source/Evidence/Relation 对象应复用 AI 原生知识系统标准，不要求每个 Markdown 文件都机械包含所有字段。

## 四、生命周期状态

- DRAFT：草稿。
- RESEARCHING：研究中。
- REVIEW：待审查。
- VERIFIED：关键来源和内容已经核验，但不代表组织批准。
- APPROVED：已获得相应决策批准。
- ACTIVE：当前实际使用。
- SUPERSEDED：被新版本取代。
- ARCHIVED：停止活跃使用但保留历史价值。

内容可信状态、组织批准状态和使用状态必须分开。不能因文档已合并就自动标记 VERIFIED 或 APPROVED。

## 五、AI 任务处理协议

1. **识别任务**：区分研究、诊断、战略、规划、执行、测量、复盘和知识维护。
2. **定位知识**：匹配主要领域和关联领域，检索已有 canonical 节点。
3. **检查依赖**：识别缺少的市场、用户、产品、商业、数据或合规前置条件。
4. **确定证据需求**：区分稳定知识与动态信息；必要时进行最新来源核验。
5. **形成研究计划**：明确问题、方法、来源、样本、限制和反证。
6. **研究与分析**：保留来源、口径、时间和不确定性。
7. **形成方案**：提供备选项、适用条件、成本、收益、风险和取舍。
8. **独立审计**：检查事实、推理、因果、经济性、合规和执行可行性。
9. **生成成果**：按对应资产模板输出，不把报告、决策和 SOP 混为一份无结构文章。
10. **更新知识**：判断新内容是新增节点、补充条件、新证据、反例、版本更新还是重复内容。
11. **记录状态**：保留决策、变更、引用、验收和后续复核触发器。

## 六、AI 工作模式

- RESEARCH：研究市场、用户、竞争、需求和证据。
- STRATEGY：形成市场选择、定位、价值和增长战略。
- EXECUTION：生成任务、计划、内容简报、渠道计划和 SOP。
- ANALYTICS：分析指标、实验、归因、增量和经济性。
- AUDIT：反方审查、事实核验、风险和质量检查。
- KNOWLEDGE：知识分类、去重、关系更新、版本和资产维护。

工作模式是任务路由标签，不代表必须创建六个 Agent 或六个 Skill。

## 七、调用规则

- 先检索现有知识，再决定是否研究或新增。
- 根据问题选择最小充分上下文，不默认加载整个 24 域。
- 对动态信息记录观察时间和验证时间。
- 对营销平台政策、价格、法规、算法和工具能力等快速变化内容，使用前重新核验。
- 对高影响决策保留人工批准和责任边界。
- 不让 AI 自行发布广告、承诺价格、联系客户或处理敏感数据，除非获得明确授权且满足组织控制要求。
- 生成内容不能自动升级为事实、研究结论或已验证方法。
