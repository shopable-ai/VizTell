## 状态定义

- PROPOSED：候选结构，待审计。
- DRAFT：已有初稿，尚未完成审查或验证。
- RESEARCHING：正在研究和补证。
- REVIEW：待专业或反方审查。
- ACTIVE：通过对应验收，当前有效。
- SUPERSEDED：被新版本或新节点取代，保留历史引用。
- ARCHIVED：停止日常使用，但保留检索与来源。

## 维护纪律

1. 每个主题只保留一个 canonical 内容文件；其他文件通过链接引用。
2. 总览负责导航和结论，不复制全部专业细节。
3. 领域文件负责专业定义和方法；跨领域文件负责关系与接口。
4. 机器 Schema 只有在真实使用需求和字段稳定后才建立。
5. 新增一级领域必须说明现有分类为何无法承载、适用边界、迁移影响和维护成本。
6. 任何结构迁移必须更新本 MANIFEST 与 README。
7. 文件写入仓库不等于 VERIFIED、APPROVED 或 ACTIVE。
