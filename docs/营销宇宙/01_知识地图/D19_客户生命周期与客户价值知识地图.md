## 一、领域任务与边界

D19 负责客户购买后的价值实现、关系、体验、留存和长期客户经营，回答：

- 客户是否成功实现产品/服务价值？
- 如何改善 Onboarding、Activation 和 Adoption？
- 为什么客户留存、复购、续费或流失？
- 如何建立忠诚、会员、推荐和客户倡导？
- 如何通过客户成功和服务恢复提高长期关系质量？

## 三、生命周期阶段与决策

- Onboarding：客户是否完成初始设置和理解？
- Activation：客户是否完成能体现价值的关键行为？
- Adoption：客户是否持续使用并扩大价值？
- Retention：客户是否持续选择当前产品/服务？
- Renewal / Repurchase：客户是否再次付费或续约？
- Expansion：客户是否扩大使用、席位、品类或账户范围？
- Advocacy：客户是否主动推荐或支持品牌？
- Win-back：流失客户是否有合理的重新激活条件？

不同业务模式对活跃、留存和价值实现的定义不同，必须先定义事件和观察窗口。

## 四、标准交付物

- Customer Journey Map：客户阶段、触点、目标、摩擦和证据。
- Lifecycle Model：客户状态、进入/退出条件和行为触发。
- Onboarding / Activation Playbook：首次价值和关键行为。
- Retention / Renewal Playbook：风险、干预和复核。
- Customer Success Plan：目标、价值里程碑、健康度和协作。
- Loyalty / Referral Program：权益、激励、成本和治理。
- Churn / Recovery Report：流失原因、补救和挽回。
- Lifecycle Measurement Plan：队列、留存、续费和增量指标。

## 五、质量门槛与常见反例

- 明确活跃、激活、留存、流失、复购和续费的定义；
- 按业务模式和客户群体选择观察窗口；
- 区分满意度、自述忠诚和实际留存行为；
- 客户触达有授权、频控、退订和隐私保护；
- 客户成功必须围绕客户价值，而不是只围绕续费销售；
- 不用折扣掩盖产品价值和服务问题；
- 不把相关性当作留存干预的因果效果；
- 客户挽回必须考虑客户体验、公平和长期成本。
