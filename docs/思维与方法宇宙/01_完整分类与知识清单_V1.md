# 思维模式、思维模型、方法与认知工具宇宙 V1｜完整分类与知识清单

> 本文件保存 V1 的完整分类与具体知识条目。
> 顶层总览、主分类总表和压缩版全景清单见：`00_总览与分类地图_V1.md`。
> 本文件采用“现实任务 / 认知功能 → 方法族 → 具体模型、方法、原则、工具或认知风险知识”的组织逻辑；每项知识只保留一个主要归属。
> “思维模型”“思考框架”“方法”“工具”“理论 / 原理”“效应 / 偏差 / 谬误”不是同义词，但不作为彼此割裂的主目录；本宇宙以现实任务为主分类，以知识类型作为次级属性理解和检索。

## 01 元认知、思维监控与校准

解决的问题：

> 怎样观察、控制和校准自己的思考过程，知道何时应继续、切换、怀疑或修正。

- 原则性怀疑 / 方法论怀疑（Methodic Doubt）
- 认识论谦逊（Epistemic Humility）
