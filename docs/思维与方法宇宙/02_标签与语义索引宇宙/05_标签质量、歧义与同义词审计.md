# 标签、自然语言入口与语义索引宇宙 V1｜标签质量、歧义与同义词审计

> 本文件防止三个最危险的问题：
>
> 1. 把相关词当同义词；
> 2. 把平台包装词当正式概念；
> 3. 为了“映射完整”而把不存在的等价关系硬造出来。

---

# 1. 关系判断顺序

两个词看起来相似时，按以下顺序检查：

```text
是否所有主要语境都能互换？
├─ 是 → exact_synonym 候选
└─ 否
   ↓
是否一个只是另一个写法 / 简称？
├─ 是 → alias_or_variant
└─ 否
   ↓
是否存在明确上下位？
├─ 是 → broader / narrower
└─ 否
   ↓
是否部分语义重叠？
├─ 是 → overlaps / near_synonym
└─ 否
   ↓
是否只是经常一起出现？
└─ 是 → related / co-occurs，绝不标同义
```

默认政策：**宁愿少标 exact synonym，也不要为了提高召回而破坏语义精度。**

# 3. 高歧义核心词审计

## 3.1 认知

`认知` 至少可能指：

- 心理学中的认知过程；
- 对一个领域的知识 / 理解；
- 判断水平；
- 思维方式；
- 信息差；
- 商业经验；
- 平台语境中的“懂得更多人生道理”。

所以：

```text
“提高认知”
≠ 自动推荐某个“认知模型”
```

必须结合对象：提高哪方面的判断？

## 3.2 人性

`人性` 可能指：

- 社会判断偏差；
- 动机；
- 利益和激励；
- 关系规则；
- 合作 / 竞争；
- 道德哲学；
- 情绪和行为；
- 纯经验性人物评价。

因此“人性”只适合作为主题，不是一个统一正式知识实体。

## 3.3 格局

可能被用来表达：

- 时间尺度更长；
- 系统边界更大；
- 能考虑更多利益相关者；
- 战略层级更高；
- 情绪不计较；
- 财富 / 地位的价值评价。

知识精度极低，只进传播词，拆解后再映射。

## 3.4 破局

可能是：

- 重新定义问题；
- 找瓶颈；
- 改变约束；
- 找系统杠杆点；
- 谈判；
- 改变博弈结构；
- 战略转型。

“破局”本身不能决定方法。

## 3.5 安全感

可能来自：

- 关系稳定性；
- 经济 / 环境风险；
- 自我效能；
- 可预测性；
- 依恋 / 心理健康专业语境。

因此本系统只把它作为用户状态 / 目标入口，不自行做心理学诊断或原因归纳。

## 3.6 能量

“能量高 / 低”可能只是：

- 精力；
- 情绪状态；
- 社交感受；
- 兴奋度；
- 身份评价；
- 神秘主义因果主张。

若只是比喻，可以映射到疲惫 / 动机 / 情绪等自然语言；若宣称不可见物理能量、磁场直接决定财富 / 人际，应进入证据审查，而不是正式心理知识。

## 3.7 磁场

日常“气场 / 磁场合不合”可视作比喻性传播语言；若将物理磁场作为人格吸引、命运或财富的无证据因果解释，标记 F 类疑似伪概念。

# 4. 包装词去重簇

以下采用“一个传播簇 + 多个保留入口”，而不是把所有词硬合成一个词。

## 4.1 强者簇

```text
强者思维（首要传播入口）
├─ 强者认知
├─ 强者心态
├─ 强者逻辑
├─ 强大自己
└─ 内心强大
```

共享：身份提升 / 自我强化。  
差异：思维、认知、心态、状态和目标并不完全相同。

## 4.2 认知升级簇

```text
提高认知（稳定目标）
├─ 认知提升（语序变体）
├─ 认知升级（传播）
├─ 认知跃迁（传播）
├─ 认知突破（传播）
├─ 认知破局（传播）
└─ 认知觉醒（传播，强调“意识到”）
```

规范路由优先指向 `提高认知`，但传播词继续保存，便于搜索真实内容。

## 4.3 清醒 / 真相簇

```text
人间清醒
├─ 清醒认知
├─ 现实清醒
├─ 大实话
├─ 扎心真相
├─ 社会真相
└─ 人性真相
```

这些词共享“揭露 / 看清”修辞，但实际主题差别巨大，不能合成一个规范语义标签。

## 4.4 自我稳定簇

```text
内核稳定（复合核心目标）
├─ 稳定内核（写法变体）
├─ 内心强大（近义传播）
├─ 情绪稳定（部分重叠）
├─ 松弛感（相关状态）
├─ 主体性（相关能力 / 身份）
├─ 自洽（相关状态）
└─ 心理韧性（相关但不同）
```

## 4.5 自我关系簇

```text
爱自己（大众上位入口）
├─ 自我接纳
├─ 自我关怀 / 自我慈悲
├─ 停止自我攻击
├─ 自我价值
├─ 人际边界
└─ 照顾自己的需求
```

这些不是 exact synonym，应作为一组相关语义。

## 4.6 社会关系簇

```text
人情世故
├─ 为人处事
├─ 处世之道
├─ 分寸感
├─ 识人术
├─ 潜规则
└─ 人际关系
```

其中“潜规则”是非正式规范，“识人术”是判断目标，“分寸感”是关系行为标准，不能合并成一个概念。

# 5. 疑似伪概念 / 不稳定概念审计

> F 级不是一句“都是假的”。它表示：**名称暗示了稳定知识或因果规律，但当前不能仅凭名称确认有稳定定义、证据或与上游正式知识的明确对应。**

| 候选 | 风险 | 处理 |
|---|---|---|
| 顶级认知 | 无可检验边界，几乎任何内容都能装入 | E，不升格 |
| 高维认知 / 高维思维 | 借“维度”制造专业感，但通常不说明维度是什么 | E；若明确指层级 / 多视角再映射 |
| 宇宙法则 | 暗示普遍规律却常缺定义和证据 | F；具体主张逐条核验 |
| 量子思维 | 容易借量子物理词汇装饰心理 / 成长内容 | F；除非明确讨论真实量子理论 |
| 高能量人格 | “能量”含义不清，可能把比喻物理化 | E/F |
| 磁场决定人际 / 财富 | 缺少明确机制与证据时属于无根据因果化 | F |
| 吸引力法则 | 若主张仅凭思想“吸引”外部事件，需严格证据审查 | F，不作为正式规律 |
| 富人思维 / 穷人思维 | 把复杂财富结果本质化到群体思维，易幸存者 / 归因偏差和刻板化 | D/E，仅作传播审查 |
| 阶层跃迁秘籍 | 把复杂社会流动包装成单一秘诀 | E/F，需证据 / 情境 |
| 看一眼就能识人 | 过度承诺社会判断准确性 | E/F，需防基本归因错误与伪科学线索 |

# 6. 保留、合并、降级、排除规则

## 6.1 保留为核心规范标签

满足长期、稳定、有检索价值，例如：

- 自我接纳；
- 拖延；
- 选择困难；
- 情绪稳定；
- 内核稳定；
- 职场；
- 创业者；
- 自我效能；
- 长期主义。

其中“内核稳定 / 长期主义”虽然不是单一正式理论，但作为稳定用户目标 / 身份入口有价值。

## 6.2 合并为别名 / 写法变体

只有语义高度稳定时：

- 提高认知 ← 认知提升；
- 内核稳定 ← 稳定内核；
- 贝叶斯更新 ← Bayesian Updating（英文别名）；
- 金字塔原理 ← Minto Pyramid Principle（英文名称）。

## 6.3 保留为近义，不合并

- 爱自己 ↔ 自我接纳；
- 自我接纳 ↔ 自我关怀；
- 情绪稳定 ↔ 内核稳定；
- 主体性 ↔ 独立思考；
- 强者思维 ↔ 强者心态；
- 复盘 ↔ 反思。

## 6.4 降级到传播词

- 顶级认知；
- 高维思维；
- 社会真相；
- 人性真相；
- 强者认知；
- 认知觉醒。

## 6.5 进入动态词而不是稳定库

- 某一天热门梗；
- 某事件专属热词；
- 一次性标题变体；
- “2026 必看十大……”式时间包装。

## 6.6 排除

与本宇宙没有稳定关系的：

- 人名；
- 品牌；
- 手机型号；
- 普通软件命令；
- 任意编程语言关键词；
- 任意热点实体。

它们可以存在于外部搜索系统，但不进入本标签本体。

# 7. 上游正式知识缺口审计

标签层不能悄悄修复上游。以下只作为下一阶段候选：

| 候选缺口 | 标签层证据 | 当前处理 |
|---|---|---|
| 自我接纳 | `自我接纳 / 接受自己 / 爱自己` 是稳定入口 | 保留核心标签，标 GAP，不硬映射 |
| 自我关怀 / 自我慈悲 | `爱自己 / 停止自我攻击` 需要更精确概念 | 标 GAP |
| 情绪调节知识族 | `情绪稳定 / 情绪管理 / 被情绪影响` 高频 | 先路由 ABC、认知重构、自我监控，标不完整 |
| 人际边界设定 | `边界感 / 不会拒绝 / 被越界` 高频 | 路由 DESC、困难对话、NVC、谈判；禁止用系统边界替代 |
| 主体性 / agency | `主体性 / 做自己 / 拿回主动权` 高频 | 路由价值澄清、SDT、自我效能，标 GAP |
| 情绪智力 | `高情商` 是稳定用户目标 | 路由倾听、观点采择、沟通，标 GAP |
| 个人心理韧性 | `内核稳定 / 内心强大 / 韧性` 高频 | 禁止直接把工程“韧性”当心理韧性 |

下一阶段若要修上游，必须重新按上游正式知识实体的证据、边界和去重标准审查。

# 8. 反方审查：假设 V1 标签体系是错的

## 8.1 是否把主题和问题混在一起？

发现风险：`人性 / 职场 / 心理` 是主题，而 `拖延 / 不会拒绝` 是问题。

修复：采用双轴分面；主题、问题、场景分别编码。

## 8.2 是否把用户语言和专业语言混在一起？

发现风险：`精神内耗` 容易被写成专业诊断名。

修复：表达层 E3 / E5 与正式知识 E1 分离；用户语言可有高检索价值但不自动专业化。

## 8.3 是否把流量词当正式理论？

发现风险：`强者思维 / 顶级认知 / 社会真相` 名称很像知识实体。

修复：D/E 传播层 + `needs_disambiguation`。

## 8.4 是否分类过细？

发现风险：如果每一种标题写法都新建标签，词典会无限扩张。

修复：写法变体进入 `platform_variants / alias`；只有稳定新语义才新建 ID。

## 8.5 是否产生大量无法连接知识的标签？

发现风险：`格局 / 能量 / 磁场` 等可能没有明确知识目标。

修复：允许“高传播、低语义精度”和“排除 / 待审查”，不强行映射。

## 8.6 是否遗漏普通人真正会说的话？

发现风险：只从 1018 个正式知识反推会产生“术语的术语”。

修复：单独建设 `03` 自然语言地图，并使用公开视频标题 / 标签校准。

## 8.7 是否只从现有知识反推？

修复：V1 纳入公开抖音 / Bilibili 可索引样本，发现 `内核稳定、松弛感、边界感、人间清醒、强者思维、认知觉醒` 等真实入口。

## 8.8 是否因为追求专业性删除高价值大众表达？

修复：`强者思维 / 人间清醒 / 底层逻辑` 不删除，而是降到传播入口层。

## 8.9 是否因为追求流量污染正式知识？

修复：传播层与上游正式知识物理分离；映射只用关系，不改正式实体名称。

## 8.10 是否支持多对多？

修复：一个标签允许映射多个任务、问题、场景和知识；一个正式知识也保留多个语言入口。

# 9. 审计结论

V1 最重要的治理规则不是“找到更多标签”，而是：

> **允许真实世界的语言保持模糊，同时不让这种模糊进入正式知识本体。**

因此系统应保留三种答案：

1. **可以直接映射；**
2. **需要结合上下文拆解；**
3. **当前无法可靠映射 / 应排除。**

第三种答案是高质量语义系统必须拥有的能力，而不是失败。
