## 1. 入口画像代码

字段：

- `N`：直接正式名称入口；
- `T`：已有规范标签 / 稳定别名入口；
- `Q`：已有用户问题入口；
- `G`：已有目标入口；
- `S`：已有场景入口；
- `R`：已有搜索问题句 / 搜索语言入口；
- `D`：已有大众表达；
- `P`：已有传播 / 平台语言入口。

| D1 | Y | N | N | N | N | N | N | N | 1 | 极低 | 低 | D 名称依赖 |

说明：

1. 画像描述**当前入口层**，不是知识价值评分；
2. `C/D` 不代表知识不重要，只表示普通用户不知道名称时较难发现；
3. 同一知识若有高度大众化但语义漂移明显的入口，仍可能从 A 降为 B；
4. `P=Y` 只代表存在传播语言，不代表传播词与正式知识严格同义；
5. 本轮对专业长尾采用保守判定：没有可靠实体级问题句时，不为提高覆盖率虚构 `Q/G/D/P`。

# 30. 逐项审计后的覆盖结论

## 30.1 A 级最集中区域

自然语言入口最丰富的正式知识明显集中于：

- 认知偏差与常见逻辑错误；
- 证据核查；
- 根因分析；
- 常见决策工具；
- 执行与时间管理；
- 学习与记忆；
- 行为改变；
- 沟通表达；
- 常见商业分析；
- 高频系统思维与风险工具。

这些知识往往同时具有：正式名称、大众别名、明确问题句、目标句、工作 / 生活场景和搜索句。

## 30.2 C 级最集中区域

C 级主要集中于：

- 高级因果识别；
- 高级统计模型；
- 运筹优化；
- 专业安全工程；
- 专业系统建模；
- 文献计量细分方法；
- 前瞻研究长尾方法。

它们通常有“方法族任务入口”，但缺少实体级口语入口。

## 30.3 D 级并不需要清零

本轮仍明确保留少量 D1，例如：

- 禁忌搜索；
- GSN 等极专业条目。

只要用户没有真实检索失败、真实场景或稳定搜索表达，就不应为了指标把每个专业名词强行配上虚构的“普通人都会这样问”。

## 30.4 最大新增缺口不是标签数量，而是实体级可发现性

V1 已经做到：

> 28 类都能通过自然语言进入。

V1.1 逐项审计进一步发现：

> 同一个一级类内部，A 与 C/D 的实体可发现性差距非常大。

因此后续新增入口的顺序应为：

```text
真实用户检索失败
→ 找到对应 C/D 正式知识
→ 补真实问题 / 场景 / 搜索句
→ 重新审计歧义
→ C→B 或 B→A
```

而不是平均给所有知识制造同样数量的标签。
