# 标签、自然语言入口与语义索引宇宙 V1｜标签到正式知识映射

> 本文件负责把规范标签、用户问题和传播入口连接到上游 `01_完整分类与知识清单_V1.md` 的 28 类正式知识。
>
> **映射不是等价。**“拖延 → COM-B”表示 COM-B 是可用于诊断拖延行为条件的知识入口，不表示“拖延就是 COM-B”；“强者思维 → 自我效能”也不表示两者同义。

---

## 1. 映射类型

| 代码 | 名称 | 含义 | 例子 |
|---|---|---|---|
| DIRECT | 直接对齐 | 标签就是正式知识名称或非常稳定的名称变体 | 贝叶斯思维 → 贝叶斯定理 / 贝叶斯更新 |
| ROUTE | 问题路由 | 该知识能帮助分析或处理这个问题 / 目标 | 拖延 → COM-B、实施意图 |
| CONTEXT | 场景路由 | 只有结合具体场景才适用 | 职场被否定 → SBI / 困难对话 / 认知重构 |
| DISAMBIG | 必须消歧 | 标签太宽或包装性强，不能直接给单一知识 | 强者思维、社会真相、提高认知 |
| GAP | 上游候选缺口 | 高价值入口存在成熟或稳定语义，但当前上游没有完全对应条目 | 自我接纳、人际边界、主体性 |

推荐系统排序原则：

```text
DIRECT > 高相关 ROUTE > CONTEXT > DISAMBIG 拆解后的候选
```

`GAP` 不能被邻近条目伪装成“已经正式覆盖”。

# 5. 典型“一个标签 → 多知识”示范

## 5.1 强者思维

```text
强者思维
├─ 想更相信自己能做到 → 自我效能
├─ 想把失败当学习 → 成长型思维 / 错误驱动学习
├─ 想少受别人观点影响 → 反证搜索 / 认识论谦逊 / 从众效应检查
├─ 想更敢行动 → 实施意图 / COM-B / 行动计划
├─ 想做长期选择 → 二阶思维 / 现在偏差检查 / 战略选择
├─ 想守住边界 → DESC / 困难对话 / 原则式谈判（并标记人际边界知识缺口）
└─ 想“看懂博弈” → 报酬矩阵 / 重复博弈 / 信号 / 委托—代理
```

**结论**：它有很高入口价值，但不应该成为一个正式知识实体。

## 5.2 精神内耗

```text
精神内耗
├─ 反复回想 / 想不停 → 元认知监控 / 停止规则 / 认知重构
├─ 两个价值目标冲突 → 价值澄清 / 价值树 / 多准则决策
├─ 一直纠结选哪个 → 决策矩阵 / 满意化 / 信息价值
├─ 想太多不行动 → 实施意图 / 行动计划 / 时间盒
├─ 因外界评价反复否定自己 → 自我效能 / 认知重构 / 价值澄清
└─ 因关系冲突持续消耗 → 困难对话 / DESC / 原则式谈判
```

**结论**：标签应该触发“问题分型”，而不是触发一个万能疗法。

## 5.3 内核稳定

```text
内核稳定
├─ 知道自己重视什么 → 价值澄清
├─ 自主做决定 → 自我决定理论 / 决策结构化
├─ 相信自己能行动 → 自我效能
├─ 不被一次评价定义 → 元认知 / 认知重构
├─ 接受不确定性 → 不确定性显式化 / 概率思维
└─ 行动与价值一致 → 目标—指标—行动链 / 实施意图
```

**结论**：它更适合作为“复合目标标签”。

## 5.4 提高执行力

```text
提高执行力
├─ 目标不清 → SMART / 目标分解
├─ 不知从哪开始 → WBS / 任务分解
├─ 任务太多 → 优先级 / WIP Limit
├─ 没动机 → COM-B / 自我决定理论
├─ 环境总干扰 → 环境重构 / 刺激控制
├─ 想做但忘 → 实施意图 / 提示线索
├─ 开始后中断 → 应对计划 / 进度监控
└─ 不知道做到什么算结束 → 完成定义
```

| 非暴力沟通 | 怎么表达感受需求又不攻击、关系冲突怎么说 |

# 7. 上游知识缺口候选

本轮不修改上游 `01`，但标签映射揭示以下值得独立审计的候选缺口：

| 候选 | 为什么出现 | 当前临时路由 | 为什么不能硬等同 |
|---|---|---|---|
| 自我接纳（Self-Acceptance） | 用户语言和心理学概念都稳定 | 价值澄清、SDT、自我效能、认知重构 | 这些概念只覆盖部分机制 |
| 自我关怀 / 自我慈悲（Self-Compassion） | “爱自己 / 少自我攻击”高频 | 价值澄清、SDT | 上游无直接正式条目 |
| 情绪调节（Emotion Regulation）完整知识族 | “情绪稳定 / 情绪管理”高频 | ABC、认知重构、自我监控 | 目前只是局部干预，不等于完整情绪调节理论 |
| 人际边界设定（Interpersonal Boundary Setting） | “边界感 / 不会拒绝 / 被越界”高频 | DESC、困难对话、NVC、谈判 | `系统边界设定` 是不同概念，不能冒用 |
| 主体性 / 个人能动性（Agency） | “主体性 / 做自己 / 拿回主动权”高频 | 价值澄清、SDT、自我效能、决策 | 邻近但不完全覆盖 |
| 情绪智力（Emotional Intelligence） | “高情商”长期高价值入口 | 积极倾听、观点采择、NVC、冲突沟通 | 沟通技巧不等于完整 EI 构念 |
| 个人心理韧性（Psychological Resilience） | “内核稳定 / 逆境恢复”高频 | 自我效能、成长型思维、反馈学习 | 上游“韧性工程”是系统工程概念，不能直接挪用 |

这些只进入“候选缺口”，下一轮应按上游收录标准独立核验。

1. **先匹配 DIRECT，再匹配 ROUTE。**
2. 包装词必须先做语义拆解，不能用热词本身决定答案。
3. 同一标签允许映射多个类，但要根据问题、目标、场景重新排序。
4. 心理状态只作为用户语言入口，不自行诊断。
5. `GAP` 必须显式呈现，不能用最相邻知识冒充完全覆盖。
6. 对商业、投资、医疗、法律等高风险具体决策，标签路由只能帮助找到思考方法，不代替专业事实核查和专业意见。
7. 新增映射必须能说明“为什么相关”，不能只因为两个词常在平台标题一起出现。
