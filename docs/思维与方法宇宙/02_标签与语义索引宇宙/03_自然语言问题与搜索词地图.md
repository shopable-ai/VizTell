# 标签、自然语言入口与语义索引宇宙 V1｜自然语言问题与搜索词地图

> 本文件保存“普通人真正会怎么说”。
>
> 目标不是把每一句话机械匹配一个知识，而是完成：
>
> ```text
> 用户原话
> → 识别问题 / 目标 / 状态 / 场景
> → 规范标签
> → 候选正式知识类
> → 必要时二次消歧
> ```

---

# 1. 使用规则

同一句话可能同时包含多个信号。例如：

> “我每天想很多计划，但最后就是不开始。”

至少包含：

- 问题：过度分析、执行启动困难；
- 目标：提高执行力；
- 任务：计划、行动；
- 候选知识：停止规则、满意化、实施意图、行动计划、COM-B、时间盒。

因此以下表格里的“知识类”表示首选路由，不表示唯一答案。

# 18. 高频标签的搜索扩展示范

## 18.1 自我接纳

**标准词**：自我接纳  
**常见表达**：接受自己、接纳自己、接纳不完美的自己  
**相关但非同义**：爱自己、自我关怀、自我慈悲、自尊、自我效能  
**问题句**：

- 为什么我总是否定自己；
- 怎么停止自我攻击；
- 怎么接受自己的缺点；
- 怎么不再因为不完美讨厌自己。

**英文检索**：self-acceptance。`self-compassion` 只作相关词，不当同义词。

## 18.2 精神内耗

**标准词**：精神内耗  
**变体**：内耗、反复纠结、脑内打架、想太多  
**相关但非同义**：反刍思考、自我怀疑、决策停滞、完美主义式卡住、评价压力  
**问题句**：

- 为什么我总在脑子里反复演练；
- 怎么停止想太多；
- 为什么我知道没必要还一直纠结；
- 内耗和拖延有什么关系。

## 18.3 内核稳定

**标准词**：内核稳定  
**变体**：内在稳定、稳定内核、内心稳定  
**相关**：主体性、自我效能、情绪稳定、自洽、价值稳定、心理韧性、边界感  
**传播变体**：真正的强者都有稳定内核、强大内核  
**问题句**：

- 怎么不被别人评价影响；
- 怎么建立自己的价值标准；
- 为什么别人一句话就能让我动摇；

# 19. 八个真实入口完整路由

## 19.1 “我不知道自己想要什么。”

```text
表达层：用户自然语言
问题：目标模糊 / 价值不清
规范标签：目标澄清、价值澄清、方向迷茫
首选知识：价值澄清、价值聚焦思维、目标层级 / 手段—目的链
必要追问：这是人生方向、职业选择、项目目标还是近期任务？
```

## 19.2 “我最近一直很内耗。”

```text
表达层：用户问题语言
规范标签：精神内耗
需要分型：反复思考 / 决策冲突 / 完美主义 / 评价压力 / 拖延 / 关系冲突
候选知识：元认知监控、停止规则、价值澄清、决策平衡表、认知重构、实施意图
边界：不根据一句“内耗”自行诊断心理疾病
```

## 19.3 “我想变成一个内核稳定的人。”

```text
表达层：身份愿望 + 用户目标
规范标签：内核稳定
拆解：价值稳定、自主性、自我效能、情绪恢复、不被评价轻易摇动
候选知识：价值澄清、自我决定理论、自我效能、元认知、认知重构
状态：复合大众目标，不是单一正式理论
```

## 19.4 “强者思维。”

```text
表达层：平台传播语言
等级：D，高传播、低到中等知识精度
处理：禁止直接当理论
消歧：想提高自信 / 判断 / 执行 / 边界 / 长期选择 / 博弈中的哪一种？
候选知识：自我效能、成长型思维、反证搜索、实施意图、二阶思维、谈判 / 博弈工具
```

## 19.5 “社会真相。”

```text
表达层：平台传播语言
等级：E，高歧义包装词
处理：要求具体主张、场景、证据
可能主题：社会激励、组织规则、人际关系、商业竞争、权力 / 治理
```

# 20. 语言采集与新增原则

新增真实语言时保存原话，但**不要把每一句原话都升级成规范标签**。

```text
大量原话
→ 聚类
→ 提取稳定问题 / 目标 / 场景
→ 与已有规范标签比对
→ 新增别名 / 近义 / 新标签
→ 映射知识
```

一个新表达如果只是“强者思维 2.0”“顶配认知”“天花板认知”这类标题变体，优先进入传播词 / 动态词，不新增核心标签 ID。
