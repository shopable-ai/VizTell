## 1. 一句话结论

现有知识宇宙回答：

> **有什么正式知识可以用？**

本目录回答：

> **当用户并不知道正式名称，只会说“我很内耗”“想变得内核稳定”“强者思维”“怎么提高认知”时，系统怎样理解他真正的问题，并把他带到相关正式知识？**

因此两层关系是：

```text
自然语言 / 搜索词 / 平台标签
            ↓
      规范语义标签
            ↓
  问题 / 目标 / 状态 / 场景
            ↓
      一个或多个知识任务
            ↓
   一个或多个正式知识实体
```

正式知识仍遵守上游“一项知识一个主要归属”；**入口标签必须允许多对多映射**。

## 2. 四类对象严格分离

| 层 | 对象 | 示例 | 是否直接进入正式知识清单 |
|---|---|---|---|
| K：正式知识实体 | 有相对稳定名称、结构和专业含义的知识对象 | 贝叶斯更新、六顶思考帽、COM-B、金字塔原理 | 是，由上游 `01` 维护 |
| T：规范语义标签 | 为检索、路由和关系建模而规范化的语义入口 | 自我调节、执行困难、情绪调节、信息过载 | 否，进入本目录 |
| U：用户自然语言 | 用户真实描述问题、目标、状态的句子或短语 | “我总是想很多但不行动” | 否，作为入口表达 |
| P：传播 / 平台语言 | 标题、话题、标签、注意力包装词 | 强者思维、顶级认知、人性真相 | 否，单独治理 |

禁止跨层误升格：

- `强者思维` 可以很有检索价值，但不能因此成为一个“正式心理学理论”；
- `精神内耗` 可以稳定表达真实体验，但不是因为流行就自动获得专业诊断地位；
- `贝叶斯思维` 既可以是搜索入口，也能直接对齐上游的贝叶斯定理 / 贝叶斯更新；
- `职场` 是场景，不是一个方法；
- `创业者` 是角色，不是知识实体。

## 3. 对三套分类方案的比较

### 方案 A：按“词从哪里来”分类

分类：专业术语 / 大众概念 / 用户口语 / 平台流行词。

优点：非常容易判断来源和专业性。

缺点：无法回答“这个词是在表达问题、目标、状态还是场景”。例如“情绪稳定”既可能是目标，也可能是状态描述。

**不单独采用。**

### 方案 B：按“用户语义功能”分类

分类：任务 / 问题 / 目标 / 状态 / 主题 / 场景 / 角色 / 身份价值 / 知识类型 / 查询意图。

优点：最适合搜索、推荐和知识路由。

缺点：不能区分“自我接纳”和“顶级认知”在专业稳定性、传播来源上的巨大差异。

**不单独采用。**

### 方案 C：双轴分面体系（V1 采用）

每个入口同时记录：

1. **表达层 E：它以什么语言形态出现；**
2. **语义分面 F：它在表达什么；**
3. 再附加质量、稳定性、时间性和映射关系。

这样可以同时表达：

```text
“强者思维”
E = 平台传播语言
F = 身份愿望 + 目标 + 宽泛主题
质量 = E 高歧义包装词
知识映射 = 多对多，必须二次消歧
```

和：

```text
“拖延”
E = 稳定大众 / 用户问题语言
F = 用户问题
质量 = B/C
知识映射 = COM-B、实施意图、时间盒、承诺装置、自我监控……
```

这比强行把所有词塞进一棵树更稳定。

## 4. 表达层（E 轴）

| 代码 | 表达层 | 含义 | 例子 |
|---|---|---|---|
| E1 | 正式知识名称 | 能直接对齐上游知识实体 | 第一性原理、贝叶斯更新、金字塔原理 |
| E2 | 规范语义标签 | 为检索人工选择的标准入口词 | 执行困难、自我调节、决策停滞 |
| E3 | 用户自然语言 | 真实问题句、口语、目标句 | “为什么我总是拖到最后才做” |
| E4 | 搜索语言 | 为搜索而压缩或改写的查询 | 如何提高执行力、怎么停止内耗 |
| E5 | 传播 / 平台语言 | 标题、话题、内容标签和包装词 | 强者思维、人间清醒、顶级认知 |
| E6 | 动态热点语言 | 有明显时间窗口、事件依赖 | 某日新闻热词、阶段性梗 |

E1—E5 可互相映射；E6 原则上不进入长期核心词典，只保留动态索引。

## 5. 语义分面（F 轴）

### F01 认知与现实任务

用户当前要做什么：分析、判断、决策、学习、表达、计划、执行、复盘、创新、谈判、预测、验证等。

### F02 用户问题 / 困难

用户哪里卡住：拖延、反复纠结、选择困难、注意力分散、表达混乱、不敢拒绝、不会复盘等。

### F03 用户目标 / 期望结果

用户希望变成什么状态：提高执行力、增强自信、提高判断力、情绪更稳定、学习更高效等。

### F04 心理与主观状态

用户此刻的体验：焦虑、迷茫、自我怀疑、疲惫、压迫感、愤怒、羞耻、后悔、卡住、平静等。

> 本分面只是自然语言与检索入口，不承担临床诊断；持续、严重或具有医学意义的状态不应被一个标签系统自行诊断。

### F05 主题 / 领域

内容主要在谈什么：自我成长、认知、人际、职场、商业、学习、管理、财富、社会、研究、数据等。

### F06 场景 / 情境

问题发生在哪里：会议、汇报、职场反馈、求职、创业、亲密关系、家庭、考试、投资决策、内容创作等。

### F07 人群 / 角色

谁在遇到问题：学生、职场新人、管理者、创业者、研究者、内容创作者等。

### F08 身份、价值与自我叙事

用户希望如何定义自己：做真实的自己、成为长期主义者、成为独立思考者、拥有稳定内核等。

### F09 知识形态

用户在找哪种知识对象：模型、框架、方法、原则、工具、偏差、谬误、理论、检查表、图、流程等。

### F10 查询与检索意图

用户在搜索中要什么：定义、原因、方法、对比、案例、清单、步骤、证据、适用场景、反例等。

### F11 传播包装

词的主要功能是否是吸引注意力、身份动员或制造“洞察感”：强者思维、认知觉醒、社会真相、顶级思维等。

### F12 时间性 / 平台性

稳定长期词、阶段性流行词、事件热词、平台特有写法分别标记，不混入永久本体。

## 6. 为什么不是“一级分类树”，而是分面标签

真实入口经常同时属于多个维度：

- `情绪稳定`：既是目标，也可能是状态；
- `职场被领导否定`：场景 + 事件 + 自我评价问题；
- `创业者`：角色；
- `提高认知`：宽泛目标；
- `强者思维`：传播包装 + 身份愿望 + 多主题入口；
- `第一性原理`：可以直接对齐正式知识实体。

如果强制“一词一类”，会丢失大量检索信息。因此 V1 允许：

> **一个标签有一个主要分面，同时拥有多个次级分面。**

## 7. 关系模型

V1 至少维护以下关系：

| 关系 | 含义 | 示例 |
|---|---|---|
| `preferred_label` | 规范展示名 | 精神内耗 → 精神内耗 |
| `exact_synonym` | 可安全互换的同义表达 | 仅在可全局互换时使用 |
| `alias_or_variant` | 别名、简称、写法变体 | 贝叶斯思维 → Bayesian thinking |
| `near_synonym` | 近义但不可完全替换 | 自我接纳 ↔ 爱自己 |
| `broader` / `narrower` | 上下位 | 人际关系 → 职场人际 |
| `related` | 相关但非上下位 | 拖延 ↔ 自我调节 |
| `overlaps` | 部分重叠 | 情绪稳定 ↔ 情绪管理 |
| `contrast` | 对照 / 相反 | 发散 ↔ 收敛 |
| `expresses_problem` | 表达某类问题 | “总想很多不行动” → 执行启动困难 |
| `expresses_goal` | 表达目标 | “想变得更自信” → 增强自我效能 |
| `occurs_in_scene` | 场景关系 | 不敢发言 → 会议 / 公开表达 |
| `maps_to_knowledge` | 指向正式知识 | 拖延 → 实施意图 |
| `packaging_of` | 包装词拆解到较稳定语义 | 底层逻辑 → 第一性原理 / 机制解释 / 因果分析 |
| `needs_disambiguation` | 进入知识前必须追问或结合上下文 | 强者思维、社会真相 |
| `temporal_variant` | 阶段性平台变体 | 当期流行写法 → 稳定标签 |

关系设计参考了知识组织系统常见的“首选词 / 替代词 / 上下位 / 相关”思路；实现上可兼容 SKOS 的 `prefLabel / altLabel / broader / narrower / related`，但本仓库先保持人工可读 Markdown，不要求立即 RDF 化。

## 8. 标签质量等级

质量等级衡量**语义和专业稳定性**，不衡量流量价值。

| 等级 | 名称 | 判断标准 | 例子 |
|---|---|---|---|
| A | 正式稳定 | 有明确专业定义，可直接对齐知识或成熟构念 | 贝叶斯更新、成长型思维 |
| B | 稳定大众概念 | 大众长期使用，语义相对稳定，但不一定是独立理论 | 自我接纳、时间管理 |
| C | 高价值用户语言 | 问题 / 目标 / 场景表达稳定，检索价值高 | 拖延、选择困难、不敢拒绝 |
| D | 平台传播词 | 有较高发现价值，专业精度有限 | 强者思维、认知觉醒 |
| E | 高歧义包装词 | 可以装入大量不相干内容，必须二次拆解 | 顶级认知、高维思维、社会真相 |
| F | 疑似伪概念 / 重新包装 | 暗示独立理论但缺稳定定义或证据，需要审查 | “某某宇宙定律”式自造概念 |

重要原则：

> D / E 标签完全可能比 A 标签更值得做搜索入口；但它们不能因此被提升为正式知识理论。

## 10. 查询路由规则

### 规则 1：先判断表达类型，不直接猜方法

用户说“内耗”，先判断它是在描述：

- 反复思考；
- 决策冲突；
- 完美主义式反复检查；
- 社会评价压力；
- 任务拖延；
- 关系矛盾；
- 普通情绪困扰；
- 还是更严重、超出本知识库边界的心理健康问题。

不同含义应进入不同知识。

### 规则 2：能直接对齐正式知识时，不绕远路

```text
“贝叶斯思维”
→ 贝叶斯定理 / 贝叶斯更新 / 基准率 / 似然比
```

### 规则 3：包装词先拆意图，再推荐

```text
“强者思维”
→ 是想要更自信？
→ 更敢行动？
→ 更会做长期选择？
→ 更懂人际博弈？
→ 更有边界？
→ 更会判断信息？
```

不要一次把所有“强者”相关内容都塞给用户。

### 规则 4：问题 + 目标 + 场景联合消歧

```text
问题：总是犹豫
目标：更快做决定
场景：工作中方案二选一
```

比单独搜索“犹豫”能更准确路由到决策结构化、信息价值、满意化、时间盒等知识。

### 规则 5：不得把心理状态标签当临床诊断

`焦虑 / 抑郁情绪 / 高敏感 / 内耗` 等在本层首先只是用户语言。标签系统不能因为一句话自行诊断疾病。

## 11. 核心标签进入标准

一个候选词至少满足以下一项才进入稳定主词典：

- 能明显提高正式知识检索召回；
- 能明显提高用户问题理解；
- 能帮助知识推荐或路由；
- 在真实自然语言中稳定出现；
- 能连接多个正式知识且具有重要入口价值；
- 对公开内容 / 创作者研究具有稳定主题价值。

以下对象默认不进入：

- 任意品牌；
- 任意人物姓名；
- 任意商品型号；
- 单一软件命令；
- 每日热点；
- 与思维、方法、认知工具宇宙无稳定关系的任意名词。

## 12. 稳定词与动态词分层

### 核心层

长期使用：自我接纳、拖延、批判性思维、决策、系统思维、情绪调节等。

### 传播层

长期可检索但需降权解释：强者思维、人间清醒、认知觉醒、底层逻辑等。

### 动态层

平台阶段性写法、事件热词、短期梗：记录 `平台 + 日期 + 稳定语义映射`，不直接加入核心本体。

动态数据与稳定本体物理分离，是避免标签宇宙无限膨胀的关键。

## 13. 与 28 类正式知识的连接方式

本层不复制正式知识清单，只保存入口到知识的关系。典型路由：

- “想清楚自己到底要什么” → 02 价值、目标、边界与问题定义；
- “怎么把搜索词扩展开” → 03 信息获取、观察与研究设计 → 查询扩展 / 受控词表检索；
- “信息太多理不清” → 04 信息组织、知识表征与概念建模；
- “怎么建立长期检索词典” → 04 → 受控词表 / 叙词表 / 术语管理；
- “网上这个说法靠谱吗” → 06 批判性思维与证据审查 + 07 认知偏差；
- “怎么判断未来概率” → 10 概率、不确定性与预测；
- “选择困难” → 13 判断、决策与多准则权衡；
- “卡在一个问题上” → 15 问题解决、计算与算法思维；
- “没创意” → 16 创造力、发散与创新；
- “系统交互顺序怎么画” → 17 人本设计、工程设计与方案形成 → 序列图 / 时序图等架构建模工具；
- “总拖延” → 20 计划与执行 + 23 行为改变与自我调节；
- “学完就忘” → 22 学习、记忆与技能形成；
- “表达总是说不清” → 24 结构化表达、沟通与知识外化；
- “怎么看人际利益冲突” → 25 协作 + 26 激励、博弈、谈判与机制设计；
- “商业上该怎么选” → 27 战略、竞争与商业判断；
- “未来会怎样” → 28 前瞻、未来研究与情景探索。

具体多对多映射见 `02_标签到正式知识映射_V1.md`。

## 15. 专业知识组织依据

V1 不照搬外部标准，但采用成熟知识组织系统的基本原则：

- W3C SKOS 区分首选标签、替代标签、上下位和相关关系；
- SKOS 明确区分直接上下位与可用于查询扩展的传递关系；
- ISO 25964 面向信息检索的叙词表建设和多词表映射，支持将本层视为检索词汇层，而非第二套学科分类。

同时，最新上游 `01` 已正式收录 `受控词表（Controlled Vocabulary）`、`叙词表（Thesaurus）`、`术语管理（Terminology Management）`、`同义词与查询扩展（Query Expansion）` 等知识，因此本目录不仅与外部知识组织标准一致，也已经有明确的仓库内部正式知识支点。

- W3C, *SKOS Primer*: https://www.w3.org/TR/skos-primer/

| 维度 | 分数 | 说明 |

### 主要扣分原因

1. V1 不是对当前全部正式知识逐项生成全部口语、搜索词和平台词的穷举版；
2. 公开网页检索只能代表可索引样本，不能等同于各平台真实搜索量或完整标签频率；
3. `自我接纳 / 自我关怀 / 情绪调节 / 人际边界 / 主体性` 等入口揭示了少量上游正式知识覆盖候选缺口，本轮按约束不直接改写上游分类。

这些扣分不影响本层作为 V1 的结构稳定性。
