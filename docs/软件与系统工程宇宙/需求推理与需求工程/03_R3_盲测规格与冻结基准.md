## 3. 配对运行规格（正式运行前完成独立基准复核、许可/费用检查）
- A 基线：同一原始输入和阶段约束 + AI-Project-OS 固定版本 [需求设计工作流](https://github.com/shopable-ai/ai-native-project-os/blob/1a1867640b7ee538bac21cd1a16d50f6a7e19c0f/docs/workflows/REQUIREMENT_DESIGN_WORKFLOW.md) 与 [功能需求卡](https://github.com/shopable-ai/ai-native-project-os/blob/1a1867640b7ee538bac21cd1a16d50f6a7e19c0f/templates/standard-project/requirements/functions/FUNC-001_功能需求卡.md) 原文 + §1共同输出约束。不能故意把基线变成只问一句话的弱基线。
- B 增强：A 的全部内容（完全相同的版本、顺序与用户输入）+ 九算子指令：纵向拆必要条件；横向审角色/场景；反向从成功结果推前提；异常/失败/恢复；硬依赖与可选前提；冲突与裁决；从风险/旅程发现隐藏义务；生命周期；去重/必要性/可验收/停止。不得预置案例答案。
- 第一阶段固定 3案例 × 2个经授权的独立模型/运行环境 × 3重复 × 2组 = 36个运行槽（计划数，不是已执行数）。在首个运行之前记录实际模型快照、账号授权及隐私边界、reasoning设置、temperature/seed（若支持；否则明确不可控）、输入hash、最大输出预算（建议每组3500 token，若模型不支持则在两组一致且事前冻结）、上下文长度、运行顺序（每对AB/BA交替）、判卷角色和费用上限。模型ID及价格未知前不消费。每槽独立空白会话，关闭记忆、项目上下文、网络、工具、RAG；不可控则排除该环境，记录原因。两组都不得访问任何参考答案。对运行者仅提供§1相应输入、A/B单独指令与固定OS文本。运行者不得是当前看过基准的对话；判卷者仅见随机化匿名输出及基准，不知组别。记录所有成功、失败、截断、拒绝、超时、无效回执；不选择最佳输出替代失败。
- 真实成本和时延：记录实际提供者 usage / billing / request id（脱敏）、输入/输出/推理 token（如有）、耗时、币种、计费方式。订阅环境不能推算账单成本；无观测填 null+原因，不能当零。各对同等预算，不因B额外指令免计输入成本。

## 4. 判卷与日志
每原子条目记 C=完整（对象、条件、义务及可观察结果吻合）、P=部分（发现方向但缺关键条件或可验证结果）、M=未发现；所有必需项 C+P+M=冻结分母。每条同时给出模型原文定位、理由、独立判卷者和争议裁决；不能关键词自动替代语义判卷。安全项部分命中同样记安全缺陷。对于模型的每条独立候选另分类 valid / reasonable-new / incorrect / overdesign / undecided；同一候选可有错误与越界标签但总误报去重。错误=与目标/事实/授权冲突；过度设计=无必要性、明确排除或把候选实现当需求；正确的可选项若明确延期不算过度设计。两名独立判卷者逐条打标，分歧由第三方复核或保持 unresolved，均保留原判卷。

指标：C/N、P/N、M/N；加权完整覆盖=sum(C权重)/sum(M类权重)，P单独报，不默认半分；错误数、过度设计数、去重误报率=两类并集/候选总数；安全遗漏/部分/危险错误清单、越权/目标漂移一票否决；额外问答实际轮数与问题数、token/耗时/成本按真实记录；分母为零或无法观测填 null。失败运行列入总体失败率，不从总尝试隐藏；没有可判内容不得当作覆盖为0的正常输出，可另给最坏情形敏感性分析。按案例及模型分别报告 A/B 配对差值、样本量、未配对失败和排除理由。

每个运行保存不可变记录：experiment_version、case_id、arm、pair_id、attempt_id、model/version/settings、可见输入和hash、隔离证明/限制、原始回答与所有问答、状态、请求回执、usage、时延、费用、失败/排除原因。另保留匿名判卷逐项表、差异及独立评审签名/角色，不能上传凭证或个人简历等敏感数据。建议证据目录 experiments/R3/runs/ 仅在真实运行之后创建；执行前先固定 run manifest（36槽ID与实际参数）。当前无真实输出，禁止创建假日志。模型执行状态 BLOCKED：没有验证过的独立推理接口；本机 Browser Core 状态探测返回 SSE HTTP 429；当前可用沙箱未发现常见用户模型API环境变量。CodexPro handoff 只能写计划、不能启动独立模型；不能将当前回答或历史图样例当试验。已查历史 R2 提交树，无路径匹配 reasoning.*eval / eval.*reasoning；不宣称原评测脚本不存在于所有版本，不在本轮重造正式运行器。
