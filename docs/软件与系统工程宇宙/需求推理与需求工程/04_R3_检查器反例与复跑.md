## 本地复跑规格
从本专题目录执行 `node snapshots/R2-original/validate-fixtures.mjs`（标准Node，保留stdout、exit code）。用 Python jsonschema 的 Draft202012Validator 检查 schema 本身及每组 input/output：
```python
import json
from pathlib import Path
from jsonschema import Draft202012Validator
p = Path("snapshots/R2-original")
s = json.loads((p/"reasoning.schema.json").read_text(encoding="utf-8"))
Draft202012Validator.check_schema(s)
v = Draft202012Validator(s)
f = json.loads((p/"fixtures.json").read_text(encoding="utf-8"))
for z in f:
    for k in ("input","output"):
        errors = list(v.iter_errors(z[k]))
        print(z["output"]["projectId"], k, [e.message for e in errors])
        assert not errors
```
