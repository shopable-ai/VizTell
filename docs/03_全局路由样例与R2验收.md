## 2. 案例A：互联网注意力竞争

**Case ID：VZCASE-A-META-2022。问题**：新平台增长，为什么可能引发竞争响应，而不是必然导致对手收入减少？

### 2.1 全局路由及因素召回

| 对象/工作 | 唯一责任或引用 | 本轮产出 |
| --- | --- | --- |
| 通用竞争机制 | 社会运行规则宇宙SR-004，关联SR-002/SR-005 | 反制需要感知、能力、预期收益与约束等条件 |
| 行业竞争分析 | 营销D07竞争战略与竞争情报 | 不把社会机制当作某平台已证事实 |
| 收入结构 | 商业模式宇宙 | 注意力、广告展示、收入与利润分开 |
| 响应时滞/阶段 | 周期与演化宇宙 | 标时间窗口，不声称发现固定周期 |
| 来源与案例事实 | 本文件E-VZ-A-META-2022 | 其他分析只引用，不复制完整来源记录 |
| 首轮因素 | VZF-003注意预算、VZF-001稀缺、VZF-018切换成本、VZF-026信息可核验、VZF-045反馈滞后 | 最小召回只是排查候选，不表示五因素已被证实有因果效应 |

参与者分开：用户、广告主、创作者、竞争平台、分发平台。相同增长可让某一方受益而让另一方承压，不能用平台利润代表所有主体的价值。

以下为A的**研究假设表**，不是对Meta或具体人物的已核动机；收益、信息与权限均需现场景证据。它让“竞争反制”有可区分的参与者与动作，避免只列利益名词。

| 参与者 | 可研究的策略选项 | 需查的信息/利益与成本 | 权限/外部选择边界 |
| --- | --- | --- | --- |
| 用户 | 多平台使用、迁移、减少使用 | 内容与互动收益、注意/切换代价；不直接等同平台广告收入 | 可用替代平台、实际迁移限制 |
| 广告主 | 重新配置预算、试验渠道、暂不变化 | 增量效果、价格、归因可测性与风险 | 预算/品牌约束与实际可投渠道 |
| 创作者 | 多平台发布、专属供给、退出 | 触达、分成、创作成本和规则稳定性 | 内容权利、独家条款及可兑现外部选择 |
| 竞争平台 | 产品改进、差异化、合作、忽略或退出 | 预期收益变化、研发/获客成本、回应时滞 | 决策权、技术/资本能力及约束 |
| 分发平台 | 修改规则、合作、保持中立 | 生态收益、控制成本与监管/契约约束 | 原始规则及其合法有效范围另核 |

这类表只在博弈/代理问题相关时启用，不要求每个数学或艺术研究Run填写。

### 2.2 结果和测量口径

先固定地区、受众、产品集合、时间窗与去重方法。若时长份额定义为 `s_i=t_i/Σt_j`，则同一集合份额和为1只是定义；集合、总时长或收入可同时变化。跨平台人数有重叠，不能直接相加得到独立人口。

以下为**合成数学反例**，不是Meta事实：旧平台收入从100变成110，行业总收入从200变成300；它的收入份额从50%变为36.67%，但绝对收入增加。注意力份额又是另一个变量，不能拿该算例冒充注意力的实测数据。

广告收入可按一致口径分解为“广告展示量×每次展示平均广告收入（在同一统计总体上定义平均值）”；这只是会计/测量分解。时长到展示、展示到收入、收入到利润的每一步都还有条件和成本，不是已识别的因果链。

### 2.3 竞争解释、反事实及状态

- H-A1：受众重叠与时间替代引发预期收益压力，促成回应。
- H-A2：共同的视频偏好、带宽/设备等变化，同时推动多个平台发展。
- H-A3：广告需求、隐私测量或地区结构改变收入，与某一竞争者没有单一对应。
- H-A4：新产品扩大市场或形成互补；企业也可以合作、差异化、忽略或退出。

逆推“已回应”不能证明“必然受到实际收入损失”。反事实应问：若新平台未增长而其他条件相同，对手是否仍会推出新形式？需要可比市场/用户群、事件时序和可区分预测；仅有先后顺序不足。

**本轮状态**：`state=provisional`，`run_outcome=ended`，来源主张`validation_scope=source_statement`、路由断言`validation_scope=structure`；一般因果`unresolved`，行动上限`research_only`。

**本例后续问题**：在一个指定市场/时期区分时间替代与共同视频化趋势。输入缺口是可比口径数据和竞争解释时间线；最多两个检索判定回合，取得可区分证据或明确不可得即停止；新领域只进地图backlog。该问题仅保留队列，不与本轮唯一下一任务并行启动。

## 3. 案例B：技术交付、用户采用与商业回报不同步

### 3.2 结果向量

| 结果轴 | 此次证据状态 | 不得推导 |
| --- | --- | --- |
| 技术能力 | 公司自述基础较强 | 不是技术完全成功、没有缺陷或性能独立合格 |
| 服务交付 | 曾推出面向消费者的服务 | 不等于达成全部质量/交付目标 |
| 用户采用 | 公司称未达预期 | 完整用户数、阈值、留存与人群结构未知 |
| 商业回报 | 公告没有足以复算ROI的数据 | 关闭不等于已知具体亏损额 |
| 退出决策 | 官方宣布逐步停止消费服务 | 退出不必然是错误；也不意味着公司整体失败 |
| 技术复用 | 公告表达其他应用机会 | 机会不等于已实现经济回收 |

候选解释包括需求弱、目标用户未被触达、内容/互补品不足、切换成本、价格价值错配、竞争、可信承诺不足、资源约束；本轮不选一个填成确定根因。

### 3.3 一次可继续的局部研究

先把“需求弱”操作化：目标用户的问题负担/紧迫度、已有替代方案，以及在声明价格与采用条件下对当前方案的相对价值和实际支付意愿分别检验；**不以采用量低来定义需求弱，再用需求弱解释采用量低**。问题需求与对某个产品的需求不是同一对象。

核心对比：H-B1在指定人群、报价及替代方案下，问题负担或预期相对净价值较低；H-B2价值需求存在但未触达；H-B3触达后切换/采用成本高。可区分预测分别是：合适人群充分知晓且采用障碍降低后需求仍弱；触达变化能增加有效试用；降低迁移障碍能增加实际采用。真实研究仍需处理选择偏差、同期变化和对照可比性，不能把观察差异直接称为因果。

证据不足时三项假说均保持Unknown，不能用“缺证据”代替“需求低”。H-B1/B2/B3允许并存和交互，不是互斥根因。降低切换成本会提高净价值，触达也可能改变信任和产品认知。一次行为响应最多支持该条件下的局部效果，不能排他证明唯一原因；需分别测问题负担、方案价值、触达、迁移障碍，并声明共同变化和识别不了的部分。

反例入口：同一技术路径下采用较好的公开服务；对照必须匹配时期、人群、定价、内容和分发条件。若无法取得资料，承认无法识别；不为“有成功对照”选一个完全不同产品。

**本轮状态**：`state=provisional`，`run_outcome=ended`，来源主张`validation_scope=source_statement`、路由断言`validation_scope=structure`；采用原因和回报`unresolved`。

**下一轮唯一优先任务**：运行 `VZRUN-NEXT-ADOPTION-01`（研究任务ID `VZR-002`；一个任务可有后续不同run_id）。IT-01为失效问题Owner，营销D04为需求专业Owner；不把两个Owner写成同一正文的共同编辑者。取得可比较的公开采用证据、形成竞争解释矩阵和一个有边界的结论；或记录数据阻塞，两种都可结束本轮。预算和停止条件见第8节提示词。

## 4. 案例C：假设性软件创业跨维问题

**Case ID：VZCASE-C-HYPOTHETICAL。全部为假设；不是用户事实，没有访问或复制私密资料。**

虚构主体P投入软件项目S较长时间，却尚缺充分商业成果证据。问题是：“在接下来的一个约定预算周期，继续、缩减、改变验证方式还是暂停？”不假定P的年龄、收入、家庭状态、资金或真实动机。

### 4.1 三层不可偷换

| 层 | 问什么 | 结果和事实归属 |
| --- | --- | --- |
| 个人 | 哪种未来安排更符合P声明的目标与底线 | AI人生系统的个人结果Owner；此处只引用契约，不创建真实档案 |
| 项目 | 交付、采用、现金与价值假设怎样 | IT失败/企业项目失败分别解释；项目价值不同于个人价值 |
| 行业 | 竞争、供需、产品与商业模式的条件规律 | VizTell专业宇宙；行业平均不能直接判定P个人结果 |

在此假设中，“是否继续项目”可由**事业结果**承担主决策评价；**财富**提供可承受损失约束，**时间**提供容量/机会成本，**学习**评价可迁移能力，**认知**检查信念更新与证据。它们是不同结果/资源职责，不是五个已经证实的原因，更不是世界知识的五个顶层目录。主目标若改成学习，结果Owner应随显式目标调整。

### 4.2 候选、未知与决策边界

召回VZF-002可用时间、VZF-004现金缓冲、VZF-010需求紧迫度、VZF-018切换成本、VZF-026信息可核验、VZF-045反馈滞后、VZF-054恢复能力、VZF-055不可逆损失暴露。

没有个人数据时，风险暴露、需求强度、现金保障都为UNKNOWN；UNKNOWN不是0，也不等于已触发灾难风险。研究应先明示目标、约束及低成本观测，不能自动给P“继续”或“放弃”的建议。

竞争解释：价值存在但采用周期长；目标用户没被触达；需求弱；价格/渠道不匹配；技术学习有收益但商业目标未实现；目标变化未被明示。投入时间长本身不证明能力弱、需求成立或项目必然失败。

反事实比较的是**同一未来预算**下的可行选项。已发生投入不能收回，现有代码、技能、客户关系等可用资产仍影响未来收益；“避免沉没成本偏误”不等于把已形成资产清零。

**状态**：`state=provisional`，`run_outcome=ended`，`validation_scope=structure`，`evidence_status=not_assessed`，`action_permission=research_only`。

**本例后续问题**：在目标及风险约束已给出的前提下，改变一个用户分组或触达方式，能否获得更有区分力的采用信号？输入缺口为主体自定目标、预算和真实数据；本例不补造数值。约束缺失即paused，只有另获授权与输入才继续现实研究；纯结构测试到此结束。
