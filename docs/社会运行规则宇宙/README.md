# 社会运行规则宇宙（V0.1）

> **独立研究域**。研究个人、人际、组织、企业、市场与社会中的资源、利益、权力、信息、竞争、合作和制度机制。不是“大鱼吃小鱼”的同义词，也不把复杂社会现象预设为零和博弈。当前是可验证的研究框架和候选机制库，尚非经实证证成的“社会定律大全”。

## 1. 核心问题与边界

面对任何社会或商业现象，依次问：谁参与？谁想获得什么？资源是否有限/可创造？各方知道什么、拥有什么权力？如何互动？条件变化后结果为何不同？我能干预哪些变量？

研究层级可以是个人、关系、群体、公司、行业、社会；**层级是横向坐标，不是统一树状层级**。具体软件项目或 IT 系统失败应链接独立的失败宇宙，而不在这里保存第二套故障报告。

## 2. 底层因素（变量，而非必定成立的规律）

- **资源与稀缺**：时间、注意力、资金、土地、人才、算力、规则制定权；资源能否增加。
- **利益与激励**：个人/群体目标、短期与长期收益、风险承担、外部性、激励相容。
- **信息与认知**：信息不对称、可得证据、误判、信号、预期、学习。
- **权力与依赖**：退出选择、议价权、控制权、转换成本、资源通道。
- **网络与地位**：关系结构、声誉、网络效应、协调与从众。
- **制度与边界**：法律、道德、合约、产权、合法性、群体规范。
- **动态与适应**：反馈、时滞、阈值、路径依赖、生命周期、对手学习。
- **能力与约束**：执行能力、成本、替代性、风险、恢复能力、外部冲击。

时间和演化在本宇宙是必需分析变量；独立的周期分类和模型归 [周期与演化宇宙](../周期与演化宇宙/README.md) 维护。

这些是**候选研究条目**，不能只凭命名判定普遍有效。每条需写前提、作用机制、失效条件、至少一个反例、证据来源和时间适用性。

## 4. 代表性推演：互联网注意力竞争

前提：用户可用时间有限，平台追求用户使用时长或变现。若新平台份额提升，老平台可能因预期利益受损而改善产品、增加投入、差异化、合作或退出；响应取决于盈利模型、对手能力、用户迁移和制度。

**必须避免的错误**：
- 在份额总和固定的定义下，份额分配可为零和；但行业总收入增长时，其他公司绝对收入可能同步增加。
- 份额“增加 40%（相对增长）”与“增加 40 个百分点”不相同。
- 假设竞争者“必定攻击”没有依据，战略反制、合作或不回应都可能发生。
- “强者恒强”有条件；新技术、监管、进入壁垒降低或网络迁移可能反转格局。

分析时同时记录竞争者可能的回应、合作路径和市场扩大路径。对**发生时机、周期叠加**的深入研究引用 [周期与演化宇宙](../周期与演化宇宙/README.md)。

## 5. 本宇宙的单条机制卡（最小规范）

- **ID / 名称 / 定义**：是可检验命题还是仅是解释性比喻？
- **参与者 / 资源 / 激励 / 约束**：谁在何种条件下行动？
- **因果链 / 反馈 / 时间滞后**：明确观察事实与机制假设的区别。
- **成立条件 / 边界 / 反例**：什么变化会使结论不成立？
- **证据与可信度**：来源、取样/时间、独立性、反对证据、未解决问题。
- **关联**：周期阶段、失效模式、决策动作、其他机制的稳定引用。
- **可执行含义**：可干预变量、预警指标、验证动作，而非自动行动指令。

知识身份和关系断言以 [知识原子与 Canonical Knowledge](../AI原生知识系统/16_知识原子、标准知识与关系模型.md) 的通用契约为准。

## 6. 怎样继续完善一个节点

先画横向候选机制图 → 选最可能改变实际判断的 1–2 个节点 → 向下拆前提和机制 → 搜支持与反驳证据 → 放入两个不同领域/层级验证边界 → 对比竞争性解释 → 记录暂定结论、剩余不确定性与下次触发条件。

例如先只研究 SR-004：用实际市场事件核验“威胁被感知”是否有证据、实际反制是什么、是否存在合作/忽视的反例，不必为了完整性顺带遍历十二条。
