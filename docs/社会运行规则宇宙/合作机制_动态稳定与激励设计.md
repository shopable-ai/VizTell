## 0. 先看结论

### 0.1 核心结论

**长期合作不是一次分配的结果，而是一套能够持续通过变化与偏离检验的动态机制。**

合作机制至少要回答五个不同问题：

1. **有无合作增量：** 组合资源和能力后，是否比各方独立行动创造更多净价值？
2. **个人是否愿意加入：** 每个人得到的持续收益，是否不低于其可信的外部选择？
3. **联盟是否稳定：** 是否存在一组参与者，可以离开当前联盟并组成更有利的子联盟？
4. **行为是否有激励：** 如实披露、按约定投入、报告错误，是否比隐瞒、搭便车和操纵规则更有利？
5. **关系能否适应变化：** 贡献、市场、风险、资源控制和外部选择变化后，是否有可信的调整与退出路径？

这五个问题不能由同一个“公平比例”回答。

### 0.2 本轮最重要的六项判断

- **公平不等于稳定。** 公平分配指标、个体参与约束、联盟稳定和激励相容是不同性质的检验。
- **贡献不等于收益权，更不等于控制权。** 资金、劳动、技术、客户、风险和关键资产应分别识别，不能压缩成一个未经解释的贡献分数。
- **Shapley Value 不是稳定性保证。** 它分摊平均边际贡献；只有在特定博弈结构（例如凸博弈）下才有进入 Core 的保证。
- **固定规则和动态规则各有适用条件。** 最稳妥的常见结构不是“所有权益随贡献实时变化”，而是把既得权利、持续报酬、浮动收益、风险补偿和控制权分开设计。
- **监督不是越多越好。** 监督成本、误判、指标游戏和信任损耗可能抵消收益；关键是让决策相关行为可验证。
- **退出机制不是合作失败的标志。** 清晰、可执行且不过度惩罚的退出机制，可以降低被锁定的恐惧；没有退出路径的合作反而容易积累控制权冲突。

### 0.3 一句话总模型

**合作价值创造 → 个体与联盟可接受的分配 → 真实行为激励 → 可验证的履约治理 → 动态调整与退出。**

三个一级层次仍然是 R1 的：

1. 合作价值创造。
2. 合作价值分配。
3. 长期合作稳定。

激励、信息、监督、控制和治理不是额外的一级层次，而是贯穿三个层次的机制。

### 0.4 研究结论的证据身份

本文区分：

- **已有理论：** 可追溯到合作博弈、机制设计、重复博弈、产权理论和组织治理的定义、定理或论文结果。
- **本轮综合推导：** 将多个理论连接成适用于合作设计的检查链、动态变量和规则组合。
- **合成模拟：** 为验证公式与反例而构造的数据，不代表真实企业或市场统计。
- **待实证：** 需要真实合同、行为日志、组织数据或对照实验才能判断的效果。

## 2. 动态合作机制的因果结构

### 2.1 从合作意愿到长期稳定

合作不是“大家觉得应该合作”就会发生。一个可检验的因果链是：

1. 参与者拥有不同资源、能力或市场位置。
2. 组合后可能产生独立行动无法实现的增量价值。
3. 增量价值必须足以覆盖协调、交易、监督、风险和转换成本。
4. 分配结果必须使每个必要参与者愿意加入。
5. 分配结果还必须考虑子联盟的替代收益。
6. 规则不能让隐瞒、少投入或控制关键资源成为更有利的策略。
7. 未来收益、声誉、监督和承诺必须足以约束短期偏离。
8. 环境变化后，合作必须能调整；调整失败时，参与者必须能有序退出。

任何一个环节失败，都可能让“总价值更大”的合作无法启动或无法持续。

### 2.2 四种不同的稳定性

| 检查 | 关键问题 | 典型失败 |
|---|---|---|
| 个体稳定 | 每个人是否愿意留下？ | 某一方退出更有利 |
| 联盟稳定 | 是否有子联盟能够共同改善？ | 两人或多方私下另组联盟 |
| 策略稳定 | 诚实和履约是否是有利策略？ | 虚报贡献、隐瞒信息、搭便车 |
| 动态稳定 | 变化后规则能否持续运行？ | 原有协议失效、控制权集中、反复重新谈判 |

四种稳定性彼此相关，但不等价。一个分配可以满足个人参与约束，却被子联盟阻断；一个分配可以位于 Core，却仍然存在隐藏行动和指标操纵。

### 2.3 合作与竞争不是互斥关系

合作可以只发生在特定资源、活动或时间段：

- 企业可以共同建设基础设施，同时竞争客户。
- 供应商与生产商可以共同降低供应链成本，同时独立经营其他客户。
- 多个 Agent 可以共享任务上下文，但独立验证关键结果。
- 合伙人可以共享品牌和渠道，但保留各自的既有知识产权。

因此，合作边界必须明确到资源、活动、客户、数据、知识产权和决策事项，而不是笼统要求“所有方面都合作”。

## 3. 动态合作机制的统一模型

### 3.1 状态变量

设参与者集合为：

\[
N_t=\{1,\ldots,n_t\}
\]

参与者数量、联盟结构和资源状态都可以随时间变化。

定义：

| 变量 | 含义 | 不能误解为 |
|---|---|---|
| \(v(S,t)\) | 时间 t 时，联盟 S 的净价值 | 单纯营业额或总收入 |
| \(d_i(t)\) | 参与者 i 在 t 时的外部选项净收益 | 主观威胁或随意报价 |
| \(c_i(t)\) | 参与者 i 的多维贡献 | 一个可以直接观测的单一数字 |
| \(r_i(t)\) | 参与者 i 的风险承担及风险暴露 | 单纯投入金额 |
| \(x_i(t)\) | 参与者 i 获得的经济收益 | 所有权和控制权 |
| \(h_i(t)\) | 参与者 i 的权利集合 | 收益比例 |
| \(s_t\) | 市场、技术、信息、资源和组织状态 | 固定不变的背景 |
| \(\Pi_t\) | 参与者当前形成的联盟划分 | 只有大联盟一种结构 |

贡献可以进一步表示为向量：

\[
c_i(t)=
(c_i^{capital},c_i^{labor},c_i^{technology},
c_i^{market},c_i^{knowledge},c_i^{quality})
\]

风险也不应只记录一个金额。需要区分资金损失风险、经营风险、法律责任、声誉风险、机会成本和不可逆投入。

权利集合至少要区分：

- 收益权。
- 所有权。
- 决策权。
- 控制权。
- 资产使用权。
- 知识产权和数据权。
- 信息访问权。
- 退出与转让权。

### 3.2 先判断合作是否创造真实增量

在没有外部性、收益可转移且比较口径一致的简化模型中：

\[
\Delta_N(t)=v(N,t)-\sum_{i\in N}d_i(t)
\]

其中 \(v(N,t)\) 必须是扣除直接经营成本、协调成本等后的净价值；\(d_i(t)\) 是各方独立行动或其他可信替代方案的净价值。

- 若 \(\Delta_N(t)<0\)，当前合作结构没有创造足够的净增量。
- 若 \(\Delta_N(t)=0\)，合作可能只是重新组织资源，没有产生可分配的额外剩余。
- 若 \(\Delta_N(t)>0\)，说明存在合作剩余，但不代表所有参与者都愿意加入。

如果存在非货币收益、共同保险价值、长期选择权或第三方外部性，应将其明确纳入效用或社会价值口径，不能悄悄混入营业收入。

**价值创造与价值分配必须分开测量。**

例如，甲从乙处获得 20 万元，可能只是收益转移；只有合作使客户、产能、质量、效率或其他真实产出增加，才构成新增价值。还应扣除合作导致的协调成本、垄断损失、第三方损害和新增风险。

### 3.3 参与约束：Individual Rationality

最简单的静态表达：

\[
x_i\ge d_i
\]

若参与者留在合作中获得的效用低于其独立行动收益，就存在退出动机。

动态合作不能只比较当期现金。应比较剩余合作的继续价值与退出价值：

\[
W_i^{stay}(s_t)\ge W_i^{exit}(s_t)
\]

其中：

\[
W_i(s_t)=u_i(t)+
\delta_i\mathbb E[W_i(s_{t+1})\mid s_t]
\]

\(\delta_i\) 表示参与者对未来收益的重视程度；\(u_i(t)\) 包含当期经济收益、风险、工作成本和其他相关效用。

需要注意：

- 外部选项可能随时间变化。
- 参与者可能拥有多个替代方案。
- 退出成本可能使账面收益高于实际可获得收益。
- 合作中的非现金收益也可能影响参与约束。
- 不能通过人为制造高退出成本来证明合作稳定。

如果总合作收益不足以满足所有人的参与约束，正确做法可能是调整合作边界、减少成本、增加价值、改变风险分配或放弃合作，而不是强行寻找一个数学比例。

### 3.4 联盟稳定：Core

对可转移效用（TU）的特征函数合作博弈，设联盟 S 的价值为 \(v(S)\)，分配为 \(x\)。

Core 的标准条件：

\[
\sum_{i\in N}x_i=v(N)
\]

\[
\sum_{i\in S}x_i\ge v(S),
\quad \forall S\subsetneq N
\]

第一项要求大联盟分配完全部价值；第二项要求任一子联盟得到的总收益，不低于其单独形成联盟可获得的价值。

若外部选项 \(d_i\) 与单人联盟价值不同，还应明确加入：

\[
x_i\ge d_i
\]

Core 的实际意义：

- 不是要求每个人拿到一样多。
- 不是保证没有任何人抱怨。
- 不是自动执行合同的工具。
- 它是一个联盟偏离检验：在给定价值函数和转移条件下，是否有子联盟可以改善其成员的收益。

#### Core 可能为空

经典三人多数联盟例子：

- 任意两个人组成联盟，可以创造价值 1。
- 单人价值为 0。
- 三人大联盟总价值也是 1。

若 Core 存在，就必须满足：

\[
x_A+x_B\ge1
\]

\[
x_A+x_C\ge1
\]

\[
x_B+x_C\ge1
\]

三式相加：

\[
2(x_A+x_B+x_C)\ge3
\]

但效率要求：

\[
x_A+x_B+x_C=1
\]

矛盾。因此 Core 为空。

这说明：**任何一种大联盟分配都会被至少一个两人联盟的偏离约束击穿。**

Bondareva–Shapley 定理进一步给出：有限 TU 合作博弈的 Core 非空，当且仅当该博弈是 balanced。直观上，不能让一组互相重叠的子联盟通过分数权重重复计算价值，却要求大联盟承担无法满足的总承诺。[1][2]

Core 为空时，可以考虑：

- 改变联盟成员范围。
- 重新设计共同资产或收益来源。
- 降低子联盟偏离的交易成本或外部性。
- 设计可验证的长期合同和转移支付。
- 让参与者拥有不同但可接受的非现金权利。
- 接受分阶段合作，而不是强行维持一个大联盟。

但不能宣称通过增加一份合同就一定能消除 Core 为空的问题。

#### 特征函数与外部性：企业联盟尤其需要注意

标准特征函数 \(v(S)\) 假设联盟 S 的价值只取决于 S 的成员。

现实中，供应商、生产商和渠道商的联盟价值，可能取决于其他企业如何组成联盟、市场是否出现替代供应商、竞争者是否反制。

这时更适合考虑分区函数形式：

\[
v(S,\Pi,t)
\]

即联盟 S 在整体联盟划分 \(\Pi\) 和时间 t 下的价值。

忽略外部联盟结构，可能会错误估计子联盟退出后的收益。[16]

### 3.5 动态联盟稳定：本轮综合模型

静态 Core 只描述给定博弈中的分配稳定性。

长期合作还需要把继续合作的未来价值放入判断。

本轮采用一个动态诊断表达：

\[
W_S^{stay}(s_t)\ge
W_S^{deviate}(s_t)
\]

其中右侧需要考虑：

- 子联盟脱离后可创造的价值。
- 其他参与者可能采取的反应。
- 共同资产如何分割。
- 转换、重建和交易成本。
- 退出后是否还能使用原有客户、数据、技术或品牌。
- 未来各期的收益和风险。

这不是声称存在一个适用于所有动态博弈的统一 Core 公式，而是把静态联盟偏离检查扩展为持续价值比较。

**动态稳定不是只看今天有没有人退出，而是看在关键状态变化和可行历史之后，是否仍然没有更有吸引力的可信偏离路径。**

## 4. Shapley、Nash、Core 与 Nucleolus：怎样组合？

这四种概念解决的问题不同，不能将它们当作四种可以随意替换的分配公式。

### 4.1 四种理论的分工

| 理论 | 主要解决什么 | 主要输入 | 不保证什么 |
|---|---|---|---|
| Shapley Value | 按不同加入顺序的平均边际贡献分配价值 | 各种联盟的价值 \(v(S)\) | 不自动保证 Core、真实贡献可观测或激励相容 |
| Nash Bargaining | 考虑分歧点和议价权，选择互利协议 | 可行收益集合、外部选项、议价权重 | 不自动保证子联盟稳定 |
| Core | 判断是否存在能阻止所有可行子联盟偏离的分配 | 全部相关联盟价值 | 不保证唯一，也可能为空 |
| Nucleolus | 以最不满意的联盟为先，逐级最小化联盟不满程度 | 各联盟价值及可行分配集合 | 不解决隐藏信息、道德风险或合同执行 |

### 4.2 Shapley Value

参与者 i 的 Shapley Value：

\[
\phi_i(v)=
\sum_{S\subseteq N\setminus\{i\}}
\frac{|S|!(n-|S|-1)!}{n!}
[v(S\cup\{i\})-v(S)]
\]

它把参与者在不同联盟加入顺序下产生的边际价值取平均。

经典 Shapley Value 由效率、对称性、虚拟参与者和可加性等公理刻画。[3]

**它适合回答：**

如果从不同可能的合作顺序看，一个参与者平均为联盟增加了多少价值？

**它不适合单独回答：**

- 这个人投入了多少小时？
- 谁应该拥有公司？
- 谁承担了多少风险？
- 谁应该拥有最终决策权？
- 参与者会不会为了增加自己的 Shapley 份额而操纵联盟价值？
- 当前分配能否阻止某个子联盟退出？

Shapley Value 依赖对各个子联盟价值的估计。参与者人数增加后，联盟组合数达到 \(2^n\)，真实估值和计算成本都会上升。

一个重要边界：在凸合作博弈中，Shapley Value 位于 Core；但一般合作博弈不能作此推断。[2][4]

### 4.3 Nash Bargaining

标准纳什议价形式：

\[
\max_{u\in F,\ u_i\ge d_i}
\prod_{i\in N}(u_i-d_i)^{\alpha_i}
\]

其中：

- F 是可行收益集合。
- \(d_i\) 是谈判失败或不合作时的收益。
- \(\alpha_i\) 是议价权重。
- \(u_i-d_i\) 是合作带来的增量收益。

在可转移效用、线性收益且总剩余固定的简化情形中：

\[
u_i=d_i+
\frac{\alpha_i}{\sum_j\alpha_j}\Delta
\]

它强调的是：各方从不合作基准上获得多少增量，以及议价权如何影响剩余分配。

外部选项更好的人，即使投入数量没有增加，也可能在谈判中获得更有利的结果。

这不一定意味着不公平，而是说明议价结果与贡献归属不是同一个问题。[5]

### 4.4 Nucleolus

定义联盟 S 的不满程度：

\[
e(S,x)=v(S)-\sum_{i\in S}x_i
\]

Nucleolus 按从大到小排列联盟不满程度，再以字典序方式最小化该向量：

\[
\nu(v)=
\arg\min_{\text{lex}}
\operatorname{sort}_{\downarrow}
\{e(S,x)\}
\]

它不是简单地平均每个人的收益，而是优先压低最严重的联盟不满，再处理次严重的联盟不满。

主要性质：

- 在合理的非空 Imputation Set 条件下存在唯一解。
- 如果 Core 非空，Nucleolus 位于 Core。
- 如果 Core 为空，Nucleolus 仍不能把一个不稳定博弈变成具有真正 Core 的博弈。
- 对大规模博弈，联盟数量和计算难度可能非常高。[6]

### 4.5 四种理论之间能否同时满足？

不能保证。

- Core 可能为空，此时没有任何分配能满足所有联盟稳定约束。
- Shapley Value 在一般博弈中可能落在 Core 之外。
- Nucleolus 在 Core 非空时能够提供一个 Core 内的单点选择。
- Nash Bargaining 受外部选项和议价权重影响，不会自动满足所有联盟约束。
- 即使四种分配结果一致，也不代表参与者会如实披露信息或履行长期义务。

因此，实际设计应先判断问题类型，再选理论工具：

| 实际问题 | 优先使用 |
|---|---|
| 估计多方平均边际价值 | Shapley Value |
| 协商合作剩余和外部选项 | Nash Bargaining |
| 检查子联盟是否会退出 | Core |
| Core 非空时选取一个兼顾联盟不满的分配 | Nucleolus |
| 检查是否会虚报和隐瞒 | Mechanism Design / IC |
| 检查长期履约能否自我维持 | Repeated Games / Relational Contracts |

**推荐组合：先建立联盟价值模型，再检查 Core；若 Core 非空，再用 Shapley、Nash 或 Nucleolus 作为候选分配依据；最后独立进行激励相容和动态履约审查。**

## 5. 激励相容与信息不对称

### 5.1 机制设计的核心问题

参与者不一定会报告真实偏好、真实成本、真实能力或真实风险。

因此，不能假设只要把规则解释清楚，参与者就会按规则的设计意图行动。

设参与者真实类型为 \(\theta_i\)，向机制报告的类型为 \(\hat\theta_i\)，机制为 M。

激励相容的基本含义是：真实报告至少不比虚假报告更差。

\[
\mathbb E_{\theta_{-i}}
[u_i(M(\theta_i,\theta_{-i});\theta_i)]
\ge
\mathbb E_{\theta_{-i}}
[u_i(M(\hat\theta_i,\theta_{-i});\theta_i)]
\]

这是 Bayesian IC 的一种表达。若要求对其他参与者的每一种类型都成立，则是更强的 Dominant-Strategy IC。

但这里的类型报告只是问题的一部分。参与者还可能在签约后隐藏真实行动和努力。

### 5.2 必须区分两种信息不对称

| 类型 | 发生时间 | 典型行为 | 机制设计重点 |
|---|---|---|---|
| Adverse Selection（逆向选择） | 合作前或签约时 | 隐瞒能力、风险、资源质量、真实成本 | 筛选、信号、验证、分级合同 |
| Moral Hazard（道德风险） | 合作开始后 | 减少努力、隐瞒错误、转移风险、降低质量 | 监督、绩效契约、责任边界、激励 |

Principal-Agent Problem 不只存在于老板与员工之间，也存在于：

- 投资人与创业者。
- 委托企业与供应商。
- 联盟管理者与成员企业。
- 组织与外包团队。
- Agent 调度器与执行 Agent。

当委托方无法完全观察行动，或者代理方拥有更多私人信息时，就会产生激励问题。

### 5.3 搭便车：为什么有人减少贡献？

设合作产生公共收益，每个人都可以分享结果，但个人投入成本由自己承担。

参与者可能认为：

- 我少做一点，整体结果仍然可以完成。
- 其他人多做一点，我仍然可以分享收益。
- 我的努力很难被识别。
- 多投入带来的额外收益不一定归我。

于是，个人最优行为可能偏离团队最优行为。

Holmström 的团队道德风险研究指出，多人团队中的 Free Riding 和信息性监测会影响激励安排；竞争本身并不会自动带来价值。[7]

可选机制：

- 事先明确责任和最低投入承诺。
- 把任务完成与可验证交付关联。
- 对共同结果和个人责任分别评价。
- 对关键工作设置验收门槛。
- 对难以独立归因的工作采用团队收益与个人责任结合的结构。
- 对长期贡献设置阶段性复核。

不能仅靠“平均分收益”解决搭便车。

### 5.4 指标造假：为什么绩效规则可能适得其反？

如果奖励与某个容易统计的指标直接绑定，参与者可能优化指标而非真实目标。

例如：

- 销售额增加，但利润和客户质量下降。
- 代码提交数量增加，但缺陷和维护成本增加。
- Agent 消耗更多 Token，但结果质量没有提高。
- 员工完成更多任务数量，但重要任务质量下降。

Holmström 与 Milgrom 的多任务委托代理研究说明，当工作包含多个维度，而部分维度更容易测量时，过度依赖可测量指标可能使努力从难测任务转移到易测任务。[8]

Baker 对绩效测量的研究也指出，代理人报酬若依据与委托人真实目标不完全一致的绩效指标，可能产生低效率激励和指标操纵。[9]

**机制设计原则：不要让一个容易被操纵的指标代表全部贡献。**

应组合：

1. 数量指标。
2. 质量指标。
3. 长期结果。
4. 风险和返工成本。
5. 独立验收。
6. 反向指标，例如缺陷率、投诉率和异常回滚。
7. 抽样审计和证据追溯。

### 5.5 VCG 与机制设计的不可能性

VCG 等机制在特定条件下能够让参与者如实报告私人价值，并实现效率目标，但其保证依赖拟线性效用、私人价值、可行选择等假设。

它不等于：

- 公平分配。
- 预算一定平衡。
- 没有串通。
- 没有外部性。
- 适用于所有组织关系。

Myerson–Satterthwaite 定理给出一个重要反例：在双方拥有私人估值、估值区间重叠的标准双边交易环境中，一般不能同时实现激励相容、个体理性、事后效率和无外部补贴的预算平衡。[10]

这意味着：**诚实、效率、公平参与和预算约束之间可能存在理论冲突。**

机制设计不能承诺所有目标在所有信息结构下同时实现。

### 5.6 可执行的抗操纵规则

| 问题 | 规则方向 | 必须保留的边界 |
|---|---|---|
| 虚报贡献 | 以可验证交付、成果证据和独立验收为依据 | 不能把所有知识劳动都量化成工时 |
| 隐瞒风险 | 重要风险披露、风险声明、阶段性复核 | 不能假设所有私人信息都能被发现 |
| 减少投入 | 明确持续责任、最低履约要求和补救期 | 不应把正常效率提升误判为减少贡献 |
| 隐瞒错误 | 鼓励及时报告、独立测试、缺陷追踪 | 不能让报告错误本身必然受到重罚 |
| 操纵指标 | 多维指标、抽样审计、质量门槛 | 指标越多也可能造成复杂性 |
| 串通 | 冲突披露、独立审计、敏感事项回避 | 不可能通过合同消灭所有串通 |
| 策略性拖延 | 明确时间窗口、交付依赖和默认处理规则 | 需要允许真实阻塞和不可抗力 |

## 6. 长期重复合作：为什么一次成功不代表长期成功？

### 6.1 重复博弈的基本逻辑

一次性合作中，参与者可能更重视眼前收益。

长期合作中，参与者还要考虑：

- 未来收益。
- 声誉损失。
- 未来合作机会。
- 对方的反应。
- 违约后的替代选择。
- 惩罚是否可信。

将长期效用表示为：

\[
U_i=\sum_{t=0}^{\infty}\delta_i^t u_i(t)
\]

\(\delta_i\) 越高，未来收益在当前决策中的权重越高。

Fudenberg 与 Maskin 的 Folk Theorem 说明，在满足相应条件且参与者足够重视未来时，重复互动可以支持大量满足个体理性的长期结果；但这不是说任何关系都能通过重复合作自动稳定。[11]

### 6.2 一个可以复算的惩罚阈值

设两方每一期有如下收益：

| 行为结果 | 合作方收益 | 偏离方收益 |
|---|---:|---:|
| 双方合作 | 3 | 3 |
| 一方偏离、另一方合作 | 0 | 5 |
| 双方进入惩罚状态 | 1 | 1 |

定义：

- 合作收益 R=3。
- 单方偏离收益 T=5。
- 惩罚收益 P=1。
- 未来折现因子为 \(\delta\)。

若采用完全监测下的 Grim Trigger（一次偏离后永远惩罚），持续合作的收益为：

\[
V_C=\frac{R}{1-\delta}
\]

偏离收益为：

\[
V_D=T+\frac{\delta P}{1-\delta}
\]

持续合作要求：

\[
\frac{R}{1-\delta}
\ge
T+\frac{\delta P}{1-\delta}
\]

整理得到：

\[
\delta\ge\frac{T-R}{T-P}
=\frac{5-3}{5-1}=0.5
\]

这表示：在该简化模型中，参与者足够重视未来时，长期合作可以比一次背叛更有利。

但这个例子依赖完全监测和惩罚能够可信执行的假设。

### 6.3 监测不完全时会发生什么？

假设偏离行为只有概率 q 能够被发现，未发现时合作继续，发现后进入惩罚状态。

在忽略误报的简化模型中：

\[
\delta\ge
\frac{T-R}
{(T-R)+q(R-P)}
\]

仍使用 R=3、T=5、P=1：

| 偏离发现概率 q | 合作所需最低折现因子 |
|---:|---:|
| 100% | 0.500 |
| 80% | 0.556 |
| 25% | 0.800 |

监测能力越差，合作就越依赖参与者对未来的重视。

这个公式是特定触发策略下的演示模型，不是所有不完全监测重复博弈的通用定理。

Sugaya 与 Wolitzky 对重复博弈中的监测精度和折现进行了联合研究，进一步说明合作激励取决于未来收益与偏离行为可识别程度的共同作用。[12]

### 6.4 惩罚为什么可能破坏合作？

惩罚可以抑制偏离，但也可能产生：

- 误判后双方互相报复。
- 一次小错误导致长期惩罚。
- 参与者隐瞒问题以避免处罚。
- 惩罚强度超过实际损害。
- 对方已经愿意纠正，但制度不允许恢复。
- 双方都不愿继续合作，却被原规则锁定。

因此，惩罚机制需要：

1. 证据标准。
2. 违规严重程度。
3. 发现后的通知和解释。
4. 合理的纠正期限。
5. 分级制裁。
6. 复核与申诉。
7. 纠正后的恢复机制。
8. 严重或重复违约时的退出机制。

惩罚必须可信，但不应设计成一旦触发就无法恢复的报复链。

### 6.5 正常调整与机会主义背叛如何区分？

不能只看结果变化，需要检查行为和信息。

| 观察维度 | 正常调整的典型特征 | 机会主义风险信号 |
|---|---|---|
| 原因 | 市场、技术、成本或角色发生变化 | 利用对方已投入后形成的依赖 |
| 披露 | 及时说明原因和证据 | 隐瞒关键事实或延迟披露 |
| 时间 | 按预先约定的复核窗口提出 | 在对方无法退出时突然提出 |
| 调整范围 | 面向未来、比例合理 | 追溯既得收益、单方面改变规则 |
| 对称性 | 相关方承担合理调整义务 | 只要求对方让步 |
| 复核 | 接受中立评估和证据核验 | 拒绝核验，依赖控制权施压 |

这些是风险识别信号，不是判断当事人主观恶意的充分证据。

### 6.6 Relational Contracts：正式合同之外的可信承诺

现实中有些行为无法低成本地写入合同并由法院完全验证，例如：

- 主动分享重要市场信息。
- 关键时刻提供额外协助。
- 不利用技术漏洞损害合作伙伴。
- 在市场冲击后主动调整合作安排。

关系契约依赖未来合作价值、声誉、可信承诺和反复协商。

正式合同与关系契约可以互补，而不是二选一。Watson、Miller 与 Olsen 的研究还说明，长期合同、外部执行和重新谈判可以形成相互作用的治理结构。[13]

### 6.7 声誉、信任与集体治理的正确使用

声誉不是未经核实的评分标签。

应记录：

- 约定是否清楚。
- 是否履约。
- 是否及时披露风险。
- 是否主动修复错误。
- 是否存在不可控的外部冲击。
- 违规是否重复。
- 是否有独立证据。

信任可以降低监督成本，但不能代替必要的证据、责任和退出规则。

在共同资源治理中，Ostrom 的研究提供了重要补充：清晰的参与者与资源边界、与本地条件相符的规则、用户参与规则制定、可问责的监测、分级制裁、低成本冲突解决和多层嵌套治理，都是长期制度可能成功的重要设计因素。[19]

这些原则来自公共池资源治理研究，不应机械复制为所有企业的合同模板。

## 7. 控制权、依赖关系与 Hold-up Problem

### 7.1 为什么最初平等的合作可能逐渐失衡？

假设两个企业共同开发产品：

- A 提供核心技术。
- B 提供客户和渠道。
- 双方共同投入时间和资金。

合作开始时双方互相依赖。

但随着合作深入：

- 客户关系可能全部集中到 B。
- 核心技术可能只掌握在 A 手里。
- 其他资源逐渐被专用化。
- 一方的退出成本越来越高。
- 另一方拥有更多替代方案。

此时，原有的收益比例即使没有变化，真实议价权也可能发生变化。

### 7.2 Hold-up Problem：关系专用投资后的议价风险

关系专用投资（Relationship-Specific Investment）是指某项投入在当前合作关系中价值很高，但离开该关系后价值明显下降。

例如：

- 专用设备。
- 深度系统集成。
- 为某个合作伙伴开发的专用技术。
- 客户导入和定制流程。
- 专属数据清洗。
- 特定供应链认证。

如果一方已经投入且无法轻易转移，另一方可能在事后利用其退出困难重新索取利益。

这不是简单的道德问题，而是合同不完整、投资不可逆和控制权分配共同造成的激励问题。

Grossman 与 Hart 的产权理论强调，合同难以列出全部未来权利时，资产所有权所包含的剩余控制权会影响双方投资激励；控制权集中也可能损害另一方的投入积极性。[14]

Hart 与 Moore 进一步研究了所有权、控制结构和企业边界之间的关系。[15]

### 7.3 需要区分四种权力

| 权力 | 典型来源 | 风险 |
|---|---|---|
| 资源控制权 | 资金、技术、设备、客户、数据 | 控制关键入口 |
| 决策权 | 表决权、管理权限、预算权限 | 单方决定重大事项 |
| 信息权 | 掌握真实成本、订单、客户和技术状态 | 信息优势被用于议价 |
| 退出影响力 | 替代资源、转换成本、资产可携带性 | 一方可以退出，另一方无法退出 |

收益比例相同，不代表双方权力相同。

### 7.4 防止共同创造的价值被单方控制

候选措施：

- 共同开发资产的权属事先明确。
- 关键知识产权采用明确许可、共同持有或分层授权安排。
- 关键数据有合理的访问和导出机制。
- 关键设备和系统支持可迁移或替代。
- 核心交付物采用托管、交接或阶段性移交。
- 重要投资采用分阶段投入。
- 重大事项设置共同决策或特定否决权。
- 对单方控制的关键资源设置服务连续性和退出交接要求。
- 约定关键合作中断时的使用权、许可权和资产处置方式。

这些措施不能全部同时采用。每项措施都可能增加管理成本、降低单方投资动力或引入新的控制冲突。

**核心目标不是消灭所有权和控制权差异，而是避免一方利用不可替代性获得未事先约定的单方面收益。**

## 8. 动态调整：哪些应该固定，哪些应该变化？

### 8.1 固定分配与动态分配的比较

| 机制 | 优点 | 风险 | 适用条件 |
|---|---|---|---|
| 固定分配 | 可预期、低管理成本、方便投资规划 | 外部条件变化后可能失衡 | 权利边界稳定、贡献承诺清楚 |
| 按贡献动态调整 | 能反映持续投入变化 | 贡献测量困难、容易被操纵 | 贡献可验证且双方接受计量规则 |
| 按绩效动态调整 | 与结果关联 | 可能牺牲长期质量和难测任务 | 绩效目标可验证且多维度 |
| 固定收益加浮动收益 | 兼顾稳定和激励 | 需要明确基准和浮动规则 | 贡献和经营结果同时重要 |
| 触发式重新协商 | 适应重大变化 | 容易产生策略性重新谈判 | 有清晰事件、证据和程序 |
| 定期复核 | 可以发现长期失衡 | 频繁复核增加交易成本 | 合作持续且变化可预期 |

不存在动态机制必然优于固定机制的结论。

### 8.2 建议把收益和权利拆成不同账户

一种可复用的结构：

| 组成 | 解决的问题 | 变化规则 |
|---|---|---|
| 资本或资产权益 | 谁投入了资本、拥有了什么资产 | 按约定归属，不随普通工作量波动 |
| 劳动或服务报酬 | 谁持续提供工作 | 随角色、工作量和责任变化 |
| 风险补偿 | 谁承担了额外风险 | 按事先约定的风险范围调整 |
| 浮动收益 | 谁参与了新增价值创造 | 按事先约定的可验证公式变化 |
| 控制与决策权 | 谁能决定哪些事项 | 根据资产权属、责任和治理约定设计 |
| 退出和回购权益 | 离开时如何处理既得权益 | 按事先约定的估值、归属和交接规则 |

这不是要求每个项目都建立六个账户，而是要求设计者不要将它们混成一个股权百分比。

### 8.3 什么时候应该调整？

适合触发复核的情况：

- 某参与者的职责长期发生实质变化。
- 关键资源或技术发生重大替换。
- 市场或监管条件发生结构性变化。
- 某方外部选项发生显著变化。
- 原定风险承担范围已经发生变化。
- 经营结果持续偏离原有模型。
- 某方长期无法履行约定的核心义务。
- 新的关键资产或共同成果出现。

调整应满足：

1. 有明确触发条件。
2. 有可核验的事实。
3. 能说明对合作价值的影响。
4. 说明影响哪些权利和收益。
5. 只调整必要的部分。
6. 优先对未来生效。
7. 有争议处理和默认规则。

例如，合同可以约定：某项业务职责持续两个复核周期超过约定阈值，才触发重新评估。具体周期和阈值需要按行业和合作周期确定，不存在通用的 20% 或 30% 最佳值。

### 8.4 什么时候不应该调整？

- 只有短期随机波动。
- 贡献变化无法核实。
- 指标可能被策略性操纵。
- 原有权利已经明确归属且不存在触发条款。
- 变化只是一次性成果，已经通过奖金或项目报酬补偿。
- 一方试图在另一方完成专用投资后追溯改变收益规则。
- 调整的管理成本高于潜在收益。
- 真实问题是职责不清，而不是分配比例。

**贡献变化不自动等于股权变化。** 有时调整未来工资、任务、奖金或风险责任就足够了。

### 8.5 沉没成本与重新协商

沉没成本是已经发生、无法收回的投入。

它不应被每一期重新计算成新的贡献，也不应自动成为一方要求更多未来收益的理由。

但必须区分：

- 已经消耗的资金。
- 仍然存在的设备、知识产权和数据资产。
- 尚未完成的合同义务。
- 已经形成但尚未结算的应收款。
- 为合作专门形成、离开后价值降低的资产。

这些项目具有不同的经济意义。

重新协商应基于未来可创造的价值、现有权利、继续合作的可行性和可验证的新增义务，而不是简单比较谁过去花的钱更多。

### 8.6 退出、回购与资产分割

退出机制至少需要明确：

1. 通知期限。
2. 已归属与未归属权益。
3. 资产和负债估值。
4. 共同知识产权的后续许可。
5. 客户关系和合同如何转移。
6. 数据导出与删除责任。
7. 未完成项目如何交接。
8. 违约和正常退出的区别。
9. 回购资金来源与支付期限。
10. 退出后仍然有效的保密、责任和其他义务。

退出价格不能简单采用一个永远固定的估值倍数。

应明确使用资产净值、约定估值方法、独立评估或其他适当方式，并考虑流动性、负债、市场变化和交易成本。

不合理的退出惩罚会形成新的锁定问题；没有交接义务又可能让退出方将全部转换成本留给其他成员。

### 8.7 争议解决

建议分层处理：

1. 事实和证据核对。
2. 相关责任人直接协商。
3. 中立专业人员进行技术或财务评估。
4. 调解。
5. 合同约定的仲裁或司法途径。

同时设置：

- 争议期间继续履行哪些义务。
- 哪些事项可以暂缓。
- 是否需要临时托管或保全资产。
- 谁承担评估费用。
- 评估结论如何被复核。

争议处理规则应当在冲突发生前确定，而不是发生后由控制权更强的一方临时决定。

## 9. 反面行为与防操纵机制矩阵

本节不把所有负面行为归结为道德缺陷，而是分析行为人的收益动机、可利用条件和制度漏洞。

### 9.1 搭便车

- **利益动机：** 少投入但继续分享公共收益。
- **发生条件：** 个人投入难以观察，收益又不能排除低贡献者。
- **损害：** 其他成员承担更多成本，长期投入意愿下降。
- **规则：** 明确责任、最低履约要求、交付验收和团队收益条件。
- **证据：** 任务记录、成果质量、责任交接、履约时间。
- **副作用：** 过度记录可能挤压真正工作；个人指标可能损害团队协作。
- **无法完全消除：** 难以量化的帮助、知识共享和团队协同始终存在归因误差。

### 9.2 隐瞒信息

- **利益动机：** 通过信息差获得更好的议价条件。
- **发生条件：** 一方掌握真实成本、市场、能力或风险，另一方难以验证。
- **损害：** 合作决策错误，风险被不公平转移。
- **规则：** 重要事项披露、关键数据核验、风险声明、阶段性审计。
- **证据：** 原始记录、合同、业务系统数据、第三方证明。
- **副作用：** 全量披露可能泄露商业秘密，增加合规和安全风险。
- **无法完全消除：** 私人知识和未来市场信息不可能完全公开。

### 9.3 虚报贡献

- **利益动机：** 夸大投入以提高收益权。
- **发生条件：** 贡献定义模糊，统计权由当事人控制。
- **损害：** 真实贡献者被稀释，资源分配错误。
- **规则：** 事先定义贡献类型、验收标准和独立审计。
- **证据：** 交付物、版本记录、客户验收、可复算成果。
- **副作用：** 过度强调证据可能低估创造性和长期基础工作。
- **无法完全消除：** 共同创造和知识贡献存在不可完全分割的部分。

### 9.4 减少投入但保留收益

- **利益动机：** 降低个人成本而维持原有收益。
- **发生条件：** 持续义务没有定义，或贡献与报酬完全脱节。
- **损害：** 其他成员承担新增劳动。
- **规则：** 持续职责、最低服务标准、浮动收益和补救期限。
- **证据：** 交付质量、工作记录、职责履行和长期结果。
- **副作用：** 可能将正常效率提升或健康、家庭等合理变化误判为违约。
- **无法完全消除：** 不可能将每个人的真实努力完全观察出来。

### 9.5 控制关键资源

- **利益动机：** 利用唯一技术、资金、渠道或数据入口提高议价权。
- **发生条件：** 其他参与者缺乏替代方案，且已经进行专用投资。
- **损害：** 合作价值被单方控制，投资激励下降。
- **规则：** 关键资产许可、数据可携带性、双供应源、托管和持续服务条款。
- **证据：** 资产清单、权限日志、许可范围和替代成本。
- **副作用：** 复制关键资源会增加成本，过度共享也会损害安全。
- **无法完全消除：** 技术稀缺、规模优势和资源集中可能客观存在。

### 9.6 机会主义退出

- **利益动机：** 获取共同投资形成的资产或客户后退出，避免承担后续义务。
- **发生条件：** 共同资产归属和退出交接不明确。
- **损害：** 其他成员承担损失和重建成本。
- **规则：** 归属期、交接义务、回购、许可和责任清算。
- **证据：** 投入记录、资产权属、合同和退出前后业务变化。
- **副作用：** 过度惩罚退出会阻碍正常人才流动和新合作。
- **无法完全消除：** 市场机会、健康和组织变化可能使退出合理且必要。

### 9.7 联盟背叛或私下建立子联盟

- **利益动机：** 通过私下组合获得比原联盟更高的收益。
- **发生条件：** 子联盟有替代资源，原联盟分配不能满足其参与约束。
- **损害：** 原联盟价值和信任受损。
- **规则：** 明确合作范围、冲突披露、排他事项和允许独立经营的边界。
- **证据：** 合同约定、利益冲突、资源转移和客户交易记录。
- **副作用：** 过度限制私下合作可能违反合理商业自由，也会压制创新。
- **无法完全消除：** 只要存在多个可行联盟，就无法保证成员永远不重新组合。

### 9.8 操纵规则

- **利益动机：** 利用条款漏洞、模糊定义或权限不对称获取利益。
- **发生条件：** 规则只覆盖常见情况，没有处理边界情况。
- **损害：** 规则失去可信度，参与者不断寻找漏洞。
- **规则：** 版本管理、反规避条款、边界案例复核、独立争议处理。
- **证据：** 规则版本、操作日志、利益流向和异常事件。
- **副作用：** 条款越多越复杂，解释空间可能扩大。
- **无法完全消除：** 不可能事先列出所有未来行为。

### 9.9 指标造假

- **利益动机：** 通过提高可考核数字获得奖励。
- **发生条件：** 奖励与单一指标强绑定。
- **损害：** 真实质量和长期价值下降。
- **规则：** 多维绩效、质量门槛、随机审计和长期结果复核。
- **证据：** 独立验收、客户结果、缺陷率、返工率和审计样本。
- **副作用：** 过多指标会导致管理复杂化和目标冲突。
- **无法完全消除：** 指标与真实目标之间始终存在测量误差。

### 9.10 恶意重新谈判

- **利益动机：** 等对方投入不可逆成本后，再要求更高收益或控制权。
- **发生条件：** 关键资产专用化、退出成本高、原合同不完整。
- **损害：** 投资方被锁定，未来投资动力下降。
- **规则：** 预先设定调整触发条件、未来生效、独立估值和退出选择。
- **证据：** 投资时间线、原协议、市场变化、双方通知和估值依据。
- **副作用：** 过度限制重新谈判会使有效的合作调整无法进行。
- **无法完全消除：** 未预见的冲击和新信息仍然可能要求重新协商。

### 9.11 防操纵的共同原则

1. 不把所有参与者假设为诚实。
2. 不把所有行为假设为恶意。
3. 不要求所有信息都公开，只要求关键决策信息可核验。
4. 不用单一指标代替复杂贡献。
5. 不以过度惩罚替代规则设计。
6. 不把合理退出当成背叛。
7. 不把合同写得越长等同于治理越好。
8. 规则必须考虑自身可能被操纵。

## 10. 动态合作机制的方案比较

### 10.1 固定分配

适合：

- 权利和资产边界稳定。
- 未来贡献承诺明确。
- 外部选项变化不大。
- 需要长期投资和可预测性。

失败边界：

- 持续贡献发生重大变化。
- 风险和职责被重新分配。
- 某方获得明显更好的外部选择。
- 原有收益安排已经不满足参与约束。

### 10.2 按贡献分配

适合：

- 贡献可验证。
- 工作和成果可以区分。
- 参与者事先接受贡献计量规则。

失败边界：

- 贡献不可量化。
- 合作存在互补效应。
- 参与者为争取更高份额而争夺可计量任务。
- 长期基础工作被短期产出掩盖。

### 10.3 按绩效分配

适合：

- 绩效结果与真实目标高度一致。
- 质量可以验证。
- 结果可归因。

失败边界：

- 指标可以操纵。
- 长期价值难以测量。
- 团队贡献难以拆分。
- 外部市场变化影响绩效。

### 10.4 固定收益加浮动收益

适合：

- 一部分工作需要稳定报酬。
- 另一部分收益取决于合作结果。
- 风险与贡献可以分开定义。

优点：

- 不必将所有权益都动态调整。
- 可以保留基本参与收益。
- 可以将增量收益与新增贡献关联。

失败边界：

- 基础收益设置过高，削弱努力激励。
- 浮动收益指标不可靠。
- 风险补偿和绩效奖金重复计算。

### 10.5 触发式重新协商

适合：

- 合作周期较长。
- 未来状态不确定。
- 可以识别重大变化事件。

优点：

- 不必频繁重谈所有条款。
- 可以预先规定何时调整。
- 能降低单方临时施压的空间。

失败边界：

- 触发条件模糊。
- 重新谈判权力高度不对称。
- 触发后没有中立评估机制。
- 调整会反复发生，造成预期不稳定。

### 10.6 退出机制

适合：

- 长期合作存在不确定性。
- 参与者拥有不同的替代机会。
- 共同资产能够合理估值和交接。

优点：

- 降低被永久锁定的恐惧。
- 为无法修复的合作关系提供结束路径。
- 提高初始参与意愿。

失败边界：

- 退出价格不合理。
- 一方承担全部转换成本。
- 共同资产无法清晰分割。
- 退出安排诱发策略性威胁。

## 11. 四个场景的合成数据验证

所有数字都是为验证模型而构造的假设数据，不是实际企业、市场或 AI Agent 的统计结果。

### 11.1 案例 A：两个人创业

#### 初始状态

A 提供资金和技术，B 提供劳动和客户资源。

初始联盟价值：

| 项目 | A | B |
|---|---:|---:|
| 独立行动收益 | 60 | 50 |
| 合作总净价值 | 180 | — |
| 合作剩余 | 70 | — |

Shapley Value：

\[
\phi_A=(60+180-50)/2=95
\]

\[
\phi_B=(50+180-60)/2=85
\]

固定平均分配为 90、90，也满足双方参与约束。

#### 一年后

A 的投入没有增加；B 的劳动和客户贡献明显增加；市场环境也变化。

假设：

| 项目 | A | B |
|---|---:|---:|
| 新的外部选项 | 80 | 170 |
| 新的合作总净价值 | 300 | — |
| 合作剩余 | 50 | — |

新的 Shapley Value：

\[
\phi_A=(80+300-170)/2=105
\]

\[
\phi_B=(170+300-80)/2=195
\]

比较不同方案：

| 方案 | A | B | 个体参与约束 |
|---|---:|---:|---|
| 原固定 50/50 | 150 | 150 | B 不满足 |
| Shapley | 105 | 195 | 满足 |
| 等权 Nash Bargaining | 105 | 195 | 满足 |
| 40/60 总收益比例 | 120 | 180 | 满足 |
| 40/60 议价剩余比例 | 100 | 200 | 满足 |

本例中，等权 Nash 与 Shapley 数值相同，是两人 TU 模型下的特殊结果，不应推广为一般等价关系。

Core 条件为：

\[
x_A+x_B=300
\]

\[
x_A\ge80,\quad x_B\ge170
\]

因此：

\[
80\le x_A\le130
\]

\[
170\le x_B\le220
\]

Core 中存在多个可行分配。稳定性并不能单独决定唯一分配。

**案例结论：**

- 外部选项变化可能让原有固定分配不再满足参与约束。
- Shapley、Nash 和贡献比例可能产生不同结果。
- 收益比例不是所有权、知识产权和决策权。
- 如果 B 的新增贡献是持续劳动，可能调整未来劳动报酬，而不必追溯改变 A 已经拥有的技术资产。
- 重新分配前必须先明确原始协议是否将未来贡献变化列为调整条件。

### 11.2 案例 B：三个人合伙经营

假设三人共同经营，C 的持续劳动贡献逐渐减少，但 C 仍保留既有资产或合作权益。

设联盟价值如下：

| 联盟 | 可创造净价值 |
|---|---:|
| A | 70 |
| B | 60 |
| C | 40 |
| AB | 145 |
| AC | 120 |
| BC | 115 |
| ABC | 210 |

大联盟合作剩余：

\[
210-(70+60+40)=40
\]

#### 方案一：固定平均分配

\[
x=(70,70,70)
\]

检查 AB：

\[
70+70=140<145
\]

AB 可以脱离大联盟并将 145 分给两人，使 A、B 都比原来更好。

因此，固定平均分配不在 Core 中。

#### 方案二：按贡献或绩效分配

假设按可验证的贡献指标分配为：

\[
x=(84,84,42)
\]

联盟约束：

- AB：168 ≥ 145。
- AC：126 ≥ 120。
- BC：126 ≥ 115。
- 三人单独收益约束均满足。

该方案位于 Core。

但如果绩效指标容易操纵，C 可能通过夸大工作量或选择容易计量的任务来提高份额。

#### 方案三：Shapley Value

根据全部联盟价值计算：

\[
x=(82.5,75,52.5)
\]

该方案总和为 210，并满足上述联盟约束，因此位于 Core。

#### 方案四：等权 Nash Bargaining

三人的外部选项分别为 70、60、40，剩余价值为 40。

等权分配剩余：

\[
x=(83.33,73.33,53.33)
\]

本例中也满足 Core 约束。

#### 方案五：固定报酬加浮动收益

假设采用：

- A、B 的持续经营职责获得更高报酬。
- C 保留既有权益，但不再获得原有持续劳动报酬。
- 其余价值按合同约定分配。

一个满足本例联盟约束的示意分配为：

\[
x=(90,80,40)
\]

C 恰好达到其外部选项；A、B 的联合收益为 170，高于 AB 的 145。

这不是普遍推荐的比例，而是说明固定权益、持续劳动报酬和剩余收益可以分开设计。

#### 本案例比较

| 方案 | A | B | C | Core 检查 |
|---|---:|---:|---:|---|
| 固定平均 | 70 | 70 | 70 | 不满足 |
| 贡献/绩效 | 84 | 84 | 42 | 满足 |
| Shapley | 82.5 | 75 | 52.5 | 满足 |
| 等权 Nash | 83.33 | 73.33 | 53.33 | 满足 |
| 固定报酬加浮动收益 | 90 | 80 | 40 | 满足 |

**案例结论：**

- 固定平均分配可能无法阻止子联盟退出。
- 贡献分配能反映投入变化，但需要防止指标操纵。
- Shapley 和 Nash 是不同逻辑的分配方法。
- 既有权益与未来劳动报酬应当区分。
- 如果 C 正常退出，必须单独核算退出回购、既得权益和 A/B 新联盟的资产与价值，不能把原大联盟的 210 直接当成退出后的可用资金。

### 11.3 案例 C：多个企业建立合作联盟

参与者：

- S：供应商。
- M：生产商。
- C：渠道商。

假设各联盟价值如下：

| 联盟 | 净价值 |
|---|---:|
| S | 20 |
| M | 30 |
| C | 25 |
| SM | 100 |
| SC | 70 |
| MC | 125 |
| SMC | 150 |

这里假设 M 和 C 可以寻找替代供应来源，所以 MC 联盟的价值可能独立于原供应商而存在。

Shapley Value 计算：

\[
\phi_S\approx34.17
\]

\[
\phi_M\approx66.67
\]

\[
\phi_C\approx49.17
\]

总和为 150。

但 M 与 C 的合计分配：

\[
66.67+49.17=115.84<125
\]

因此 M、C 可以组成更有利的子联盟。

Shapley 分配不在 Core 中。

一个满足所有联盟约束的示意分配是：

\[
x=(25,75,50)
\]

检查：

- S+M：100，满足 SM。
- S+C：75，高于 SC 的 70。
- M+C：125，满足 MC。
- 单人收益均满足各自外部选项。
- 总和为 150。

因此该分配属于 Core。

**案例结论：**

- 企业联盟的收益分配不能只看各方平均边际贡献。
- 子联盟可能通过替代供应商、渠道或技术形成新竞争关系。
- 关键资源控制权和联盟退出能力会改变稳定性。
- 供应链合作需要研究联盟外部性，不能只使用简单的特征函数模型。

### 11.4 案例 D：多个 AI Agent 协作

假设四个 Agent：

- P：任务规划。
- R：资料研究。
- I：任务实施。
- V：独立验证。

它们的 Token 消耗：

| Agent | Token 消耗 |
|---|---:|
| P | 1,000 |
| R | 1,500 |
| I | 8,000 |
| V | 1,200 |
| 合计 | 11,700 |

Token 占比：

| Agent | Token 占比 |
|---|---:|
| P | 8.5% |
| R | 12.8% |
| I | 68.4% |
| V | 10.3% |

假设通过合成的联盟价值评估得到以下任务价值：

| 联盟 | 任务价值 |
|---|---:|
| P | 4 |
| R | 6 |
| I | 18 |
| V | 2 |
| PR | 14 |
| PI | 25 |
| PV | 8 |
| RI | 28 |
| RV | 12 |
| IV | 34 |
| PRI | 48 |
| PRV | 20 |
| PIV | 39 |
| RIV | 47 |
| PRIV | 60 |

按全部联盟的加入顺序计算 Shapley Value：

| Agent | Shapley 价值 | 任务价值占比 |
|---|---:|---:|
| P | 8.75 | 14.6% |
| R | 13.25 | 22.1% |
| I | 29.08 | 48.5% |
| V | 8.92 | 14.9% |

这与 Token 占比明显不同。

注意：这里的 Shapley 数值依赖合成联盟价值，不能当作真实 Agent 的贡献评价。

#### AI Agent 的特殊风险

| 行为 | 具体表现 | 机制 |
|---|---|---|
| 重复劳动 | 多个 Agent 做相同研究或重复实现 | 任务注册、责任边界和重复工作检查 |
| 任务抢占 | Agent 占用任务却不完成 | 任务租约、过期释放、明确交付 |
| 错误隐瞒 | Agent 不报告失败或不确定性 | 独立验收、失败报告不自动等于处罚 |
| 贡献争夺 | 夸大自己的工作或降低他人评价 | 依据最终交付、因果贡献和独立证据 |
| 权限滥用 | Agent 使用超出任务需要的工具权限 | 最小权限、分阶段授权、审计日志 |
| 过度协作 | 讨论和通信成本超过并行收益 | 记录通信成本、延迟和质量增益 |

Agent 的贡献应从以下维度评估：

- 任务是否完成。
- 结果质量是否提升。
- 是否发现关键错误。
- 是否减少后续返工。
- 是否提供可复用信息。
- 是否承担了必要的验证工作。
- Token、算力和时间成本是多少。

Token 消耗属于成本，不是贡献本身。

AgentWorld（2026 年 9 月预印本）在长周期、多角色协作任务中报告：最佳模型任务成功率为 52%，其提出的因果协作效率指标也显示大量 Agent 行动没有直接贡献于最终成功；常见问题包括沟通中断、角色混乱、重复工作和共享计划失效。[17]

MASBench（2026 年 10 月预印本）将部分可观察环境、通信成本和成本效率纳入多 Agent 协作评估，说明不能只统计最终任务得分或 Token 总量。[18]

这些是特定基准上的实验结果，不应推广成所有 AI Agent 系统的固定成功率。

**案例结论：**

AI Agent 合作机制应采用：

- 任务边界。
- 可验证交付。
- 质量评价。
- 独立验收。
- 通信成本。
- 权限约束。
- 失败披露。
- 团队结果与个体责任分离。

不能简单按 Token 数量或任务数量分配贡献。

## 12. 五种专业视角的反方审查

以下为模型化的专业角色审查，不冒充五位外部独立专家。

### 12.1 合作博弈与经济学视角

**攻击：**

- 总价值增加不代表每个人都受益。
- Core 可能为空。
- 外部选项变化可能使原有分配失效。
- Shapley Value 可能被子联盟偏离。
- 外部性可能使特征函数模型失效。

**修正：**

- 分别计算合作价值和外部选项。
- 检查个体理性。
- 检查所有相关子联盟。
- 对联盟外部性使用分区函数。
- 把 Core 当作稳定性检验，而不是分配偏好。

### 12.2 机制设计与激励相容视角

**攻击：**

- 参与者会隐藏信息。
- 贡献指标会被操纵。
- VCG 不等于公平。
- 激励相容、个体理性、效率和预算平衡可能无法同时满足。
- 监督成本可能超过减少的损失。

**修正：**

- 先定义真实目标和可观察信号。
- 区分类型报告与隐藏行动。
- 使用多维指标和独立验收。
- 对无法验证的行为设计合理风险分担，而不是假装能够完全监控。

### 12.3 企业合作与组织治理视角

**攻击：**

- 股权、收益权、工资和控制权混在一起。
- 创业者的角色变化不等于原有股权自动变化。
- 关键技术和客户资源可能造成锁定。
- 过度强调短期贡献会伤害长期投资。

**修正：**

- 区分既得权益、持续报酬和浮动收益。
- 明确资产和控制权。
- 为关键专用投资设计退出与补偿。
- 不对所有贡献采用同一个权重。

### 12.4 动态博弈与长期合作视角

**攻击：**

- 未来收益未必足够重要。
- 偏离可能无法被发现。
- 惩罚可能不可信。
- 误判会形成惩罚循环。
- 重新谈判可能破坏原有承诺。

**修正：**

- 检查折现因子与监测精度。
- 设计分级、可逆和可复核的制裁。
- 允许合理的状态调整。
- 把可信承诺和重新谈判程序一起设计。

### 12.5 反方与失败机制审计

**攻击：**

- 参与者可能串通。
- 强势成员可能控制监督机构。
- 退出成本可能成为胁迫工具。
- 规则复杂度可能创造新的漏洞。
- 贡献审计可能被用来排斥难以量化的劳动。
- 动态调整可能让合作永远无法稳定。

**修正：**

- 监督机构本身也需要约束。
- 重要决定采用独立复核和利益冲突披露。
- 保留退出和申诉。
- 只为真实风险增加规则。
- 定期检查制度是否产生新的反向激励。

### 12.6 反方审查后的修订结论

| 原有假设 | 反方结果 | 修订 |
|---|---|---|
| 公平分配可以维持合作 | 不成立 | 必须独立检查 IR、Core、IC |
| 贡献可以准确量化 | 不成立 | 采用多维贡献和不确定性记录 |
| Shapley 能解决收益分配 | 不成立 | 只作为边际贡献工具 |
| 有合同就不会背叛 | 不成立 | 合同与关系契约、监督、退出结合 |
| 监督越严格越稳定 | 不成立 | 监测收益必须高于成本与副作用 |
| 动态调整一定优于固定分配 | 不成立 | 先固定可稳定的权利，再调整必要的未来收益 |
| 所有人都能被完全激励 | 不成立 | 明确不可观察、不可验证和不可实现的目标 |
| 退出机制必然保护弱势方 | 不成立 | 还需要公平估值、流动性和资产可携带性 |

## 13. 最小充分的通用合作机制架构

前述候选十个模块不必全部作为独立模块存在。

综合理论、场景和反例后，保留三个一级层次、六个核心模块。

### 第一层：合作价值创造

**模块 1：参与者、合作边界和外部选项**

- 谁参与？
- 谁可以退出？
- 哪些活动属于共同合作？
- 哪些资源仍由个人或企业独立控制？
- 各方独立行动可以创造什么价值？

**模块 2：资源组合、能力互补和共同价值**

- 各方提供什么资源和能力？
- 组合后新增什么价值？
- 是否存在协调、转换和监督成本？
- 是否产生第三方外部性？
- 是否存在更有利的替代联盟？

### 第二层：合作价值分配

**模块 3：权利、责任、贡献和风险**

- 所有权归属。
- 决策权和控制权。
- 资源使用权。
- 贡献责任。
- 风险承担。
- 退出和转让权。

**模块 4：收益与价值分配**

- 基础报酬。
- 资本收益。
- 风险补偿。
- 浮动收益。
- 共同增量价值。
- Shapley、Nash、Core 和 Nucleolus 等候选分析工具。

### 第三层：长期合作稳定

**模块 5：激励、信息和监督**

- 激励相容。
- 信息披露。
- 贡献核验。
- 绩效和质量评价。
- 反操纵。
- 责任与补救。

**模块 6：治理、动态调整和退出**

- 重大事项决策。
- 定期复核。
- 事件触发调整。
- 重新协商。
- 争议处理。
- 回购、退出和联盟解散。

### 13.1 三层之间的约束关系

| 层次 | 必须回答 | 失败后果 |
|---|---|---|
| 价值创造 | 是否有足够的真实增量价值？ | 合作没有必要 |
| 价值分配 | 各方是否愿意加入并接受权利安排？ | 无法启动或个人退出 |
| 长期稳定 | 是否能抵抗联盟偏离和策略操纵？ | 合作无法持续 |

### 13.2 四道贯穿式稳定性检查

1. **个体理性：** 每个必要参与者是否愿意加入和继续？
2. **联盟稳定：** 是否有可行子联盟能获得更高收益？
3. **激励相容：** 诚实披露和履约是否优于操纵？
4. **动态可执行：** 变化、争议和退出是否有可信规则？

这四项是检查条件，不是新增的组织层级。

### 13.3 最小机制流程

1. 明确合作边界和独立行动基准。
2. 估计共同价值和子联盟价值。
3. 分别定义资产、权利、责任、贡献和风险。
4. 选择收益分配方案。
5. 检查个人参与约束与 Core。
6. 检查信息披露和激励相容。
7. 设计监测、纠偏和争议处理。
8. 设计复核、重新协商和退出规则。
9. 在关键状态变化后重新评估。

### 13.4 何时不应该合作？

合作不是天然优于竞争。

以下情况应考虑独立行动、市场交易、模块化合作或放弃合作：

- 合作没有产生足够增量价值。
- 协调成本超过协同收益。
- 关键资源控制导致无法接受的依赖。
- 各方外部选项与议价权严重不对称，且无法通过规则改善。
- Core 长期为空，且无法改变联盟价值结构。
- 关键行为无法验证，监督成本又过高。
- 合作需要承担的风险超过各方接受范围。
- 共享资源会损害核心知识产权或竞争优势。

**合理的合作机制不仅要回答怎样合作，也必须能够识别什么时候不应该合作。**

## 14. 本轮研究的综合结论

### 14.1 最重要的因果关系

1. 资源互补可能创造合作增量。
2. 增量必须覆盖机会成本、协调成本和风险。
3. 个体参与约束决定成员是否愿意加入。
4. Core 检查子联盟能否通过偏离改善收益。
5. 激励相容决定信息和行为是否容易被操纵。
6. 重复博弈和关系契约决定长期承诺是否可信。
7. 产权和控制权决定关键投资后的议价能力。
8. 动态治理决定环境变化后是否能调整而不破坏整个合作关系。

### 14.2 本轮综合提出的设计原则

**原则一：先创造价值，再讨论分配。**

不能先确定比例，再倒推合作价值。

**原则二：分配权利与分配收益分开。**

贡献、风险、所有权、控制权和劳动报酬不应使用同一权重。

**原则三：先保障参与约束，再检查联盟稳定。**

一个人愿意留下，不代表整个联盟不会被子联盟瓦解。

**原则四：不要假设真实贡献可以完全观察。**

要把测量误差、信息不对称和策略性行为放入设计。

**原则五：固定既得权利，动态调整必要的未来收益。**

避免每次贡献变化都重新打开所有历史权益。

**原则六：监督与惩罚必须可复核、可恢复。**

不要让小错误演变成长期报复。

**原则七：关键资产和退出能力必须在合作开始前设计。**

不要等到形成依赖关系后才讨论控制权。

**原则八：允许合作关系正常结束。**

有序退出比无法执行的永久承诺更可信。

### 14.3 已解决与仍未解决的问题

| 问题 | 本轮状态 |
|---|---|
| 为什么公平分配不一定带来长期合作 | 已建立理论区分 |

## 16. 最终定位

R1 的成果是：

**静态资源分配与公平选择机制研究。**

R2 的成果是：

**动态合作价值、利益分配、激励相容、联盟稳定、控制权和长期治理的综合机制研究。**

两者共同形成：

**合作机制 = 价值创造 + 权利与收益分配 + 长期稳定治理。**

其中：

- 价值创造回答为什么合作。
- 权利和收益分配回答怎样合作。
- 激励、监督和治理回答怎样持续合作。
- 动态调整和退出回答条件变化后怎样继续或结束合作。

这套模型可以用于个人合伙、团队、企业联盟、供应链、共同资源治理以及多 AI Agent 协作。

它不是保证所有人永远合作的公式，而是一套能够识别合作价值、发现不稳定因素、设计激励和治理规则，并判断何时应该调整或退出的通用分析框架。
