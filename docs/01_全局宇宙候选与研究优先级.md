# 全局宇宙候选与研究优先级（R2）

> **唯一职责**：登记已有资产和开放式研究候选，判断独立性，并为具体研究任务排程；不保存各领域的第二份权威正文。  
> **稳定入口**：`docs/01_全局宇宙候选与研究优先级.md`。全局边界以 [00 地图](00_知识宇宙目录与跨域关联.md) 为准，知识与证据身份以 [知识原子与关系模型](AI原生知识系统/16_知识原子、标准知识与关系模型.md) 为准。  
> **版本状态**：2026-11-22，R2 / REVIEW。覆盖审计与研究排程提案；不是完整世界知识清单，不代表候选机制已经得到因果验证。  
> **维护 Owner**：Global Map 登记维护角色；具体正文、结果及执行 Owner 仍由相应领域决定。新增候选先查本表和领域 Registry，再决定增补现有节点、建立引用或申请独立研究。

## 1. 先说明“重要”对什么而言

本期排序范围固定为：**使 VizTell 跨域研究设施可执行，并检验 A 互联网注意力竞争、B 技术成功但采用/商业结果不足、C 假设性软件创业跨维问题**。没有任何行在评价一个人的价值，也没有把个人财富、健康或艺术的价值降低为当前项目的相关性。

“存在独立学科价值”“当前要研究它”“现在应该创建目录”是三个不同决定。下文每行保留：对象类型、独立性判断、正文 Owner、基础/决策/风险价值及本期优先级；优先级改变不改稳定 ID。

遵守 [知识价值、学习投入与消费路由](AI原生知识系统/18_知识价值、学习投入与消费路由.md)：本表的 100 分只为 **研究排程** 服务，不能替代 `Epistemic Gate`、个人学习投入、工具消费路由或行动授权。高研究价值且证据薄弱的正确下一步是验证；不能把它直接当真或投入生产执行。

### 分类标签

| 标签 | 含义 | 本轮物理处理 |
|---|---|---|
| EXISTING | 已存在、继续保留的宇宙或独立知识资产 | 只补导航与交叉引用，不重排其编号 |
| UNIVERSE_CANDIDATE | 有独立研究价值，建议保留独立宇宙候选身份 | 先登记；满足准入且有真实正文后才建目录 |
| DOMAIN | 专业范围或现有资产内的子领域 | 路由现有 Owner；未有 Owner 时显式待归属 |
| AXIS | 时间、尺度、反事实等横向推理坐标或算子 | 复用多维协议，不建同名知识库 |
| FACTOR_MECHANISM | 条件变量、关系或作用过程 | 进入因素/关系索引及领域正文 |
| CASE_COLLECTION | 共享事实源上的案例与对照集合 | 保存案例身份，领域分析分别引用 |
| DEFER | 当前不值得独立维护，或边界不成立 | 保留原因与重启条件，不建空目录 |

候选表里的“高/中/低”是**排程粗筛**：基础值看解释/复用潜力，决策值看本期 A/B/C，R表示相关问题中损失主题的**风险召回关注度**，不是已知现实暴露或第5节的数值风险分。粗筛置信度统一为低；无当前任务或暴露依据不能从“高”直接触发风险门，当前低也不等于该领域永远低风险。不得从三个字反推精确总分。P级均为暂定，进入执行队列前用同一目标与风险对象按第5节细评。

### 3.8 仍然开放的遗漏清单

本表有广度但没有“穷尽世界”的证据。后续通过以下入口继续发现，新增前先记录具体缺口而非扩标题：

- 非西方/跨文化概念与研究传统，避免以单一语言的分类充当全世界分类。
- 感觉、身体技能、隐性经验、工艺、实践者知识，不能只收能写成抽象命题的知识。
- 地区、法域、语言、时间和群体代表性；同一因素在不同群体的测量是否等价。
- 残障、可达性、照护、性别与生命周期差异等情境；目前通过人/制度/健康等领域路由，未逐项研究。
- 海洋、宇宙空间、边缘生态与极端环境等自然专业分支；先作为 VZC-002/003 的覆盖缺口，不即刻建目录。
- 新兴技术、新型组织、公共品、全球性风险与相互依赖；不能因“新兴”自动高排。
- 规范性、诠释性、形式证明和经验因果知识的不同有效性标准；共同要求可追溯，不要求采用同一种实验。

新增行只需：`新问题 → 查已有 Owner/别名 → 说明缺口 → 对象类型 → 本期价值 → 首验/暂缓理由`。每次 Focused Run 结束时顺带记录真实暴露的遗漏；不得把每次遗漏审计变成全库重建。

## 5. 研究排程的 100 分模型

### 5.1 输入、分量与计算

每次评分必须有 `scope_id、具体问题、目标/结果、决策时限、可用预算、已有状态、当前暴露、评审日期、评审者、来源或假设`。同时明确`risk_subject / decision_at_risk / exposure_basis`：风险由谁承担、哪个决定可能受损、有哪些相关暴露依据。只有目标、风险对象和边界可比的profile才能横向比较总分；历史案例或假想现实损失不能混进当前研究队列。领域名本身不足以评分。

每项 `s_i ∈ {0,1,2,3,4}`：0是**经判断确实没有/不相关**，不是未知；4是当前范围内很强，不是世界最高。总分：

\[
S=\sum_i w_i\frac{s_i}{4}=B+D+R+Q,\qquad \sum_i w_i=100
\]

| 字段（固定顺序） | 权重 | 0 / 2 / 4 的判断锚点 |
|---|---:|---|
| B1 解释范围 | 12 | 无明确现象 / 一类清楚现象 / 多类明确现象且能区分竞争解释；泛泛可套用不算4 |
| B2 跨场景迁移 | 10 | 无迁移 / 相邻情境可复用 / 多种不同情境有清楚迁移条件；类比不能充当证明 |
| B3 前置依赖 | 8 | 不阻塞其他任务 / 支撑一个重要任务 / 是多个高价值任务的必要接口；链接数量不算依赖 |
| D1 结果影响 | 12 | 对当前结果无影响 / 影响局部表现 / 条件成立时足以改变主要结果；需写结果与量纲 |
| D2 行动敏感性 | 12 | 不会改变选择 / 改变局部配置 / 可能改变继续/暂停或主要方案；区别于结果幅度 |
| D3 使用频率 | 6 | 本期极少/无复现 / 多次但非普遍 / 本期反复遇到；不是历史热度 |
| R1 损失严重度 | 12 | 无相关损失 / 可控且有边界 / 重大且不可承受后果；需有相关暴露 |
| R2 不可逆/恢复困难 | 8 | 可低成本回滚 / 恢复昂贵但可行 / 基本不可恢复或后果极长期 |
| R3 级联/共同失效 | 5 | 隔离在局部 / 影响多个相关节点 / 可能跨系统扩散或共同失效 |
| Q1 时间敏感性 | 5 | 无窗口 / 近期影响选择 / 不及时研究会错失当前关键决策窗口 |
| Q2 可改变决定的知识缺口 | 6 | 已足够回答 / 有局部未知 / 关键未知足以翻转行动；“全未知”不自动高分 |
| Q3 可行性与成本 | 4 | 当前无法有意义验证 / 有成本可做 / 可用少量可靠证据/试验显著收敛且维护成本低 |

1、3分别表示介于相邻锚点的可解释情况。B、D、R、Q 的满分分别为30、30、25、15；报告时保留向量，不能只给总分。B2 跨场景与 B3 前置依赖需要分别给理由，R1 后果严重度与 R3 传播范围也不能同一事实重复刷分。

本模型是待校准的项目规则，不是公认心理量表、机制真值、概率或成功率。风险研究可参考 NIST 将影响、可能性与不确定性分开记录的思路，但本表权重、阈值和风险门属于 VizTell 的设计，不是 NIST 标准公式。[S2]

### 5.2 证据、置信度与缺失

- `claim_status` 继续使用 AI 知识系统的 `verified_for_scope / supported / weak_evidence / contested / unverified_claim / falsified / obsolete / unknown` 等状态；每条命题按其适用范围判断，不给整个宇宙盖“已证实”章。
- `rating_confidence` 是“为什么这样排程”的信心，至少低/中/高；`evidence_confidence` 是“机制成立”的信心。它们可能不同。评级置信度高需有明确目标、可比信息及独立复核，不能因公式算得出小数就标高。
- **不将证据成熟度乘以总分**。低证据高损失应先核验；同时，Epistemic Gate 未过不能升级为现实行动建议。
- 缺失项记 `?` 并保留 `[0,4]`，或有依据的更窄区间；总分报告 `[S_min,S_max]`。不能填0、2或重归一化已知权重。覆盖率是已知评分权重/100，不是“科学证据覆盖率”。
- 区间跨档则 `priority_provisional`；先补最可能改变分档/行动的信息。多个节点区间重叠时可同组，不制造精确先后。
- 没有实际暴露信息时，不得伪造风险概率。写明 `exposure_unknown`；若存在可信严重后果路径且不确定性阻碍安全行动，先走风险核验门。

### 5.3 P0—P3 与独立风险门

| 档位 | 默认分段 | 含义与调度 |
|---|---|---|
| P0 | S≥85，或基础前置/风险门覆盖 | 必须先建立的最低研究规范，或必须先澄清/控制的相关硬风险；不等于深研整个领域 |
| P1 | 65≤S<85 | 高价值系统研究，按可行验证与依赖顺序推进 |
| P2 | 45≤S<65 | 专业/场景任务，在触发条件和预算合适时推进 |
| P3 | S<45 | 保留索引、案例或候选；当前不主动扩充正文 |

所有阈值都是本期暂定调度规则。基础门须写清“哪个当前任务被哪个未建立接口阻塞”，不能仅说“这个领域很基础”；本期仅指对象/Owner、测量/证据、停止/回写等最低接口。接口验收后退出 P0 待办，不永久挂最高优先。

**风险硬门**：相关暴露 + 可解释的重大不可逆/灾难性/级联损失路径，或关键不确定性足以阻止安全行动 → P0 风险核验/保护性验证，不受低频或平均分压低。记录 `trigger、exposure、loss_path、evidence/unknown、owner、时限、解除条件`。只在取得安全边界、隔离/可恢复性证据或确认无相关暴露后解除。它提升的是调查与保护优先级，**不是宣布风险必然发生，也不是授权不可逆行动**。

例如低频数据彻底丢失风险可以优先于常见体验优化；但无相关任务时，不因能想象全世界灾难而冻结全部研究。若风险核验超预算，明确暂停相关行动及下一证据，不扩成无界灾难研究。

这里的缺失区间是**评分允许范围**，不是统计置信区间。若未来有分布和样本，另报告真正统计区间，不混名。

进入队列前对关键权重做相对 ±20% 变化并重新归一化到100；保留风险门。若合理变动就改变档位/首选，则记录排序不稳，优先用同一组或先补信息。无需在每次小改动时重算全表：只在目标、时限、证据、暴露、前置依赖或成本变化时重评受影响节点。

## 7. 维护、迁移与继续研究

1. **唯一正文**：登记表只写边界、路由、排程和状态，不复制某宇宙完整理论。商业 U01—U27、营销 D01—D24、方法28类、C01—C30及既有知识身份保持不变。
2. **稳定 ID**：`VZU`=既有资产导航、`VZC`=全局候选、`VZR`=具体研究任务。改名保留别名；合并记录`superseded_by`，禁止把旧 ID静默赋给新含义。这些是全局索引身份，不是领域机器 Schema 的替代。
3. **复用外部系统**：AI人生的十维/因素记录仅作链接与契约映射；不复制 15 类或 144 因素表，不迁移结果Owner，不写入个人事实。跨库同名先核定义、范围和观测方式，不自动 exactMatch。[S3]
4. **分级状态**：候选状态、研究进展、证据状态和排程P级分开；研究已经运行不等于结论成立。后续状态转移以 [多维推理与节点续研协议](思维与方法宇宙/03_跨宇宙多维推理与节点续研协议.md) 为准。
5. **差量重评**：目标、数据、风险、法域、技术条件或维护成本发生变化，才重评受影响条目；更新时写清改变的是边界、证据、优先级还是结论。
6. **停止与回归**：已有资产能回答就引用结束；重复名词、无可验证问题、超预算或缺关键数据则暂停并记触发器。真实反例、接口冲突、归属变更或指标口径变化触发受影响节点回归，不自动全库重测。
