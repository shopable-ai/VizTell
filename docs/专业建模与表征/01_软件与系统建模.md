# 软件与系统建模

> 本文件保存从 `思维与方法宇宙` 主清单中移出的软件、系统、业务流程与架构专业建模知识。
>
> 这些对象有明确的专业用途，但不再与第一性原理、六顶思考帽、问题树、设计思维等作为同粒度“思维方法”平铺统计。

## 一、先区分“开发环节”和“建模表示”

软件项目可能经历：

> 需求理解 → 方案设计 → 架构设计 → 详细设计 → 开发 → 测试 → 部署 → 运维

组件图、序列图、部署图等可能在其中若干阶段被使用，但它们**不是开发阶段本身**。

更准确的关系是：

> 开发 / 设计活动 → 选择建模体系 → 选择适合的问题视角 → 生成某一种图或模型。

例如组件图主要回答“系统由哪些可替换或可部署的软件组件构成、组件如何依赖或提供接口”；序列图主要回答“多个参与者或对象按时间顺序怎样交换消息”。

## 二、UML｜统一建模语言

UML（Unified Modeling Language）属于专业建模语言，而不是一个单一思维模型。

### 结构建模

- 类图（Class Diagram）
- 对象图（Object Diagram）
- 组件图（Component Diagram）
- 组合结构图（Composite Structure Diagram）
- 包图（Package Diagram）
- 部署图（Deployment Diagram）

### 行为建模

- 用例建模 / 用例图（Use Case Modeling / Use Case Diagram）
- 活动图（Activity Diagram）
- 状态机图（State Machine Diagram）

### 交互建模

- 序列图 / 时序图（Sequence Diagram）
- 通信图（Communication Diagram）
- 交互概览图（Interaction Overview Diagram）
- 定时图（Timing Diagram）

### 名称校准

“时序图”在中文软件工程语境中经常指 Sequence Diagram。为了避免与 UML 中独立存在的 Timing Diagram 混淆，本知识库统一写作：

- **序列图 / 时序图（Sequence Diagram）**
- **定时图（Timing Diagram）**

二者不得合并为同一条目。

## 三、SysML｜系统建模语言

SysML（Systems Modeling Language）面向系统工程，覆盖需求、结构、行为和约束等不同视角。

### 当前重点图类型

- 块定义图（Block Definition Diagram, BDD）
- 内部块图（Internal Block Diagram, IBD）
- 需求图（Requirement Diagram）
- 参数图（Parametric Diagram）

这些属于 SysML 体系下的专业子知识，不作为四种独立“通用思维方法”回填主宇宙。

## 四、C4｜软件架构分层表达

C4 是面向软件架构沟通的分层模型体系。

### 核心视图

- 系统上下文图（C4 System Context Diagram）
- 容器图（C4 Container Diagram）
- 组件图（C4 Component Diagram）
- 代码层视图（Code-level View，按需）

### 辅助视图

- 动态图（C4 Dynamic Diagram）
- 部署图（C4 Deployment Diagram）

注意：**C4 组件图与 UML 组件图不是同一个建模体系中的同一种图。** 名称相似时必须带体系上下文检索。

## 五、流程、功能与系统结构建模

### 业务与过程

- 业务流程模型与标记（Business Process Model and Notation, BPMN）
- 数据流图（Data Flow Diagram, DFD）

### 功能建模

- IDEF0 功能建模（IDEF0 Functional Modeling）
- 功能流方框图（Functional Flow Block Diagram, FFBD）

### 关系、依赖与接口结构

- N² 图 / N2 图（N-Squared Diagram）
- 设计结构矩阵（Design Structure Matrix, DSM）
- 系统上下文图（System Context Diagram）

## 六、企业与架构建模

- ArchiMate 企业架构建模（ArchiMate）

这类知识主要服务于企业架构、业务—应用—技术关系和系统结构表达，不作为通用思维框架处理。

## 七、选择图，而不是记图

选择建模表示时优先从问题出发：

| 想回答的问题 | 优先考虑 |
|---|---|
| 系统与外部参与者的边界是什么？ | 系统上下文图 / C4 System Context |
| 软件由哪些主要运行单元构成？ | C4 容器图 |
| 一个软件单元内部由哪些组件构成？ | C4 组件图；必要时 UML 组件图 |
| 多个对象怎样按时间顺序交互？ | 序列图 / 时序图 |
| 状态如何迁移？ | 状态机图 |
| 活动、分支与并发如何流动？ | 活动图 / BPMN（取决于语境） |
| 软件如何部署到运行环境？ | UML 部署图 / C4 部署图 |
| 系统块之间如何连接？ | SysML IBD |
| 需求与系统结构怎样关联？ | SysML 需求相关视图 |
| 功能怎样分解和连接？ | IDEF0 / FFBD |
| 模块之间的依赖密度怎样？ | DSM / N² 图 |

因此，本目录的使用目标不是“把所有图都学会”，而是：

> **先判断要表达和推理的问题，再选择具有对应语义的专业表示。**
