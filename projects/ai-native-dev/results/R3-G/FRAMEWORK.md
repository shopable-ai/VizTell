## 1. 多维分类（不是13个平行逻辑类别）
| 一级视图 | 二级模式/操作 | 含义 |
|---|---|---|
| 逻辑推断 | 演绎、归纳、溯因 | 必然结论、经验概括、解释假设，证据义务不同 |
| 推导方向 | 条件→结果（预测）；目标→必要条件；失败→候选原因 | 分别回答会发生什么、必须满足什么、为什么可能发生 |
| 对象与关系分析 | 分解、抽象、类比、组合、系统关系/反馈 | 找组成与边界、共性、迁移、交互、循环依赖；分解和抽象是认知操作，不宣称是新形式逻辑 |
| 探索与反例 | 场景、边界、对抗、反事实、时间演化 | 展开正常/异常、极限、破坏条件、替代假设、长期变化 |
| 因果与证据 | 因果分析、证据审查、竞争假设比较 | 区分预测、解释和证实，明确证据适用范围 |
| 约束与价值决策 | 约束推理、价值权衡、候选比较/裁决 | 可行性、必要性、冲突、成本收益和风险；不是纯逻辑推断 |
保留原13模式：正向归条件预测；逆向拆目标逆推与失败溯因；因果/证据归证据分析；对抗/反事实/场景/边界/时间演化归探索；类比/组合归对象关系；约束/价值归决策。另将抽象、分解、综合列为候选认知操作，以免缺少从复杂问题到模型的能力，但不与演绎归纳强行同级。

## 2. 理解推理的接口
每个方法应能说明所解决的未知、所需前提、输入对象、推断性质、可产生的结果、反例、停止/回退、证据要求。信息检索用于获得证据，代码工具用于执行，专家角色提供视角；三者不是推理模式。模型输出的解释也不是实际事实。

## 3. 组合与选择（方法层候选）
| 任务性质 | 最小推理组合 | 不应发生 |
|---|---|---|
| 理解目标/需求 | 分解与场景→目标逆推→约束→必要性/证据 | 一种可行方案当必要条件 |
| 发现遗漏/风险 | 场景与组合→边界/对抗→价值筛选 | 无限枚举、把所有猜想当需求 |
| 理解系统 | 抽象/分解→关系与时间→条件预测 | 用结构图替代运行逻辑 |
| 诊断失败 | 溯因→竞争解释→可证伪预测→因果证据 | 相关或自信当根因 |
| 选择方案 | 硬约束→候选比较→反事实/权衡→决策 | 评分抵消硬性约束 |
| 审查结论 | 证据审查→反例→更新/保留未知 | 自评高分当真实验证 |
组合可迭代或按需并行，不能证明完备。停止由“新判断能否改变目标、方案、风险、证据或后续任务”决定。需要人工决策、外部事实或真实实验时保留待证。

## 4. 核心边界
- 目标逆推的必要性需要 G⇒条件 的依据或已限定的设计空间；某种实现充分不代表必要。
- 溯因是假设，归纳有样本边界，演绎依赖前提正确及推理有效。
- 反事实预测依赖模型和假设；受控实验也只能支持特定环境。
- 分解和综合互补，过度拆分会丢失系统交互。
- 推理方法用于各阶段和 C/H/I，不是固定工作流；D 表达知识对象，G 操作和判断对象。

## 5. F2：按认知任务选择推理及组合

| 认知任务 | 优先方法 | 输出性质 |
|---|---|---|
| 从规则和已知条件得出结果 | 演绎 | 在前提有效及逻辑有效时的结论 |
| 从样本寻找共性 | 归纳 | 有范围的概括或统计判断 |
| 观察到异常，寻找原因 | 溯因 | 候选解释及可区别它们的条件 |
| 由目标发现必要前提 | 逆向/目标反推 | 条件与候选方案，不自动成为必需 |
| 理解复杂系统 | 分解、综合、抽象、系统推演 | 子对象、关系与交互 |
| 探索替代和边界 | 反事实、情景、类比、组合 | 假设空间、边界、预测 |
| 冲突与方案选择 | 约束筛选、价值权衡、比较 | 可行方案及取舍 |
| 质疑和收敛 | 对抗、反例、证据核查 | 否决、限定或保留结论 |

SEP Abduction（https://plato.stanford.edu/entries/abduction/，2025-06-18修订，本轮查阅）区分解释性推断与逻辑必然；生成解释和以解释优势支持假设也有区别。其支持溯因不自动真值保持；上表的工程路由为候选归纳。

**组合原则：** 目标/疑问→选一类足以产生所需结果的方法→显式区分候选、前提与推断→用不同方向寻找反例或竞争解释→不满足时修正或标记未知。溯因生成候选→演绎推出可区分预期→依据可信观察进行更新；本轮只研究组合，不进行观察实验。抽象反例：P⇒Q 且 Q 成立，不能推出 P，另有 R⇒Q；这类肯定后件谬误可同时破坏根因推理和需求逆推。停止于新增推理不能改变判断、关键分歧已明确或需要外部信息时，不以循环次数称深度。

## R1 深化：原13种模式的推理操作、前提与结论强度

13种阅读模式保留，不能冒称13种彼此排斥的逻辑推断。正/逆向属于方向；演绎/归纳/溯因是结论依据；场景、组合等是探索组织；约束/价值是决策问题。一次工作可组合多种类型。

| 原模式 | 必要输入与思路 | 产出与结论边界/停止 |
|---|---|---|
| 正向 | 前置、规则、事件→推演后果 | 条件化结果；规则未知则不宣称必然 |
| 逆向 | 目标或异常→寻找可能前置/解释 | 候选必要条件或原因；按C排除替代、按因果证据判定 |
| 因果 | 原因候选、时间/机制、混杂因素、证据 | 可区别的解释与支持强度；相关性非因果 |
| 对抗 | 当前主张、允许边界、失败目标→搜索反例 | 一个有效反例足以否定相应全称主张；没有找到不证明完备 |
| 反事实 | 明确观察事实、替换条件与因果假设 | 在假设下对未发生结果的比较；无可识别依据则保留未知 |
| 类比 | 源与目标对象、关系映射及差异 | 候选迁移方法；仅相似表面不支持结论 |
| 组合 | 因素域、约束、交互强度 | 有界有效组合和关注交互；按A/H说明未覆盖区域 |
| 约束 | 硬条件、资源、相容关系 | 可行集合或矛盾；不以偏好抵消禁止条件 |
| 场景 | 主体、目标、状态、触发 | 正常/替代/异常/恢复候选；非所有路径已证明 |
| 边界 | 域、临界条件、不变量 | 内外/等于/缺失/极限时的判别义务；未知阈值不捏造 |
| 价值 | 目标、受益方、代价、备选及不确定性 | 权衡、非劣候选或裁决；区分事实与主观权重 |
| 证据 | 待支持主张、来源/版本/范围、反证 | 支持、反驳、不可判定；不以文本数量或自信为证据 |
| 时间演化 | 初始状态、变化规则、时序、外部条件 | 路径、反馈、累积与失效假设；无未来证据不宣称已发生 |

### 方法选择与组合

未知的是事实→先K检索与来源检查；目标是否需要某条件→C逆向+反例；现象为什么发生→溯因提出竞争解释、演绎预测各解释不同后果、再求能区分的证据；何种方案可行→约束筛选后评价价值；复杂状态→分解+正向+组合+边界；审查全称主张→对抗寻找反例、证据确认。每步记录可解释结论及关键依据即可，不要求暴露完整思维过程。

演绎在前提为真且形式有效时保证结论；归纳及溯因超出前提，可能因新证据撤回。用先验、似然与后验刻画不确定性时，证据来源和相关性需显式处理；重复同一来源不等于独立似然，无法估计时不造精确概率。观察条件下 P(Y|X) 一般不等于干预 X 的结果；反事实依赖结构假设。可能性、可行性、必要性、充分性、已证实事实、授权选择是六种不同结果，不能沿链升级。

抽象反例：P→Q，观察Q；P与另一原因R均可产生Q，逆向得到的是候选而非P的证明。若增加独立事实¬P，应撤销P解释而非忽略证据。另一反例：从有限样本全为Q不能演绎所有对象Q；适用范围与抽样条件必须保存。

来源：https://plato.stanford.edu/entries/abduction/ （本轮核对公开条目，区分三类推断、非单调性）；C的必要性与H的审计边界。表中路由和反例是工程综合，尚未完成完整形式逻辑、因果识别和不确定性理论的专项审查。

## R1.1 裁决：推理的正交轴、因果识别与证据义务

保留13种原入口，不将它们当作同类逻辑。一次推理可同时采用不同轴上的方法。

| 轴 | 方法/操作 | 证据义务和失败边界 |
|---|---|---|
| 推断关系 | 演绎、经验归纳、溯因 | 演绎需有效推理及真实前提；经验归纳依抽样/分布/外推；溯因产出竞争解释，非确认原因。数学归纳是演绎证明技术，不是经验归纳 |
| 查询方向 | 条件→后果；目标→必要条件；结果→候选解释 | 逆向不等于逆蕴含；必要性见C；一个充分解释不能排除其他 |
| 认知操作 | 抽象、分解、组合、类比、系统关系 | 保留当前性质和假设；相似性产生迁移假设，不证明相同 |
| 探索策略 | 场景、边界、对抗、组合、时间演化、一般假设变化 | 明确允许域、目标性质和覆盖范围；反例须合法；无发现不证明完备 |
| 认识评价 | 来源追溯、证据质量、概率更新、可证伪性 | 同源重复不算独立证据；没有校准不输出伪精确置信度 |
| 决策方法 | 约束满足、优化、价值权衡、信息价值 | 可行不等于最优；硬约束先于偏好；权重及风险承受需有依据 |

### 因果：从猜想走向可识别结论

Pearl 2010, An Introduction to Causal Inference（https://pmc.ncbi.nlm.nih.gov/articles/PMC2836213/，公开正文摘要、§1–2及方法导航）区分观察关联和干预，强调数据之外的因果假设及先识别后估计。借此建立三种主张：预测P(Y|X)；干预P(Y|do(X))；给定已发生观测及结构机制的个体反事实。一般“如果换条件会怎样”的假设推演不必声称已具备严格反事实识别。

自构反例：U为均匀二元变量。模型甲 X=U,Y=U；模型乙 X=U,Y=X。两者观察分布均为X=Y，各取0/1的概率相等。干预do(X=1)后甲Y仍由U决定，乙Y恒1。即使观察样本无限也不能只凭相同分布选出正确机制。先陈述因果假设、变量与选择过程，检查混杂、共同原因、选择偏差、碰撞变量（不能机械控制全部变量）、数据与目标场景的可迁移性；若多种符合现有证据的模型对干预给出不同答案，则当前不可识别。识别之后才谈估计误差；机制证据与统计数据需区分，不能以模型自信填空。

### 证据、组合和停止

概率更新需区分先验、似然与后验；多个证据应按联合似然处理，只有条件独立等适当假设下才分解相乘。同一来源被三篇文档转述不是三份独立样本。若无法给出可解释概率，只报告方向性支持、反驳、条件和缺口。先选能回答当前未知的最小方法组合：目标不清→C的解释比较及反例；因果未知→溯因生成解释、演绎区别预测、研究可区分证据；复杂组合→A/D的条件和模型、H的组合审计；价值权衡→可行性筛选与有权裁决。停止于当前问题有相称证据、进一步信息不会改变决策或已无法合法取得；高影响未知不能以成本或重复分析强行关闭。理论有效、模型推导有效、经验适用与事实确认分别标记。

## R1.2 纵向样本 · 目标逆向推理 → 必要条件发现

**独立研究问题：** 给定一个希望达到的结果，在尚未选定方案时，怎样发现成功不能缺少的条件、找到尚未识别的障碍，并把它们正确转成条件化义务，而不是把想到的一种实现当作必须功能？归属04推理与决策（G）；C维护需求语义、义务分配及验收转换。B给边语义，D表达模型，H做反方审查，07提供领域知识，K维护主张证据。不是需求执行流程或软件开发任务。

### 1. 先理解要判断的对象

目标G是待满足的性质，可能是终态、过程、安全不变量、限时/最终发生或可度量的软目标。先说明成功对谁、什么对象、量词、时域和环境成立。目标含糊时保留解释G1/G2，优先询问或研究会改变必要义务的差异；未定义量表/阈值的软目标不可伪造布尔判定。硬规范H可独立于目标成立；领域事实/假设D须区分已获证据与暂定。候选条件R是一个可判断的命题（或轨迹/策略性质），它可能已由环境满足、需系统实现、需其他角色承担，或根本不成立；条件成立、条件必要、已满足与已决定采取措施是不同主张。

### 2. 三种逆向查询及其证据

| 查询对象 | 判断方法与可交付结果 | 不允许的外推 |
|---|---|---|
| 目标蕴含的必要性（未选方案） | 令U为已限定的合法解释/轨迹集合，S={x∈U: G(x)∧H(x)}。S非空且每个x∈S都满足R，才能称R在该域对合法成功必要；等价于不存在S中满足¬R的反例 | 逻辑合法成功集合非空不证明有可执行策略；H不可当成已遵守事实 |
| 固定动作/方案的前置（已知转移） | 已给定且语义充分的动作a及目标Q，计算或论证wp(a,Q)：能保证a正常终止且所有可能结果满足Q的最弱状态条件。若只要求终止时正确则另用部分正确语义 | 某个动作的最弱前置不是所有替代动作都必须具备的条件 |
| 所有成功轨迹共同经历的条件（顺序/过程） | 给定初态、合法转移及可达目标；在每条成功轨迹上存在某时刻R成立，记∀成功轨迹τ∃t:R(τ,t)。若有可靠依据也可判定必要先后 | ∃t不等于全程成立、初始必须成立或结束仍成立；顺序启发式不等于逻辑必然 |

必要性与充分性必须分开：在相同D/H及解释域下，G⇒R是必要，R⇒G是充分（必须同时检查R在该域可满足及与硬约束兼容，不能用空前提得出有用方案）。可以两者皆有、仅必要、仅充分或都不是。多个R的联合可充分但各个不必要；单个必要也不保证组合充分。逻辑证成仍可能缺乏物理、资源、权限或策略可实现性。对有对抗/不确定环境的保证，应在可观测性、控制、合法环境与行为非空约束下检查是否存在同一个合法策略π，使其对每个允许环境及所有需保证行为满足目标；不能交换∀环境∃选择和∃策略∀环境，也不能把不利环境偷偷排除。概率目标另按明示概率/风险语义论证。

### 3. 可公开复核的判断方法：如何发现而非只会验证

| 关键问题（何时触发） | 可执行的研究操作及依据 | 产出及分支 |
|---|---|---|
| 目标到底要求什么？ | 写出受益者、成功状态/轨迹、适用环境、非目标、硬约束；优先区别不同解释是否改变条件；不能观察的目标先定义可证成性质而非假代理量 | 明确G、D、H与范围；重大歧义未解则只给条件化结论 |
| 哪些情况足以使目标失败？ | 研究¬G，把它分解成若干可发生障碍O，核查D/H允许O且O足以推出失败；从因素与专业知识查信息、资源、时序、权限、环境、边界、交互障碍，不按目录全遍历 | 合法失败情形及有界必要补集¬O；仅提高失败概率者标风险，不能宣称必然 |
| 是否有别的成功方式？ | 从成功目标向前找可能转移/原因，建立替代路径的OR与路径内部联合条件AND；区分可控分支与外部随机/非确定分支；查共同地标和状态不变量 | 候选必要条件、替代集合和方案条件；未证明备选覆盖全域时保持候选 |
| 去掉候选条件仍可成功吗？ | 搜索合法成功且¬R的反例；真实可实现的反例否决实现层普遍必要性，单纯抽象模型反例只在该模型否决逻辑必要性。若条件是推断中间结果，检查模型覆盖和证明假设 | 有反例→非普遍必要（可仍是偏好/某方案前提）；有非空成功见证+完整否定证明→有界必要；找不到但无证明→待证 |
| 条件能否转成可实现的义务？ | 明确谁能监测/控制、前后条件、时序、资源、权限、共同环境、冲突。查联合策略，避免独立满足却联合不可能；环境假设不等于系统保证 | 已满足条件/环境假设、系统/其他主体义务、备选措施、冲突或不可实现；未经授权不自行放宽目标 |
| 是否足以达成目标？ | 对已选义务集合正向推演，寻找所有条件为真却G失败的合法反例；对未证的覆盖/模型保真性保留缺口；删减非独立义务，区分极小与最优 | 充分性论证、缺失条件、验收性质和依据；由C转为可判别义务，由H审证 |

这里的操作是按未知触发的可复核判断，不是固定六步、不可改变的执行顺序。负向和正向必须形成可检验闭环；若专业规律未知，去07查具体领域知识，不用角色扮演替代证据。

### 4. 新增专业理论及适用条件（定向原始资料核验）

- **KAOS目标障碍（GORE）**：van Lamsweerde & Letier, Handling Obstacles in Goal-Oriented Requirements Engineering, IEEE TSE 26(10), 2000, 978–1005，DOI 10.1109/32.879820，[原文](https://www.cs.ucf.edu/~turgut/heng_than.pdf) §3.1–3.3（印刷页983–984，原文及页面图核对）。在领域模型下可发生且必然破坏目标的障碍，其否定是成功的必要条件；只有障碍否定的联合能推出目标，才是相对于已知领域的完整障碍集。AND组合障碍不代表每个子条件单独阻碍。此处是把原理论用于通用发现的综合，不称穷尽真实环境或复制其全套方法。
- **最弱前置条件**：Dijkstra, Guarded Commands, Non-determinacy and Formal Derivation of Programs, CACM 18(8), 1975, 453–457，[作者档案 EWD472](https://www.cs.utexas.edu/~EWD/transcriptions/EWD04xx/EWD472.html)，§3（HTML正文核对，含总正确、可终止和非确定转移）。固定操作、状态和后置性质清晰时可从结果严格反推保证条件；含任意未建模环境、模糊目标或动作未知时不能直接用它宣称通用必要性。
- **规划地标**：Hoffmann, Porteous & Sebastia, Ordered Landmarks in Planning, JAIR 22, 2004, 215–278，DOI 10.1613/jair.1492，[原文](https://fai.cs.uni-saarland.de/hoffmann/papers/jair04.pdf) §3.1（印刷页218，原文及页面图核对）。对给定经典规划问题，所有成功计划中至少出现一次的事实是地标；若任务无解，空集全称使任何事实表面都成立；合理排序启发式与必然先后不同。该论文的具体复杂性结果限于其规划形式，不推出一切需求推理复杂度相同。
- **主体可实现性**：Letier & van Lamsweerde 2002, Agent-based Tactics for Goal-Oriented Requirements Elaboration, ICSE, DOI 10.1109/ICSE.2002.1007958，[机构摘要](https://research.dial.uclouvain.be/entities/publication/bce90b0f-32b2-4546-a319-469a22cad035)（沿用C R1.1并再次核对摘要，未全文复核）。用于提醒责任分配受可观测/可控变量限制；策略量词及抽象例子是本文说明，不声称复现论文全部形式系统。

适用性选择：状态/动作模型精确→最弱前置；可表达失败性质→障碍；目标是过程且有转移模型→共同地标及必要先后；目标模糊或开放环境→领域研究、条件化论证及竞争解释；有外部对抗/不确定性→策略可实现性，必要时专门形式理论。因果必要性需独立因果假设与证据（见R1.1），不能由统计相关或逻辑模型自动推出。没有能够改变结论的专业依据时，标未知而非构造定理。

### 5. 完整抽象推演（非实际软件或测试）

设A、B是两种可替代成功条件，Q是共同质量条件，D允许三个布尔变量独立取值，H为空，G=(A∨B)∧Q。成功见证A=真、B=假、Q=真；替代见证A=假、B=真、Q=真，故A、B均非普遍必要。

- 从失败方向分解：¬G=(¬A∧¬B)∨¬Q。两个障碍O1=¬A∧¬B、O2=¬Q均在D可发生且各自足以使G失败。其否定分别为A∨B、Q，在D对G均必要；两者联合才充分。A∨B不等于要求A和B都成立；¬A单独不足以阻碍G。
- 从成功方向：A∧Q与B∧Q分别充分，但它们是两组替代方案条件。要求A会排除合法替代见证；仅要求Q允许A=B=假，故不足。若Q已经由环境可靠保证，不必为Q额外实现功能，但应确认保证范围及失败处置。
- 若D扩展为还有替代C且G改变为(A∨B∨C)∧Q，原A∨B不再必需（A=B=假，C=Q=真）。说明候选条件依赖目标版本/领域覆盖；需要重审受影响主张而非全库失效。
- 过程变体（独立的小模型）：唯一合法成功路径为 s0→a→k→g 或 s0→b→k→g，节点代表该状态事实。k在每条路径上曾成立但在g不再成立；a/b不各自必要；若允许s0→g，k即不再必经。不能用一个快照证明轨迹必要性。
- 固定动作变体：若动作把x变为x+1、保证正常终止，目标终态x≥3，则其最弱前置为初态x≥2；另一可控动作x+2的前置为x≥1。若两动作均合法可由主体选择，至少x≥1即可选出成功动作；若两动作结果均可能且选择不可控，保证两者都成功需x≥2。这个算例只在给定转移语义下成立。

| 易错断言 | 可复核反例或校正 |
|---|---|
| 无合法成功场景时仍可列必要条件 | 若G要求A与¬A同时成立，成功集合为空；任意R的蕴含空真，不应产生有用条件；阻断并回溯G/D/H |
| 局部条件都可满足，整体就可实现 | 两项要求同一不可分资源分别同时供不同主体独占；单独可满足、联合不行。或沿用C不可观测e的量词反例 |
| 找不到反例就是已证明 | 搜索只覆盖部分路径，其他合法路径可能绕过R；不完备搜索只能产生待证候选 |
| 阻碍往往导致失败，所以其否定必需 | 若某风险提高失败概率但仍允许目标成功，则不是严格障碍；另记风险/概率目标 |
| 必要条件必定是系统功能 | 环境已提供Q或规范由其他责任主体承担；必要性质不等于实现任务 |
| 联合充分集合最短或最优 | C的包含意义极小性不推出全局最低代价；硬规范不可随方案删减 |

### 6. 结果记录、选择及停止边界

为每条关键主张记录最少信息：目标和范围/版本；条件及其语义类型（普遍必要、方案条件、充分集合、轨迹地标、独立规范、偏好、假设等可组合标签）；必要性/充分性的独立结论；推导依据与反例；事实满足状态（已知/不满足/未知）和可实现性；责任及尚需证据；因D/G/H变化的失效边界。认识状态与条件类别分轴：候选、反例否定、模型内证明、经领域证据支持、无法判定；“有权批准”另记为决定，不升级事实。记录没有真实证据时不能标成已满足，理论例子中的给定D不是现实事实。

**样本输出示例**：G=(A∨B)∧Q中，A∨B、Q为该布尔域内已证明必要，联合充分；A/B为备选路径；D独立变量为假设；具体主体、资源、实际满足情况、目标外推均未知。转C的义务须按真实责任与证据重新判别。停止于高影响主张有相称依据且可解释边界，或已明确有权裁决/外部知识/不可实现的阻断；未知高影响条件不允许用评分或“没有再想到”关闭。低影响分支只有不能改变决定时才停止并说明原因。形式域内证明不等于开放世界穷尽或实际验收。

**研究组织价值**：先问题与适用范围，再给定义、方法、理论、反例、判断结果和停止；分类服务于选择而非目录扩充。此样本包含可核验的公开推理规则，不是AI私有思维记录；不声称独立专家、实证、运行或其他分支已按此模板改造。
